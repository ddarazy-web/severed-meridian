# Story Continuity

기존 자료를 기준으로 모순과 독자가 납득하기 어려운 단절을 찾는다. 취향 차이와 실제 연속성 오류를 구분하고, 사용자의 의도 없이 원문을 수정하지 않는다.

## 검수 우선순위

1. `canon`과 직접 충돌하는 사실
2. 시간, 나이, 거리, 이동, 소유물, 부상과 상태의 불가능한 변화
3. 원인 없이 생긴 결과 또는 결과 없이 사라진 중요한 원인
4. 인물이 알 수 없는 정보를 아는 문제
5. 욕망, 관계, 성장선과 맞지 않는 행동 변화
6. 설치됐지만 회수되지 않은 복선과 회수 근거가 부족한 반전
7. 명칭, 호칭, 외형, 규칙 표현의 불일치

## 판정 방식

각 발견을 다음처럼 구분한다.

- `확정 오류`: 자료가 직접 모순됨
- `높은 위험`: 설명이 없으면 독자가 모순으로 받아들일 가능성이 큼
- `의도 확인`: 서술 트릭이나 의도적 불확실성일 수 있음
- `개선 제안`: 오류는 아니지만 이해를 돕는 보완

근거가 부족하면 오류로 단정하지 않는다. 발견마다 관련 문서나 장면, 충돌하는 사실, 독자에게 생기는 문제, 최소 수정안, 파급 범위를 제시한다.

## 정사 보호

`canon`을 자동으로 덮어쓰지 않는다. 해결책은 가능하면 원고의 작은 수정, 설명 보강, 장면 순서 변경, 설정 변경 순으로 비용을 비교하되 작품 의도에 맞게 판단한다. 설정 변경이 필요하면 영향을 받는 캐릭터, 플롯, 에피소드와 복선을 함께 표시한다.

협업 모드에서는 수정안을 승인받기 전 파일을 변경하지 않는다. 자동 검수를 요청받아도 명시적으로 수정까지 요청받지 않았다면 보고서만 작성한다.
