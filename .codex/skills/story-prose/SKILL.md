# Story Prose

합의된 설정과 장면 목적을 독자가 경험할 수 있는 소설 문장으로 구현한다. 정보 요약보다 장면 속 행동, 감각, 선택과 반응을 우선하되 작품이 요구하는 서술 밀도를 따른다.

## 입력 확인

가능하면 관점 인물, 장면 목표, 시작과 끝의 변화, 배경, 등장인물, 반드시 드러낼 정보, 피할 요소, 목표 분량을 확인한다. 협업 모드에서 결과를 크게 바꾸는 누락만 한 번에 최대 3개 묻는다. 자동 모드는 필요한 가정을 밝힌다.

## 집필 기준

- 요청된 시점, 시제, 어조와 기존 원고의 문체를 유지한다.
- 인물마다 목표, 지식, 관계와 말투에 맞는 행동과 대사를 쓴다.
- 묘사는 관점 인물이 현재 주목할 감각과 의미를 통해 선택한다.
- 설명은 독자가 이해해야 하는 시점과 장면의 압력 안에 배치한다.
- 문장 길이와 문단 호흡은 긴장, 성찰, 행동의 속도에 맞춘다.
- 장면 끝에는 반드시 절벽 결말이 아니라 의미 있는 변화나 잔향을 남긴다.

특정 작가의 고유 문체를 그대로 복제하지 않는다. 사용자가 작가명을 참고로 제시하면 고수준 특성으로 변환해 독자적인 표현을 만든다.

## 수정 작업

문체 수정 시 사건, 설정, 관점 정보, 인물 의도를 임의로 바꾸지 않는다. 구조적 문제가 문장 수정만으로 해결되지 않으면 원인을 구분해 알리고 `story-episode` 또는 `story-plot` 수준의 변경을 제안한다.

## 설정과 저장

`canon`과 충돌하는 새 사실을 무심코 만들지 않는다. 필요한 빈칸은 `draft` 가정으로 표시한다. 협업 모드에서는 원고를 먼저 제시하고 승인 후 저장하며, 자동 모드도 지정된 출력 경로가 없으면 파일을 만들지 않는다. 결과 언어는 사용자 지정이나 기존 원고를 따른다.
