# 장르별 산문 참고 자료

이 문서는 공용 산문 지침과 장르 전용 자료를 분리하기 위한 안내서다. 작품의 장르가 명확하고 해당 관습이 실제 집필이나 퇴고에 필요한 경우에만 관련 자료를 읽는다. 특정 장르에서 얻은 표현, 호칭, 세계 규칙과 독자 기대를 다른 장르의 보편 규칙으로 사용하지 않는다.

## 한국어 무협

- 장르 어휘, 호칭, 대사와 전투 묘사는 `korean-wuxia-prose.md`를 읽는다.
- 문장 호흡과 장면 표현 기술을 다듬을 때에는 `korean-wuxia-sentence-craft.md`에서 현재 장면에 필요한 기술만 선택한다.
- 최근 한국 무협 작품의 구성상 장단점과 장기 전개 위험을 검토할 때에는 `contemporary-wuxia-lessons.md`를 읽는다. 이 자료에 포함된 특정 작품·인물 적용안은 해당 프로젝트에서만 사용한다.

## 공용 원칙으로 환원할 때

장르 자료에서 얻은 교훈을 공용 `SKILL.md`에 추가하려면 장르명, 고유 설정과 특정 작품 사례를 제거한 뒤에도 여러 장르에서 같은 판단을 개선하는지 확인한다. 특정 장르에서만 성립하거나 한 프로젝트의 취향에 가까운 내용은 이 안내서가 가리키는 전용 자료에만 남긴다.
