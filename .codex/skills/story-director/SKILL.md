# Story Director

사용자의 컨셉을 소설 제작 과정으로 전환하고 다음 전문 작업을 선택한다. 작품 고유 설정을 스킬 자체의 규칙으로 만들지 않는다.

## 모드

- 기본은 `협업 모드`다. 결과를 크게 바꾸는 질문만 한 번에 최대 3개 묻고, 모르는 항목에는 2~3개 선택지와 추천안을 제시한다.
- 사용자가 자동 생성을 명시하면 `자동 모드`로 진행한다. 질문 대신 합리적인 가정을 사용하고 결정 목록을 결과에 표시한다.
- 사용자가 깊은 인터뷰나 Grill Me를 요청하면 한 번에 한 질문씩 모호함이 해소될 때까지 진행한다.

## 초보자 안내 흐름

컨셉이 있으면 다음 순서로 빠진 핵심을 찾는다. 모든 설정이 완성될 때까지 집필을 미루지 않는다.

1. 독자에게 약속하는 핵심 재미
2. 주인공의 욕망과 이를 막는 장애물
3. 실패할 때 잃는 것과 핵심 갈등
4. 갈등을 성립시키는 최소 세계 규칙
5. 주요 인물 관계
6. 시작, 중간 전환, 예상 결말
7. 대표 장면 또는 첫 장의 시험 집필
8. 시험 결과를 반영한 보완과 연속성 검수

## 전문 영역 연결

- 컨셉과 작품 약속: `story-concept`
- 세계, 시대, 세력, 문화, 장소: `story-world`
- 인물, 관계, 성장선, 말투: `story-character`
- 전체 사건 구조, 전환점, 결말, 복선: `story-plot`
- 장, 회차, 장면의 구조: `story-episode`
- 실제 소설 문장과 문체: `story-prose`
- 설정, 시간선, 인과, 복선의 충돌 검사: `story-continuity`

전문 작업을 대신 수행하지 말고, 현재 단계에 필요한 입력과 완료 조건을 정리한 뒤 적합한 영역으로 진행한다. 여러 영역이 얽히면 가장 상위의 미결정 사항부터 해결한다.

## 설정 상태와 저장

주요 설정은 `draft`, `canon`, `deprecated`, `unknown`으로 구분한다. `canon`은 명시적 승인 없이 변경하지 않는다. 협업 모드에서는 먼저 대화로 제안하고 승인 후 파일을 쓴다. 자동 모드에서도 출력 폴더가 지정되지 않았다면 파일을 임의 생성하지 않는다.

작품 폴더가 지정되면 사람이 읽기 쉬운 Markdown과 최소 YAML 메타데이터를 사용한다. 권장 분류는 `concept`, `world`, `characters`, `plot`, `episodes`, `continuity`, `manuscript`이며 기존 구조가 있으면 그것을 우선한다.

결과 언어는 사용자의 지정, 기존 원고, 대화 언어 순으로 결정한다.
