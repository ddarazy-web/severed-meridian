# 전투 카드 콘셉트 참고 자료

이 폴더의 이미지는 전투 카드 아트 방향을 정의하기 위한 **참고용 콘셉트**다.
Unity 런타임 에셋이 아니며 빌드에 포함하지 않는다.

## 선택된 기준 샘플

- `combat-card-attack-sword-ink-reference.png`: 공격 카드 기준. 큰 검 궤적과 거친 먹의 비백을 사용한다.
- `combat-card-defense-ink-reference.png`: 방어 카드 기준. 방어 자세와 몸 앞의 굵은 차단 획을 사용한다.
- `combat-card-internal-energy-ink-reference.png`: 내공·심법 카드 기준. 좌선 자세와 인물 주변의 큰 원형 먹획을 사용한다.

## 사용 원칙

- 명나라 중기의 무공 비급 삽화를 연상시키는 구도와 복식을 사용한다.
- 별도의 채색 없이 검정과 먹의 농담만 사용한다.
- 가는 균일선보다 굵기 변화, 먹 뭉침, 마른 붓의 갈라짐과 큰 획을 우선한다.
- 카드마다 인물 한 명과 핵심 동작 하나를 중심으로 단순하게 구성한다.
- 공격과 방어는 각각의 기준 샘플을 우선하며, 다른 카드 유형은 내공 샘플을 포함한 기준 샘플들의 붓질과 구도를 변형해 사용한다.
- 실제 게임에 사용할 결과물은 별도로 정리해 `Assets/Art/Production/` 아래에 내보낸다.
- 이 폴더의 이미지나 경로를 씬, 프리팹, ScriptableObject, Resources, StreamingAssets 또는 Addressables에서 직접 참조하지 않는다.
