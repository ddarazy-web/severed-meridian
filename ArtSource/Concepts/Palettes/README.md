# 팔레트 콘셉트

이 폴더는 프로젝트 마스터 팔레트의 검토 자료를 보관한다. Unity `Assets` 밖에 있으며 빌드에 포함하지 않는다.

## 제안 01

- 파일: `master-palette-32-proposal-01.svg`
- 미리보기: `master-palette-32-proposal-01.png`
- 가져오기용 팔레트: `servered-meridian-master-32.gpl`
- 상태: 기준안 확정
- 구성: 한지 4색, 먹 5색, 피부 4색, 목재·황토 5색, 초목 5색, 금속 4색, 강조색 5색
- 목적: 캐릭터, 환경, 재료, 무기와 UI가 공유할 수 있는 저채도 동양 채색화 색상 체계 검증
- 검토 항목:
  - 한지 위 먹색의 가독성
  - 피부와 목재의 분리
  - 초목과 옥색 상태 효과의 분리
  - 철제 무기의 명암 폭
  - 주홍, 황토금, 청회와 옥색 강조의 과포화 여부
  - 5단계 품질 표식에 사용할 색의 구분성
- SVG 안의 적용 예시는 색면 조합을 보기 위한 도식이며 프로덕션 에셋이 아니다.
- SVG는 색과 역할의 시각 기준, GPL은 정확한 32색 가져오기 원본, PNG는 빠른 미리보기로 사용한다.
- 에셋마다 임의의 강조색을 추가하지 않는다. 새 강조색은 지역·세력 또는 게임플레이 의미 체계에서 반복 사용할 필요가 검증된 경우에만 추가한다.
