# 아이콘 콘셉트 참고 자료

이 폴더의 이미지는 그래픽 방향을 검토하기 위한 참고 자료다. Unity `Assets` 밖에 있으며 빌드에 포함하지 않는다.

## 상태·부상·의도 픽토그램 01

- 파일: `status-injury-intent-pictogram-concept-01.png`
- 상태: 방향 승인, 프로덕션 사용 불가
- 목적: 32×32 상태·부상·적 의도 아이콘을 먹도장형 픽토그램으로 표현하는 방식 검토
- 배열:
  - 위: 출혈, 골절, 내상, 중독
  - 아래: 공격 의도, 방어 의도, 내공 강화, 기절
- 유지할 요소:
  - 먹색 중심의 크고 즉시 읽히는 실루엣
  - 한 상태당 하나의 핵심 상징
  - 필요한 경우에만 제한된 저채도 보조색
- 수정할 요소:
  - 실제 32×32 논리 그리드에서 다시 그린다.
  - 내상과 중독 등 세부가 많은 표식을 더 단순화한다.
  - 1~2px 굵기의 형태와 여백을 실제 크기에서 검증한다.
  - 종이 슬롯, 배경과 테두리는 아이콘에 포함하지 않고 UI 레이어로 분리한다.
  - 생성 이미지의 형태를 그대로 축소해 사용하지 않는다.
