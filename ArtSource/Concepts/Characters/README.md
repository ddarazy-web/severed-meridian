# 캐릭터 콘셉트 참고 자료

## 주인공 약초꾼 단계 기준

- 파일: `chr_protagonist_herbalist_concept_01.png`
- 상태: `CONCEPT / APPROVED BASELINE`
- 용도: 남성형 유청운과 여성형 유설란의 1~20레벨 불입류·약초꾼 단계 정면 기준
- 비례와 화풍: 약 2.5등신 SD 픽셀 아트, 동양 채색화 팔레트와 선택적 먹선
- 복식: 명 중기 가난한 약초꾼의 청회색 작업복, 해진 덧댐, 등짐 약초 바구니와 실용적인 신발

### 공통 고유 표식

- 화면 오른쪽으로 짧게 묶인 빛바랜 청회색 머리끈
- 화면 왼쪽 허리의 직사각형 약초 장부집과 작게 드러난 종이 귀퉁이
- 화면 오른쪽 허리의 짧고 비대칭인 부러진 약초칼과 절제된 주홍 수선 끈
- 남성형과 여성형은 세 표식의 위치, 색과 의미를 공유한다.
- 약초 바구니를 사용하지 않는 상위 성장 단계에서도 세 표식은 형태 또는 휴대 위치를 조정해 계승한다.

### 머리색 성장 규칙

- 약초꾼 단계는 먹갈색 바탕에 불규칙한 회백색이 섞인 조기 백발을 사용한다.
- 무공 경지가 높아질수록 회백색 영역이 점차 넓어지고, 고수 단계에서는 머리 전체가 은백색 중심으로 전환된다.
- 은백색은 힘과 주인공성을 강화하되 순백색, 금속성 광택, 청색 발광과 상시 기운 효과를 사용하지 않는다.
- 상위 단계에서도 짙은 먹색 뿌리, 외곽선과 안쪽 그림자를 남겨 현실 기반 고무협의 무게를 유지한다.
- 단계별 정확한 회백색 비율과 전환 시점은 각 성장 단계 정면 시안을 만들 때 확정한다.

### 병약함 표현

- 상시 발광이나 과도한 창백함 대신 낮은 어깨, 얕은 호흡과 간헐적인 숨 고르기 대기 동작으로 표현한다.
- 성장할수록 자세와 호흡은 안정되지만 조기 백발은 사라지지 않고 은백색 정체성으로 발전한다.

- 기준 자료이므로 Unity `Assets`에는 직접 반입하지 않는다. 실제 애니메이션 제작 시 네 방향과 전체 프레임에서 캐릭터 크기, 발 기준선과 소품 위치를 고정한다.

## 주인공 2단계 후보 — 초입 무인

- 파일: `chr_protagonist_stage_02_concept_01.png`
- 상태: `CONCEPT / APPROVED BASELINE`
- 적용 구간: 21~39레벨, 삼류·이류
- 역할 인상: 이름 없는 초입 무인이지만 약초꾼 생활과 실용성을 아직 유지하는 떠돌이
- 1단계에서 유지:
  - 남녀 얼굴과 약 2.5등신 SD 비례
  - 부분 회백발과 화면 오른쪽의 청회색 머리끈
  - 화면 왼쪽의 직사각형 약초 장부집
  - 화면 오른쪽의 주홍 수선 끈이 감긴 부러진 약초칼
- 2단계 변화:
  - 어깨와 목을 세우고 두 발의 중심을 안정시킨다.
  - 청회색 맞깃 작업복을 조금 더 몸에 맞게 정돈하고 어깨에 짙은 덧옷 구조를 추가한다.
  - 손목 보호대, 구조화된 천 허리띠, 튼튼한 천 신발과 발목 끈을 사용한다.
  - 바구니는 부피를 줄인 이동용 약초 채집 바구니로 바꾸고 보이는 약초량을 줄인다.
  - 바지는 한 곳의 수선 자국만 남겨 생활 형편과 장비 관리가 나아졌음을 보여준다.
  - 회백색 비율은 1단계보다 조금 늘리되 아직 먹갈색 뿌리와 안쪽 면이 우세하다.
- 검과 도는 플레이어 장착에 따라 달라지므로 기준 몸체에 고정하지 않고 별도의 장비 오버레이로 둔다.
- 문파 표식, 갑주, 긴 소매, 망토와 상시 기운 효과는 사용하지 않는다.

## 프로덕션 전환 시

- 기존 픽셀 방식은 생성 이미지를 축소해 바로 사용하지 않고 64×96px 논리 몸체를 128×128px 셀에 다시 그린다.
- 1단계 남성 탐색 캐릭터는 승인된 256×256 비도트 기준에 따라 부드러운 축소 필터와 실제 알파를 사용하는 프로덕션 규격으로 제작한다.
- 픽셀 방식의 마스터 32색·불투명 픽셀 제한은 기존 픽셀 에셋과 별도로 픽셀 방식이 유지되는 분류에만 적용한다.
- 정면 확정 뒤 좌·우·후면의 복식 겹침과 바구니 실루엣을 별도로 설계한다.
- 남녀 모두 같은 애니메이션 태그, 프레임 수와 재생 속도를 사용한다.
