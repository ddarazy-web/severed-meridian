# UI 콘셉트 참고 자료

이 폴더의 이미지는 UI 재질, 색, 테두리와 정보 위계를 탐색하기 위한 참고용 콘셉트다.
Unity 런타임 에셋이 아니며 빌드에 포함하지 않는다.

## 현재 샘플

- `ui-landscape-paper-ink-material-concept-01.png`
  - 미색 종이, 먹선, 절제된 목재 프레임과 제한된 주홍 강조의 조합을 확인하는 샘플이다.
  - 가로형 화면에서 종이 면적을 넓게 두고 목재 프레임을 얇게 사용하는 방향을 보여준다.
  - 무공 카드 삽화가 UI 안에서 어떻게 보일 수 있는지 확인하기 위한 예시다.

## 해석 주의

- 이 이미지는 여러 UI 콘셉트 중 하나이며 최종 전투 화면 설계가 아니다.
- 화면에 등장하는 두 인물, 인물의 위치와 크기, 카드 수, 상태 표시, 적 의도 및 각 패널의 배치는 확정 사항이 아니다.
- 실제 전투에서 인물이 화면에 등장한다는 요구사항을 의미하지 않는다.
- 이미지 안의 문자처럼 보이는 무늬, 수치와 아이콘은 생성 과정의 임시 표현이며 실제 UI 문구나 도상 기준으로 사용하지 않는다.
- 실제 화면 구조는 해당 기획서와 UI 설계가 확정된 뒤 별도로 결정한다.

## 보관 규칙

- 실제 제작 에셋은 정리와 검증을 거쳐 `Assets/Art/Production/UI/` 아래에 별도로 내보낸다.
- 이 폴더의 이미지나 경로를 씬, 프리팹, ScriptableObject, Resources, StreamingAssets 또는 Addressables에서 직접 참조하지 않는다.
