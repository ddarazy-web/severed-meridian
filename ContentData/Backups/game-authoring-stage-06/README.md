# 6단계 제작 원본 전환 복구 자료

`before-adoption.json`은 최초 JSON 원본 채택 직전의 팩, Addressables 설정/그룹/메타, 제작 원본 선택 파일을 보관한다. `bytes`는 Base64이며 `null`은 해당 파일이 없었다는 뜻이다. 재실행으로 이 복구본을 갱신하지 않는다.

현재 기본 원본은 `ProjectSettings/AuthoringSource.json`이 가리키는 `ContentData/Candidates/main`이다. 기존 SO 원본은 원래 경로에 보관하며 자동 동기화하지 않는다. JSON을 편집한 뒤 구형 SO를 다시 내보내어 덮어쓰지 않는다.

## 복구 원칙

1. Unity를 닫고 현재 JSON·팩·설정과 미저장 작업을 별도로 보관한다.
2. 팩 교체 중단으로 `Library/AuthoringPacks/publication.json`이 남았다면 다음 변환 시 자동 복구가 먼저 실행된다. 이 기록을 임의로 지우지 않는다.
3. 최초 전환 이전 상태로 되돌려야 한다면 `before-adoption.json`에 나열된 경로만 복원한다. `bytes`가 있는 파일은 디코딩한 원본으로, `null` 파일은 전환 과정에서 생성된 파일인지 확인한 뒤 제거한다. 메타도 함께 복원한다. 다른 파일이나 JSON 작업 폴더는 삭제하지 않는다.
4. 현재 코드의 기본 변환/게임 로더는 JSON 선택과 콘텐츠 세대 파일을 요구한다. 따라서 최초 전환 전의 산출물만 복원한 상태를 정상 실행 상태로 보지 않는다. 현재 코드를 유지한다면 검증된 JSON 원본을 재채택하고 같은 세대 팩을 다시 생성해야 한다. 코드까지 과거 방식으로 되돌리는 작업은 별도 범위다.
5. Unity에서 재임포트 후 원본 선택·주소·팩 세대를 다시 검사한다. 자동 복구는 배포된 외부 번들을 변경하지 않는다.

이 파일은 복구 방법 안내이며 자동 삭제/복원 스크립트가 아니다. 6단계의 구조·데이터·제품 구성 검증을 완료했다. 실제 배포 빌드·실기 확인은 별도 승인 후 수행한다.
