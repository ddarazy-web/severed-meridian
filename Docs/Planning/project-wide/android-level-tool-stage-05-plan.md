# Android 레벨툴 5단계 — 고급 편집·게임 시험·통합 검수

2026-10-11 · 구현·자동 검증 범위 완료. 실기기 검사는 제외한다.

[통합 계획](2026-10-11-android-level-tool-plan.md) · [목표](../../Goals/project-wide/android-level-tool-stage-05-goal.md) · [실행문](../../Commands/project-wide/android-level-tool-stage-05-command.md)

## 목적과 범위

같은 LevelTool 씬과 공통 JSON 편집 로직을 유지하면서, 손가락만으로 고급 레벨 제작과 게임 시험까지 이어지는 흐름을 마무리한다. 1~4단계에 이미 구현·검증한 기능을 다시 만들지 않는다. 기존 검증 기록과 실제 코드를 먼저 대조하고 부족한 부분만 수정한다.

작업은 아래 네 단위로 진행한다. 작은 수정마다 별도 단계를 만들지 않는다. 실기기 검사는 사용자가 요청할 때 수행하며, 이번 실행의 기본 범위는 Editor·Portable 검사와 가능한 Android 스크립트 컴파일이다.

## 작업 1. 고급 편집의 모바일 조작 마무리

- 흐름·중력·공급·벽·포털·발전기 연결·모양·튜토리얼 대상 지정의 기존 화면과 공통 명령을 조사한다.
- 작은 연결점 선택, 겹치는 대상, 경로의 시작/완료/취소, 좁은 화면의 확인 버튼을 검증한다. 기존 확대·이동·작업 메뉴를 재사용한다.
- 핀치·롱터치·패널 전환·중단이 중간 경로를 확정하거나 배경 셀을 수정하지 않도록 한다. 완료된 편집은 공통 세션의 Undo/Redo 계약을 따른다.
- 튜토리얼의 조작 칸·조건 대상 선택과 신규 블록 공급 설정을 터치로 조립할 수 있는지 검사한다. 장애물별 튜토리얼 로직을 새로 만들지 않는다.

주요 위치: `LevelToolScreen.Flow*`, `Connection*`, `Tutorial*`, `BoardTouch`, `Mobile*`, `LevelAuthoring/Editing` 및 기존 외부 테스트.

검증: 휴대폰 세로/가로·좁은 태블릿·넓은 태블릿에서 대표 경로와 튜토리얼을 실제 UI 이벤트로 편집하고, JSON·선택·Undo/Redo를 대조한다. 테스트가 이미 보장하는 부분은 중복 구현하지 않는다.

## 작업 2. 게임 시험과 결과·복귀

- 현재 편집 레벨의 게임 시험, 튜토리얼 재생, 봇/여러 레벨 시험, 기록·결과 화면을 모바일 크기로 검사한다.
- 필수 시작/취소/복귀 버튼과 결과 스크롤을 키보드 없이 사용할 수 있게 한다. 실제 부족한 배치·접근 문제만 수정한다.
- 게임 시험 중 뒤로가기·중단·팝업 처리에서 게임용 팝업 관리와 레벨툴의 종료 계약을 혼동하지 않는다.
- 시험 후 같은 프로젝트·레벨·선택·편집 이력으로 돌아오고, 시험 결과가 제작 원본을 임의 변경하지 않도록 한다.

검증: 수동 게임 시험→복귀, 튜토리얼 시험→복귀, 봇 취소·완료→결과 확인, 좁은 화면·회전·중단 중 상태 보존. 기존 공통 게임 로직을 그대로 사용한다.

## 작업 3. 제작→저장→시험→전송 통합 검사

- 일반/파워 블록·2×2 장애물·바닥·덮개·내부 연결·튜토리얼을 포함한 대표 프로젝트를 사용한다.
- 터치 편집→Undo/Redo→JSON 저장→게임 시험→복귀→ZIP 내보내기→새 내부 프로젝트 가져오기→재열기를 검사한다.
- 같은 입력·seed의 JSON 직접 시험과 MemoryPack 변환 시험에서 초기 보드와 결과 의미를 비교한다. 제작 저장소는 JSON, 게임용 변환은 기존 MemoryPack 경계를 유지한다.
- 잘못된 제작 데이터는 저장/시험/전송 단계에서 설명하고 현재 편집본을 유지한다. 임시 SO나 테스트 코드를 제품 데이터로 포함하지 않는다.

검증: 공통 데이터 비교와 실제 UI 연결을 함께 검사한다. 모의 스트림 왕복은 실제 PC↔Android 파일 전송 검증으로 보고하지 않는다.

## 작업 4. 회귀·정리와 남은 플랫폼 검증 기록

- 변경과 직접 연결되는 Windows 마우스/단축키·저장·16:10, 모바일 패널/IME·Safe Area·터치/Back·복구 회귀를 순차 검사한다.
- 가능한 Android 스크립트 컴파일을 수행한다. Unity 검사·제품 선택·에셋 변경은 동시에 실행하지 않는다.
- 임시 테스트 연결·제품 프로필·콘텐츠 선택을 원상태로 돌리고, HTML 매뉴얼은 갱신하지 않는다.
- `Docs/Verification/project-wide/android-level-tool-stage-05-progress.md`에 자동 검사 근거, 수정 범위, 남은 실제 플랫폼 확인을 기록한다.
- 실기기·APK/Player/Addressables 빌드·실제 SAF·외부 키보드/IME·OS 프로세스 종료·게임/툴 동시 설치 검증은 별도 승인 후 수행할 목록으로 남긴다. 모의 검사로 대신 완료 처리하지 않는다.

## 진행 규칙

커밋·푸시·빌드·HTML 매뉴얼 갱신·SDK/플러그인 설치는 하지 않는다. 필요한 질문은 제한시간 없는 일반 채팅으로 한다. 하위 에이전트를 사용해도 Unity 실행과 공유 파일 변경은 직렬화한다. 완료 보고와 실제 변경에 맞는 짧은 복사용 커밋 메시지를 제공하되 커밋은 실행하지 않는다.

## 완료 결과

네 작업 단위의 구현·자동 검증을 완료했다. 변경·RED/GREEN·최종 회귀 근거는 [완료 기록](../../Verification/project-wide/android-level-tool-stage-05-progress.md)에 모았다. 실제 Android/네이티브 검증은 별도 확인 항목이며 커밋·푸시·Player 빌드·HTML 갱신은 수행하지 않았다.
