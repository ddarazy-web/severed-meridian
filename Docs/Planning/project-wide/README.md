# 전체 기획

## 한 줄 콘셉트

선천적인 구음절맥으로 인해 성장할수록 죽음에 가까워지는 주인공이 무공 수련, 영약, 채집과 제작을 통해 운명을 극복하고 환골탈태에 도전하는 무협 RPG.

## 핵심 목표

- **확정**: 주인공은 1레벨부터 시작한다.
- **확정**: 모든 레벨에서 네 생존 능력치 중 하나라도 0이 되는 즉시 사망한다.
- **확정**: 20레벨 이전에는 생존에 필요한 기반을 갖추는 것이 핵심 목표다.
- **확정**: 20레벨 이후에는 경험치를 채우고 해당 레벨에 맞는 적을 쓰러뜨려야 승급한다.
- **확정**: 현재의 최종 목표는 환골탈태다.
- **미정**: 환골탈태 이후에도 게임을 이어갈지, 엔딩으로 끝낼지 결정하지 않았다.

## 기획 진행 순서

1. 세계관과 주인공의 시작 상황
2. 구음절맥 및 1~20레벨 생존 규칙
3. 성장과 수련 구조
4. 전투 및 승급 구조
5. 채집, 채광, 제련, 제조 구조
6. 적의 등급과 콘텐츠 배치
7. 환골탈태 조건과 엔딩

- **확정**: 선물만으로 명장급 NPC의 최고 관계 단계에 도달할 수 없다.
- **확정**: 명장급 제작 및 최고 등급 카드 승급 의뢰에는 반드시 희귀 재료가 필요하다.
- **확정**: 시작 시 기초 약초 채집과 기초 약재 가공을 보유한다.
- **확정**: 5레벨 돌파 후 상위 약초 채집과 제약, 탕약·고약·환약 제조가 열린다.
- **확정**: 10레벨 돌파 후 채광, 제련, 도구 제작과 무기 제작이 열린다.
- **확정**: 15레벨 돌파 후 연단, 단약 제조, 상위 가공·제련과 카드 승급용 특수 재료 제작이 열린다.
- **확정**: 20레벨 이후 각 생활 기술의 상위 교본, 명장, 희귀 재료와 최고 등급 제작이 열린다.
- **확정**: 생활 기술은 레벨 돌파만으로 자동 지급되지 않는다.
- **확정**: 새 구역에서 5~10분 정도의 짧은 튜토리얼 퀘스트를 완료하면 관련 기술 1레벨과 기본 제작법을 얻는다.
- **확정**: 튜토리얼 퀘스트는 재료 확보, 도구 복구와 첫 제작을 통해 해당 기술의 기본 조작을 가르친다.
- **확정**: 생활 기술 숙련도는 작업 성공, 최초 재료·제작법 발견과 높은 등급 결과물 획득으로 상승한다.
- **확정**: 현재 숙련도보다 낮은 단계의 작업을 반복하면 숙련 경험치가 점차 감소하고 결국 0이 된다.
- **확정**: 채집과 채광에서 낮은 확률로 상위 등급 재료를 획득할 수 있으며 결과물 등급에 맞는 추가 숙련 경험치를 얻는다.
- **확정**: `어려운 작업 성공`과 `상위 등급 결과물 획득`은 결과 등급 기반 추가 경험치라는 하나의 규칙으로 통합한다.
- **확정**: 희귀 재료 획득 확률은 기술 숙련도, 도구 품질과 지역 등급으로 높일 수 있다.
- **확정**: 낮은 단계 지역에는 획득 가능한 재료 품질의 상한이 존재한다.
- **확정**: 채집·채광 재료와 가공·제련·제약·도구·무기 제작 결과물은 각각 품질 등급을 가진다.
- **확정**: 재료와 제작 결과물의 공통 품질은 범품, 양품, 상품, 명품, 절품의 5단계다.
- **확정**: 약초는 다양한 종류로 구성하며 종류마다 채집 난도, 출현 지역, 기본 가치와 용도가 다르다.
- **확정**: 약초 종류의 기본 단계와 같은 약초 안에서의 품질 등급은 서로 다른 수치로 관리한다.
- **확정**: 주요 원재료 분야마다 우선 10종의 서로 다른 재료 종류를 구성한다.
- **확정**: 약초 10종, 광석 10종처럼 분야별 종류 수를 각각 계산한다.
- **확정**: 각 재료 종류는 고유한 획득 난도, 요구 숙련도, 지역, 용도와 범품~절품 품질을 가진다.
- **확정**: 초기 원재료 분야는 약초, 광석, 목재 세 계열로 제한한다.
- **확정**: 약초 10종, 광석 10종, 목재 10종을 초기 기본 목록으로 구성한다.
- **확정**: 가죽, 독물, 보석과 특수 생물 소재는 20레벨 이후의 확장 분야로 보류한다.
- **확정**: 재료 종류와 품질이 모두 같을 때만 하나의 인벤토리 스택으로 합친다.
- **확정**: 같은 종류라도 범품·양품·상품·명품·절품은 서로 다른 스택으로 보관한다.
- **확정**: MMO가 아닌 싱글플레이 RPG로 기획한다.
- **확정**: 로그인, 계정 연동, 저장 데이터 관리를 위한 플레이어 계정 정보는 필요하다.
- **확정**: 고정된 서사 주인공을 사용하므로 플레이어가 별도의 아바타 이름이나 캐릭터 계정 정보를 만들 필요는 없다.

## 오프닝 개요

- **확정**: 주인공은 어린 시절부터 원인을 모르는 병을 앓으며 홀로 살아왔다.
- **확정**: 16세가 된 어느 날, 평소처럼 약초를 팔러 간 약방에서 쓰러진다.
- **확정**: 약방 주인이 의원을 부르고, 주인공은 생애 처음 진맥을 받는다.
- **확정**: 의원의 진단을 통해 자신이 구음절맥이라는 사실과 죽음의 고비를 처음 알게 된다.
- **확정**: 마을에는 상주 의원이 없으며, 사건 당일 우연히 외지 의원이 머물고 있어 진맥을 받을 수 있었다.
