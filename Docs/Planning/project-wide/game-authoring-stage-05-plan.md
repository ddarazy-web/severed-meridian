## 전제와 범위

- 4단계의 LevelTool 씬, AuthoringToolWorkspace/AuthoringEditSession, 공통 편집 연산, JSON 저장소, PuzzlePlayRequest/CreateTest를 확장한다. 같은 기능을 별도 실행 로직으로 복제하지 않는다.
- 제작 문서는 JSON 작업 폴더가 원본이며 SO와 자동 동기화하지 않는다. 공통 튜토리얼 flowId와 레벨별 bindings, 문서·배치·단계 ID 및 학습 완료 ID 의미를 보존한다.
- Windows 배포 앱 빌드와 전체 SO 원본 이관, 정식 MemoryPack/Addressables 입력 전환은 6단계다. 50레벨 팩 규칙을 유지한다.
- 이번 단계는 **두 작업 묶음**으로 진행한다. 화면별 잔작업마다 별도 단계를 늘리지 않는다.
- 커밋·푸시·Player/Addressables 빌드·요청 전 HTML 매뉴얼 수정 금지. 필요 시 하위 에이전트를 사용하고 질문은 제한시간 없는 일반 대화로 한다.

## A. 제작 기능 완성

1. 1단계 기능 목록, 3단계 기존 창의 JSON 연결, 4단계 구현을 대조해 기능별 공통 연산·새 화면·검증 사례의 대응표를 작성한다. 필수 기능을 말없이 제외하지 않는다.
   - 4단계 리뷰의 경미한 UX 후속: 팔레트 선택 테두리를 즉시 갱신하고, 거절된 입력 필드를 실제 초안 값으로 복원한다. 현재는 오류 문구가 표시되지만 필드/선택 표시가 다음 갱신까지 남을 수 있다.
2. 튜토리얼 단계/행동/조건 조립, 보드 대상 선택과 강조, 공통 구성의 공유 수정/독립 복사, 레벨별 값, 샘플 등록·적용, 생성 블록 설정과 논리 재생을 연결한다. 조건 종류는 기존 등록 목록을 사용하고 장애물별 튜토리얼 분기를 만들지 않는다.
3. 고정/유지 공급과 소진 정책, 연결·전선·포털·낙하 흐름·병합·벽·도착점, 2×2 관련 설정, 보드 모양 등록·조회·적용과 여러 레벨 작업을 연결한다. 원문 보존에 그치던 고급 필드를 실제 화면에서 조작할 수 있게 한다.
4. 오류를 문서·단계·셀 위치로 안내하고 해당 위치를 선택할 수 있게 한다. 툴팁과 화면 문구를 초보 제작자도 이해할 수 있게 작성한다. HTML 갱신은 하지 않는다.
5. 폴더 전환뿐 아니라 도구 종료·씬 이동·Unity Play Mode 종료 시 미저장 보호를 연결한다. 저장/버리기/취소를 제공하고, 취소 불가능한 종료 경로에는 복구 가능한 초안을 보관한다. 실패/도메인 재로드 후 선택과 이력 복원도 확인한다.

**검증:** 기존 창과 같은 초기 문서·동작으로 결과 비교, 공유 범위와 독립 사본, 안정 ID·참조, 생성 블록을 포함한 여러 행동 튜토리얼, 단일 Undo/Redo, 오류/취소·저장 재열기 및 미저장 종료 복구.

## B. 검사 기능 연결과 기본 경로 전환

1. 구조/참조/실행 가능성 검사, 자동 플레이·반복 시험·시드 비교·결과/난이도 조회를 기존 공통 로직에 연결한다. 필요한 제품용 실행기/기록 저장은 Editor API에서 분리하되 Tests 스크립트를 제품에 포함하지 않는다.
2. 실제 게임 시험과 논리 시험의 차이, 봇 결과의 한계를 화면에서 구분한다. 중단·재시험·여러 레벨 시험 실패가 편집 상태와 정식 기록에 영향을 주지 않도록 한다.
3. 대응표의 필수 항목을 검증하고 같은 문서/시드/행동의 결과를 비교한다. 누락이 있으면 기본 편집 화면을 성급하게 바꾸지 않는다.
4. 기능 동등성·저장 보호·실제 게임 왕복이 확인되면 기존 ‘레벨 편집’ 진입을 레벨툴 씬으로 연결한다. 기존 중복 편집 UI는 비활성화/정리하고 필요한 실행·구형 가져오기 어댑터만 유지한다. 창 제거로 기존 사용자의 자료를 삭제하지 않는다.
5. 결과·남은 제약을 기록하고 6단계 계획·목표·복사용 명령문을 작성한다. 다음 단계 구현은 자동 시작하지 않는다.

**검증:** 기능 대응표 전 항목, 정식 진행/보상/학습 기록 불변, 기존 가져오기와 팩 회귀, 기존 씬 보존, 기본 메뉴의 신규 경로, 런타임 Editor API 및 테스트 어셈블리 비의존 확인.

완료 범위는 Unity Play Mode 검증이다. 실제 빌드가 금지된 상태에서 Windows exe 또는 네 제품 배포 검수를 완료했다고 표현하지 않는다.
