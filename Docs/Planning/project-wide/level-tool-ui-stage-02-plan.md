# 레벨툴 UI 개선 2단계 — 소재 선택과 보드 편집

2026-10-09 · 후속 계획. 1단계 검증 완료 후 별도 실행 요청으로 착수한다.

[통합 가이드](level-tool-ui-overhaul-plan.md) · [목표](../../Goals/project-wide/level-tool-ui-stage-02-goal.md) · [실행문](../../Commands/project-wide/level-tool-ui-stage-02-command.md)

## 목표와 범위

이미지로 소재를 찾고 보드에 배치하며, 반복 배치를 복사·붙여넣기로 처리한다. 기존 LevelTool 씬·편집 세션·배치 검증·Undo를 재사용한다. 저장 형식과 게임 규칙은 바꾸지 않는다.

## A. 소재와 선택

- 현재 팔레트를 이미지·한국어 이름·종류로 구분하고 검색을 제공한다. 검색 결과 없음과 사용할 수 없는 이유를 명확히 표시한다.
- 선택/배치/지우개, 편집 층, 현재 소재를 항상 알아볼 수 있게 한다. 기존 동일 층 교체 규칙과 2×2 전체 개체 규칙을 유지한다.
- 클릭·영역 선택·전체 선택·선택 해제를 같은 선택 모델에 연결한다. 이미지 로딩 중에도 선택·배치를 잃지 않는다.
- V/B/E, Ctrl+A, Ctrl+Shift+A, Delete를 보드 문맥에만 연결한다. 삭제는 기존 참조 보호 정책을 따르고 한 번 Undo로 복구한다.

검증: 일반/파워/장애물/덮개/바닥, 2×2 부분 선택, 검색 전후 선택 유지, 공유 사본·모달·입력 중 차단을 확인한다.

## B. 보드 클립보드

- Ctrl+C/X/V를 현재 층의 선택 요소에 적용한다. 텍스트 입력은 기본 클립보드를 사용한다.
- 버전과 형식 식별자가 있는 JSON을 OS 클립보드에 기록한다. 임의 텍스트·다른 버전·존재하지 않는 소재는 변경 없이 이유를 안내한다.
- 2×2 일부 선택은 전체 개체 한 번으로 정규화한다. 상대 좌표로 복사하고 붙여넣는 개체에는 새 instance ID를 부여한다.
- 붙여넣기 미리보기에서 위치·충돌·경계 오류를 보여준다. 확정 시 전체를 하나의 편집 명령으로 적용한다. 일부만 적용하지 않는다. Esc는 원본과 클립보드를 보존한다.
- 잘라내기는 직렬화·클립보드 쓰기·기존 삭제 검증이 모두 성공한 뒤 삭제한다. 취소 후 복구는 기존 Undo로 제공한다.
- 공급·연결·튜토리얼 등 외부 참조를 자동 복제하거나 재연결하지 않는다. 기존 삭제 정책상 참조를 끊는 작업은 차단하고 설명한다. 참조 의미를 바꿔야 하는 사례가 발견되면 일반 채팅으로 논의한다.
- 같은/다른 레벨, 같은/다른 작업 폴더 모두 대상의 소재 ID와 배치 조건을 검증한다. 다른 층 데이터는 몰래 포함하지 않는다.

검증: 복사→미리보기→취소/확정→Undo/Redo, 새 ID, 경계·충돌·참조·잘못된 클립보드, 실패한 잘라내기의 원본 보존을 검사한다.

## C. 화면 조작과 마감

- Ctrl++/Ctrl+=/숫자패드+, Ctrl+-/숫자패드-, Ctrl+0, Ctrl+휠, Space+드래그를 보드 확대·축소·맞춤·이동에 연결한다.
- 다른 패널의 스크롤과 문자 입력을 유지한다. 앱 비활성화·모달·시험 진입 시 드래그와 누른 키 상태를 정리한다.
- 메뉴·툴팁·검색 가능한 한국어 도움말은 1단계 공통 명령 정의를 확장한다. OS 창 조절과 보드 확대를 구분한다.
- 네 해상도와 편집→저장→재열기→게임 시험 왕복을 확인한다. 실제 Windows 창 조작은 빌드 승인 전까지 미검증으로 남긴다.
- 완료 보고 후 3단계 계획·목표·복사용 실행문을 작성한다. 자동 착수하지 않는다.

## 구현·검증 원칙

수정 전 배치/삭제/참조의 실제 호출부를 확인해 기존 편집 명령을 재사용한다. 보드 클립보드는 순수 데이터 변환과 UI 미리보기 책임만 분리하며 범용 프레임워크를 추가하지 않는다. 외부 Tests 폴더에서 의미 있는 실패/성공 회귀를 작성하고 Unity 검사는 순차 실행한다. 기존 미커밋 변경과 GUID를 보존한다.

커밋·푸시·Player/Addressables 빌드·HTML 수정 금지. 필요하면 하위 에이전트 사용 가능. 질문은 제한시간 없는 일반 채팅으로 한다.
