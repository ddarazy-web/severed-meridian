## 한 단계의 결과

EF-32까지 기존 장애물6종의 배치·피해 원인·색·집계·제거 미션 값을 정의로 연결했다. 그러나 ObstacleDamageRules.Query는 여전히 Generator 종류로 충전 조회와 내구도 조회를 선택한다. 다음은 **정의의 반응 행동 키 → 명시적 등록표 → 기존 조회**를 한 책임으로 연결한다. 키 추가만 하고 실제 사용을 미루거나 여섯 종류별로 같은 등록 작업을 나누지 않는다.

기존6종만 연결한다. 작은 행동 집합은 내구도 피해와 발전기 충전 두 가지이며 콘텐츠별 enum을 늘리지 않는다. 구형 종류→정의 ID 어댑터와 Supports, Safe의 미정의 원인 예외·ColorLock 색 조건은 남긴다. 이 단계는 모든 종류 분기 제거나 완전한 요소 실행기 구현이 아니다.

## 최소 계약과 변경 경계

- ElementDefinition에 불변 반응 행동 키를 추가한다. 기존 메타데이터 전용/부분 생성자는 유지하며 행동이 없는 정의를 내구도 행동으로 추론하지 않는다. 실제 사용 시 누락/미지원 키를 정의 ID 포함 오류로 거절한다. 키 표현은 실제 호출부를 보고 작은 의미 enum 또는 동등한 불변 값 중 단순한 것으로 선택한다.
- LegacyElementDefinitions의 기존 내구도형5종과 발전기1종에 키를 명시한다. 기존 ID·이름·정책 bool·프로필 참조/값·배치·미션 매핑은 유지한다.
- Elements/Runtime의 명시적 ElementBehaviorRegistry에서 키로 조회 경로를 한 번 선택한다. 전체 등록표 순회·리플렉션·문자열 함수 호출·콘텐츠 ID별 등록은 사용하지 않는다. 기존 GeneratorRules.Query와 내구도 조회의 실제 규칙을 재사용한다.
- ObstacleDamageRules.Query의 기존 Supports 및 원인 정책 거부 뒤 행동 선택을 연결한다. 내구도 조회를 분리하더라도 Safe/ColorLock의 예외 순서·전체 응답/메시지·집계와 제거된 본체 처리까지 그대로 유지한다. Evaluate의 자석 전단, Apply/Remove/예약 피해량/미션/생성·충전 적용은 전환하지 않는다.
- 기존 검사의 임시 정의 교체가 새 키를 잃는 호출부는 키 전달만 보완한다. 의도적으로 누락한 기존 프로필은 그대로 누락해야 한다. 생성자/정책/응답/오류 기대값을 낮추지 않는다. 새 메타데이터 필드 자체의 예상 차이는 별도 기록하고 실행 상태 차이로 숨기지 않는다.

생산 후보는 ElementDefinition, LegacyElementDefinitions, 새 행동 키/등록표와 ObstacleDamageRules의 조회 경계다. 공통 프레임워크·패키지·asmdef·등록 수정 공개 API는 추가하지 않는다.

## 작업과 검증

- [x] work·미커밋/원본/GUID/enum·과거 증거·무시된 Addressables 상태/패키지 서명을 보호하고 정확한 정의 생성/복사·Query 호출부와 같은 입력/시드 전환 전 기준을 확보한다.
- [x] 검사부터 작성한다. 두 행동의 명시적 연결·키 누락/미지원 ID 오류·메타데이터 정의 호환·다른 정책/프로필 참조 보존·선행 거부와 조회 무변경을 확인한다. 실제 실패 근거와 이후 GREEN을 기록한다.
- [x] 행동 키·명시적 등록표·실제 Query 선택을 함께 최소 연결한다. 실제 반응 응답/Amount/메시지와 public Swap 효과 실행, 내구도/충전/미션/문맥을 검증한다. 정의 키를 무시하고 종류로 대신 선택하지 않는 사례도 확보한다.
- [x] 기본 등록의 같은 입력/시드 전체 실행 상태/비공개 문맥/규칙·전역 난수/미션/예약·재선정/발전기/공급/검증/팩 전체 바이트를 비교한다. 새 검사와 EF-32 최종25종을 정확한 메서드로 별도 Editor에서 실행하고 종료0/필수FAIL0과 출력 복원을 확인한다.
- [x] 원본·기존 작업·과거 출력 전체 감사와 diff check, 변경/실측/의도적 차이/미검증/남은 문제 보고를 완료한다. 다음 한 단계 계획/목표/전체 복사용 명령문만 작성하고 다음 구현은 시작하지 않는다.

검증은 등록표 호출 횟수/선택 경로와 실제 반응을 함께 본다. 내구도 전체 범위, 본체/칸/hit/턴, 색/null, 네 원인 및 -1/4/99, 발전기 연결/철거, EF-30~32 자석 예외, 누락 기존 프로필 오류 순서를 포함한다. 의미가 맞지 않는 키/프로필 조합은 기본 행동으로 대체하지 않고 오류로 드러내며, 런타임 구성과 오류 시점의 변경이 있으면 숨기지 않고 기록한다. 신규 종류 제작·저장 전환·적용 행동 등록은 이후 별도 단위다.
