# 조합형 튜토리얼 후속 계획 — 사용자 제작 흐름 점검

상태: 완료 · 2026-10-08. 사용자가 선택한 임시 3매칭 샘플에서 점검했고 수정할 문제는 재현되지 않았다.

[목표](../../../Goals/MoonRabbitJunkyard/Tutorial/composer-authoring-review-goal.md) · [실행문](../../../Commands/MoonRabbitJunkyard/Tutorial/composer-authoring-review-command.md)

## 목적

3단계의 공유 구성과 레벨별 설정을 사용자가 실제로 조립해 보고, 제작 과정에서 막히는 부분만 다듬는다. 새 실행 엔진이나 실제 레벨용 튜토리얼을 대신 만들지 않는다.

## 진행

1. 사용자가 선택한 작업 중 레벨 또는 임시 사본에서 샘플 선택 → 보드 대상 연결 → 조건 값 지정 → 검사 → 게임 실행을 확인한다. 공유가 필요하면 공통 구성 연결과 독립 복사의 차이를 확인한다.
2. 질문과 오류를 실제 화면/행동으로 재현한다. 메뉴 이름, 툴팁, 오류 이동, 설정값 입력에서 확인된 불편만 작은 단위로 수정한다. 추가 기획 결정은 일반 메시지로 한 항목씩 묻고 답변을 기다린다.
3. 바꾼 경로의 자동 검사와 사용자 제작 흐름을 다시 확인한다. 문제가 없다면 변경 없이 결과를 보고하고 이 점검을 종료한다.

## 범위와 제약

- 조건 종류·횟수·대상·발생 원인과 기존 초기 배치/공급 기능의 조합을 유지한다.
- 사용자 지시 없이 실제 레벨, 완료 기록, 배포 팩을 덮어쓰지 않는다.
- HTML 매뉴얼은 사용자가 별도로 요청할 때만 업데이트한다.
- 빌드·커밋·푸시를 하지 않는다. 모바일 성능은 실제 기기에서 측정하지 않았다면 보장하지 않는다.
- 모든 다음 단계 문서를 미리 만들지 않는다. 이 점검에서 확인된 필요에 따라 다음 작업을 정한다.
