# 네이티브 레벨툴 UX 2단계 — 보드 중심 편집

상태: 2026-10-22 구현·Editor 검증 완료. [완료 보고](../../../Verification/MoonRabbitJunkyard/2026-10-22-native-level-tool-ux-stage02.md). 3단계 구현은 시작하지 않았다.

## 목표와 경계

Android·Windows에서 보드를 주 작업 영역으로 두고, 필요한 도구를 쉽게 열고 닫으며 같은 편집 세션을 유지한다. [통합 계획](2026-10-22-integrated-plan.md)의 4단계 중 2단계다. 웹 빌드로 전환하지 않는다.

1단계의 시작 화면·빈 프로젝트·레벨 생성 대화상자는 재사용한다. 이번 단계는 편집 화면의 배치·입력·도구 접근을 개선하며 미션·튜토리얼 조립 UX는 3단계로 남긴다. 저장·ZIP·검색·최근 편집·dirty 확인을 새로 구현하지 않는다.

## 작업 묶음 A — 상단과 반응형 패널

- 목업의 간결한 상단 구조를 적용한다. 프로젝트/레벨 정보, 저장 상태, 저장·시험, 핵심 편집 도구를 우선 표시하고 부가 명령은 메뉴로 옮긴다.
- Windows는 왼쪽 목록·소재, 중앙 보드, 오른쪽 속성을 제공한다. 작은 화면은 목록·소재·속성 중 필요한 패널만 펼친다.
- 패널 표시/숨김과 보드 집중 모드를 제공하되 선택·실행 취소·도구 전환으로 돌아갈 길을 유지한다. 재시작은 일반 화면으로 시작한다.
- 패널 전환·회전·키보드 표시 때 선택 셀, 미확정 필드, 스크롤, 보드 확대 상태와 undo 기록을 보존한다. UI를 매번 재생성하거나 프로젝트를 다시 읽지 않는다.
- Windows 기존 최소 창 크기·비율·Alt+Enter/F11·위치 복원 정책은 바꾸지 않는다.

검증: 실제 UI Toolkit 화면의 1280×800·1440×900, 논리 영역 390×844·844×390·820×1180에서 캡처하고 보드·패널·메뉴·닫기 버튼 경계를 확인한다. 휴대폰에서 모든 패널을 동시에 펼쳐 보드를 가리지 않는다.

## 작업 묶음 B — 소재와 배치 도구

- 소재는 분류·검색·최근 사용으로 찾고 실제 프로젝트 이미지와 이름을 함께 표시한다. 소재 선택 시 해당 편집 층을 명확히 표시한다.
- 선택·배치·지우기의 현재 모드를 지속적으로 보여준다. 지우개는 현재 층만 지우고 전체 삭제는 별도 확인을 거친다.
- 우클릭과 롱터치는 같은 작업 메뉴로 연결한다. 스크롤·드래그·핀치 종료가 배치나 삭제로 잘못 처리되지 않아야 한다.
- 기능은 기존 명령 라우터와 편집 세션을 호출한다. 단축키는 메뉴에 함께 표시하고 모바일에서는 해당 기능의 터치 경로를 제공한다.

검증: 단일 셀·영역·2×2 장애물, 같은 층 교체/삭제·undo/redo, 메뉴 취소 후 원본 보존, 목록 행 선택과 편집 버튼 경계를 검사한다.

## 작업 묶음 C — 보드 전용 확대와 성능 회귀

- 보드 위 Ctrl+휠과 두 손가락 제스처는 보드만 확대·축소한다. 메뉴·팝업·글자 크기는 유지한다.
- 화면 맞춤과 확대 상태 표시를 제공하고, 기존 확대 상한을 목업 값만으로 낮추지 않는다. 보드 밖 휠은 해당 스크롤 영역에 전달한다.
- 가상 목록을 유지하고 1천·1만 메타데이터 목록에서 전체 레벨 JSON을 읽지 않는지 확인한다. 패널·선택 변경으로 문서 전체 사본이나 파일 저장이 늘지 않아야 한다.
- 기존 기능의 메뉴 접근을 점검한 뒤 검증된 중복 UI만 제거한다. 프리팹을 편집하는 일회성 Editor 생성 코드는 추가하지 않는다.

검증: UI 크기·보드 셀 크기 전후 수치, JSON 읽기 수, 목록 셀 수, 동일 조건의 선택/패널 갱신 시간과 할당을 기록한다. 제품/Android 실기기 성능으로 확대 해석하지 않는다.

## 진행·인계

관련 Runtime partial, USS와 기존 검사부터 조사한다. 각 묶음에서 재현 검사→필요한 수정→회귀 검사 순서로 진행한다. 단순 UI 확인용 RenderTexture에도 스텐실 버퍼를 사용하고 모바일 검사는 논리 배율을 명시한다.

제품 빌드·설치, 커밋·푸시, HTML 매뉴얼 갱신은 하지 않는다. 실제 데이터와 최종 증거를 보존하고 소유한 임시 검사 사본만 정리한다. 질문이 필요하면 시간제한 없는 일반 문답을 사용한다.

종료 시 변경·검증·제약을 보고하고 3단계 계획/목표/복사용 실행문과 간략한 커밋 메시지를 제공한다. 3단계 구현은 자동 시작하지 않는다.
