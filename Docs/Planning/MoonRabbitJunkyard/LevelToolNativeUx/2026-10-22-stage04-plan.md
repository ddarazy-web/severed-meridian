# 네이티브 레벨툴 UX 4단계 — 시험·저장과 통합 인계

상태: 2026-10-23 승인된 Editor 범위 구현·검증 완료. [4단계 최종 보고](../../../Verification/MoonRabbitJunkyard/2026-10-23-native-level-tool-ux-stage04.md)에 검사·대표 화면·제한과 전체 단계 감사를 기록했다. 추가 작업을 자동 시작하지 않는다.

## 목표와 범위

[통합 계획](2026-10-22-integrated-plan.md)의 마지막 단계다. Android·Windows에서 프로젝트 생성→레벨 편집→튜토리얼 작성→게임 시험→JSON 저장→ZIP 전달의 연결을 마무리한다. 기존 편집 세션·파일 전송·오류 표시·미저장 확인을 재사용한다. 새로운 저장 형식이나 웹빌드는 추가하지 않는다.

## 작업 A — 시험과 편집 복귀

- 일반 게임 시험의 입력 원본을 쉽게 식별하게 하고, 시작 실패 시 원인과 수정 위치를 연결한다.
- 시험 전 선택 레벨·보드 줌·패널·선택 칸·미확정 입력의 처리 경계를 점검한다. 복귀 시 편집 데이터와 Undo/Redo를 보존한다.
- 튜토리얼 작성 중 내부 시험은 허용하고, 전체 취소·완료 및 파일 저장을 혼동하지 않게 한다. 시험 실행과 실제 조작 확인을 구분한다.

검증: 정상 시작/복귀, 로딩 취소, 잘못된 데이터·리소스 실패, 재시도, 편집본/MemoryPack 선택 및 정식 진행 기록 불변.

## 작업 B — 저장과 ZIP 전달

- 현재 프로젝트 위치와 미저장 상태, 저장 완료·실패를 명확히 표시한다.
- 새 프로젝트, 사본 저장, ZIP 내보내기·가져오기에서 다음 동작과 실제 저장 위치를 안내한다.
- Android의 파일 선택/공유 취소와 Windows 경로 오류가 기존 작업을 덮어쓰지 않게 한다. 기존 권한·충돌 확인을 재사용한다.

검증: 명시적 저장·재열기, ZIP 왕복, 취소/손상/충돌/쓰기 실패, 이전 dirty와 공유 데이터 보존. 사용자 프로젝트 대신 소유한 검사 사본을 사용한다.

## 작업 C — 통합 접근성과 인계

- 시작 화면부터 저장·이동까지 대표 제작 시나리오를 한 번에 검사한다.
- 메뉴·단축키·툴팁·뒤로가기·우클릭/롱터치와 패널 표시/숨김의 접근을 확인한다.
- 1280×800·1440×900·390×844·844×390·820×1180에서 화면, 키보드, 회전, 필수 버튼 접근을 검사한다.
- 1천/1만 레벨 목록, 선택한 문서만 읽기, 화면 재사용, 수동 저장 경계를 회귀 검사한다. 측정 조건이 다른 수치를 개선율로 비교하지 않는다.

## 종료와 제한

실제 Windows/Android 제품 빌드·설치와 실기기 시험은 별도 승인 전 수행하지 않는다. Editor 시뮬레이션과 실기기 결과를 구분한다. 커밋·푸시, HTML 매뉴얼 갱신도 요청 전 수행하지 않는다.

완료 보고에는 변경 내용, 대표 화면, 검증 증거, 남은 문제와 실기기 미검증을 기록한다. 최종 보고서와 대표 원본 측정만 보존하고 소유한 임시 사본을 정리한다. 전체 4단계의 완료 여부를 항목별로 감사하고 추가 단계는 자동 시작하지 않는다.
