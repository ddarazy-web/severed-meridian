# 네이티브 레벨툴 UX 3단계 — 미션과 튜토리얼 조립

상태: 2026-10-23 구현 및 승인된 Editor 검증 완료. [완료 보고](../../../Verification/MoonRabbitJunkyard/2026-10-23-native-level-tool-ux-stage03.md)에 항목별 근거와 실기기 미검증을 기록했다.

## 목표와 경계

[통합 계획](2026-10-22-integrated-plan.md)의 총 4단계 중 3단계다. Android·Windows 공통 편집 화면에서 무엇을 설정해야 하는지 이해하고, 기존 조립식 튜토리얼을 목적부터 작성할 수 있게 한다. 2단계의 반응형 패널·소재·보드 선택·확대와 기존 편집 세션·조건 등록·공급·시험 엔진을 재사용한다.

기존 레벨 1~15와 JSON 계약, 인정 원인·조건 조합 정책을 보존한다. 장애물별 전용 튜토리얼 구현이나 새 저장 형식은 추가하지 않는다. 일반 시험·ZIP 전체 UX 정리와 통합 인계는 4단계다.

## 작업 묶음 A — 제작 안내와 미션

- 보드 구성, 이동 횟수·미션, 플레이 확인, 저장의 체크리스트를 제공한다. 순서를 강제하지 않고 설정 위치로 연결한다. 작은 화면은 간단한 다음 할 일과 전체 목록 열기를 제공한다.
- 설정 유효성, 실제 플레이 확인, 미저장 상태를 구분한다. 설정만으로 시험 완료를 표시하지 않는다.
- 미션은 목적→대상→수량으로 선택하고 실제 이미지와 쉬운 설명을 제공한다. 만든 미션은 요약·수정·삭제로 표시한다.

검증: 일반 블록 수집·장애물 관련 대표 미션의 추가/변경/삭제, 잘못된 수량, Undo/Redo, 미저장 유지. 기존 데이터와 시험 결과는 임의 변경하지 않는다.

## 작업 묶음 B — 목적 기반 조립과 단계 표시

- 교환·매칭, 파워 생성, 사용·조합, 내구도 감소, 직접 조립으로 시작한다. 도우미는 필요한 항목만 제안하며 사용자가 대상과 수치를 결정한다.
- 기존 튜토리얼도 순서와 쉬운 문장을 먼저 표시한다. 위치 보기·수정·여기까지 시험을 연결한다.
- 위치가 필요하면 보드를 먼저 선택한다. 교환 두 칸/단일 개체처럼 정해진 수를 채우면 필수 설정 팝업을 연다. 자유 영역은 선택 완료를 사용한다. 보드 전체·앞 단계 결과에는 불필요한 칸 선택을 요구하지 않는다.
- 유효한 대상만 강조하고 잘못된 선택은 이유를 표시한다. 필수 수치가 유효해야 적용할 수 있고 취소는 항상 제공한다.
- 세부 조건을 접어도 적용 내용을 문장에 남긴다. 앞 단계 결과 연결은 제안·확인 방식이며 앞 단계 변경으로 깨진 연결은 자동 수정하지 않고 확인 필요로 표시한다.
- 신규 공급은 ‘다음에 내려올 블록 지정’으로 기존 열·순서 편집에 연결한다. ‘여기까지 시험’은 처음부터 선택 단계까지 진행하며 중간 상태를 만들어 점프하지 않는다.

검증: 3매칭, 파워 생성→사용, 조합, 지정 원인 내구도 감소·정확히 N, 신규 공급, 앞 단계 결과 연결과 연결 오류. 기존 레벨의 의미를 보존하며 대표 fixture에서 검사한다.

## 작업 묶음 C — 완료·전체 취소와 모바일

- 튜토리얼 작업 중 일반 작업으로 나가려 하면 ‘계속 작성 / 튜토리얼 작업 전체 취소’를 제공한다. 내부 보드 배치·대상 선택·공급·시험은 허용한다.
- 신규 취소는 신규 튜토리얼을 제거하고, 기존 수정 취소는 시작 시점으로 복원한다. 작업 중 함께 바꾼 해당 레벨 보드·공급도 복원하되 작업 이전 변경·다른 레벨·공유 데이터는 유지한다.
- 완료에는 필수값·연결 검사를 요구한다. 실제 플레이 시험은 선택이며 하지 않았으면 ‘플레이 확인 필요’로 표시한다. 완료는 메모리 반영이며 파일 저장이 아니다.
- 2단계의 패널·모달·입력 보류 처리를 재사용하고 작은 가로 화면·키보드 표시 때 필수 설정과 완료/취소에 접근할 수 있게 한다.

검증: 신규 전체 취소, 기존 수정 전체 취소, 이전 dirty·타 레벨·공유 변경 보존, 완료 후 명시적 저장·재열기, 팝업 취소·회전·키보드·뒤로가기 시뮬레이션. 전체 레벨 JSON 로드나 반복 편집 자동 저장을 추가하지 않는다.

## 진행과 인계

각 묶음은 관련 기존 코드/검사를 확인하고 재현→수정→회귀 순서로 진행한다. Windows 1280×800·1440×900, 휴대폰 논리 390×844·844×390, 태블릿 820×1180의 실제 UI Toolkit 캡처와 의미 검사를 남긴다. 실기기 미검증은 별도 표시한다.

제품 빌드·설치, 커밋·푸시, HTML 매뉴얼 갱신을 하지 않는다. 질문은 시간제한 없는 일반 문답을 사용한다. 실제 작업 데이터와 최종 증거를 보존하며 소유한 임시 검사 사본만 정리한다.

완료 시 변경·검증·남은 항목, 4단계 계획·목표·복사용 실행문, 간략한 커밋 메시지를 제공한다. 4단계 구현은 시작하지 않는다.
