## 선택 1 — 원본 참조와 변경분을 담는 도구 복구 v2 (권장)

- 게임 콘텐츠 JSON·ZIP·MemoryPack은 그대로 두고 도구 복구 형식만 확장한다. 기존 v1 읽기는 유지한다.
- 변경하지 않은 원본은 프로젝트 내 상대 경로와 버전 확인 정보로 참조한다. 복구 준비를 위해 미선택 원본 전체를 읽지 않는다.
- 변경한 문서와 Undo/Redo에 필요한 해당 문서의 버전은 복구 기록에 보관하고 같은 버전의 중복 본문은 피한다.
- 복원 시 필요한 본문만 읽는다. 원본이 바뀌거나 없어졌으면 다른 내용으로 조용히 대체하거나 덮어쓰지 않는다. 기존 세션과 복구 기록을 유지하고 문제를 알린다.
- **차이:** 전체 프로젝트를 복원하려면 참조한 프로젝트 파일도 필요하다. 복구 파일 하나만으로 원본 폴더 삭제에 대비하는 독립 전체 백업은 되지 않는다. 독립 전달/백업은 기존 ZIP 내보내기를 사용한다.
- 변경본/이력의 보존 범위, 원본 이동·삭제·외부 변경, 저장 세대 보존과 취소/실패 시 원상태 유지 검사를 먼저 정의하고 작은 단위로 구현한다. 자동 저장은 추가하지 않는다.

## 선택 2 — 자기완결형 v1 유지

- 전체 원본 없이 복구 파일만으로 상태를 복원하는 기존 의미를 유지한다.
- 바깥 문자열 읽기·큰 중간 객체 등 남은 메모리 비용과 안내/취소를 개선한다.
- 모든 본문 읽기와 상태별 중복 기록은 기존 형식에 남으므로 대량 프로젝트의 복구 파일 크기·처리 시간을 목록 수준으로 줄일 수는 없다.
