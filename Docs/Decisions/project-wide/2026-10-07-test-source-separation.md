# 테스트 소스의 Assets 외부 관리

- 날짜: 2026-10-07
- 상태: 사용자 승인에 따라 적용
- 근거: 관리 목적의 테스트 분리 요청과 권장안 진행 승인

## 결정

자동 검증 소스를 같은 저장소의 `Tests/Editor`로 이동한다. 기능은 Features, 공통 시스템은 Systems로 구분한다. 테스트 실행 도구가 `Assets/__ProjectTests/Editor`에 임시 복사하고 Unity 종료 후 해제한다. 기존 namespace, `.meta` GUID, 기본 Editor 어셈블리 및 public static 검사 메서드를 유지한다.

검사 도구는 게임 에셋과 패키지를 별도로 복제하지 않는다. 연결 상태에서 원본을 수정하지 않고, 복사본 변경·추가 파일·미소유 폴더 발견 시 자동 삭제를 중단한다. 열린 프로젝트의 Editor를 임의로 종료하지 않는다.

## 대안과 비용

독립 Unity 프로젝트는 게임 소스·에셋·설정 동기화가 필요하므로 현재 관리 목적보다 비용이 크다. 별도 테스트 asmdef는 기본 Assembly-CSharp 및 기존 Editor 내부 타입 참조를 해결해야 하므로 이번 변경에 포함하지 않는다. 일반 .NET 프로젝트는 실제 씬·입력·Addressables·Play Mode 검사를 대체할 수 없다.

임시 복사는 연결 시 파일 복사와 재컴파일이 필요하다. 대신 평상시 게임 컴파일에서 테스트가 빠지고, 테스트와 게임의 버전을 같은 커밋으로 관리할 수 있다. 수동 연결 시 배포 작업 전 반드시 해제한다.
