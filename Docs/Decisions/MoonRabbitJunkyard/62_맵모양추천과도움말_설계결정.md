# 맵 모양 추천과 편집기 도움말

작성일: 2026-09-28

후속 변경: 고정 10종 추천과 사용 이력 정렬은 [63번 등록형 맵 모양 목록](63_등록형맵모양목록_설계결정.md)으로 대체했다. 아래는 이전 구현 기록이며, 도움말 아이콘 동작은 유지한다.

## 확정한 동작

- 모양이 같은 레벨을 다시 만들어도 된다. 초반에 다양한 모양을 경험하도록 앞선 레벨에서 덜 사용한 후보를 먼저 보여준다.
- 추천 선택은 현재 맵을 바꾸지 않는다. 파일 이름과 레벨 번호를 지정하여 새 레벨을 만든다.
- 모양 미리보기와 함께 사용할 장애물 후보·배치 주의점을 표시한다. 공간 조건에 맞으면 모든 장애물을 후보로 제공한다.
- 장애물과 미션은 제작자가 직접 설정한다. 추천이 클리어 가능성이나 난이도를 보장하지 않는다.
- 설명은 제목 옆 `!` 아이콘에 마우스를 올려 본다. 클릭하면 HTML 설명서의 해당 문단을 연다. 제목의 원래 편집 동작은 보존한다.
- 핵심 코드에는 한국어로 처리 의도, 순서, 입력 취소 조건, 반환 의미를 보강한다.

## 구현 범위와 선택 이유

추천은 연결된 10×10 활성 칸 템플릿 10개로 시작한다. 임의의 칸을 무작위로 끄는 방식은 공급이 끊기거나 작은 고립 공간이 생길 수 있어 채택하지 않았다. 각 세로 구간의 첫 칸에 기본 생성구를 두며, 보드·공급 데이터의 기존 저장 형식은 유지한다.

기존 Assets 레벨들의 활성 칸 100개를 비교한다. 모양이 정확히 같은 경우만 집계하고, 앞선 레벨 사용 횟수 → 전체 사용 횟수 → 기본 목록 순서로 정렬한다. 회전·이동 유사도나 별도의 사용 이력 파일은 만들지 않는다. 특정 초반 구간을 임의로 고정하지 않으며 이미 사용한 모양도 선택할 수 있다.

현재 맵에 적용하는 방식은 비활성 칸의 장애물·전선·공급 데이터와 충돌할 수 있다. 사용자가 선택한 새 파일 생성 방식을 사용하여 기존 배치를 보존한다. 레벨 번호·파일 이름 충돌은 생성 전에 검사한다.

도움말은 `LevelEditorHelp`에서 설명과 문서 위치를 관리한다. UI를 다시 만드는 경로에서도 적용하되 중복 아이콘을 만들지 않는다. Unity Label의 자식으로 버튼을 넣으면 글자가 가려지는 문제가 실제 화면에서 확인되어 제목 옆의 별도 버튼으로 배치한다.

## 코드 위치

- `Assets/Scripts/Features/ShapeCatalog/Editor/Application/LevelShapeRecommendations.cs`: 모양, 이력 정렬, 장애물 후보, 새 레벨의 기본 공급.
- `Assets/Scripts/Features/LevelEditor/Editor/Presentation/LevelEditorWindow.Recommendations.cs`: 추천 UI, 번호·이름 검사, 생성 동작.
- `Assets/Scripts/Features/LevelEditor/Editor/Presentation/LevelEditorHelp.cs`: 설명·아이콘·문서 연결.
- 기존 편집·연결·공급·탭 수명주기 및 `Simulation/MatchResolution`, `SettlementResolution`, `DroneTargetManager`: 핵심 로직 주석 보강. 공통 게임 판정은 변경하지 않는다.

## 완료 판정

1. 10가지 모양의 칸 연결과 아래 중력 공급 도달 범위 확인.
2. 추천 조회·선택·닫기·새 레벨 생성 후 기존 레벨 내용 보존 확인.
3. 이력 정렬, 재사용 허용, 큰 장애물의 공간 조건 확인.
4. 잘못된 파일 이름·중복 번호 차단과 새 파일 저장 확인.
5. 아이콘·툴팁 생성, 반복 갱신 중복 방지, 좁은 창 버튼 접근 및 실제 화면 확인.
6. 설명서의 내부 링크·문단·이미지 경로와 코드의 도움말 경로 확인.

검증 기록: `Logs/LevelShapeVerification/`. 브라우저의 로컬 파일 열기 정책으로 HTML 브라우저 화면과 실제 외부 브라우저 이동은 자동 검증하지 않는다. Unity UI 캡처 및 문서 경로의 정적 검사를 구분해서 기록한다.

최종 결과: 추천·도움말 93개 PASS, 기존 파일 이름·플레이 진입 38개 PASS. Unity 프로세스 모두 정상 종료(0). HTML 10페이지·332개 참조·154개 문단 참조·11개 이미지 검사 통과. 코드 도움말 경로 29개 모두 유효하며 공통 실행 로직 3개 파일은 주석 외 변경이 없음을 비교 검사했다.
