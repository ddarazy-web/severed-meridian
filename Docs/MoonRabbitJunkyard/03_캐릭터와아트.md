# 달 토끼 고물상 — 캐릭터와 아트

## 확정 사항

- 기본 블록은 다섯 종류의 달토끼다.
- 다섯은 정거장에서 함께 자란 소꿉친구다.
- 색상과 모양을 함께 사용하여 한눈에 종류를 구분할 수 있어야 한다.
- 별·달·우주·고물 소재는 기본 매칭 블록 대신 장애물 등에 사용한다. 개별 역할은 미정이다.
- 그림체는 단순하고 귀여워야 한다.
- 한국적 소재는 직관적으로 어울릴 때만 사용하고 억지로 넣지 않는다. 파워 블록 이름은 효과를 알아보기 쉬운 이름을 쓴다.

## 한국적 소재 제안 — 세부 확정 전

- 절구·절굿공이: 큰 윤곽만으로 알아볼 수 있는 작업 도구 또는 장애물 후보.
- 떡 시루·떡판: 고물상에 남아 있는 생활 소품 또는 장애물 후보.
- 찹쌀가루 포대·떡 반죽: 덮개나 끈적한 장애물 후보.

두 번째 장애물은 직관성을 위해 찹쌀 반죽에서 거미줄로 변경했다. 위 한국적 소재는 확정 장애물이 아닌 후보일 뿐이다. 작은 퍼즐 칸에서는 글자·무늬·복잡한 장식을 넣지 않고 형태와 색으로 구분한다.

## 확정 장애물의 외형

- 장애물 등장 레벨은 종류와 규칙을 정한 뒤 별도로 검토한다.
- 바닥형 장애물 ‘먼지’는 내구도 1~3단계를 옅은 먼지·작은 먼지 더미·두꺼운 먼지 더미로 구분한다. 다른 장애물과 겹쳐도 보이도록 칸 가장자리에도 표시한다.
- 확산하는 덮개 ‘우주 곰팡이’는 내구도 1단계의 불투명한 덩어리로 표현한다. 안의 일반 블록 색과 파워 블록 종류를 완전히 가리며, 제거하면 보존된 원래 블록이 드러난다.

- 첫 장애물은 나무상자다. 절구 대신 표현하기 쉬운 상자를 사용한다.
- 나무판을 덧대는 형태로 내구도 1~6단계를 구분한다. 피해를 받으면 보강판이 떨어져 나간다. 작은 칸에서도 단계 차이가 보이도록 단순한 큰 형태로 표현한다.
- 두 번째 장애물은 거미줄이다. 굵고 단순한 줄 몇 가닥으로 표현하고, 안의 달토끼 색과 파워 블록 종류를 알아볼 수 있게 한다.
- 내구도 1~3단계를 구분하고, 피해를 받을수록 줄이 약해지거나 일부가 끊어지며 마지막에 완전히 사라지는 효과를 사용한다.
- 이동 가능한 장애물 ‘고철 뭉치’는 회색의 둥근 본체와 굵은 금속 띠로 표현한다. 갈색 네모 나무상자와 구별한다. 띠 위치는 고정하고 기본 그림에 겹쳐 사용한다.
- 고철 뭉치의 내구도 5·4·3·2·1단계는 각각 금속 띠 4·3·2·1·0개다. 피해를 받으면 띠가 하나씩 끊어지고 마지막에는 본체가 부서진다.

- 잠긴 고물 금고는 정면의 굵은 잠금 막대 1~5개로 내구도를 표시하고 피해마다 하나씩 제거한다.
- 색깔 자물쇠는 공통 형태에 지정 색과 달토끼 표식을 함께 표시한다. 내구도 1~3단계의 세부 시각 표현은 미정이다.
- 고철 벽은 블록 칸을 차지하지 않고 두 칸 사이 경계에 표시하는 파괴 불가능한 지형이다.
- 대형 폐가전은 2×2 본체 정면에 큼직한 십자 나사 머리 최대 8개를 두 줄로 배치한다. 내구도 9는 나사 8개와 본체, 내구도 1은 빈 본체로 표현한다. 맞은 위치와 무관하게 정해진 순서대로 피해량만큼 나사가 빠지고 마지막 피해에 본체가 무너진다. 내부 배터리 제안은 나사로 대체했다.

## 발전기와 연결 전선

- 발전기는 2×2 크기로 표현하고 필요 충전량에 맞춘 큰 표시등 3~5개를 본체에 배치한다. 충전마다 하나씩 켠다.
- 발전기와 연결 대상에 같은 색·모양의 단자를 표시하고 전선으로 연결한다. 색만으로 연결 관계를 구분하지 않는다.
- 전선은 블록 사이의 틈을 따라 지나가고 양 끝만 단자에 들어간다. 가늘고 둥근 피복으로 표현하여 두껍고 각진 고철 벽과 구분하며 벽이 있는 경계는 피한다.
- 발전기당 연결 대상은 최대 3개이고 전선끼리 교차하지 않도록 제작자가 경로를 정한다. 플레이 중 블록이 이동해도 전선 경로는 고정하며 항상 확인할 수 있어야 한다.
- 충전할 때 전선을 따라 짧은 빛이 흐른다. 대상이 먼저 파괴되면 해당 전선과 대상 단자가 사라진다. 발전기 작동 연출은 연결 대상만 제거하며 주변 폭발 피해는 없다.

## 이동 통로의 연결 표시

- 이동 통로는 한 레벨에 여러 쌍을 배치할 수 있으므로 각 입구·출구 쌍에 같은 색과 문양을 표시한다. 색만으로 짝을 구분하지 않는다.

## 파워 블록 이름과 외형 방향

- 직선 4개로 만드는 블록의 이름은 방향과 관계없이 ‘청소로켓’으로 통일한다. 로봇 청소기처럼 고물을 빨아들이는 인상에, 로켓을 닮은 단순한 몸체를 결합한다.
- 가로·세로 효과는 별도의 이름 대신 로켓 몸체와 진행 방향이 보이는 그림으로 구분한다. 해당 블록이 파괴할 줄의 방향이 한눈에 보여야 한다.
- 나머지 이름은 직선 5개 ‘무지개 자석’, ㄱ·ㄴ·T ‘달 폭탄’, 2×2 ‘수거 드론’이다.
- 파워 블록은 생성에 사용된 달토끼 색을 유지하지 않는다. 종류별 고유한 외형으로 보여주어 일반 달토끼와 매칭되지 않는다는 점을 구분한다.
- 작은 블록 크기에서 흡입구·화살표 등 핵심 특징만 남기고 복잡한 기계 묘사는 피한다.

## 퍼즐 UI 색감·글꼴·숫자 — 2026-09-29 확정

- [HTML 목업](Mockups/puzzle-screen.html)의 색감과 아이콘 방향을 유지한다. 사용자의 승인 범위는 시각 방향이며 모든 최종 게임 에셋이 제작·검수된 상태는 아니다.
- 패널은 크림색, 글자·테두리는 짙은 남색, 주요 버튼·선택 강조는 노란색을 사용한다. 배경은 채도가 낮은 작업실 색으로 블록보다 약하게 표현한다.
- 목업 기준색: 크림색 `#FFF4D9`, 남색 `#28364F`, 노란색 `#F5C85A`, 작업실 청회색 `#617986`, 이동 부족 강조 주황색 `#F69B51`.
- 버튼과 패널은 둥근 모서리와 얕은 그림자로 표현한다. 복잡한 장식과 강한 젤리 광택은 피한다.

### 일반 문구와 다국어

- 기본 글꼴은 **Noto Sans 계열**이다. 한국어는 Noto Sans KR, 일본어는 JP 등 지원 언어에 맞는 같은 계열 글꼴을 구성한다. 파일 하나로 모든 언어를 지원한다고 가정하지 않는다.
- 설명·설정·버튼 문구에 적용한다. 실제 지원 언어 목록과 각 문자권의 글꼴·표시 검수는 후속 작업이다.
- 무료 상업 이용·게임 포함 배포가 가능한 SIL OFL 1.1을 사용하며 폰트 저작권과 라이선스 안내를 배포에 포함한다. 근거: [Noto 공식 안내](https://github.com/notofonts/get-noto), [OFL 공식 라이선스](https://openfontlicense.org/).
- HTML 목업에는 Noto Sans KR과 라이선스를 포함했다. Unity 프로젝트에 폰트를 설치·연결했다는 뜻은 아니다.

### 커스텀 숫자

- 이동 횟수·목표 수량·보상 등 강조 숫자는 직접 만든 숫자·기호 조각을 조합해 표현한다. 수량별로 문자열 전체를 이미지로 제작하지 않는다.
- 통통하고 둥근 형태, 크림색 면, 남색 테두리, 얕은 그림자를 사용한다. 이동 횟수가 5회 이하이면 기존 규칙에 따라 면을 주황색으로 바꾼다.
- `0~9`, `+`, `×` 등 실제 필요한 기호를 준비한다. 작은 보유 수량은 장식보다 가독성을 우선한다.
- **목업 후속 수정:** 아이템 숫자의 크기를 줄이고 여백을 확보하여 자릿수가 늘어나도 수량 배지 밖으로 벗어나지 않게 한다. 현재 목업은 보존하고 후속 화면 작업에 반영한다.
- HTML 숫자는 직접 그린 임시 글자 조각이다. 최종 글자 굵기·간격·작은 크기에서의 식별성은 실제 화면으로 검수한다.

## 기본 블록의 시각 방향과 초기 제안

단색 면, 일정한 굵기의 외곽선, 점 눈과 작은 입을 사용한다. 기본 블록에는 몸 전체보다 얼굴과 귀를 크게 표현하고, 의상·작은 소품·털 묘사·복잡한 광택은 생략한다.

| 종류 | 색상 초안 | 실루엣 초안 |
| --- | --- | --- |
| 빨강 | 코랄 레드 | 곧은 두 귀, 길쭉한 얼굴 |
| 노랑 | 골드 옐로 | 짧은 두 귀, 동그란 얼굴 |
| 파랑 | 스카이 블루 | 넓게 벌어진 두 귀 |
| 초록 | 라임 그린 | 한쪽 접힌 귀, 둥근 네모 얼굴 |
| 보라 | 바이올렛 | 양옆으로 처진 귀, 가로로 넓은 얼굴 |

위 표는 초기 후보이며 최종 제작 명세가 아니다. 현재는 사용자가 승인한 HTML 목업의 색감·아이콘 방향을 시각 기준으로 삼는다. 작은 블록 크기와 흑백 표시에서도 구별되는지에 대한 최종 에셋 검수는 아직 하지 않았다. 이름·성격·담당 역할까지 목업 승인으로 확정하지 않는다.

## 역할과 성격 제안 — 아직 확정하지 않음

| 토끼 | 담당 | 성격과 일상 갈등 |
| --- | --- | --- |
| 빨강 | 수거 | 행동이 빠르지만 너무 큰 물건까지 가져온다. |
| 노랑 | 판매·응대 | 친화력이 좋지만 손님 사연을 들으면 덤을 준다. |
| 파랑 | 수리·발명 | 솜씨가 좋지만 필요 없는 기능까지 추가한다. |
| 초록 | 분류·창고 | 정리를 좋아하지만 동료들이 창고를 어지럽힌다. |
| 보라 | 감정·기록 | 숨은 가치를 찾지만 추억 때문에 물건을 못 버린다. |

위 담당 업무는 이야기용 제안이다. 색상별 블록 능력 차이는 결정하지 않았다. 이름과 구체적인 말투도 미정이다.
