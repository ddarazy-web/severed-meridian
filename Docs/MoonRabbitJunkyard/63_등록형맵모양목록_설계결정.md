# 등록형 맵 모양 목록

작성일: 2026-09-28. 이전 62번 문서의 고정 모양 추천과 자동 정렬을 이 결정으로 대체한다. 도움말 아이콘 동작은 유지한다.

## 동작

1. 사용자가 직접 만든 레벨을 저장한다.
2. `맵 모양 목록 → 현재 레벨 모양 등록`을 누른다.
3. 활성 칸이 같은 기존 항목이 있으면 중복을 안내하고 해당 항목을 선택한다. 기존 기록을 덮어쓰지 않는다.
4. 새 모양이면 모양, 원본 이름·레벨 번호, 사용 장애물 종류·개수를 등록한다.
5. 목록에서 모양을 선택하고 새 파일 만들기를 확정할 때만 새 레벨에 적용한다.

## 데이터 범위

- 10×10 활성 칸 위치가 완전히 같은 경우 중복이다. 이름·장애물·미션은 비교하지 않으며 회전·이동은 별개다.
- `LevelShapePreset`은 독립된 값 복사로 저장한다. 원본 수정·이름 변경·삭제 후에도 등록 당시 기록을 보존한다.
- 등록은 현재 저장된 내용에 대해 수행한다. 미저장 수정이 있으면 먼저 저장하라고 안내한다. 연결·미션 완성도나 난이도로 등록을 제한하지 않는다.
- 장애물 본체 개수, 덮개·먼지 칸 수, 고철 벽 구간 수를 기록한다. 공급되는 고철은 고정 목록 수량/유지 목표로 구분한다. 내구도는 수량에 곱하지 않는다.
- 이력은 참고용이며 새 레벨에 장애물·특수 중력·연결·미션을 배치하지 않는다. 활성 칸과 기본 아래 중력의 세로 구간별 생성구만 만든다. 원본 전체 복사에는 기존 레벨 복제 기능을 사용한다.
- 고정 10종 및 자동 추천 순서는 제거한다. 등록 목록은 이름순으로 표시하며 처음에는 비어 있다.

## 저장과 구현

등록 파일: `Assets/Editor/LevelShapes/*.asset`. 게임 실행용 레벨과 구분되는 Editor 전용 에셋으로 프로젝트와 함께 관리한다. 등록할 때만 필요한 폴더를 만든다.

`Assets/Scripts/Features/ShapeCatalog/Editor/Data/LevelShapePreset.cs`는 저장 모델, `LevelShapeRecommendations.cs`는 등록·조회·적용, `LevelEditorWindow.Recommendations.cs`는 화면을 담당한다. 기존 파일과 meta GUID는 유지하여 참조 변경을 줄였다. 별도 서버·외부 의존성·전체 레벨 검사기를 추가하지 않았다.

## 검증

`LevelShapeVerification.Start`를 별도 Unity에서 실행해 38개 PASS, 종료 코드 0을 확인했다. 미저장 차단, 동일 모양 중복, 장애물 변경에도 중복 유지, 한 칸 다른 모양 등록, 같은 원본 이름의 파일 충돌 방지, 디스크 재로딩, 원본 수정·삭제 후 보존, 등록 버튼 성공, 목록 선택·닫기, 새 레벨 생성과 기본 공급 정합성, 좁은 창 버튼 접근을 포함한다.

증거: `Logs/LevelShapeCatalogVerification/`. 실제 UI 캡처를 설명서에 추가했다. HTML 10페이지의 참조 338개 및 코드의 도움말 경로 29개 검사 통과. 외부 브라우저의 실제 HTML 표시는 기존 로컬 파일 열기 정책에 따라 자동 검증하지 않았다.
