# 달 토끼 고물상 — 규칙 조회와 드론 목표 관리

- 확정된 구조·행동 기획이며 구현 완료를 의미하지 않는다.
- 드론은 게임의 파워 효과이고 [플레이 봇](10_자동플레이와난이도분석.md)은 사용자 대신 조작하는 평가 로직이다. 둘을 구분하며 내부 목표 관리 정보를 봇에 공개하는 통로로 사용하지 않는다.

## 책임 분리

- 대상별 반응 규칙: 어떤 효과에 반응하는지, 지금 피해·제거·덮개 해제·충전이 가능한지와 예약 범위를 판단한다.
- 미션 규칙: 예상 변화가 현재 남은 미션 목표에 기여하는지 판단한다.
- 목표 관리 매니저: 후보 목록 관리·추천·선택과 예약 등록·예약 해제를 담당한다. 장애물별 반응을 매니저 하나에 모아 구현하지 않는다.
- 드론: 목표를 요청하고 이동·타격을 실행한 뒤 완료를 보고한다.
- 실제 효과 처리와 사전 조회는 같은 대상별 규칙을 공유한다. 사전 조회는 실제 보드를 변경하지 않는다.
- 조회 결과에는 반응 종류, 예상 변화량, 불가능한 이유를 포함한다. 예를 들어 내구도 1 감소, 충전 1 증가, 이번 수에 이미 피해받음 등을 설명할 수 있다.

## 후보 목록과 추천

- 첫 요청 때 후보 목록을 조회해 보관한다. 보드·미션 상태가 같으면 재사용하되 현재 예약을 반영해 제외 대상을 거른다.
- 타격 등으로 상태가 바뀌면 목록을 갱신 대상으로 표시하고 다음 요청 때 다시 조회한다. 이미 예약한 목표의 유효성도 확인한다.
- 초기 구현 방향은 상태 변경 시 전체 후보 재평가다. 변경 칸만 증분 갱신하는 복잡한 방식은 성능 측정 후 필요한 경우에 검토한다.
- 목표 선택과 예약 등록은 하나의 동작으로 처리하여 다음 드론이 갱신된 예약 정보를 보게 한다.
- 요청에는 실제 도착 후 효과를 포함한다. 일반 드론은 한 칸, 로켓 조합은 유지된 방향의 한 줄, 폭탄 조합은 3×3 범위를 기준으로 미션 기여를 판단한다.
- 유효한 미션 후보 중 무작위 선택을 유지한다. 미션 후보가 없으면 타격 가능한 일반 블록 중 무작위로 선택하고, 일반 블록도 없을 때만 추가 타격 없이 종료한다.

## 예약 범위와 해제

- 일반 블록·1칸 장애물은 해당 칸을 예약한다.
- 발전기는 한 수에 한 번만 충전되므로 본체 네 칸 전체를 하나의 예약 범위로 취급한다.
- 대형 폐가전은 조준한 칸을 예약하며 다른 칸에는 별도 드론을 배정할 수 있다. 타격 후에도 본체가 남으면 후속 타격 대상이 될 수 있다.
- 조합 드론은 조준 칸 외에 도착 후 직접 효과 범위에서 타격할 미션 대상도 함께 예약한다. 범위 밖으로 이어질 추가 연쇄는 예측해 예약하지 않는다.
- 타격 완료 또는 목표 무효화 시 예약을 해제한다. 예약 중인지와 이번 수에 이미 피해받았는지는 별도로 관리한다. 예약 해제가 장애물의 피해 제한을 초기화하지 않는다.
- 비행 중 목표가 사라지면 기존 예약을 해제하고 현재 상태에서 미션 후보를 다시 찾는다. 없으면 일반 블록을 무작위로 선택하고, 일반 블록도 없으면 추가 타격 없이 종료한다. 새 목표도 다른 드론 예약을 피해 등록한다.

## 예상 진행량 관리

- 예약된 직접 타격이 해결할 것으로 예상되는 미션 수량을 관리해 과도한 중복 조준을 줄인다. 상자 목표 1개가 남고 이미 완전 제거 가능한 예약이 있으면 다음 드론은 다른 미션 후보를 찾으며, 없으면 일반 블록을 선택한다.
- 내구도 감소·발전기 충전 같은 중간 진행량도 합산한다. 예를 들어 내구도 2인 폐가전의 서로 다른 칸에 각 1피해가 예약되면 제거 예정으로 판단할 수 있다.
- 대상별 피해·충전 제한에 따라 직접 타격으로 계산할 수 있는 변화만 반영하며 추가 연쇄는 제외한다.
- 예상 상태는 실제 보드와 분리한다. 실제 미션 완료는 타격 결과로만 처리한다. 예약 취소 시 예상 기여량도 되돌리고 실제 상태가 바뀌면 다시 평가한다.
