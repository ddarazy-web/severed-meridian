# 32단계 개발 목표 — 시험 기록 관리

- 작성일: 2026-09-29.
- 상태: 2026-09-29 구현·검증 완료. [13조건 증거 및 보존 결과](93_32단계_검증진행기록.md)를 확인한다.
- 작업 계획: [32단계 시험 기록 관리](91_32단계_시험기록관리_작업계획.md).

## 목표

기존 통합 작업창에서 지난 여러 레벨 시험을 선택해 결과를 확인하고, 반복 시험·이동 횟수 추천·여러 레벨 시험의 로컬 기록을 전체 삭제할 수 있게 한다. 레벨 원본, 등록 맵, 별도 내보낸 파일과 개발 검증 자료는 보존한다. 개발 과정에서는 임시 기록으로 삭제 기능을 검증하며 사용자의 실제 기록을 삭제하지 않는다.

## 실행 원칙

1. 현재 Goal을 확인한다. 같은 미완료 32단계 목표는 이어가고 활성 Goal이 없을 때만 생성한다. 다른 활성 Goal을 덮어쓰거나 임의 완료하지 않는다.
2. 프로젝트 AGENTS와 unity-project-conventions·ponytail을 적용한다. 핵심 미확정 사항에만 grill-me를 사용하며 deep-planning은 사용하지 않는다. 세 종류 전체 삭제 범위는 이미 확정되었다.
3. 계획 T1~T5와 아래 완료 조건을 따른다. 기존 사용자 변경, 원본 에셋·GUID/meta·기존 실측 기록을 보존한다.
4. 스크립트는 AutoPlay 기능 내부의 역할별 폴더로 나눈다. 기존 UI·저장·분석 코드를 재사용하고 복잡한 로직의 의도를 한국어 주석으로 남긴다.
5. 실제 UI의 사용자 확인 이후에만 삭제한다. 개발 검사는 주입한 임시 저장 루트/소유 사본에서 실행한다. 시험·일시정지·내보내기와 삭제가 충돌하지 않게 한다.
6. 저장 위치 밖의 파일과 임의 외부 폴더를 삭제하지 않는다. 경로 검증, 부분 실패, 최근 기록 포인터와 화면 캐시 정리를 함께 검증한다.
7. 난이도 네 단계, 1~100회 제품 시험 범위와 공통 게임 실행기를 유지한다. 이번 검증에서는 20,000판을 실행하지 않으며 필요한 소규모 검사만 한다.
8. Unity 검사 실행 중 Assets를 수정하거나 중복 검사 프로세스를 시작하지 않는다. 실패 조건을 보존하고 같은 조건으로 재검사한다.
9. HTML 안내와 연결된 도움말을 갱신한다. 브라우저 배치 검수는 기존 후속 이관을 유지하고 다른 미검증 항목은 완료로 표현하지 않는다.
10. 개별 삭제, 자동 정리, CSV, 중단 시험 재개, 저장 형식/패키지 변경으로 범위를 넓히지 않는다. 완료 증거를 남긴 후에만 Goal을 완료한다.

## 완료 조건

- [x] 1. 관련 코드·수명주기와 기존 데이터 보존 기준을 확인했다.
- [x] 2. 지난 여러 레벨 실행을 최근 순서로 나열하고 시각·종류·레벨 수·상태로 구분한다.
- [x] 3. 실행 선택 시 해당 레벨별 결과와 기존 네 난이도 추천을 조회하며 자동 실행·원본 수정·최근 포인터 변경이 없다.
- [x] 4. 손상·누락·버전 불일치를 표시하고 정상 기록 조회를 유지한다.
- [x] 5. 세 종류별 삭제 대상 수를 확인 창에 표시하고 취소 시 파일과 화면 선택을 보존한다.
- [x] 6. 임시 루트의 세 종류 기록과 중첩 결과를 중복 집계 없이 삭제하고 빈 상태를 표시한다.
- [x] 7. 실행·일시정지·재개 대기·내보내기 중 삭제를 막고 삭제 중 신규 시험과 중복 삭제를 막는다.
- [x] 8. 삭제 이후 읽기·재생·비교·캐시·선택 상태를 정리하며 삭제 기록이 화면에 남지 않는다.
- [x] 9. 부분 실패를 정확히 보고하고 남은 기록 재조회 및 최근 포인터 정리를 확인했다.
- [x] 10. 허용 루트 밖 경로와 링크 우회를 거절하고 원본/등록 맵/외부 내보내기/개발 증거를 보존했다.
- [x] 11. 많은 기록의 목록·삭제가 원시 판 전체 분석 없이 동작하며 실제 UI 응답과 진행 표시를 확인했다.
- [x] 12. 관련 컴파일·회귀와 실제 Unity UI 검사를 통과했다. 실제 판 수·합성 검사·재사용 증거를 구분하고 20,000판은 실행하지 않았다.
- [x] 13. 한국어 매뉴얼·도움말 링크, 조건별 검증 기록과 남은 제한을 정리했다. 사용자 실제 기록을 삭제하지 않았음을 대조했다.
