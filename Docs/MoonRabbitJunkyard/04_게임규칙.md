# 달 토끼 고물상 — 게임 규칙

## 확정된 범위

- 장르: 스테이지 기반 매치3 퍼즐.
- 기본 블록: 달토끼 5종.
- 참고 범위: 캔디 크러쉬 소다의 매칭, 특수 블록 생성·조합, 장애물과 목표, 보드 기믹.
- 모바일과 PC에서 동일한 보드와 규칙을 사용한다.
- 1~5레벨은 장애물 없이 기본 매칭과 파워 블록을 익힌다. 나무상자는 6레벨, 거미줄은 21레벨에서 소개·해금한다.
- 장애물은 실제 주문 완료 여부와 관계없이 지정된 퍼즐 레벨에 도달하면 해금한다. 주문별 필요 별에 대응하는 예상 퍼즐 진행량을 기준으로 해금 레벨을 미리 정한다. 첫 주문은 총 별 20개이므로 다음 장애물인 거미줄은 21레벨에 해금하며, 첫 주문이 미완료여도 동일하다.
- 한번 소개된 장애물은 이후 레벨에서 언제든 사용할 수 있는 목록에 남는다. 모든 레벨에 반드시 등장시키지는 않는다.
- 첫 장애물은 나무상자, 두 번째 장애물은 거미줄이다. 이후 종류와 둘 이상을 함께 사용하는 시점은 미정이다.
- 네 종류의 파워 블록은 처음부터 모두 생성·사용할 수 있다. 첫 주문에서 설명을 순차적으로 소개한다.
- 새로운 매칭 형태와 파워 블록은 최초 소개 시 한 번, 고정 배치에서 지정된 교환을 직접 해보는 짧은 튜토리얼로 안내한다.
- 한국적 소재는 직관적으로 어울리는 경우에만 사용하며 억지로 적용하지 않는다. 장애물 없는 입문 구간은 첫 주문 전체가 아니라 1~5레벨이다.

## 미션과 첫 레벨 튜토리얼

- 레벨마다 미션을 최소 1개, 최대 4개 지정하며 모두 달성해야 클리어한다. 초반에는 단일 미션부터 소개한다.
- 지정 색 달토끼 수집, 나무상자 제거, 거미줄 제거를 미션으로 사용하며 함께 지정할 수 있다. 색상별 달토끼 수집은 각각 미션 1개로 센다. 예를 들어 노랑·파랑 수집과 상자·거미줄 제거는 총 4개다.
- 달토끼 수집은 일반 매칭·파워 블록·아이템으로 제거한 수량을 모두 포함한다. 매칭으로 파워 블록이 되는 달토끼도 포함하므로 같은 색 4개로 로켓을 만들면 4개를 수집한다.
- 거미줄만 약해지거나 벗겨지고 안의 달토끼가 남으면 달토끼 수집으로 세지 않는다. 달토끼가 실제 제거되거나 파워 블록으로 바뀔 때 센다.
- 나무상자·거미줄 제거 미션은 내구도와 관계없이 완전히 제거한 한 칸을 1개로 센다. 내구도 감소만으로는 목표 수량을 줄이지 않는다.
- 1레벨은 지정된 달토끼 3개를 한 번 매칭하면 클리어하는 튜토리얼이다. 안내한 두 블록의 교환만 허용한다. 시작 전 부스터 선택을 건너뛰고 게임 중 아이템도 사용할 수 없다.
- 1레벨 첫 클리어 후에는 메인으로 돌아와 작업 아이콘을 안내하고, 받은 별 1개로 첫 주문의 ‘상태 점검’을 수행하여 퍼즐과 주문 작업의 연결을 익힌다.

## 초반 해금과 튜토리얼 순서

| 레벨 | 소개·해금 내용 |
| --- | --- |
| 1 | 기본 3매칭 |
| 2 | 직선 4매칭으로 청소로켓 생성 |
| 3 | ㄱ 모양으로 달 폭탄 생성 |
| 4 | 2×2 매칭으로 수거 드론 생성 |
| 5 | 직선 5매칭으로 무지개 자석 생성 |
| 6 | 나무상자 소개 |
| 7 | 고물 망치 해금·무료 1회 체험 |
| 9 | 청소로켓 + 청소로켓 조합 안내 |
| 12 | 자리 바꾸기 해금·무료 1회 체험 |
| 16 | 섞기 해금·무료 1회 체험 |
| 21 | 거미줄 소개 |

- 2~5레벨은 파워 블록을 직접 생성하고 인접 블록과 교환하여 발동하는 과정까지 안내한다. 더블터치·더블클릭 기능은 유지하지만 설명하지 않는다. 안내 후 같은 보드에서 자유롭게 플레이하며 남은 미션을 완수한다.
- 3레벨에서는 ㄱ 모양만 대표로 직접 안내한다. ㄴ·T 생성도 유효하지만 별도 강제 튜토리얼은 제공하지 않는다.
- 9레벨은 청소로켓 두 개를 인접한 칸에 미리 배치하고, 안내된 교환으로 조합 효과를 체험한 뒤 자유 플레이로 전환한다. 나머지 조합은 별도의 강제 튜토리얼 없이 플레이하며 발견하도록 한다.
- 게임 중 아이템은 지정 레벨에서 하나씩 해금한다. 최초 해금 때 보유 수량을 차감하지 않는 1회 체험 튜토리얼을 제공한다.

## 보드 구성과 시작 조건

- 기본 보드 크기는 10×10이다.
- 일부 칸을 비활성화하여 구멍이나 좁은 통로가 있는 비정형 보드를 만들 수 있다.
- 시작 보드는 이미 완성된 매칭이 없고, 유효한 교환이 최소 하나 있는 상태로 구성한다.
- 퍼즐 레벨마다 사용할 달토끼를 3~5종 선택한다. 종류 수와 실제 색상 목록을 제작자가 지정하며, 무작위 생성·공급은 선택된 종류 안에서 균등 확률로 처리한다.
- 시작 배치는 전체 고정, 전체 무작위, 일부 칸만 고정하는 방식을 모두 지원한다. 고정은 초기 배치 지정이며 플레이 중 이동을 막는 잠금이 아니다.
- 시작 배치에 일반 달토끼·파워 블록·장애물을 지정할 수 있다.
- 재도전 시 지정한 고정 배치는 유지하고, 무작위 칸은 새로 배치한다.
- 매칭은 실제로 이어진 칸에서만 성립한다. 비활성 칸은 연결을 끊으며, 그 너머의 블록을 이어서 매칭하지 않는다.
- 청소로켓의 줄 제거 효과는 비활성 칸을 통과하여 같은 행·열의 반대편 블록에도 적용한다.

## 이동 횟수와 성공·실패 판정

- 기본 퍼즐에는 시간제한을 두지 않는다. 레벨별로 정해진 이동 횟수 안에 목표를 달성한다.
- 재도전은 무료이며 횟수를 제한하지 않는다. 재도전 자체에 하트나 광고 시청을 요구하지 않는다.
- 마지막 한 수로 이동 횟수가 0이 되어도 모든 효과·낙하·자동 매칭을 끝까지 처리한 뒤 성공·실패를 판정한다. 그 과정에서 목표를 달성하면 성공이다.
- 이동 횟수 0에서 마지막 연쇄가 끝나도 미션이 남으면 게임 중 아이템을 사용할 수 없다. 광고 또는 이어하기 아이템으로 이동 횟수를 얻거나 재도전한다. 이어하기 아이템은 실패 패널 전용이며 두 수단의 한도는 [성장과 보상](05_성장과보상.md)을 따른다.
- 이동 횟수가 남아 있을 때 목표를 달성하면 현재 진행 중인 연쇄를 마무리한 뒤 바로 클리어한다. 남은 이동 횟수를 모두 사용할 필요는 없다.
- 점수와 1~3성 등급은 사용하지 않는다. 목표 달성 여부만 판정하고 첫 클리어 보상으로 별 1개를 지급한다.

## 클리어 후 라스트팡

- 현재 연쇄를 마친 뒤 클리어를 확정·저장하고 라스트팡을 진행한다. 남은 이동 횟수 1회당 일반 블록 1개를 무작위 위치에서 청소로켓으로 바꾸며, 로켓 방향도 무작위로 정한다.
- 변환 가능한 일반 블록이 남은 이동 횟수보다 적으면 가능한 수만큼만 변환한다.
- 보드에 남아 있던 파워 블록도 모두 발동한다. 단, 거미줄에 묶인 블록은 로켓 변환과 일괄 발동 대상에서 제외하며 강제로 덮개를 벗기지 않는다.
- 거미줄에 묶인 블록이 다른 효과에 맞으면 기존대로 거미줄에 한 단계 피해를 적용한다. 안의 파워 블록이 이후 별도의 타격을 받으면 연쇄 발동한다.
- 낙하·새 블록 보충·자동 매칭·파워 블록 생성을 정상 처리한다. 새로 생성된 파워 블록도 다시 발동하며, 현재 효과와 낙하가 끝나 자리 잡은 뒤 발동한다. 이는 일반 플레이의 새 파워 블록 보호 규칙에 대한 라스트팡 전용 예외다.
- 화면 터치 또는 PC 클릭으로 라스트팡을 건너뛰고 결과 화면으로 이동할 수 있다. 건너뛰어도 클리어와 보상은 동일하다.
- 라스트팡 도중 앱이 강제 종료되면 재실행 시 연출을 반복하지 않고 결과 화면으로 이동한다. 클리어 보상은 누락·중복 없이 한 번만 지급한다.

## 기본 교환·매칭 규칙

- 플레이어는 상하좌우로 인접한 달토끼 블록 두 개를 교환한다.
- 일반 교환과 ‘자리 바꾸기’ 모두 두 칸에 블록이 있어야 하며, 빈칸으로 블록을 밀어 넣는 조작은 허용하지 않는다.
- 교환 조작은 드래그와 두 칸 순차 선택을 모두 지원한다. 매칭·파워 효과·낙하·보충 등 전체 연쇄가 끝나 보드가 안정된 뒤에만 다음 조작을 받는다.
- 유효한 매칭이 생기면 한 수를 소비하고, 매칭이 생기지 않으면 두 블록을 원래 위치로 되돌리며 이동 횟수를 소비하지 않는다.
- 파워 블록은 인접 블록과 교환하거나 제자리에서 더블터치해 발동할 수 있다. 어느 방식이든 발동하면 한 수를 소비한다. 파워 블록 교환은 새 매칭이 없어도 발동하는 예외다.
- 파워 블록은 일반 달토끼 블록과 같은 색으로 판정하지 않으며, 일반 블록과 함께 3개 이상의 매칭을 이루지 않는다.
- 파워 블록은 생성 당시 달토끼의 색을 속성으로 유지하지 않고 종류별 고유한 외형으로 표시한다.
- 직선 5개 파워 블록을 일반 블록과 교환하면 교환한 블록의 색을 제거한다. 제자리에서 더블터치하면 게임이 제거할 색을 무작위로 선택한다. 플레이어가 색을 직접 고르지 않는다.
- 무지개 자석의 무작위 색 선택은 현재 보드에 실제로 남아 있는 일반 달토끼의 색으로 한정하되, 곰팡이에 숨겨진 블록은 제외한다. 이 조건은 더블터치·연쇄 발동·색을 고르는 조합 효과에 공통으로 적용한다. 아래 자석 규칙의 일반 달토끼 유무도 이 대상 기준으로 판정한다.
- 거미줄에 묶인 달토끼도 색 선택 대상에 포함한다. 해당 색의 제거 효과를 받으면 거미줄에 한 단계 피해가 적용되고 안의 달토끼는 남는다.
- 일반 달토끼가 하나도 없으면 무지개 자석의 단독 발동을 막고, 유효한 파워 블록 조합만 허용한다. 이 상태의 무지개 자석 단독 발동은 가능한 행동으로 세지 않는다.
- 일반 달토끼가 없는 상태에서 연쇄 피격으로 발동하는 무지개 자석은 추가 효과 없이 소모한다. 이번 수에 매칭으로 생성한 파워 블록의 피격 보호 규칙은 그대로 적용한다.
- 일반 교환 조작으로 두 파워 블록을 서로 교환하면 해당 조합의 전용 효과를 발동한다. ‘자리 바꾸기’ 아이템은 예외로 위치만 교환한다. PC에서는 더블클릭으로 제자리 발동한다.
- 같은 종류의 달토끼가 직선으로 연속 3개 매칭되면 일반 매칭으로 처리한다.
- 같은 종류의 달토끼가 직선으로 연속 4개 또는 5개 이상 매칭되면 파워 블록을 생성한다.
- 가로 직선 4개 매칭은 세로 한 줄을 제거하는 ‘청소로켓’을 생성한다.
- 세로 직선 4개 매칭은 가로 한 줄을 제거하는 ‘청소로켓’을 생성한다.
- 직선 5개 이상 매칭은 한 색의 달토끼를 보드 전체에서 제거하는 ‘무지개 자석’ 하나를 생성한다. 생성 칸을 제외한 해당 직선의 연결 블록은 모두 제거한다.
- 같은 종류의 달토끼가 3×3 영역 안에서 ㄱ·ㄴ·T 형태로 매칭되면 파워 블록을 생성한다. 아래 기준 모양은 각각 총 5칸이다. ㄱ·ㄴ은 네 모서리 방향을, T는 위·아래·왼쪽·오른쪽 방향을 모두 유효하게 판정한다.
- ㄱ·ㄴ·T 매칭은 모두 파워 블록을 중심으로 주변 3×3칸을 제거하는 ‘달 폭탄’을 생성한다.

  ```text
  ㄱ      ㄴ      T
  ■■■    ■··    ■■■
  ··■    ■··    ·■·
  ··■    ■■■    ·■·
  ```
- 같은 종류의 달토끼가 2×2로 매칭되면 파워 블록을 생성한다. 2×2의 네 칸만 있어도 유효하며, 같은 종류의 블록 하나가 더 붙어 있어도 유효하다.
- 2×2만 만들어지고 직선 3개가 생기지 않은 교환도 유효한 수로 인정한다. 이 경우에도 한 수를 소비하고 파워 블록을 생성한다.
- 2×2 매칭으로 만든 ‘수거 드론’은 발동 위치의 가운데 칸과 상·하·좌·우를 포함한 `+` 모양 총 5칸에 파괴 판정을 적용한다. 여기에 더해 보드의 블록 한 칸을 추가로 제거한다.
- 드론의 추가 제거 대상은 아래의 공통 목표 선택 규칙을 따른다. 달 폭탄·드론 등 범위 효과는 보드 밖과 비활성 칸에 걸친 부분만 무시하고 실제 존재하는 칸에 적용한다. 청소로켓은 기존대로 비활성 칸을 통과한다.
- 생성 패턴이 같은 칸을 공유하며 겹치면 무지개 자석 > 달 폭탄 > 청소로켓 > 수거 드론 순으로 우선하여 파워 블록 하나만 생성한다. 서로 별개인 패턴은 각각 인정한다.
- 무지개 자석의 직선 매칭과 수거 드론의 2×2 매칭이 겹치면, 무지개 자석을 생성하고 생성 칸을 제외한 해당 직선의 블록만 제거한다. 직선 밖에 있는 2×2 패턴의 블록은 남긴다.
- 모든 패턴 중첩에서 우선순위로 선택된 패턴의 블록만 처리한다. 파워 블록 생성 칸은 해당 파워 블록으로 바꾸고 나머지 선택 패턴의 블록은 제거한다. 우선순위가 낮은 패턴에만 속한 블록은 남긴다.
- 겹친 패턴의 우선순위가 같으면 더 많은 블록을 포함한 패턴을 선택한다. 블록 수도 같으면 무작위로 선택한다.
- 직선 6개 이상도 위의 5개 이상 규칙을 적용하며, 길이에 따라 무지개 자석을 여러 개 생성하지 않는다.

## 파워 블록 조합 — 기본 효과 확정

서로 다른 파워 블록 또는 같은 파워 블록 두 개를 교환해 전용 효과를 발동한다. 네 종류의 파워 블록으로 가능한 두 개 조합 10가지를 모두 포함한다. 좌우 순서는 같은 조합으로 취급한다. 청소로켓의 가로·세로 방향은 같은 종류의 변형으로 센다.

조합 효과의 중심인 ‘교환 지점’은 플레이어가 움직인 블록의 도착 칸이다. 드래그는 놓은 칸, 두 칸 순차 선택은 두 번째 칸을 사용한다.

| 조합 | 전용 효과 |
| --- | --- |
| 청소로켓 + 청소로켓 | 두 로켓의 방향과 관계없이 교환 지점을 지나는 가로 한 줄과 세로 한 줄을 제거한다. |
| 청소로켓 + 달 폭탄 | 교환 지점을 중심으로 가로 3줄과 세로 3줄을 제거한다. |
| 청소로켓 + 수거 드론 | 교환 지점의 가운데와 상하좌우 `+` 5칸에 먼저 파괴 판정을 적용한다. 파괴 후 남은 미션 목표 중 드론의 목적지를 고르고, 그 칸에서 청소로켓 방향의 한 줄을 제거한다. 해당 목표가 없으면 임의의 칸을 고른다. 청소로켓의 가로·세로 방향은 유지한다. |
| 달 폭탄 + 달 폭탄 | 교환 지점을 중심으로 5×5칸에 파괴 판정을 적용한다. |
| 달 폭탄 + 수거 드론 | 교환 지점의 가운데와 상하좌우 `+` 5칸에 먼저 파괴 판정을 적용한다. 파괴 후 남은 미션 목표 중 드론의 목적지를 고르고, 그 칸을 중심으로 3×3을 제거한다. 해당 목표가 없으면 임의의 칸을 고른다. |
| 수거 드론 + 수거 드론 | 교환 지점을 중심으로 3×3칸을 먼저 파괴한 뒤 수거 드론 3대를 생성한다. 각 드론은 파괴 후 남은 미션 목표를 한 칸씩 찾아 제거한다. 목표가 부족하면 남은 드론은 일반 블록을 무작위로 선택한다. |
| 무지개 자석 + 청소로켓 | 게임이 달토끼 색 하나를 무작위로 고른다. 보드의 해당 색 일반 블록을 모두 청소로켓으로 바꿔 발동한다. 새 청소로켓마다 가로·세로 제거 방향을 무작위로 정한다. |
| 무지개 자석 + 달 폭탄 | 게임이 달토끼 색 하나를 무작위로 고른다. 보드의 해당 색 일반 블록을 모두 달 폭탄으로 바꿔 각각 3×3 제거 효과를 발동한다. |
| 무지개 자석 + 수거 드론 | 게임이 달토끼 색 하나를 무작위로 고른다. 보드의 해당 색 일반 블록을 모두 수거 드론으로 바꿔 발동한다. 각 드론은 자기 자리의 가운데와 상하좌우 `+` 5칸을 파괴한 뒤 남은 미션 목표 한 칸을 찾아 제거한다. |
| 무지개 자석 + 무지개 자석 | 보드 전체의 모든 칸에 한 번씩 파괴 판정을 적용한다. 일반 블록은 제거하고, 여러 번 타격해야 하는 장애물은 한 단계만 손상시킨다. |

무지개 자석 조합의 예외는 다음과 같다.

- 무지개 자석 + 무지개 자석은 일반 달토끼가 없어도 보드 전체 타격을 발동한다.
- 무지개 자석 + 청소로켓·달 폭탄·수거 드론은 일반 달토끼가 없으면 교환을 되돌리고 이동 횟수를 소비하지 않는다.
- 변환할 색으로 선택된 달토끼가 거미줄에 묶여 있으면, 해당 칸은 파워 블록으로 변환하지 않고 거미줄에 한 단계 피해를 적용한다. 안의 달토끼는 남는다.

## 수거 드론의 공통 목표 선택

- 일반 발동과 조합으로 생성된 드론 모두 유효한 미션 목표를 우선한다. 유효한 미션 목표가 여러 개이면 그중 무작위로 선택한다.
- 색상 수집 목표에서는 바로 수집 가능한 노출된 목표색 달토끼를 우선한다. 그런 대상이 없으면 거미줄에 묶인 목표색 달토끼를 겨냥한다. 장애물 미션과 색상 수집 미션 사이의 추가 우선순위는 지정하지 않았다.
- 이번 수에 이미 피해를 받은 장애물은 목표 후보에서 제외한다. 반복 피해를 허용하는 대형 폐가전은 예외로, 본체가 남아 있으면 다시 후보가 될 수 있다.
- 다른 드론이 이미 겨냥한 칸도 후보에서 제외하여 목표가 겹치지 않도록 한다.
- 미션 목표가 없거나 드론 수보다 적으면 나머지 드론은 일반 블록을 무작위로 선택한다. 이때도 다른 드론이 겨냥한 칸은 제외한다.
- 선택 가능한 미션 목표와 일반 블록 후보가 모두 없으면 해당 드론은 추가 타격 없이 종료한다.
- 거미줄에 묶인 파워 블록도 거미줄 제거 미션의 목표라면 겨냥할 수 있다. 해당 타격으로는 거미줄에 한 단계 피해를 적용한다.
- 목표 관리 매니저가 대상별 반응·미션 기여 규칙을 조회하고 후보 추천과 예약을 관리한다. 상태가 같으면 후보 목록을 재사용하고 변하면 재평가한다. 상세 구조는 [규칙 조회와 목표 관리](11_규칙조회와목표관리.md)를 따른다.
- 목표 요청은 일반 드론·로켓 조합·폭탄 조합의 실제 도착 후 효과 범위를 반영한다. 조합 드론은 직접 효과로 타격할 미션 대상도 함께 예약하되 추가 연쇄까지 예약하지 않는다.
- 예약된 직접 타격의 예상 미션 수량·내구도 감소·충전을 반영하여 불필요한 중복 목표를 줄인다. 실제 보드·미션 완료와 예상 상태는 분리하며 예약 취소와 실제 상태 변경 때 갱신한다.
- 타격 완료·목표 무효화 시 예약을 해제하지만 한 수당 피해·충전 제한은 별도로 유지한다. 비행 중 목표가 사라지면 미션 후보를 다시 찾고, 없으면 일반 블록을 무작위로 선택한다. 일반 블록도 없을 때만 추가 타격 없이 종료한다.

## 파워 블록 연쇄 발동

- 수를 시작할 때 이미 보드에 있던 파워 블록은 파괴 효과에 맞으면 즉시 기본 효과로 연쇄 발동한다. 거미줄로 덮인 경우에는 아래 덮개 규칙을 먼저 적용한다.
- 같은 파워 블록은 여러 효과에 맞아도 한 번만 발동한 뒤 소모한다. 피격 발동을 낙하 이후로 예약하는 방식은 사용하지 않는다.
- 이번 수의 매칭으로 새로 생성한 파워 블록은 해당 수의 전체 연쇄가 끝날 때까지 피격에 의한 발동·제거로부터 보호한다. 낙하·보충 과정에서는 정상적으로 이동하며, 다음 플레이어 수부터 기존 파워 블록과 동일하게 처리한다.
- 무지개 자석 조합으로 일반 블록을 변환한 파워 블록은 이 보호의 예외로, 조합 효과에 따라 바로 발동한다.
- 무지개 자석이 다른 파괴 효과에 맞아 연쇄 발동하면, 현재 보드에 남아 있는 일반 달토끼의 색 중 하나를 무작위로 골라 제거한다.
- 전용 조합 효과는 플레이어가 두 파워 블록을 직접 교환했을 때만 적용한다. 효과 범위에서 파워 블록 여러 개가 함께 맞았다는 이유로 조합 효과를 만들지 않는다.
- 한 수에서 발생한 여러 폭발이나 연쇄 효과가 겹쳐도 같은 장애물은 최대 1회만 피해를 받는다. 예를 들어 내구도 3인 장애물이 한 수에 달 폭탄 세 개의 폭발을 맞아도 내구도는 2가 된다. 대형 폐가전은 예외로 아래의 개별 타격·반복 피해 규칙을 적용한다.
- 현재 효과와 기존 파워 블록의 즉시 연쇄, 드론 이동·타격을 모두 마친 뒤 낙하·보충한다. 모든 블록이 자리 잡은 뒤 자동 매칭을 판정한다.
- 낙하·보충 후 생긴 매칭은 추가 이동 횟수를 소비하지 않고 자동으로 처리한다. 직선 4·5개, ㄱ·ㄴ·T, 2×2 조건을 만족하면 직접 교환으로 만든 매칭과 동일하게 파워 블록을 생성한다.
- 제거와 효과 처리가 끝나면 다시 낙하·보충한다. 효과와 자동 매칭이 모두 없어져 보드가 안정될 때까지 반복한다.
- 직접 교환으로 만든 파워 블록은 플레이어가 움직인 블록의 도착 칸에 생성한다.
- 자동 매칭으로 만든 파워 블록은 마지막으로 도착해 매칭을 완성한 블록의 칸에 생성한다.
- 여러 블록이 동시에 도착해 매칭을 완성하면, 동시에 도착한 후보 블록의 칸 중 하나를 무작위로 골라 파워 블록을 생성한다.
- 한 번의 교환으로 양쪽에 서로 별개의 파워 블록 생성 패턴이 완성되면 각각 인정한다. 교환된 각 블록의 도착 칸에 해당 파워 블록을 하나씩 생성한다.
- 원래 생성 위치가 거미줄에 묶인 칸이면 그 칸은 거미줄에 한 단계 피해를 적용하고, 같은 매칭에 참여한 덮개 없는 다른 칸에 파워 블록을 생성한다. 대체 칸은 원래 위치에서 가로·세로 칸 수의 합이 가장 작은 칸으로 고르며, 같은 거리의 후보가 여럿이면 무작위로 선택한다.

## 장애물

- 장애물의 종류와 규칙을 먼저 정하고 등장 레벨 배치는 이후에 검토한다. 기존 나무상자 6레벨·거미줄 21레벨 기록은 그때 함께 검토하며, 고철 31레벨 제안은 채택하지 않았다.

### 공통 피해 규칙

- 같은 장애물은 한 수의 전체 연쇄 동안 최대 1회만 피해를 받는다. 대형 폐가전은 별도 규칙에 따라 반복 피해를 받는다.
- 일반 매칭은 상하좌우로 인접한 나무상자에 피해를 준다. 파워 효과는 장애물 칸에 직접 닿아야 피해를 주며, 주변 일반 블록만 제거한 것으로 인접 피해를 주지는 않는다.
- 청소로켓은 내구도가 남은 장애물을 포함한 모든 블록을 관통하여 해당 행·열의 끝까지 효과를 적용한다. 장애물의 한 수당 피해 제한은 유지한다.

### 나무상자 — 첫 장애물

- 한 칸을 차지하는 고정 장애물로, 교환하거나 낙하하지 않는다.
- 고정 장애물은 시작 배치 이후 일반적으로 추가 생성·보충하지 않는다. 특별한 이벤트가 있는 경우에만 예외를 허용하며, 이벤트 조건과 방식은 미정이다.
- 상하좌우 인접 일반 매칭 또는 직접 닿는 파워 효과로 내구도가 1 감소한다. 내구도가 0이 되면 제거한다.
- 제작자가 내구도를 1~6단계로 지정한다. 처음에는 1단계로 소개한다. 6단계 상자는 최소 여섯 수에 걸쳐 피해를 받아야 제거된다.
- 나무판을 덧댄 정도로 단계를 구분하고, 피해를 받으면 보강판이 떨어져 나가도록 표현한다.

### 거미줄 — 두 번째 장애물

- 블록 위에 씌우는 고정 덮개다. 제작자가 내구도를 1~3단계로 지정할 수 있으며, 21레벨에서는 1단계로 소개한다. 완전히 제거될 때까지 안의 블록은 이동·낙하·직접 발동할 수 없다.
- 덮인 일반 달토끼는 교환·낙하할 수 없지만, 주변 블록의 이동으로 같은 종류의 매칭에 참여할 수 있다.
- 덮인 달토끼가 매칭에 참여하거나 파워 효과가 해당 칸에 직접 닿으면 거미줄에 한 단계 피해를 적용하고 안의 블록은 남긴다. 같은 매칭의 다른 일반 블록은 제거한다.
- 단순히 인접한 칸에서 매칭이 발생한 것으로는 거미줄이 제거되지 않는다. 거미줄이 벗겨지면 안의 블록은 정상적으로 이동·낙하한다.
- 파워 블록에도 씌울 수 있다. 덮인 동안 교환·더블터치·더블클릭으로 발동할 수 없다.
- 거미줄을 벗기는 한 번의 타격으로 안의 파워 블록까지 발동하지 않는다. 이후 같은 수에 별도의 타격을 받으면 기존 파워 블록은 즉시 연쇄 발동한다. 이번 수에 매칭으로 새로 생성한 파워 블록의 보호 규칙은 유지한다.
- 거미줄 피해는 한 수당 최대 1회다. 이미 피해를 받았어도 안의 달토끼는 새로 만들어진 매칭에 계속 참여한다. 새 블록의 낙하로 다시 매칭되면 일반 블록은 제거하되 거미줄에 추가 피해는 주지 않는다.
- 새 블록 유입 등 상태 변화 없이 남아 있는 동일 매칭은 반복 처리하지 않는다. 피해받은 거미줄 블록 자체를 이후 자동 매칭에서 제외하는 방식은 사용하지 않는다.
- 일반 플레이에서는 거미줄이 새로 생기거나 번지지 않는다. 특수한 경우에는 추가될 수 있으나 조건과 방식은 추후 정한다.

### 고철 뭉치 — 이동 가능한 장애물

- 고정 나무상자와 별도 종류다. 일반 블록과 같은 수직·대각선 낙하 및 지정 경로를 따라 움직인다.
- 내구도는 1~5단계다. 상하좌우 인접 일반 매칭 또는 파워·아이템의 직접 타격으로 한 단계 손상되며, 한 수당 최대 1회만 피해를 받는다.
- 고철 뭉치끼리 또는 일반 블록과 함께 매칭되지 않는다. 일반 블록과 교환해 일반 블록의 매칭이 완성되면 유효한 수로 인정한다. 매칭이 생기지 않으면 되돌린다.
- ‘자리 바꾸기’로도 이동할 수 있으며, 이때는 매칭이 없어도 교환한 위치를 유지한다. 빈칸과의 교환은 허용하지 않는다.
- 회색의 둥근 고철 뭉치에 금속 띠를 겹쳐 표현한다. 내구도 5는 띠 4개, 4는 3개, 3은 2개, 2는 1개, 1은 띠 없는 본체다. 타격마다 띠 하나가 끊어지고 마지막 타격에 본체가 부서진다.
- 청소로켓·달 폭탄·수거 드론과 일반 교환하면 매칭 없이도 해당 파워 블록이 발동하며 한 수를 소비한다. 무지개 자석과의 일반 교환은 취소하고 원위치로 되돌리며 이동 횟수를 소비하지 않는다. ‘자리 바꾸기’는 기존대로 위치만 교환한다.
- 자동 재배치와 ‘섞기’ 아이템의 대상에서 제외하며 위치와 남은 내구도를 유지한다.
- 고철 제거를 레벨 미션으로 지정할 수 있다. 내구도 단계와 관계없이 뭉치 하나를 완전히 제거하면 1개로 집계한다.
- 레벨 설정에 따라 생성 위치에서 추가 공급할 수 있다. 고철 개수 유지 또는 미리 쌓아둔 고정 공급 목록을 사용한다.
- 해금 레벨은 미정이다.
- 고철에는 거미줄을 씌우지 않는다. 거미줄은 일반 블록과 파워 블록에만 적용한다.
- 고철 제거 미션이 있으면 드론의 우선 타격 후보에 포함한다. 여러 단계의 내구도가 남아 있어도 가능하지만 이번 수에 이미 피해를 받은 고철은 제외한다.
- 무지개 자석끼리의 조합도 고철 내구도를 1단계만 손상시킨다. 이번 수에 이미 피해받았다면 추가 피해는 없다.

### 먼지 — 바닥형 장애물

- 블록 뒤의 바닥 칸에 고정되며 교환·낙하를 막지 않는다. 위의 블록이 이동하거나 제거되어도 원래 칸에 남는다.
- 내구도는 1~3단계다. 옅은 먼지·작은 먼지 더미·두꺼운 먼지 더미로 구분하며, 한 수의 전체 연쇄 동안 최대 1단계만 손상된다.
- 나무상자·고철 뭉치·거미줄과 같은 칸에 배치할 수 있다. 위쪽 내용물에 가려지지 않도록 칸 가장자리에도 먼지를 표시한다.
- 먼지 위의 일반 블록이 매칭이나 파워 효과로 제거될 때 먼지를 1단계 손상시킨다. 인접 매칭이나 고물 망치의 직접 타격으로는 먼지가 제거되지 않는다.
- 위에 장애물·파워 블록이 있거나 빈칸이면 파워 효과가 닿아도 먼지는 남는다. 위쪽 장애물과 먼지에 동시에 피해를 주는 방식은 사용하지 않는다.
- 거미줄만 손상되고 안의 일반 블록이 남으면 먼지도 그대로 남는다.
- 매칭으로 일반 블록이 파워 블록으로 바뀌는 생성 칸은 예외적으로 먼지도 1단계 손상시킨다.
- 무지개 자석 조합으로 일반 블록이 파워 블록으로 변환되는 칸도 먼지를 1단계 손상시킨다. 거미줄 때문에 변환되지 않은 칸의 먼지는 남긴다. 변환 뒤의 후속 효과에도 한 수당 피해 제한을 유지한다.
- 먼지 제거를 레벨 미션으로 지정할 수 있다. 내구도와 관계없이 한 칸의 먼지를 완전히 제거하면 1개로 집계한다.
- 먼지 제거 미션이 있으면 드론은 일반 블록이 올라가 있고 이번 수에 아직 피해받지 않은 먼지 칸을 우선 타격 후보에 포함한다. 거미줄로 묶여 일반 블록을 제거할 수 없는 칸은 먼지 미션 후보에서 제외한다.
- 시작 시 배치하며 일반 플레이 중 추가 생성되거나 주변으로 퍼지지 않는다.
- 자동 재배치와 ‘섞기’에서도 먼지의 위치와 내구도는 그대로 유지하며 위쪽 블록만 기존 규칙에 따라 섞는다.

### 우주 곰팡이 — 확산하는 덮개 장애물

- 일반 블록과 파워 블록을 보존한 채 덮는다. 덮인 블록은 교환·낙하·매칭할 수 없다. 시작 배치와 확산 모두 다른 덮개가 없는 일반·파워 블록에만 허용하며, 거미줄에 묶인 블록이나 다른 장애물에는 겹치지 않는다. 바닥 먼지는 중첩할 수 있으며 곰팡이를 제거해도 먼지는 남는다.
- 불투명한 덩어리로 안의 블록 종류와 색을 완전히 가린다. 안의 일반 블록 색·파워 종류·청소로켓 방향은 그대로 보존하며 덮개 제거 후 다시 드러난다.
- 내구도는 1단계다. 상하좌우 인접 일반 매칭 또는 파워 효과·고물 망치의 직접 타격으로 제거한다. 곰팡이를 벗기는 타격은 안의 블록까지 제거하지 않는다.
- 덮인 파워 블록은 직접 조작과 피격으로 발동할 수 없다. 덮개를 벗긴 타격으로도 발동하지 않고, 이후 별도 타격부터 발동한다. 매칭으로 새로 만든 파워 블록의 해당 수 피격 보호는 유지한다.
- 풀려난 일반 블록은 정상적으로 낙하하며, 보드가 안정된 뒤 자동 매칭에 참여한다. 덮개 제거로 드러난 블록들이 만든 매칭도 인정한다.
- 무지개 자석의 색상 선택·색 제거·색 기반 파워 변환 대상에서 곰팡이에 숨겨진 블록을 제외한다. 해당 효과로 곰팡이만 벗기는 것도 허용하지 않는다.
- 무지개 자석 + 무지개 자석의 보드 전체 직접 타격은 곰팡이를 제거한다. 안의 블록은 보존한다.
- 곰팡이 제거 미션은 고정 수량 수집이 아니라 보드에 남은 곰팡이를 전부 제거하는 목표다. 확산 시 남은 수량이 증가하고 제거 시 감소하며 0개가 되면 완료한다.
- 곰팡이 제거 미션이 있으면 드론의 우선 타격 후보에 포함한다. 안의 일반 블록·파워 블록 종류와 관계없이 덮개 제거 대상으로 취급한다.
- 자동 재배치와 ‘섞기’는 곰팡이와 그 안의 블록을 그대로 두고, 나머지 이동 가능한 블록만 기존 규칙에 따라 섞는다.

#### 곰팡이 확산

- 이동 횟수를 소비한 조작에서 곰팡이를 하나도 제거하지 못했다면, 전체 연쇄가 끝난 뒤 보드 전체에서 한 칸만 확산한다. 하나라도 제거했으면 그 수에는 확산하지 않는다.
- 게임 중 아이템 사용 뒤에는 확산하지 않는다. 아이템을 독립된 한 수로 다루는 기존 피해 규칙과 별개로, 확산 판정은 이동 횟수를 소비한 조작에만 적용한다.
- 기존 곰팡이의 상하좌우에 인접한 유효 블록 칸 중 하나를 무작위로 선택한다. 여러 곰팡이에 인접해도 동일 칸은 후보 하나로 계산한다. 다른 덮개가 없는 일반·파워 블록만 대상이며 바닥 먼지는 확산을 막지 않는다.
- 유효한 확산 대상이 없으면 확산하지 않는다. 모든 곰팡이를 제거하면 그 판에서는 다시 발생하지 않는다.
- 전체 연쇄 후 모든 미션을 달성했다면 확산 전에 클리어를 확정한다. 곰팡이가 미션에 포함되지 않은 레벨도 같다.
- 확산 후 유효한 행동이 없으면 기존 자동 재배치 규칙을 적용한다. 곰팡이와 그 안의 블록은 재배치하지 않는다.
- 마지막 이동 후 미션이 남았다면 곰팡이 확산까지 처리한 뒤 실패 화면을 표시한다. 광고·아이템 이어하기 모두 확산이 반영된 보드에서 진행한다.
- 앱 강제 종료 후 곰팡이 위치·안의 블록·확산 결과를 그대로 복구한다. 확산 도중 종료해도 대상이 바뀌거나 같은 확산이 두 번 적용되지 않도록 기존 상태 저장·행동 재실행 규칙에 포함한다.

### 잠긴 고물 금고 — 파워 타격 중심의 고정 장애물

- 이동하지 않는 고정 장애물이다. 일반 매칭으로는 손상되지 않으며 파워 블록의 직접 타격으로 손상된다. 고물 망치도 예외적으로 1단계 피해를 줄 수 있다.
- 내구도는 1~5단계다. 정면의 굵은 잠금 막대 1~5개로 구분하며, 피해를 받을 때 막대를 하나씩 제거한다. 한 수의 전체 연쇄 동안 최대 1단계만 손상된다.
- 금고 제거를 레벨 미션으로 지정할 수 있다. 내구도와 관계없이 완전히 파괴한 금고 하나를 1개로 집계한다.
- 금고 제거 미션이 있으면 드론의 우선 타격 후보에 포함한다. 여러 단계 내구도가 남아 있어도 가능하지만 이번 수에 이미 피해받은 금고는 제외한다.
- 완전히 파괴되면 빈칸이 되고 기존 낙하·보충 규칙으로 채운다. 내부 보상이나 별도 블록을 생성하지 않는다.

### 색깔 자물쇠 — 지정 색 매칭으로 손상되는 고정 장애물

- 표시된 색의 일반 블록이 상하좌우 인접 칸에서 매칭되면 손상되는 고정 장애물이다. 파워 블록과 고물 망치의 직접 타격도 색과 관계없이 피해를 준다.
- 내구도는 1~3단계이며, 제거될 때까지 지정 색을 유지한다. 한 수의 전체 연쇄 동안 최대 1단계만 손상된다.
- 제작자가 해당 레벨에서 사용하는 달토끼 색 중 하나를 지정한다. 색과 달토끼 표식을 함께 표시한다.
- 제거 미션에서는 색을 구분하지 않고 완전히 제거한 자물쇠 개수를 합산한다.
- 지정 색 매칭에 참여한 칸이 상하좌우로 인접하면 피해를 준다. 그 칸이 파워 블록 생성 칸이 되어 남아도 인접 매칭 피해를 인정한다.
- 자물쇠 제거 미션이 있으면 드론은 색과 관계없이 이번 수에 아직 피해받지 않은 자물쇠를 우선 타격 후보에 포함한다.
- 무지개 자석의 색 제거는 자물쇠 자체를 직접 타격하지 않는다. 다만 자물쇠와 같은 색의 상하좌우 인접 일반 블록을 자석으로 제거하면 자물쇠에 1피해를 준다. 이는 파워로 주변 블록을 제거해도 인접 피해가 없는 공통 규칙의 예외이며, 한 수당 최대 1피해 제한은 유지한다.
- 인접 블록과 자물쇠 사이에 고철 벽이 있으면 위의 인접 피해는 전달되지 않는다. 자석과 다른 파워의 조합으로 일반 블록이 변환되는 것만으로는 인접 피해를 주지 않으며, 이후 발동한 파워가 자물쇠를 직접 타격할 때 피해를 준다.

### 대형 폐가전 — 2×2칸을 차지하는 고정 장애물

- 활성 상태인 2×2 네 칸을 차지하며 하나의 내구도를 공유한다. 내구도는 1~9단계로 설정한다.
- 다른 블록이나 같은 공간을 차지하는 장애물과 겹쳐 배치할 수 없다. 바닥의 먼지는 중첩할 수 있다.
- 본체 정면에 큼직한 십자 나사 머리 최대 8개를 두 줄로 배치한다. 내구도 9는 나사 8개와 본체, 내구도 1은 나사 없는 본체다. 피해량만큼 나사가 빠지고 마지막 피해에 본체가 파괴된다.
- 나사는 맞은 칸의 위치와 관계없이 정해진 순서로 제거한다. 같은 남은 내구도는 항상 같은 외형으로 표시한다.
- 내구도가 남아 있는 동안 네 칸 모두를 계속 막으며 부분적으로 통로가 열리지 않는다. 완전히 파괴될 때 네 칸이 함께 비워진다. 아래의 먼지는 그대로 남는다.
- 파워 효과가 차지한 칸을 직접 타격하면 맞은 칸마다 1피해를 준다. 개별 타격 한 번에는 최대 4피해지만 한 수 전체의 피해 상한은 아니다. 같은 칸을 포함한 이후 반복 타격도 추가 피해를 준다.
- 예를 들어 로켓이 두 칸을 관통하면 2피해, 이어서 폭탄이 네 칸을 덮으면 추가 4피해로 총 6피해다. 무지개 자석끼리 조합한 전체 타격은 네 칸에 총 4피해를 준다.
- 일반 매칭은 매칭 블록과 상하좌우로 맞닿은 폐가전 칸마다 1피해를 준다. 같은 매칭에서 동일한 폐가전 칸은 한 번만 계산한다. 이후 연쇄 매칭은 다시 피해를 줄 수 있다.
- 한 번의 교환으로 동시에 생긴 서로 별개의 매칭은 각각 별도 타격이다. 두 매칭이 같은 폐가전 칸에 닿아도 각각 피해를 준다.
- 고물 망치는 네 칸 중 어느 칸을 선택하든 공유 내구도에 1피해를 준다.
- 제거 미션은 네 칸을 개별 집계하지 않고 본체 하나를 완전히 파괴하면 1개로 집계한다.
- 수거 드론은 네 칸을 각각 타격 후보로 삼는다. 여러 드론이 서로 다른 칸을 겨냥할 수 있고, 앞선 타격 후에도 본체가 남으면 후속 드론이 다시 피해를 줄 수 있다. 다른 드론이 현재 겨냥한 칸의 중복 예약 제외는 유지한다.
- 2×2 내부 경계에는 고철 벽을 설치할 수 없고 외곽 경계에는 설치할 수 있다. 벽 너머 매칭은 인접 피해를 주지 않으며 파워 효과는 벽을 통과한다.

## 고장 난 발전기 — 일회용 충전 장치

- 2×2 네 칸을 차지하는 고정 장치다. 교환·낙하·재배치되지 않으며 충전 완료 또는 자동 철거까지 위치를 유지한다.
- 제작자가 발전기마다 필요한 충전량을 3~5회로 지정한다. 본체에 큰 표시등을 필요한 횟수만큼 배치하고 충전할 때마다 하나씩 켠다.
- 외곽의 상하좌우 인접 일반 매칭 또는 네 칸 중 어느 칸에든 닿는 파워·고물 망치의 직접 타격으로 충전한다. 여러 칸과 여러 효과가 닿아도 발전기 전체가 한 수의 전체 연쇄에서 최대 1회만 충전된다.
- 완충되면 현재 효과 처리 중 즉시 연결된 장애물을 남은 내구도와 관계없이 완전히 제거한다. 진행 중인 파워 효과·연쇄가 끝난 뒤 낙하·보충한다.
- 연결 대상 자체만 제거하며 주변에 추가 폭발 피해를 주지 않는다. 제거된 장애물은 직접 파괴한 것과 동일하게 해당 제거 미션에 집계하며 대형 폐가전은 본체당 1개다.
- 작동을 마친 발전기도 사라지며, 빈칸은 기존 낙하·보충 규칙으로 채운다.

### 발전기의 연결 대상과 전선

- 연결 대상은 나무상자·잠긴 고물 금고·색깔 자물쇠·대형 폐가전이다.
- 발전기 하나당 장애물 1~3개를 연결한다. 연결 대상이 없으면 에디터에서 설정 오류로 처리한다. 하나의 장애물은 발전기 하나에만 연결할 수 있다.
- 플레이어가 연결 대상을 먼저 직접 파괴하면 해당 연결을 해제하고 전선·대상 단자도 없앤다. 다른 장애물로 대체 연결하지 않으며, 발전기 작동 시 남아 있는 대상만 제거한다.
- 연결 대상을 모두 직접 파괴하면 발전기도 충전 없이 자동 철거되어 사라진다.
- 전선은 블록 내부가 아닌 블록과 블록 사이의 틈을 따라 지나가며, 양 끝만 발전기와 대상의 연결 단자로 들어간다. 고철 벽이 있는 경계는 피하고 전선끼리 교차하지 않게 배치한다.
- 전선은 이동·매칭에 영향을 주지 않는다. 레벨 에디터에서 제작자가 경로를 직접 지정하며 플레이 중 블록이 움직여도 그 경로를 유지한다.
- 발전기와 대상에는 같은 색·모양의 단자를 표시해 색만으로 구분하지 않도록 한다. 충전 시 전선을 따라 짧은 빛이 흐른다.
- 전선은 가늘고 둥근 피복, 고철 벽은 두껍고 각진 금속판으로 표현해 역할을 구분한다. 전선 경로는 항상 확인할 수 있어야 한다.

### 발전기와 수거 드론

- 남은 미션 목표인 장애물에 연결된 발전기도 드론의 우선 타격 후보에 포함한다. 이번 수에 이미 충전된 발전기는 추가 충전이 불가능하므로 제외한다.
- 발전기의 네 칸은 하나의 충전 대상으로 묶는다. 한 드론이 겨냥하면 다른 드론은 그 발전기의 네 칸 모두를 후보에서 제외한다.

## 고철 벽 — 칸 사이의 고정 지형

- 블록 칸 자체를 차지하지 않고 두 칸 사이의 경계에 설치한다. 파괴할 수 없는 고정 지형이다.
- 벽을 가로지르는 블록 교환과 낙하를 차단한다. 매칭 연결도 벽에서 끊기므로 같은 색이라도 벽을 넘어 하나의 매칭으로 계산하지 않는다.
- 청소로켓은 벽을 관통하여 반대편도 끝까지 타격하며 벽 자체는 남긴다. 달 폭탄·수거 드론·무지개 자석을 포함한 모든 파워 효과는 벽과 관계없이 기존 효과 범위와 대상 규칙을 적용한다.
- 대각선 낙하에서는 출발 칸부터 목적지까지 가로→세로 또는 세로→가로로 이어지는 두 경로 중 하나 이상이 벽 없이 연결되어야 한다. 둘 다 벽에 막히면 대각선 이동할 수 없다. 이 조건은 벽 통과 검사이며 기존 수직 우선·구역·목적지 등 대각선 낙하 조건도 함께 적용한다.
- 벽 너머로는 인접 매칭 피해와 곰팡이 확산도 전달되지 않는다. 파워 효과의 관통 규칙은 유지한다.
- 2×2 매칭 영역 내부의 네 경계 중 하나라도 벽이 있으면 수거 드론 생성 매칭을 인정하지 않는다.
- ‘자리 바꾸기’ 아이템도 벽을 가로질러 교환할 수 없다.
- 자동 재배치와 ‘섞기’는 벽으로 분리된 구역 사이에도 블록을 재배치할 수 있다. 벽과 기존 재배치 제외 대상은 그대로 유지한다.
- 제작자가 지정한 낙하 경로가 벽을 통과하면 레벨 에디터에서 오류로 표시하고 플레이를 막는다.

## 생성 위치별 공급 설정

### 생성구의 위치와 공급 순서

- 새 블록은 에디터에서 지정한 생성구에서만 공급한다. 기본 보드는 상단 생성구를 미리 배치하며 구역 중력 변경만으로 생성구가 자동 추가되지는 않는다.
- 보드 가장자리뿐 아니라 내부 활성 칸에도 생성구를 지정할 수 있다. 생성구 칸이 차 있으면 기다리고 비었을 때만 생성한다.
- 생성구 칸으로 낙하·통로를 통해 기존 블록이 들어올 수 있으면 그 공급을 먼저 처리한다. 그래도 칸이 비어 있을 때 새 블록을 생성한다.
- 생성구와 회수 부품의 도착 바닥은 같은 칸에 배치할 수 없다.
- 생성구는 지정 칸에 블록을 공급하고 이후 이동은 그 칸의 중력·경로를 따른다. 생성구 자체에 별도 이동 방향을 지정하지 않는다.

### 고정 공급 목록

- 레벨 에디터에서 N개의 생성 위치에 총 M개의 공급 블록을 나누어 미리 쌓아둘 수 있다. 위치별 종류·수량·순서를 직접 지정한다.
- 일반 달토끼·파워 블록·고철 뭉치·회수 부품 등 이동 가능한 블록을 지정할 수 있다. 고정 장애물은 이 공급 대상에서 제외한다.
- 청소로켓의 방향과 고철 뭉치의 내구도 등 블록 상태도 지정한다. 일반 달토끼는 해당 레벨에서 사용하는 색상만 지정할 수 있다.
- 생성구에 가장 가까이 쌓인 블록부터 차례대로 공급한다. 쌓아둔 목록은 에디터에서만 보이며 플레이 중에는 보드로 들어올 때 처음 나타난다.
- 미리 쌓아둔 블록은 지정한 위치에서만 생성한다. 생성구가 막히면 순서를 유지한 채 기다리며 다른 생성구로 옮겨 나오지 않는다.
- 최초 보드 배치는 별도로 설정한다. 고정 공급 목록은 최초 보드를 채우는 데 사용하지 않고 게임 시작 후 빈칸을 보충할 때부터 소비한다.
- 목록을 모두 소진한 뒤에는 위치별로 공급 중단 또는 일반 달토끼 무작위 공급 전환을 지정한다. 무작위 공급은 레벨에서 선택한 색상 안에서 균등 확률로 처리한다.
- 생성구에서 공급된 파워 블록은 보드에 들어온 뒤 피격되면 즉시 발동한다. 매칭으로 새로 만든 파워 블록의 피격 보호는 적용하지 않는다.

### 고철 개수 유지

- 레벨마다 보드에 유지할 고철 개수와 추가 생성 한도를 지정한다. 고철이 제거되어 목표 개수보다 부족하면 지정 생성 위치에서 보충한다.
- 이 방식으로 공급하는 고철의 내구도는 레벨별로 하나를 지정해 동일하게 적용한다. 서로 다른 내구도를 순서대로 공급하려면 고정 공급 목록을 사용한다.
- 추가 생성 한도는 최초 배치한 고철을 제외한 수량이다. 예를 들어 최초 2개, 유지 목표 2개, 추가 한도 6개이면 최초 배치 외에 최대 6개를 더 공급한다.
- 여러 지정 위치 중 현재 생성 가능한 위치를 무작위로 선택한다. 부족한 수량만큼 하나씩 배정하여 유지 목표와 추가 생성 한도를 넘기지 않는다.
- 모든 지정 생성구가 막혀 있으면 비워질 때까지 기다린다. 실제 생성되었을 때만 추가 생성 한도를 차감한다.
- 고철이 부족하고 추가 생성 한도가 남아 있으면 일반 블록보다 고철을 우선 공급한다. 유지 목표가 충족되거나 추가 한도를 소진하면 일반 달토끼를 공급한다.

### 생성 방식의 충돌 제한

- 한 레벨 안에서 서로 충돌하는 생성 방식을 함께 설정할 수 없다. 생성 위치가 달라도 같은 제한을 적용한다.
- 고철을 고정 목록의 지정 순서·수량으로 공급하면서 고철 개수 유지 방식으로 추가 보충하는 조합은 금지한다.
- 서로 영향을 주지 않는 여러 위치의 고정 공급 목록은 함께 사용할 수 있다.
- 고철과 회수 부품의 개수 유지 방식을 같은 레벨에서 사용할 때는 서로 다른 생성구를 지정한다. 생성구 하나는 둘 중 한 종류의 유지 방식만 맡고, 보충이 필요하지 않으면 일반 블록을 공급한다.

### 회수 부품의 공급

- 회수 부품은 최초 배치와 고정 공급 목록 외에 보드에 일정 개수를 유지하는 추가 공급 방식을 지원한다. 예를 들어 동시에 2개 유지·총 6개 회수 목표이면 하나를 회수한 뒤 다음 부품을 공급한다.
- 개수 유지 방식은 남은 회수 목표보다 많이 공급하지 않는다. 유지 개수가 3개라도 남은 목표가 1개이고 보드에 부품이 1개 있다면 추가 공급하지 않는다.

### 공급 상태 저장과 레벨 검사

- 재도전 시 고정 공급 목록과 고철 추가 생성 한도는 레벨 시작 상태로 초기화한다.
- 앱 강제 종료 후 진행 중인 판을 복구할 때는 남은 공급 목록과 고철 생성 잔여 한도도 복구한다. 공급 위치 등 무작위 결과 역시 기존 상태 저장·행동 재실행 규칙에 따라 유지한다.
- 제거 미션 목표가 최초 배치 수량과 최대 추가 공급 수량의 합을 넘으면 레벨 에디터에서 오류로 표시하고 플레이를 막는다. 예를 들어 고철 최초 2개·추가 최대 6개이면 제거 목표 9개는 허용하지 않는다. 이 수량 검사는 실제 경로와 이동 횟수까지 포함한 클리어 가능성을 보장하는 검사는 아니다.
- 회수 미션에 도착 바닥이 없거나 최초 배치와 최대 추가 공급으로 목표 수량을 채울 수 없으면 에디터 오류로 처리한다. 불완전한 작업 상태의 저장은 허용하되 필수 오류가 있으면 테스트 플레이를 막는다. 편집 동작은 [레벨 에디터](09_레벨에디터.md)를 따른다.

## 낙하·보충 방향

- 바닥과 위의 블록을 분리한다. 바닥에는 중력 방향·이동 경로·도착 기능을 지정하고 블록은 현재 칸의 규칙을 따른다.
- 구역을 선택해 상·하·좌·우 중력을 지정할 수 있으며, 복잡하게 꺾이거나 합류하는 흐름은 기존처럼 직접 경로로 지정할 수 있다. 설정하지 않은 칸은 아래 방향이다.
- 아래의 수직 우선·대각선 채우기 설명은 아래 중력 기준이다. 다른 방향 지정 구역에는 중력 방향에 맞춰 회전 적용한다. 예를 들어 오른쪽 중력은 왼쪽에서 먼저 공급받고, 막혔으면 왼쪽 위·아래에서 대각선으로 받는다.
- 기본 낙하 방향은 위에서 아래다. 기본 보충 위치는 보드 상단이다.
- 기본 낙하는 수직을 우선하며, 빈칸을 수직으로 채울 수 없으면 왼쪽 위·오른쪽 위에서 대각선으로 채울 수 있다. 공급할 블록도 자기 바로 아래가 비어 있으면 먼저 수직으로 내려가며, 아래가 막혀 있을 때만 대각선으로 이동한다.
- 한 빈칸에 양쪽 위 블록 모두 공급할 수 있으면 무작위로 한쪽을 고른다. 블록 하나가 왼쪽 아래·오른쪽 아래 모두로 갈 수 있을 때도 목적지를 무작위로 고른다.
- 대각선 이동 후에도 수직 우선으로 낙하·보충을 반복한다. 더 이상 이동할 블록이 없을 때 매칭을 판정한다.
- 자동 대각선 이동은 출발·도착 칸이 모두 같은 방향의 중력 구역일 때만 허용한다. 서로 다른 중력 방향 사이에는 허용하지 않으며 직접 경로를 지정한 구역도 임의로 대각선 유입·유출하지 않는다.
- 직선 낙하는 다른 중력 구역으로 넘어갈 수 있다. 목적지가 비어 있고 벽이 없어야 하며, 진입한 칸부터 해당 구역의 중력을 따른다.
- 비활성 칸을 건너뛰는 낙하는 허용하지 않는다. 다만 그 아래 빈칸이 활성 칸과 대각선으로 맞닿아 있으면 위 조건에 따라 옆에서 채울 수 있다. 청소로켓은 기존대로 비활성 칸을 통과한다.
- 수직·대각선 어느 쪽에서도 공급할 수 없으면 빈칸을 그대로 둔다. 장애물을 통과시키거나 막힌 빈칸에 새 블록을 직접 생성하지 않는다. 제작자가 별도 공급 지점을 지정한 경우에는 해당 공급을 사용할 수 있다.
- 한 보드 안에서도 구역별로 다른 이동 흐름을 지정할 수 있다. 블록은 강물이 흐르듯 지정된 목표 지점을 향해 이동한다.
- 제작자가 목표 지점뿐 아니라 블록이 흐르는 경로까지 직접 지정한다. 블록은 지정된 경로를 따른다.
- 흐름을 별도로 설정하지 않은 구역에서는 기본적으로 아래로 낙하한다.
- 일반 경로의 끝 칸은 블록이 멈추는 곳이며 보드 밖으로 빠지는 출구가 아니다. 아래의 회수 부품 전용 도착 바닥은 별도 기능이다.
- 특수 경로의 새 블록 공급 지점도 제작자가 지정한다.
- 여러 경로의 합류를 허용하며, 제작자가 합류 지점의 우선 경로를 지정한다.
- 서로 다른 중력 구역에서 한 칸으로 합류하는 경우도 유입 우선순위를 지정한다. 우선 공급원이 비었거나 막혔으면 다음 공급원을 확인한다.
- 우선 경로에서 블록을 공급할 수 있으면 먼저 받는다. 그 경로가 비었거나 막혀 공급할 수 없으면 다른 경로에서 받는다.
- 한 칸에서 다음으로 이동할 칸은 하나로 고정한다. 경로가 두 갈래 이상으로 갈라지는 분기는 허용하지 않는다.
- 순환 경로는 금지한다. 모든 경로는 끝 칸에 도달해야 한다.
- 구역별 중력·직접 지정한 경로·이동 통로 연결을 합쳐 순환 여부를 검사한다. 서로 마주 보는 흐름이나 여러 구역을 잇는 순환, 출구에서 같은 입구로 되돌아오는 흐름이 있으면 레벨 에디터에서 오류로 처리한다.
- 경로는 상하좌우 인접 칸끼리 연결한다. 위쪽으로 흐르는 경로도 허용한다.
- 다음 칸이 비어 있을 때만 블록이 이동한다. 차 있으면 기다린다.
- 경로는 한 판이 진행되는 동안 고정하며, 플레이 중에는 변경하지 않는다.
- 서로 다른 낙하 구역도 활성 칸이 인접해 있으면 경계를 넘어 교환·매칭할 수 있다. 이동한 블록은 도착 칸의 낙하 경로를 따른다.
- 생성 위치와 공급 순서는 위의 생성구 규칙을 따른다. 별도 공급 방향은 두지 않으며 생성 시각 표현 등 세부 사항은 후속 기획에서 정한다.

## 이동 통로 바닥

- 입구 하나와 출구 하나를 잇는 단방향 연결이다. 일반·파워 블록·고철 뭉치·회수 부품 등 이동 가능한 블록은 입구에서 출구로 이동한 뒤 출구 칸의 중력을 따른다.
- 출구가 차 있으면 입구에서 기다리며 출구가 비었을 때 이동한다. 기존 블록을 밀어내거나 겹쳐 놓지 않는다.
- 입구에서는 통로 이동을 우선한다. 출구가 막혀도 일반·대각선 낙하로 빠져나가지 않고 기다리지만 플레이어의 유효한 교환은 허용한다.
- 입구와 출구는 이동만 연결하며 서로 인접한 칸으로 취급하지 않는다. 원격 매칭·교환·인접 피해·곰팡이 확산은 전달되지 않는다.
- 파워 효과는 통로를 타고 전달되지 않는다. 로켓을 포함한 모든 파워는 실제 보드 위치를 기준으로 기존 범위와 대상 규칙을 적용한다.
- 출구에 통로와 주변 중력으로부터 공급이 합류하면 통로도 기존 유입 우선순위에 포함하고 제작자가 순서를 지정한다.
- 한 레벨에 여러 쌍을 배치할 수 있고 각 쌍은 독립적인 1:1 연결이다. 입구·출구에 같은 색과 문양을 표시하여 짝을 구분한다.
- 한 칸은 통로 입구 또는 출구 중 하나만 맡는다. 통로를 연달아 연결하려면 사이에 일반 칸을 둔다.
- 회수용 도착 바닥과 통로 입구·출구는 같은 칸에 배치할 수 없다. 출구에서 나온 부품은 별도 도착 칸으로 이동해야 회수된다.
- 입구·출구 바닥에도 먼지를 배치할 수 있다. 통로 이동만으로 먼지가 제거되지는 않고 해당 칸에서 기존 먼지 제거 조건을 만족해야 한다.
- 입구·출구 위에 고정 장애물을 시작 배치할 수 있으며 제거하기 전까지 해당 칸을 통한 이동은 막힌다.
- 입구의 블록이 거미줄·곰팡이에 묶여 있으면 덮개를 제거하기 전까지 통로로 이동하지 않는다.

## 회수 부품과 도착 바닥

- 회수 부품은 퍼즐의 목표 지점까지 이동시켜야 하는 오브젝트다. 주문의 배달 작업과는 별개인 퍼즐 미션이다.
- 매칭에 참여하지 않고 파워 효과나 고물 망치로 파괴되지 않는다. 중력과 지정 경로를 따라 이동한다.
- 일반 블록과 교환해 일반 매칭이 성립하면 유효하다. 성립하지 않으면 원위치로 되돌리고 이동 횟수를 소비하지 않는다.
- 청소로켓·달 폭탄·수거 드론과 교환하면 해당 파워가 발동한다. 무지개 자석과의 교환은 비용 없이 취소한다.
- 자동 재배치와 ‘섞기’에서는 회수 부품의 위치를 유지한다. ‘자리 바꾸기’로는 인접한 이동 가능 블록과 매칭 없이 교환할 수 있다. 벽을 넘거나 빈칸과 교환하는 것은 허용하지 않는다.
- 도착 바닥은 지정된 회수 부품만 회수하며, 일반·파워 블록에는 해당 칸의 중력 규칙을 그대로 적용한다. 아래뿐 아니라 옆·위 등 어느 방향에도 배치할 수 있다.
- 한 레벨의 모든 도착 바닥은 같은 회수 부품을 받아들인다. 부품별 목적지를 구분하지 않으며 어느 도착 바닥으로 보내도 회수한다.
- 회수 부품이 도착 바닥에 들어오면 즉시 보드에서 회수하고 미션 남은 수량을 줄인다. 낙하 도중에도 회수로 빈칸을 만들고 뒤따르는 블록의 낙하를 계속 처리한다. 클리어 판정은 전체 연쇄가 끝난 뒤 한다.

## 행동이 없을 때의 자동 재배치

- 유효한 교환이 없고 발동할 수 있는 파워 블록도 없으면 이동 가능한 일반 블록과 파워 블록을 함께 자동으로 섞는다.
- 자동 재배치는 이동 횟수를 소비하지 않는다.
- 장애물·거미줄에 묶인 블록·경로는 그대로 유지한다.
- 재배치로 파워 블록을 발동하지 않으며 위치만 바꾼다. 청소로켓의 방향은 유지한다.
- 자동 재배치 후 완성된 매칭이 없고, 유효한 교환 또는 발동 가능한 파워 블록이 하나 이상 있으면 성공이다. ‘섞기’ 아이템에도 같은 조건을 적용한다.
- 자동 재배치로도 유효한 행동을 만들 수 없으면 진행 불가로 판을 종료하고 무료 재도전을 제공한다.
- 진행 불가 종료 시 해당 판에서 사용한 아이템과 배치된 부스터를 반환하고, 보상을 받은 이어하기 광고의 일일 사용 횟수도 복구한다. 대기 중인 부스터는 원래 소모하지 않는다.

## 게임 중 사용하는 아이템

- 고물 망치·자리 바꾸기·섞기는 퍼즐 진행 중 사용하는 아이템이다. 시작 전 부스터와 구분한다.
- 세 아이템 모두 남은 이동 횟수를 차감하지 않는다. 사용 한 번과 그 후속 연쇄를 독립된 한 수로 처리한다.
- 보유 수량 안에서 한 판에 여러 번 사용할 수 있으며 별도의 판당 사용 한도는 없다. 효과와 후속 연쇄가 모두 끝나 보드가 안정된 뒤에만 다음 아이템을 사용할 수 있다.
- 망치·자리 바꾸기는 유효한 대상을 지정하여 효과가 실제 실행될 때만 차감한다. 대상 선택만으로는 소모하지 않으며, 취소하면 차감하지 않는다. 선택 불가능한 칸을 누르면 소모 없이 대상 선택 상태를 유지한다.
- 망치는 유효한 칸을 한 번 누르면 추가 확인 없이 실행한다. 섞기는 사용 확인창에서 확인한 뒤 실행하며, 취소하거나 재배치 성공 조건을 만족시킬 수 없으면 소모하지 않는다.
- 아이템 사용을 시작하면 이전 수에서 생성된 파워 블록의 보호는 끝나며, 장애물은 이번 아이템 사용에서 다시 피해를 받을 수 있다. 같은 장애물의 피해는 해당 아이템 사용과 전체 후속 연쇄를 합쳐 최대 1회다. 대형 폐가전에는 별도의 반복 피해 규칙을 적용한다.
- 아이템 사용으로 완성한 매칭에서 새로 만든 파워 블록에도 해당 수의 피격 보호 규칙을 적용한다.

| 아이템 | 확정 효과 |
| --- | --- |
| 고물 망치 | 선택한 한 칸에 피해를 준다. 일반 블록은 제거하고 장애물은 한 단계 손상시킨다. 파워 블록을 선택하면 해당 파워 블록이 발동한다. 거미줄에 덮여 있으면 거미줄에 한 단계 피해를 적용하고 안의 블록은 남기며, 그 타격으로 안의 파워 블록을 발동하지 않는다. |
| 자리 바꾸기 | 인접한 이동 가능한 두 블록을 교환한다. 매칭이 없어도 원위치로 되돌리지 않는다. 나무상자나 거미줄에 묶인 블록은 이동할 수 없다. 파워 블록은 위치만 바뀌며, 파워 블록끼리 바꿔도 발동·조합하지 않는다. 일반 블록의 매칭이 완성되면 정상적으로 제거·파워 생성·후속 연쇄를 처리한다. |
| 섞기 | 이동 가능한 일반 달토끼와 파워 블록을 함께 무작위로 재배치한다. 장애물·거미줄에 묶인 블록은 그대로 둔다. 파워 블록은 발동하지 않고 청소로켓 방향도 유지한다. 재배치 직후 완성 매칭이 없고 유효한 교환 또는 발동 가능한 파워 블록이 하나 이상 있어야 한다. |

## 시작 전 부스터

- 새 레벨 시작, 실패 후 다시 도전, 진행 중 재시작은 레벨 번호·부스터 3칸·시작 버튼·닫기를 제공하는 진입 화면을 거치며 매번 선택을 해제한다. 부스터가 전부 잠겨도 이 화면을 보여주며 미션·이동 횟수는 표시하지 않는다. 단, 1레벨은 이 화면을 건너뛴다.
- 시작 전 부스터는 최초에는 모두 잠겨 있으며 실제 첫 주문 완료 시 청소로켓, 두 번째 주문 완료 시 달 폭탄, 세 번째 주문 완료 시 무지개 자석을 해금한다. 보드의 매칭으로 파워 블록을 만드는 기능은 이 해금과 별개로 처음부터 사용 가능하다.
- 각 부스터 최초 해금 시 해당 부스터를 5분간 보유 수량 차감 없이 사용한다. 해금 순간부터 실제 시간으로 흐르며 앱 종료 중에도 감소한다. 종류별 판당 1개 제한은 유지하고 선택은 플레이어가 한다.
- 무한 사용 적용은 퍼즐 시작 시 확정한다. 시간이 남았을 때 시작한 판은 배치가 지연되어 시간이 만료되어도 해당 부스터 수량을 차감하지 않는다.
- 부스터 선택 후 퍼즐 시작 전에 시간이 만료되면 해당 선택을 해제한다. 보유 부스터를 쓰려면 다시 선택해야 한다.

- 청소로켓·달 폭탄·무지개 자석의 세 종류를 제공한다. 수거 드론은 시작 전 부스터에서 제외하며, 2×2 매칭 생성과 기존 조합 효과는 유지한다.
- 한 판에 종류별 최대 1개씩, 최대 3개를 함께 선택할 수 있다.
- 선택한 부스터는 게임 시작 시 무작위 일반 달토끼 칸을 해당 파워 블록으로 교체하여 배치한다. 장애물·거미줄에 묶인 블록·기존 파워 블록은 교체하지 않는다.
- 교체 가능한 블록이 없으면 해당 부스터는 대기한다. 교체 가능한 블록이 생긴 뒤, 현재 연쇄와 낙하가 모두 끝나고 다음 조작을 받기 전에 순서대로 배치한다.
- 각 배치 위치는 가능한 일반 블록 칸 중 무작위로 고른다. 자리가 부족하면 나머지는 계속 대기한다. 배치 순서는 선택 화면의 왼쪽부터 청소로켓 → 달 폭탄 → 무지개 자석이며, 선택하지 않은 종류는 건너뛴다. 선택한 시점의 순서는 사용하지 않는다.
- 보유 수량은 해당 부스터가 실제로 보드에 배치될 때만 차감한다. 퍼즐 종료까지 등장하지 못하고 대기한 부스터는 소모하지 않는다.
- 청소로켓 부스터의 방향은 실제 배치 시 가로·세로 중 무작위로 결정한다.

## 아이템 사용 불가와 직접 포기

- ‘섞기’로 위 재배치 성공 조건을 만족시킬 수 없으면 아이템을 소모하지 않고 ‘지금은 섞을 수 없어요’로 안내한다.
- 직접 포기·재시작하면 이미 사용한 아이템과 배치된 부스터는 반환하지 않는다. 대기 중인 부스터는 소모하지 않는다.
- 직접 포기·재시작한 판에서 이미 보상을 받은 이어하기 광고의 일일 횟수도 복구하지 않는다. 자동 재배치 실패에 따른 진행 불가 종료만 위의 반환·복구 예외를 적용한다.
- 게임 화면에서 메인으로 나가기는 포기다. 강제 종료·백그라운드 전환과 구분하며, 확인창과 복원 흐름은 플랫폼과 화면 문서를 따른다.

## 아직 결정하지 않은 규칙

- 레벨별 보드 모양과 분리 구역의 구체적인 구성.
- 매칭 판정과 연쇄 처리의 세부 규칙.
- 자동 재배치 예외와 구역 경계의 세부 처리.
- 레벨별 이동 횟수와 구체적인 목표 조건.
- 수거 드론의 세부 대상 선정·장애물 반응, 조합 효과의 발동 순서와 연쇄 처리.
- 추가 장애물 종류·내구도·제거 조건.
- 재도전 보상.
- 수위·부유·무중력 기믹의 실제 도입 여부.
- 토끼 종류에 따른 능력 차이 유무.
