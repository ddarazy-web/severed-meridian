## Goal 목표

사용자에게 공개된 정보만 보는 기본 봇이 수동 플레이와 같은 공통 실행기로 한 판을 진행하도록 구현한다. Match에서 한 수/한 판 실행·중지와 선택 이유를 확인하고, 숨은 정보 차단·행동 동등성·종료 구분·원본 보존·독립 재현을 증명한다.

2. 이 문서를 참고한 명시적인 Goal 실행 요청 후에 구현한다. 선행이 실제로 미완료이면 누락을 보고하고 완료라고 가정하지 않는다.
3. `ponytail`, 프로젝트 Unity 규칙과 승인된 계획 T1→T6을 따른다. 문서의 과거 경로·해시로 최신 코드를 되돌리지 않는다.

5. 봇 입력은 공개 값 복사본만 허용한다. 실제 상태·정의·시드·난수·숨은 공급·곰팡이 내부·분석 기록의 참조 또는 간접 유출을 차단한다.

7. 이번 봇 시험에는 부스터·아이템·광고 이어하기를 사용하지 않는다. 기존 수동 시험 기능은 유지한다.
8. 공개 필드 허용표, 결정적 평가 기준, 한 수 진행/한 판 실행/중지의 안정 경계를 설명하고 검증한다. 평가 점수는 실제 미래 결과나 난이도 등급이 아니다.
9. 실제 Unity 검증과 독립 재현을 수행한다. 사용자 Editor를 임의 종료하거나 같은 프로젝트를 중복 실행하지 않는다. 검증하지 못한 항목은 완료로 표시하지 않는다.
10. 정의·GUID/meta·미저장 내용·기존 UI 개선을 보존한다. 소유 임시 객체만 정리한다. 복잡한 판단과 정보 경계에는 한국어 주석을 작성한다.
11. 계획 전략·반복 실행·통계·난이도 추천 등 26~30단계는 구현하지 않는다. 실제 결과와 완료 조건별 증거를 기록한 뒤에만 이 Goal을 완료한다.
