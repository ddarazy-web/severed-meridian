레벨툴 시작하기

프로젝트를 열고, 블록을 놓고, 저장한 뒤 다른 기기로 옮기기까지 따라 해 보세요.

기준2026.10.15 현재 UI · Windows / Android 레벨툴

처음이라면 이 순서로

  1. 새 프로젝트를 만듭니다. 프로젝트는 여러 레벨을 담는 작업 상자입니다. 받은 ZIP이 있다면 가져오기부터 시작하세요.
  2. 레벨을 선택하고 블록을 놓습니다. 휴대폰은 소재 선택 → 보드 탭 순서입니다.
  3. 저장을 누르고 제목 아래 저장됨을 확인합니다.
  4. 게임 시험 입력을 현재 편집본 JSON으로 정하고 시험합니다.
  5. 다른 기기로 옮길 때는 프로젝트 ZIP 내보내기를 사용합니다.

필요한 설명 바로 찾기

화면과 첫 편집버튼 위치, 블록 배치, 게임 시험, 단축키 JSON 저장·다시 열기프로젝트 만들기, 저장, 사본, 복구 ZIP 가져오기·내보내기다른 기기로 옮기고 새 이름으로 받기 Android 터치 조작탭, 길게 누르기, 영역, 확대, 복사·교체

세 가지 이름만 기억하세요

  • JSON: 레벨과 설정을 글 형태로 기록한 작업 데이터입니다. 파일을 직접 수정할 필요는 없습니다.
  • 프로젝트 ZIP: 정상 저장된 공개 JSON 문서를 묶은 전달 파일입니다. 앱이나 이미지 파일 전체를 담는 파일은 아닙니다.
  • MemoryPack: 게임용으로 따로 변환한 데이터입니다. 처음 편집할 때는 현재 편집본 JSON을 선택하세요.

추가 · 2026.10.01 보드 크기 변경

현재 보드는 9×9, 총 81칸이며 행·열은 1~9입니다. 기존 데이터는 왼쪽 위 9×9를 유지하고 마지막 행·열을 제거합니다. 화면 캡처와 기존 검증일은 변경 전 기록입니다. 이번 내용 편집은 9×9 실제 화면 검증 완료를 뜻하지 않습니다.

탭을 바꾸면 어떻게 되나요?

추가 · 창 크기 자동 조정: 선택한 탭에 필요한 크기보다 창이 작으면 부족한 가로·세로만 자동으로 늘립니다. 이미 넓혀 둔 창은 줄이지 않습니다. 최소 크기는 레벨 편집 1040 × 780 → 1040 × 808, 플레이 테스트 760 × 860 → 760 × 888, 초기 보드·진단 800 × 900 → 800 × 928입니다. 추가된 결과·이력 탭은 1000 × 760 → 1000 × 788을 기준으로 합니다. Unity 안에 도킹해서 이 크기를 확보할 수 없으면 바깥 스크롤로 가려진 영역을 확인할 수 있습니다. 자세한 목록은 각 영역 안에서 스크롤합니다.

탭을 바꾸어도 선택한 칸, 스크롤 위치, 테스트 진행 상태는 유지됩니다. 떠난 테스트의 자동 처리는 잠시 멈추고, 돌아오면 이어집니다.

다만 원본 레벨을 고치거나 다른 레벨을 선택하면 예전 테스트는 다시 시작해야 합니다. 창을 닫거나 Unity가 스크립트를 다시 읽었을 때도 테스트를 새로 시작합니다.
