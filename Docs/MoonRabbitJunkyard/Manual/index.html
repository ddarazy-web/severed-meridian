시작하기

레벨을 만들고, 직접 플레이하며, 잘못된 설정을 찾아보세요.

시작 전에 프로젝트를 Unity에서 연 뒤 시작합니다.

처음이라면 이 순서로창 열기화면의 큰 구성탭을 바꾸면 어떻게 되나요?필요한 설명 바로 찾기

처음이라면 이 순서로

  1. 새 레벨을 만들고 이름을 정합니다.
  2. 보드에 달토끼 블록을 놓습니다.
  3. 레벨 번호·이동 횟수·사용 색을 정합니다.
  4. 미션을 하나 이상 넣습니다.
  5. 검사를 누르고 오류를 고칩니다.
  6. 직접 플레이해 본 뒤 저장합니다.
기억해 두세요

처음부터 모든 장치를 넣을 필요는 없습니다. 일반 블록과 간단한 미션으로 시작하고, 익숙해지면 장애물을 추가하세요.

창 열기

Unity 위쪽 메뉴에서 Match → 통합 작업창을 누릅니다. 이미 열려 있으면 같은 창을 보여줍니다.

Match → 레벨 에디터 / 플레이 테스트 / 초기 보드 확인도 각각 같은 창의 해당 탭을 엽니다. Match → 사용 설명서는 이 설명서를 엽니다.

탭하는 일
레벨 편집블록을 놓고 레벨 조건을 정합니다.
플레이 테스트만든 레벨을 직접 플레이합니다.
초기 보드·진단처음 배치되는 모습과 처리 과정을 자세히 확인합니다.

탭을 바꾸면 어떻게 되나요?

탭을 바꾸어도 선택한 칸, 스크롤 위치, 테스트 진행 상태는 유지됩니다. 떠난 테스트의 자동 처리는 잠시 멈추고, 돌아오면 이어집니다.

다만 원본 레벨을 고치거나 다른 레벨을 선택하면 예전 테스트는 다시 시작해야 합니다. 창을 닫거나 Unity가 스크립트를 다시 읽었을 때도 테스트를 새로 시작합니다.
