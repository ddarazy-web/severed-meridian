  1. 새 레벨을 만들고 이름을 정합니다.
  2. 보드에 달토끼 블록을 놓습니다.
  3. 레벨 번호·이동 횟수·사용 색을 정합니다.
  4. 미션을 하나 이상 넣습니다.

  6. 직접 플레이해 본 뒤 저장합니다.
기억해 두세요

처음부터 모든 장치를 넣을 필요는 없습니다. 일반 블록과 간단한 미션으로 시작하고, 익숙해지면 장애물을 추가하세요.

탭을 바꾸면 어떻게 되나요?

추가 · 창 크기 자동 조정: 선택한 탭에 필요한 크기보다 창이 작으면 부족한 가로·세로만 자동으로 늘립니다. 이미 넓혀 둔 창은 줄이지 않습니다. 최소 크기는 레벨 편집 1040 × 780 → 1040 × 808, 플레이 테스트 760 × 860 → 760 × 888, 초기 보드·진단 800 × 900 → 800 × 928입니다. 추가된 결과·이력 탭은 1000 × 760 → 1000 × 788을 기준으로 합니다. Unity 안에 도킹해서 이 크기를 확보할 수 없으면 바깥 스크롤로 가려진 영역을 확인할 수 있습니다. 자세한 목록은 각 영역 안에서 스크롤합니다.

탭을 바꾸어도 선택한 칸, 스크롤 위치, 테스트 진행 상태는 유지됩니다. 떠난 테스트의 자동 처리는 잠시 멈추고, 돌아오면 이어집니다.

다만 원본 레벨을 고치거나 다른 레벨을 선택하면 예전 테스트는 다시 시작해야 합니다. 창을 닫거나 Unity가 스크립트를 다시 읽었을 때도 테스트를 새로 시작합니다.
