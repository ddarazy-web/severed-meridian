생성구 만들고 선택하기

생성구는 새 블록이 나오는 칸입니다.

  1. 왼쪽 배치 → 생성·회수 → 생성구 배치를 고릅니다.
  2. 공급을 시작할 칸을 누릅니다.
  3. 생성구 선택으로 바꾸고 그 칸을 누릅니다.
  4. 오른쪽에서 공급 방식을 정합니다.

왼쪽 목록 → 생성구에서도 위치를 찾을 수 있습니다. 상단 생성구 추가는 윗줄에 생성구를 넣는 빠른 기능입니다.

공급 방식 네 가지

방식쉬운 설명
일반 무작위이 레벨에서 쓰는 색 중에서 달토끼를 정해 공급합니다.
고정 목록내가 쌓아 둔 목록의 블록을 차례대로 공급합니다.
고철 유지레벨 공통 설정의 목표와 추가 한도에 맞춰 고철을 공급합니다.
회수 유지회수할 부품을 목표에 맞춰 공급합니다.

고철·부품의 유지 수량은 오른쪽 레벨 설정 → 공급 유지 · 레벨 공통에서 정합니다. 같은 레벨의 생성구들이 추가 한도를 공유합니다.

고정 목록 쌓기

  1. 생성구 하나를 선택하고 공급 방식을 고정 목록으로 바꿉니다.
  2. + 항목으로 항목을 넣고, 종류와 수량을 정합니다.
  3. 항목을 골라 종류에 맞는 색·방향·내구도를 정합니다.
  4. 목록을 끌거나 ↓ 먼저 / ↑ 나중에로 순서를 정합니다.
기억해 두세요

아래쪽 1번부터 먼저 나옵니다. 보이는 목록의 위쪽부터 나오는 것이 아닙니다. 목록에 쌓은 블록은 그 생성구에서만 나옵니다.

버튼 / 설정뜻
복제선택한 공급 항목을 하나 더 만듭니다.
삭제선택한 항목만 지웁니다.
비우기그 생성구의 공급 목록을 비웁니다.
소진 후 → 공급 중단목록을 다 쓰면 더 공급하지 않습니다.
소진 후 → 무작위 전환목록을 다 쓰면 일반 무작위 공급으로 바뀝니다.

여러 생성구에 같은 목록 넣기

  1. 고정 목록을 만든 생성구 하나를 선택합니다.
  2. 오른쪽 버튼 → 공급 목록 복사를 누릅니다.
  3. 고정 목록 방식인 다른 생성구를 선택합니다. 여러 개는 Ctrl/Cmd+클릭으로 고릅니다.
  4. 오른쪽 버튼 → 공급 목록 교체 붙여넣기 또는 공급 목록 뒤에 추가를 고릅니다.

교체는 기존 목록을 새 목록으로 바꿉니다. 뒤에 추가는 기존 목록을 유지하고 더 넣습니다. 붙여넣은 뒤 먼저 나올 순서를 다시 확인하세요.

회수 부품 넣기

  1. 배치 → 생성·회수 → 회수 부품을 골라 놓습니다.
  2. 도착 바닥을 정합니다.
  3. 부품이 도착 바닥까지 갈 수 있도록 중력과 경로를 확인합니다.
  4. 부품 회수 미션과 목표 수량을 넣습니다.

필요하면 생성구를 회수 유지로 정해 다음 부품을 공급합니다. 부품만 놓아서는 회수 미션이 자동으로 생기지 않습니다.
