02 · 기본 편집

보드 배치

놓을 도구를 고르고 보드의 칸을 눌러 배치합니다.

시작 전에 레벨 파일을 선택하고 레벨 편집 탭을 엽니다.

왼쪽 배치 메뉴 읽기달토끼 블록 놓기사용할 칸과 빈칸파워 블록 미리 놓기여러 칸의 같은 설정 바꾸기설정 복사와 붙여넣기실수했을 때

왼쪽 배치 메뉴 읽기

메뉴하는 일
편집 층어느 부분을 선택하거나 지울지 정합니다. 블록·장애물·덮개·먼지 등을 구분합니다.
선택칠하기를 멈추고 칸이나 물체의 설정을 봅니다.
층 지우기현재 층의 요소만 지웁니다. 칸 전체를 비우는 기능이 아닙니다.
보드칸을 사용할지 말지 정합니다.
일반 블록무작위 색 또는 정해진 색의 달토끼를 놓습니다.
파워 블록청소로켓·달폭탄·수거드론·무지개 자석을 놓습니다.
장애물 / 덮개 / 바닥 / 장치막는 물체, 블록 위의 덮개, 먼지, 발전기를 놓습니다.
생성·회수새 블록이 나오는 곳과 회수할 부품을 놓습니다.

달토끼 블록 놓기

  1. 왼쪽 배치 → 일반 블록을 엽니다.
  2. 무작위 ? 또는 고정 1~5 중 하나를 고릅니다.
  3. 보드의 칸을 누르거나 누른 채 움직여 여러 칸을 칠합니다.
  4. 오른쪽 레벨 설정 → 사용 종류에서 고른 색만 배치 메뉴에 나옵니다.

무작위 ?는 시작할 때 색을 정할 칸입니다. 고정은 시작 색을 미리 정한 칸입니다. 빈칸은 블록을 놓지 않은 칸이며, 무작위와 다릅니다.

추가 · 직접 칸을 편집하기 전에 등록 모양으로 새 레벨을 만들 수도 있습니다. 현재 맵은 보존합니다.

사용할 칸과 빈칸

표시 / 도구뜻
칸 활성화게임에 사용할 칸으로 만듭니다.
칸 비활성화 / ×보드에서 사용하지 않는 칸입니다.
빈칸 / ·사용하는 칸이지만 처음 블록은 없습니다.
?시작할 때 색이 정해집니다.
!설정을 확인해야 하는 칸입니다. 검사를 눌러 자세히 확인하세요.

보드는 10×10 칸입니다. 필요한 모양에 맞춰 일부 칸을 비활성화할 수 있습니다.

파워 블록 미리 놓기

  1. 배치 → 파워 블록에서 종류를 고릅니다.
  2. 보드에 놓습니다.
  3. 선택 도구로 그 칸을 고르고 오른쪽에서 설정을 확인합니다.

청소로켓은 가로·세로 방향도 확인하세요. 파워 블록을 미리 놓는 것은 테스트 시작 전에 고르는 시작 부스터와 다릅니다.

여러 칸의 같은 설정 바꾸기

  1. 현재 편집 층을 맞추고 선택을 누릅니다.
  2. Ctrl을 누른 채 다른 대상을 눌러 함께 선택합니다. Mac에서는 Cmd를 사용합니다.
  3. 오른쪽에 함께 바꿀 수 있는 항목이 나오면 값을 입력합니다.

값이 서로 다르면 섞인 상태로 표시됩니다. 종류가 다르면 함께 바꿀 수 없는 항목은 나오지 않습니다.

설정 복사와 붙여넣기

  1. 기준이 될 대상을 선택하고 마우스 오른쪽 버튼을 누릅니다.
  2. 설정 복사를 고릅니다.
  3. 같은 종류의 대상 하나 또는 여러 개를 선택합니다.
  4. 오른쪽 버튼 → 설정 붙여넣기를 누릅니다.
기억해 두세요

물체를 새로 만드는 복사가 아니라 내구도·방향 같은 설정을 옮기는 기능입니다. 종류가 맞지 않는 대상은 제외됩니다. 블록을 공급하는 순서 목록은 생성구의 공급 목록 복사를 사용하세요.

실수했을 때

Unity의 Edit → Undo로 되돌리고, Redo로 다시 적용할 수 있습니다. 보드를 한 번 누른 채 칠한 작업은 한 묶음으로 되돌립니다. 아직 끝내지 않은 경로·드래그는 Esc로 취소합니다.
