기준2026.10.15 현재 UI · Windows / Android 레벨툴

레벨툴 화면 열기

  1. Windows에서는 게임 앱과 별도인 레벨툴 앱을 실행합니다. Unity에서 확인할 때는 Assets/Scenes/LevelTool.unity 씬을 열고 Play를 누릅니다.
  2. 기존 작업이 열리면 제목과 폴더를 봅니다. 복구 질문은 복구 안내를 참고하세요.
  3. 작업이 없다면 새 프로젝트를 만들거나 ZIP을 가져옵니다.

처음 블록 놓아 보기

  1. 레벨 목록에서 편집할 레벨을 고릅니다. 새 레벨은 빈 레벨 추가, 복제는 현재 레벨 복사입니다.
  2. 소재 → 편집 층 → Block을 고릅니다. 층은 블록·장애물·덮개·바닥을 나누는 작업 구역입니다.
  3. 지정 달토끼 공급을 고릅니다. 선택 속성 → 배치 색에서 Type1 등 색을 고릅니다. 이 도구는 시작 블록의 색을 지정합니다.
  4. 보드의 빈 칸을 클릭하면 배치됩니다. 점(·)은 시작 배치가 없는 칸이며 게임에서 생성구를 통해 채워질 수 있습니다.
  5. 바꿀 도구를 고르고 같은 층의 기존 칸을 더블클릭하면 교체합니다. 터치는 교체 켜기 / 작업 → 현재 도구로 교체를 사용하세요.
  6. 칸만 고르려면 선택 또는 소재의 선택 도구로 돌아갑니다. 실수는 실행 취소로 되돌립니다.
  7. 레벨 설정에서 이름을 “첫 연습 레벨”, 이동 횟수를 20 등으로 입력합니다. 입력칸 밖을 눌러 확정하고 저장합니다.
층을 먼저 확인하세요

Block은 일반·파워 블록, Obstacle은 장애물, Cover는 덮개, Dust는 바닥 편집입니다. 삭제·복사는 현재 층에 적용됩니다. 다른 층 충돌이나 2×2 요소의 보드 밖 배치는 거절될 수 있습니다. 교체는 모든 층을 지우는 기능이 아닙니다.

수정한 레벨로 게임 시험하기

  1. 보드 위 게임 시험 입력 → 현재 편집본 JSON을 선택합니다. Android는 더보기 안에서 스크롤하여 찾습니다.
  2. 게임 시험(Android: 시험) 또는 Windows F5를 누릅니다. 현재 자료를 먼저 검사합니다.
  3. 오류가 나오면 고칩니다. 저장됐다고 플레이 가능한 것은 아닙니다. 미션·사용 색·배치·공급도 확인하세요.
  4. 게임 화면에서 교환해 봅니다. 시험 종료 후 편집 화면으로 돌아옵니다. 시험은 저장을 대신하지 않습니다.
수정이 안 보이면 시험 입력을 확인하세요

현재 편집본 JSON은 미저장 수정까지 시험합니다. 생성된 MemoryPack은 마지막으로 따로 생성·등록한 팩입니다. JSON 저장이나 ZIP 내보내기만으로 팩이 갱신되지 않습니다. 팩 검증이 목적일 때만 선택하고 팩 상태 확인으로 비교하세요.

창 모드는 16:10 비율, 최소 1280×800입니다. 테두리를 끌어 크기를 조절합니다. 전체 화면은 모니터를 채우고, 창 모드 복귀 시 마지막 저장 크기·위치를 사용합니다. 기록이 없으면 1280×800입니다. 최대화 모드는 제공하지 않습니다.

“편집 형식으로 전환”이 보이면

구형 레벨입니다. 보드·게임 시험은 미리 볼 수 있고 편집하려면 편집 형식으로 전환 (Undo 가능)을 누릅니다. 확인 후 저장하세요. 원본을 보관하려면 먼저 사본 저장합니다. 이는 레벨 내부 형식 전환이며 ZIP 가져오기와는 다릅니다.
