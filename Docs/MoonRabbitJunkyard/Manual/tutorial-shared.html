먼저 차이를 확인하세요

방식수정하면 어디에 반영되나요?
공통 진행 구성참조하는 모든 레벨의 동작 순서·조건·안내에 반영
이 레벨의 설정현재 레벨의 대상·셀·수치만 변경
독립 복사현재 값을 적용한 새 독립 구성. 이후 공유 원본 수정은 반영되지 않음
내 샘플적용 순간 복사. 나중에 샘플을 수정해도 기존 단계는 유지

레벨 값을 변경한다고 복사본이 생기지는 않습니다. 공통 흐름 하나에 각 레벨의 값을 연결합니다.

공통 구성 만들기 — 처음 한 번

  1. 독립 구성에서 동작·조건·안내를 만들고 검사합니다.
  2. ‘현재 흐름을 공통 구성으로 저장’을 누르고 새 에셋 이름을 지정합니다. 기존 에셋은 덮어쓰지 않습니다.
  3. 열린 원본 편집 사본에서 ‘공통 원본 편집 · 레벨별 설정 항목 지정’을 펼칩니다.
  4. 각 단계에서 레벨마다 달라질 항목을 체크합니다. 예: 첫 조작 칸, 둘째 조작 칸, 조건 대상, 조건 횟수·감소량.
  5. ‘레벨에 보여줄 이름’에 ‘연습 장애물’처럼 의미가 드러나는 이름을 적고, ‘입력 도움말·예시’에는 ‘이 레벨에서 내구도를 줄일 장애물을 선택하세요’처럼 설명합니다.
  6. ‘공통 원본에 적용하고 사용 레벨 검사’를 누릅니다. 새 항목을 추가했다면 사용하는 레벨의 설정을 연결해야 합니다.

단계를 추가·삭제했다면 ‘단계 수정 후 설정 항목 새로고침’을 누릅니다. 삭제된 단계/조건의 연결은 정리한 뒤 적용하세요. 적용 전 창을 닫으면 공유 원본은 바뀌지 않습니다.

각 레벨에 연결하기 — 레벨마다

  1. 레벨을 열고 ‘공통 진행 구성’에서 사용할 에셋을 선택합니다.
  2. ‘이 레벨의 설정’에서 보이는 항목을 입력합니다. 선언되지 않은 공통 항목은 여기에서 바꾸지 않습니다.
  3. 대상·좌표는 ‘보드에서 선택’을 이용합니다. 특정 개체는 한 칸, 영역은 여러 칸을 선택한 뒤 확정합니다. Esc는 취소입니다.
  4. 숫자를 입력합니다. 예를 들어 레벨 1은 감소량 1, 레벨 2는 감소량 3으로 설정할 수 있습니다.
  5. 레벨을 저장하고 ‘튜토리얼 논리 재생 검사’를 실행한 다음 게임 플레이를 확인합니다.

새 공통 설정이 추가되거나 삭제되면 ‘설정 목록 동기화’를 누르세요. 동일한 이름·종류의 값은 유지되고 새 항목에는 원본 기본값이 들어갑니다. 기본값이 이 레벨에도 적합한지 반드시 확인하세요.

공통 수정과 독립 복사

‘공통 원본 편집 · 사용 레벨 확인’은 수정 영향을 받는 레벨을 보여줍니다. 원본 적용 후 오류 목록에서 해당 레벨을 열어 설정을 고치세요. 원본 사본 편집 중 다른 창에서 원본을 바꿨다면 덮어쓰지 않고 다시 열도록 안내합니다.

동작 순서나 조건 종류를 현재 레벨에서만 다르게 하려면 ‘독립 복사 · 공유 연결 해제’를 누르세요. 연결 값이 적용된 독립 단계가 생기며 완료 ID는 그대로 유지됩니다. Undo로 되돌릴 수 있습니다.

내 샘플 저장과 사용

  1. 독립 구성에서 ‘내 샘플 · 저장한 구성을 복사해서 사용’을 펼칩니다.
  2. ‘현재 단계를 내 샘플로 저장’ 또는 ‘전체 흐름을 내 샘플로 저장’을 선택합니다.
  3. Assets/Data/Tutorial/Samples 아래 새 이름으로 저장합니다. 같은 이름은 덮어쓰지 않습니다.
  4. 다른 독립 구성에서 ‘적용할 샘플’을 선택하고 안내·동작·조건 개수를 미리 확인합니다.
  5. ‘미리 본 샘플을 끝에 추가’를 누릅니다. 적용 전 취소는 변경하지 않고, 적용 후에는 Undo로 되돌립니다.

샘플은 단계 구성만 복사합니다. 레벨 보드·시드·고정 공급·학습 완료 ID는 덮어쓰지 않습니다. ‘생성한 블록을 다음 단계에서 참조’하는 샘플은 앞뒤 단계를 함께 저장하거나 필요한 앞 단계를 따로 준비하세요.

학습 완료 ID와 이전 기록

학습 완료 ID는 튜토리얼 전체를 식별합니다. 예: basic.swap, power.rocket. 공통 구성이 같아도 로켓과 드론처럼 학습 내용이 다르면 다른 ID를 사용하세요. 같은 ID의 문구·수치 변경은 다시 학습시키지 않습니다.

기존 튜토리얼을 옮길 때만 ‘이어받을 이전 레벨 번호’에 예전 번호를 명시합니다. 이미 완료한 플레이어는 새 ID로 완료를 이어받으며 기존 기록은 삭제하지 않습니다. 완전히 새 학습은 새 ID와 빈 이전 번호 목록을 사용합니다. 에디터 시험 기록은 플레이어 기록과 분리됩니다.
