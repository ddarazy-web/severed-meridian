### 사용 방법

1. **Match → 레벨 에디터**를 연다. 버전 1·2 레벨은 **4단계 형식으로 전환**을 누른다. 한 번의 Undo로 되돌릴 수 있으며 디스크 반영은 **저장**으로 확정한다.
2. 왼쪽 **흐름·통로**에서 중력 방향을 선택해 칸을 클릭/드래그한다. **사각 구역 칠하기**를 켜면 시작·끝 칸 사이를 한 번에 적용한다. **중력 초기화**는 기본 아래 방향으로 돌아간다.
3. **직접 경로**에서 인접 칸을 순서대로 클릭하고 **경로 완료/Enter**로 확정한다. 마지막 칸은 끝 칸이며 기존 경로나 통로 입구로 연결할 때는 이후 설정을 유지한다. Backspace는 마지막 입력, Esc는 미완료 경로를 취소한다.
4. **흐름 선택**으로 합류 칸을 고른 뒤 오른쪽 **바닥 흐름·연결**에서 유입 순서를 ↑/↓로 바꾸고 확정한다. 후보가 달라지면 검사에서 재설정 필요를 표시한다.
5. **지형 → 고철 벽**으로 두 칸 사이를 클릭/드래그한다. 삭제 도구도 경계에 적용한다. 2×2 내부, 기존 직접 경로·전선과 충돌하는 신규 벽은 거절한다.
6. **통로 입구**를 놓고 오른쪽 **출구 지정/이동**을 누른 뒤 출구 칸을 클릭한다. 출구만 삭제하면 미완성 입구가 남고, 쌍 삭제는 둘을 함께 지운다. 같은 번호·색으로 양 끝을 확인한다.
7. **도착 바닥**을 칸에 놓는다. 통로와 중첩할 수 없으며 다른 층의 블록·먼지와 중력은 유지한다. 회수 부품·미션은 아직 제공하지 않는다.
8. 발전기를 선택해 **바닥 흐름·연결 → 연결 대상 추가**를 누르고 장애물을 고른다. **전선 그리기/재지정**으로 발전기 외곽 꼭짓점부터 대상까지 칸 사이를 순서대로 클릭한 뒤 완료한다.
9. 전선을 다 그리지 못했으면 **전선 중간 경로 기록**으로 현재 경로를 명시적으로 기록하고 저장할 수 있다. 벽·교차 등 잘못된 기하는 허용하지 않으며 대상에 도달하기 전까지 연결 오류로 남긴다. 미리보기만 있는 상태에서 저장하면 미완료 입력은 취소된다.
10. 본체 이동 시 ID 연결과 기존 전선은 유지되며 맞지 않는 단자는 재지정해야 한다. 발전기 삭제는 전선만 함께 지우고 대상은 유지한다. 대상 삭제는 해당 연결만 지운다. 각 조작은 한 번의 Undo로 복원한다.
11. **현재 사용 중인 장애물**은 기존처럼 실제 배치 개수와 위치를 제공한다. **흐름·연결 목록**은 별도로 펼쳐 확인한다. 목록/검사 오류를 클릭하면 관련 칸·벽·전선과 오른쪽 속성으로 이동한다. 범위 밖·끊긴 ID는 원본 Inspector 안내를 따른다.
12. 흐름·전선은 기본 표시를 유지하면서 약 3초 단위로 번갈아 강조한다. 실제 블록 이동이나 발전기 충전 연출이 아닌 편집용 표시다. 창이 닫히면 해당 오버레이 일정도 중단된다.

### 검증 중 수정·정리한 사항

- 직접 경로가 통로 입구로 들어가는 경우는 허용하고 입구 자체에 직접 경로를 덮어쓰는 경우와 구분했다.
- 포커스 검증은 실제 활성 창을 먼저 확인하고 다른 창으로 전환하도록 보강했다. 넓은 화면은 창 크기를 다시 지정하고 실제 크기를 검사해 잘못된 캡처를 방지했다.
- 오류 목록에서 벽과 전선을 강조하도록 연결하고, 외부 원본 변경 시 오래된 전선 대상 선택을 해제했다.
- 현재 사용 중인 장애물 목록을 앞에 유지하고, 흐름/연결 목록은 접어서 관리하며 펼침 상태를 유지한다.
- 구버전 전환 검증은 최신 버전을 사용하도록 수정했다. 기존 발전기 검증은 새로 도입된 미연결 오류 하나만 예상하도록 바꾸고 다른 속성/배치 검사는 유지했다.

```powershell
$stage4Check = Start-Process -FilePath 'C:/Program Files/Unity/Hub/Editor/6000.3.10f1/Editor/Unity.exe' -ArgumentList '-projectPath C:/Projects/Git/ServeredMeridian -executeMethod Levels.Editor.LevelFlowVerification.Start -logFile Logs/LevelFlowVerification/ui-editor.log' -WindowStyle Hidden -PassThru
Wait-Process -Id $stage4Check.Id

& 'C:/Users/ddara/AppData/Local/Unity/bin/unity.exe' run 'C:/Projects/Git/ServeredMeridian' --editor-path 'C:/Program Files/Unity/Hub/Editor/6000.3.10f1/Editor/Unity.exe' --format json -- -nographics -executeMethod Levels.Editor.LevelFlowVerification.Restart -logFile Logs/LevelFlowVerification/ui-restart.log
```
