# 달 토끼 고물상 — 게임 개요

색과 모양이 다른 다섯 달토끼를 매칭해 우주 고물을 정리하고, 소꿉친구인 다섯 토끼가 고물상을 운영하며 쇠락한 달 정거장을 되살리는 캐주얼 퍼즐 게임.

## 확정 사항

- 캔디 크러쉬 소다의 퍼즐 플레이 전반을 참고한다. 기본 매칭, 특수 블록과 조합, 스테이지 목표와 기믹을 참고 범위에 포함한다.
- 원작의 개별 규칙·모드를 전부 채택한 것은 아니다. 구체적인 적용 범위는 추가 설계한다.
- 모바일과 PC를 모두 지원한다.
- 모바일은 세로, PC는 가로 화면에 맞춰 UI를 재배치한다. 보드와 퍼즐 규칙은 동일하게 유지한다.
- 단순하고 귀여운 그림체를 사용한다. 복잡한 장식과 묘사는 지양한다.
