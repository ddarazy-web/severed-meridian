# 달 토끼 고물상 — 미정 사항

## 게임 화면 기획 정리 — 2026-09-29

퍼즐 화면의 첫 구현을 시작할 수 있도록 확정 사항을 [플랫폼과 화면](06_플랫폼과화면.md), [아트](03_캐릭터와아트.md), [성장과 보상](05_성장과보상.md)에 반영했다. 아래는 이번 화면 논의에서 남긴 항목이며, 기존 게임 전체의 미정 사항을 모두 해결했다는 뜻은 아니다.

| 구분 | 남은 내용 |
| --- | --- |
| 확정된 후속 수정 | 아이템 수량 숫자를 줄이고 자릿수가 늘어나도 수량 배지 안에 표시. 현재 HTML은 수정하지 않음 |
| 실제 화면 검수 | 최소 화면·터치 크기, 안전 영역, 다국어 줄바꿈, 영역별 최종 여백 |

| 다국어 | 지원 언어 목록, 문자권별 Noto Sans 구성과 표시 검수 |

이어하기 아이템의 +5회·1개 소비·한 판 1회, 광고와 독립된 한도, 버튼 표시·확인·취소는 확정했다. Windows 지정 화면 모드, 가로·세로 전환, 회전 중 수집 경로 변경, 수동 일시정지와 결과 흐름 우선순위도 더 이상 미정이 아니다. HTML 목업 검수와 Unity 구현·실기 검수는 구분한다.

## 기존 기획 항목

현재 장애물 등장 레벨 논의는 보류한다. 장애물 종류와 규칙을 먼저 정한 뒤 배치하며, 아래 기존 나무상자 6레벨·거미줄 21레벨 기록도 그때 함께 검토한다. 고철 31레벨 제안은 채택하지 않았다.

1. 레벨별 미션 수량과 이후 장애물 조합·해금 종류는 미정이다. 1~5레벨은 장애물 없이 기본 매칭·파워 블록을 익히고, 나무상자는 6레벨, 거미줄은 21레벨에 해금한다. 실제 주문 완료 여부와 관계없이 지정 레벨에서 해금하며 이후 레벨에 선택적으로 사용한다. 해금 레벨은 주문별 필요 별에 대응하는 예상 진행량을 기준으로 미리 정한다.
2. 직선 3/4/5개, 3×3 영역의 ㄱ·ㄴ·T, 2×2 매칭은 기본 규칙으로 확정. ㄱ·ㄴ·T의 5칸 기준 모양과 모든 방향, 2×2만 완성된 교환은 확정. 가로 4개는 세로 줄 제거, 세로 4개는 가로 줄 제거, 직선 5개 이상은 연결 블록을 모두 처리해 무지개 자석 하나를 생성하며 한 색 전체 제거, ㄱ·ㄴ·T는 주변 3×3 제거로 확정. 2×2 수거 드론은 발동 위치의 가운데와 상하좌우 5칸, 추가 대상 한 칸을 제거한다. 파워 블록은 교환 또는 더블터치로 발동하며 둘 다 한 수를 소비한다. 5개 매칭 파워 블록은 교환 시 상대 색, 더블터치 시 게임이 무작위로 고른 색을 제거한다. 드론은 유효 후보가 전혀 없으면 추가 타격 없이 종료한다. 범위 효과는 보드 밖·비활성 칸을 무시하며 청소로켓은 비활성 칸을 통과한다. 구체적인 추가 장애물·목표 조건은 미정.
3. 일반 주문은 10조각·작업당 별 5개·합계 50개, 첫 주문은 5조각·별 1개 + 4·5·5·5개로 합계 20개다. 일반 주문은 작업 3→3→4개, 첫 주문은 1→4개 묶음으로 공개한다. 주문은 순서대로 진행하되 공개된 작업은 자유 선택이며 묶음을 모두 완료해야 다음 묶음이 열린다. 고물 무게·상대 비중별 비용 방식은 폐기했다. 첫 주문은 상태 점검 1개, 부품 분류 4개, 고장 부품 교체·배선 정리·전원 점검 각 5개다.
4. 다섯 토끼의 시각 디자인과 역할 확정.
   - 나무상자는 보강판으로 1~6단계를 구분한다. 거미줄은 단순한 줄 몇 가닥으로 표현하고 피해에 따라 약해지거나 끊어진다. 안의 색·파워 종류는 식별 가능해야 한다. 한국적 소재는 자연스럽게 어울릴 때만 사용한다.
5. 첫 챕터의 손님·주문 순서와 정거장 복구 장면의 내용. 복구 장면은 주문 3건 납품마다 보여주기로 확정.
6. 초기 제작 범위와 스테이지 수, 난이도·보상 수치. 수익 모델은 아이템 판매와 선택형 보상 광고이며, 구체적인 가격·상품 구성과 플랫폼별 광고 제공 방식은 미정이다.
7. 스테이지 하나는 손님 주문 하나로 확정. 별은 주문 작업에만 쓰고, 정거장 복구 이야기는 주문 3건 납품마다 보여준다.
8. 주문 물품이 없는 빈 흑백 배경 위에 분할된 완성 그림 조각을 채운다. 이전 제거형·부품 추가형은 이 공통 방식으로 대체한다. 접수·완료에만 짧은 대사를 넣고 중간은 그림 변화·효과음으로 표현한다. 작업명과 그림 속 부위는 일대일 대응하지 않는다. 작업별 조각 위치는 제작 시 고정하고 묶음별로 인접 조각을 배정한다. 실제 분할 위치와 공통 리소스는 그림 제작 시 정한다.
9. 장부의 구체적인 배치 방식은 미정이다. 손님·물건 이름, 완료 그림, 짧은 결과 메모를 기록한다. 마지막 작업 후 완성 대사와 보상으로 자동 진행하고, 보상 수령 후 다음 주문을 자동 접수하며 메인 배경을 새 주문 초기 상태로 바꾼다.
10. 파워 블록 네 종류의 두 개 조합 10가지와 생성 위치·중첩 우선순위는 게임 규칙 문서에 정리했다. 기존 파워 블록은 피격 즉시 연쇄 발동하며, 이번 수의 매칭으로 새로 만든 파워 블록은 수가 끝날 때까지 피격 발동·제거로부터 보호하고 낙하는 허용한다. 무지개 자석 조합의 변환 블록은 보호 예외로 즉시 발동한다. 각 파워 블록은 한 번만 발동하고, 같은 장애물의 피해는 한 수당 최대 1회다. 대형 폐가전은 별도 반복 피해 규칙을 적용하는 예외다. 효과·즉시 연쇄·드론 타격을 마친 뒤 낙하·보충하고, 모두 자리 잡은 뒤 자동 매칭한다.

11. 경로의 끝 칸 정지, 공급 지점 지정, 합류와 우선 경로 지정, 우선 경로 공급 불가 시 다른 경로 사용, 분기·순환 금지, 상하좌우 인접 연결, 빈칸으로만 이동, 판 도중 경로 고정은 확정. 구역 경계를 넘어 인접 활성 칸 사이의 교환·매칭을 허용하며 도착한 칸의 경로를 따른다. 자동 대각선 유입·유출은 지정 경로 구역에서 금지한다.
12. 유효 교환과 발동 가능한 파워 블록이 모두 없으면 이동 가능한 일반·파워 블록을 무료로 재배치한다. 장애물·거미줄에 묶인 블록·경로는 유지하며 파워 블록은 발동하지 않고 로켓 방향도 유지한다. 자동 재배치와 섞기의 성공 조건은 완성 매칭 없음과 유효 교환 또는 발동 가능한 파워 블록 하나 이상이다. 자동 재배치로도 행동을 만들 수 없으면 진행 불가 종료 후 무료 재도전하며, 해당 판의 사용 아이템·배치 부스터와 이어하기 광고 일일 횟수를 복구한다.

13. 기본 보드 10×10, 일부 칸 비활성화, 시작 시 완성 매칭 없음과 유효 교환 최소 하나 보장은 확정. 매칭은 비활성 칸에서 끊기지만 청소로켓의 줄 제거는 통과한다. 구체적인 레벨별 보드 구성은 미정.
14. 시간제한 없이 이동 횟수를 제한한다. 마지막 수의 모든 효과·낙하·자동 매칭이 끝난 뒤 성공·실패를 판정하고, 일찍 목표를 달성하면 현재 연쇄 후 클리어한다. 구체적인 목표와 레벨별 이동 횟수는 미정.
15. 무지개 자석의 색 선택에는 거미줄에 묶인 달토끼도 포함한다. 일반 달토끼가 없으면 단독 발동 불가이며 피격 시 추가 효과 없이 소모한다. 자석끼리 조합은 가능하고, 다른 종류와 조합은 교환을 되돌리며 이동 횟수를 소비하지 않는다. 거미줄에 묶인 색 대상은 제거·변환 대신 거미줄에 한 단계 피해를 적용하고 안의 달토끼는 남긴다.

16. 드론은 이번 수에 이미 피해를 받은 장애물과 다른 드론이 겨냥한 칸을 제외한다. 유효 미션 목표 중 무작위로 고르고, 목표가 부족하면 일반 블록으로 대체한다. 선택 가능한 후보가 없으면 추가 타격 없이 종료한다. 색상 수집은 노출된 목표색을 우선하고 없으면 거미줄에 묶인 목표색을 겨냥한다.
17. 퍼즐 레벨마다 제작자가 달토끼 3~5종의 실제 색상 목록을 지정하며 선택된 종류 안에서 균등 확률로 공급한다. 전체 고정·전체 무작위·부분 고정 시작 배치와 일반 블록·파워 블록·장애물 지정 배치를 지원한다. 재도전 시 고정 배치는 유지하고 무작위 칸은 새로 뽑는다.
18. PC 제자리 발동은 더블클릭이며, 두 플랫폼 모두 드래그와 두 칸 순차 선택 교환을 지원한다. 보드의 전체 연쇄가 끝나야 다음 조작을 받으며, 무효 교환은 이동 횟수를 소비하지 않는다.
19. 조합 중심은 움직인 블록의 도착 칸이다. 피격 파워 블록의 낙하 후 예약 발동 방식은 폐기했다.
20. 네 종류 파워 블록의 매칭 생성은 처음부터 사용 가능하다. 최초 소개 시 고정 배치의 지정 교환을 직접 해보는 튜토리얼로 안내한다. 1레벨은 안내한 두 블록의 교환으로 지정 색 3개를 한 번 매칭하여 클리어하며, 부스터 선택 화면을 건너뛰고 게임 중 아이템 사용도 금지한다. 2레벨 로켓, 3레벨 ㄱ 모양 폭탄, 4레벨 드론, 5레벨 자석의 생성·교환 발동을 안내한 뒤 같은 보드에서 자유 플레이한다. 더블터치는 설명하지 않는다. 9레벨은 인접 로켓 2개를 미리 배치하여 교환 조합을 안내하고 자유 플레이로 전환한다. 나머지 조합의 강제 튜토리얼은 없다.
21. 거미줄은 내구도 1~3단계, 21레벨에서 1단계로 소개한다. 매칭 참여·직접 타격에 한 단계씩 손상되고 한 수당 피해는 최대 1회다. 완전히 제거되기 전까지 안의 블록은 이동·낙하·직접 발동 불가다. 새 블록으로 다시 완성한 매칭은 허용하되 추가 거미줄 피해는 없고, 상태 변화 없는 동일 매칭만 재처리하지 않는다. 완전히 벗기는 타격으로 안의 파워는 발동하지 않고 별도 후속 타격부터 발동한다. 추가 장애물은 미정이다.
22. 오프라인·기기별 독립 저장을 기본으로 한다. 서버 동기화는 차후 고려 사항이다. 앱 강제 종료 시에는 퍼즐로 바로 복귀하고, 연쇄 도중 강제 종료는 동일 입력·난수 상태로 같은 결과를 재현한다. 게임 화면에서 메인으로 나가면 포기하며 메인 이어하기 기능은 없다. 구현·검증은 아직 진행하지 않았다.

23. 재도전은 무료·무제한이고 강제 광고는 없다. 광고 이어하기는 이동 5회 추가·한 판 1회·하루 5회, 상점 보급함은 광고로 박스 1개·하루 5회·수령 후 10분 대기, 납품 보너스 광고는 추가 박스 1개·주문당 1회·하루 3회다. 종류별 한도는 독립적이며 기기 현지 자정에 초기화한다. 보급함 대기는 게임 종료 중에도 흐르고 자정을 지나도 유지한다. 보상 조건 충족 전 광고 중단·오류에는 보상·횟수 차감·보급함 대기 시작을 적용하지 않는다. 획득 확인된 보상은 저장하여 재접속해도 한 번만 지급한다. 기기 시간 변경 시 처리는 미정이다.

46. 고철 뭉치는 낙하 가능한 별도 장애물로, 일반 블록처럼 수직·대각선·지정 경로로 이동한다. 내구도 1~5, 인접 매칭·직접 타격에 한 수당 최대 1단계 손상이다. 매칭에는 참여하지 않지만 교환으로 일반 매칭을 만들면 유효하다. 자리 바꾸기는 매칭 없이도 위치를 유지한다. 외형은 금속 띠 4~0개와 둥근 회색 본체다. 로켓·폭탄·드론과 일반 교환하면 파워가 발동하며 한 수를 소비하고, 자석과의 일반 교환은 되돌리며 이동 횟수를 소비하지 않는다. 자동 재배치·섞기에서는 위치와 내구도를 유지한다. 제거 미션에 사용할 수 있으며 완전히 제거한 뭉치 하나를 1개로 집계한다. 해금 레벨은 미정이다.
47. 레벨 에디터에서 N개 생성 위치에 총 M개의 이동 가능한 블록을 나누어 쌓아둘 수 있다. 위치별 종류·수량·순서, 로켓 방향·고철 내구도를 지정하며 일반 블록은 레벨에서 사용하는 색상만 허용한다. 생성구에 가까운 순서로 해당 위치에서만 공급하고 막히면 기다린다. 목록은 에디터에서만 보이고 플레이 중에는 보드로 들어올 때 나타난다. 최초 배치와 별개이며 시작 후 빈칸 보충부터 소비한다. 소진 후 공급 중단 또는 일반 블록 무작위 공급을 위치별로 지정한다.
48. 고철 개수 유지 방식은 보드 유지 목표와 최초 배치를 제외한 추가 생성 한도를 지정한다. 부족한 수량만큼 생성 가능한 지정 위치를 무작위로 선택해 하나씩 배정한다. 모두 막혔으면 대기하고 실제 생성 시에만 한도를 차감한다. 고철 보충을 우선하며 목표 충족 또는 한도 소진 시 일반 블록을 공급한다. 한 레벨 안에서 충돌하는 생성 방식의 혼용은 생성 위치가 달라도 금지한다. 고철 고정 목록 공급과 고철 개수 유지의 병행은 금지하며, 서로 영향을 주지 않는 여러 위치의 고정 목록은 함께 사용할 수 있다.

49. 공급된 파워 블록은 보드 진입 후 피격되면 즉시 발동하며 매칭 생성 파워의 보호를 적용하지 않는다. 개수 유지 방식의 고철 내구도는 레벨별로 하나를 지정한다. 재도전은 공급 목록·한도를 초기화하고, 강제 종료 후 복구는 잔여 목록·한도·무작위 결과를 유지한다. 제거 목표가 최초 배치와 최대 추가 공급의 합을 넘으면 에디터 오류로 표시하고 플레이를 막는다.
50. 고철에는 거미줄을 씌우지 않는다. 고철 제거 미션의 드론은 여러 단계 내구도의 고철도 후보로 삼되 이번 수에 피해받은 고철은 제외한다. 자석끼리 조합해도 고철은 1단계만 손상되며 한 수당 피해 제한을 유지한다.
51. 먼지는 내구도 1~3의 고정 바닥 장애물로 교환·낙하를 막지 않는다. 다른 장애물과 중첩할 수 있지만 위의 일반 블록을 매칭·파워로 제거할 때만 손상된다. 인접 매칭·망치 직접 타격·빈칸이나 장애물·파워 위의 타격으로는 제거되지 않는다. 거미줄만 손상되고 일반 블록이 남아도 먼지는 남는다. 매칭의 파워 생성 칸과 자석 조합으로 일반 블록을 파워로 변환하는 칸은 예외적으로 손상된다. 한 수당 최대 1단계이며 완전히 제거한 한 칸을 미션 1개로 집계한다. 드론은 실제 손상 가능한 일반 블록 위의 먼지만 먼지 미션 후보로 삼는다. 시작 시 배치하고 일반 플레이에서 생성·확산하지 않으며 재배치·섞기에도 위치·내구도를 유지한다.

52. 우주 곰팡이는 일반·파워 블록을 보존한 채 불투명하게 덮어 교환·낙하·매칭·발동을 막는다. 다른 덮개·장애물과는 중첩하지 않으며 바닥 먼지만 허용한다. 내구도 1이며 인접 매칭·파워 직접 타격·망치로 제거한다. 안의 블록 색·종류·로켓 방향을 유지하고 제거 뒤 정상 낙하·자동 매칭한다. 파워는 덮개 제거 타격에 발동하지 않고 별도 후속 타격부터 발동하며 기존 새 파워 보호는 유지한다.
53. 이동 횟수를 소비한 수에서 곰팡이를 하나도 제거하지 못하면 전체 연쇄 후 보드 전체에서 한 칸만 확산한다. 상하좌우 인접 유효 블록 중 무작위 선택하며 중복 후보는 한 칸으로 계산한다. 아이템 사용 뒤에는 확산하지 않는다. 후보가 없으면 확산하지 않고, 모두 제거하면 재발생하지 않는다. 모든 미션을 달성하면 확산 전 클리어한다. 확산 후 행동이 없으면 기존 자동 재배치 규칙을 적용하되 곰팡이와 안의 블록은 고정한다. 마지막 수 실패도 확산 후 표시하며 광고·아이템 이어하기는 그 상태에서 진행한다.
54. 곰팡이 미션은 보드의 곰팡이 전부 제거다. 확산 시 남은 수량이 늘고 제거 시 줄어 0에서 완료한다. 드론은 안의 블록 종류와 무관하게 곰팡이를 미션 우선 후보로 취급한다. 곰팡이 안의 블록은 자석의 색상 선택·제거·변환 대상이 아니지만 자석끼리 조합한 전체 타격은 덮개를 제거하고 안의 블록을 보존한다. 섞기는 곰팡이와 내용물을 제외한다. 강제 종료 후 위치·내용물·확산 결과를 복구하며 중복 확산하지 않는다.

55. 잠긴 고물 금고는 이동하지 않는 고정 장애물로 일반 매칭에는 손상되지 않고 파워 직접 타격 또는 망치에 손상된다. 내구도 1~5이며 굵은 잠금 막대 개수로 표시하고 한 수당 최대 1단계만 손상된다. 완전히 파괴하면 미션 1개로 집계하며 빈칸을 기존 낙하·보충으로 채운다. 금고 제거 미션의 드론은 이번 수에 아직 피해받지 않은 금고를 후보로 삼는다.
56. 색깔 자물쇠는 지정 색의 상하좌우 인접 매칭 또는 색과 무관한 파워·망치 직접 타격으로 손상되는 고정 장애물이다. 내구도 1~3, 한 수당 최대 1단계이며 지정 색을 끝까지 유지한다. 레벨에서 사용하는 달토끼 색 중 제작자가 지정한다. 인접 매칭의 파워 생성 칸도 피해 조건으로 인정한다. 제거 미션은 색 구분 없이 완전히 제거한 수를 합산하며 드론은 이번 수에 피해받지 않은 자물쇠를 우선 후보로 삼는다.
57. 고철 벽은 칸 사이 경계에 설치하는 파괴 불가능한 고정 지형이다. 벽을 넘는 교환·낙하·매칭 연결을 막지만 모든 파워 효과는 기존 범위·대상 규칙대로 벽을 통과한다. 대각선은 가로→세로 또는 세로→가로의 두 경로 중 하나 이상이 벽 없이 연결될 때만 가능하며 기존 대각선 낙하 조건도 유지한다.

58. 고철 벽은 인접 매칭 피해와 곰팡이 확산도 막는다. 2×2 매칭 내부 경계 하나라도 벽이 있으면 드론 매칭이 성립하지 않는다. 자리 바꾸기도 벽을 넘을 수 없지만 자동 재배치·섞기는 분리된 구역 사이에도 가능하다. 지정 낙하 경로가 벽을 통과하면 에디터 오류로 표시하고 플레이를 막는다.
59. 대형 폐가전은 활성 2×2 네 칸을 차지하는 고정 장애물로 내구도 1~9를 공유한다. 외형은 위에서 본 네모 금속기둥 상자이며 내부 3×3 배열에 내구도와 같은 수의 기둥을 표시한다. 내구도 9는 기둥 9개다. 피해량만큼 우하단부터 역순으로 기둥을 제거하고 남은 기둥의 격자 위치는 유지하며, 마지막 기둥과 함께 상자가 파괴된다. 내구도가 남아 있으면 네 칸 모두 막으며 완전 파괴 때 함께 비운다. 다른 블록·공간 점유 장애물과 겹칠 수 없고 바닥 먼지는 허용하되 파괴 후에도 먼지는 남는다. 내부 벽 배치는 금지하고 외곽 벽은 허용한다.
60. 대형 폐가전은 일반 장애물의 한 수당 1회 피해 제한의 예외다. 개별 파워 타격에서 맞은 칸마다 1피해, 최대 4피해를 주며 같은 수의 반복 타격도 허용한다. 인접 매칭도 닿은 폐가전 칸마다 1피해이며 같은 매칭 안의 중복 칸만 제외한다. 동시에 생긴 별개 매칭도 별도 타격이다. 자석끼리 조합은 4피해, 망치는 1피해다. 제거 미션은 본체당 1개다. 드론은 네 칸을 각각 후보로 삼고 서로 다른 칸에 여러 대가 타격하거나 이후 반복 타격할 수 있다. 벽 너머 인접 매칭 피해는 막히고 파워는 통과한다.

61. 고장 난 발전기는 2×2 고정 일회용 장치다. 에디터에서 필요 충전량 3~5회를 지정하고 같은 수의 큰 표시등으로 보여준다. 외곽 인접 매칭 또는 어느 점유 칸이든 파워·망치로 직접 타격하면 충전하되 한 수의 전체 연쇄 동안 발전기당 최대 1회다. 완충 즉시 연결 대상을 내구도와 무관하게 제거하고 자신도 사라지며 현재 효과·연쇄 후 정상 낙하·보충한다. 주변 폭발 피해는 없고 대상 제거는 해당 미션에 집계한다.
62. 발전기 연결 대상은 나무상자·금고·색깔 자물쇠·대형 폐가전이며 발전기당 1~3개, 대상 하나당 발전기 하나만 허용한다. 무연결 발전기는 에디터 설정 오류다. 먼저 직접 제거한 대상은 연결과 전선·단자를 해제하고 다른 대상으로 교체하지 않는다. 연결 대상이 전부 직접 제거되면 발전기도 자동 철거된다.
63. 전선은 블록 사이의 틈을 지나며 고철 벽을 피하고 서로 교차하지 않는다. 제작자가 에디터에서 경로를 직접 지정하고 블록이 이동해도 유지한다. 이동·매칭을 막지 않는다. 발전기와 대상에 동일 색·모양 단자를 표시하고 충전 시 빛을 흘린다. 가늘고 둥근 전선과 두껍고 각진 고철 벽을 구분한다. 드론은 남은 미션 목표와 연결된 발전기도 우선 후보로 삼되 이미 충전된 발전기는 제외하며, 한 드론이 예약하면 네 칸 전체를 다른 드론 후보에서 제외한다.

64. 곰팡이는 시작 배치·확산 모두 다른 덮개가 없는 일반·파워 블록만 덮으며 다른 장애물에는 겹치지 않는다. 바닥 먼지는 중첩을 허용하고 곰팡이 제거 후에도 남긴다. 자석은 색깔 자물쇠를 직접 타격하지 않지만 같은 색의 인접 일반 블록을 제거하면 1피해를 주며 한 수당 피해 제한·벽 차단을 유지한다. 파워 변환 자체에는 인접 피해가 없고 이후 직접 타격만 인정한다.
65. 바닥과 블록을 분리하고 구역별 상·하·좌·우 중력과 직접 경로 지정을 지원한다. 미설정 칸은 아래다. 대각선 규칙은 방향에 따라 회전 적용하고 같은 중력 방향 구역끼리만 허용하며 직접 경로에는 적용하지 않는다. 직선으로 다른 구역에 진입하면 그 칸부터 새 중력을 따른다. 중력·경로를 합쳐 순환을 검사하고 오류로 처리한다. 합류는 유입 우선순위를 지정하고 공급 불가 시 다음 순위를 확인한다. 생성 위치·공급 순서·회수 부품 공급은 69항에 추가 확정했으며 별도 공급 방향은 두지 않으며 생성 시각 표현은 후속 기획 사항이다.
66. 회수 부품은 매칭·파워·망치로 제거되지 않는 이동 오브젝트다. 일반 블록과 교환해 매칭하면 유효하며 로켓·폭탄·드론과 교환하면 파워가 발동하고 자석과는 비용 없이 되돌린다. 재배치·섞기에서는 제외하지만 자리 바꾸기는 벽·빈칸 제한 아래 허용한다. 도착 바닥은 부품만 진입 즉시 회수하며 같은 레벨의 어느 도착 바닥도 같은 부품을 받아들인다. 일반·파워 블록은 해당 칸 중력을 따른다. 회수 후 낙하를 계속하며 전체 연쇄 후 클리어를 판정한다. 일반 경로 끝 칸과 회수용 도착 바닥은 구분한다.

67. 이동 통로는 입구·출구 1:1 단방향 연결이며 여러 쌍을 허용한다. 같은 색·문양으로 짝을 표시한다. 이동 가능한 블록은 출구가 비면 이동해 도착 칸 중력을 따르고 막히면 입구에서 대기한다. 일반·대각선 낙하로 이탈하지 않지만 유효한 교환은 허용한다. 통로는 원격 인접 관계가 아니므로 매칭·교환·인접 피해·곰팡이 확산·파워 효과를 전달하지 않는다. 중력·경로와 합쳐 순환을 검사하고 출구 공급 합류 우선순위에도 포함한다.
68. 한 칸은 통로 입구·출구 중 하나만 맡고 통로 연속 연결 사이에는 일반 칸을 둔다. 도착 바닥과 통로는 중첩하지 않는다. 먼지는 중첩 가능하나 이동으로 제거되지 않는다. 고정 장애물의 시작 배치로 입구·출구를 막을 수 있고, 거미줄·곰팡이로 묶인 블록도 풀리기 전에는 통로 이동 불가다.
69. 새 블록은 지정 생성구에서만 공급한다. 기본 보드에는 상단 생성구를 미리 두되 중력 변경으로 자동 추가하지 않는다. 내부 활성 칸도 생성구로 지정 가능하며 기존 블록의 낙하·통로 유입을 먼저 처리한 뒤 비었을 때 생성한다. 생성구와 회수 도착 바닥은 중첩 금지다. 회수 부품은 최초 배치·고정 목록 외에 보드 개수 유지 공급도 가능하며 남은 목표 수량을 초과해 추가 공급하지 않는다. 고철과 회수 부품의 유지 공급은 서로 다른 생성구를 쓰며 각 생성구는 한 종류만 맡고 보충 불필요 시 일반 블록을 공급한다.

70. 생성구는 지정 칸에 공급하고 해당 칸 중력·경로를 따르며 별도 이동 방향을 두지 않는다. 회수 미션의 도착 바닥 누락·공급 수량 부족은 에디터 오류다. 불완전한 레벨도 작업 중 저장 가능하지만 필수 오류 해결 전에는 테스트하지 못한다.
71. 게임과 에디터는 Unity 기준이다. 요소별 편집을 분리하고 클릭·드래그 칠하기 및 드래그 단위 실행 취소·다시 실행을 지원한다. 2×2 요소는 왼쪽 위 기준 미리보기와 단일 클릭으로 배치한다. 같은 종류의 다중 선택은 혼합값 표시와 수정 항목만 적용하는 공통 인스펙터를 사용한다. 공급 목록은 옆 패널에서 아래부터 공급되는 쌓기 형태로 표시하며 순서 변경·항목 복제·목록 복사·전체 교체 또는 뒤에 추가를 지원한다. 상세 내용은 레벨 에디터 문서에 정리했다.
72. 레벨은 독립 Unity 에셋으로 저장·복제하고 별도 레벨 번호로 순서를 관리하며 중복 번호를 오류로 표시한다. 테스트는 원본과 분리한 복사본에서 실행하고 같은 무작위 조건 또는 새 조건으로 재시작한다. 에디터의 흐름은 옅게 유지하면서 주기적으로 강조하며 이동 흐름과 발전기 연결을 번갈아 보여준다. 강조 시간과 구체적 창 구성·구현은 미정이다.

73. 에디터는 왼쪽 도구·가운데 보드·오른쪽 공통 인스펙터·하단 오류 목록이다. 삭제는 현재 편집 요소만 지우며 2×2 본체는 전체 삭제한다. 발전기 삭제는 전선도 정리하되 대상은 남기고, 연결 요소 이동은 연결 관계를 유지하되 경로 재지정을 표시한다. 비활성 칸의 배치는 보존하고 오류 처리한다. 2×2는 유효 위치로만 이동한다. 오류 클릭은 해당 위치를 강조한다.
74. 무작위 초기 블록은 `?`로 표시하고 고정 배치는 시작 검사에서 변경하지 않는다. 사용 색 변경의 미사용 색은 자동 변환하지 않고 오류 처리한다. 미션 인스펙터에 공급 가능 수량을 표시한다. 수동 테스트는 부스터·아이템 잠금과 재고 제한을 풀지만 자동 난이도 평가에서는 사용하지 않는다. 검토용 레벨 제작보다 에디터 개발을 우선하며 현재 ServeredMeridian 프로젝트에서 개발하기로 확정했다. 스크립트는 Assets/Scripts 바로 아래에 게임명 중간 폴더 없이 기능별로 구성한다.
75. 우선 직접 만든 레벨의 자동 플레이·분석·난이도 추천을 개발하고 무작위 레벨 생성은 후순위로 미룬다. 기본·계획 전략을 같은 시작 조건과 시드 묶음으로 비교한다. 봇은 공개 정보로만 판단하고 사용자의 조작 검증·실행 경로를 공유하며 비공개 공급·곰팡이 내부·미래 난수는 보지 못한다.
76. 봇·게임 실행부·공개 관찰 제공부·분석기는 Unity 내부에서 구조와 로직을 분리한다. 별도 프로그램 실행은 채택하지 않았다. 분석기는 내부 상태를 기록하되 봇에게 전달하지 않는다. 고속 테스트는 연출만 생략하고 동일한 판정 순서·결과를 유지한다. 반복 횟수는 77항에 확정했다. 관찰 데이터, 전략 세부 알고리즘, 난이도 산정 기준은 미정이다. 상세 기획은 자동 플레이와 난이도 분석 문서를 따른다.

77. 자동 분석은 전략별 기본 100회·총 200회이며 변경 가능하다. 새 테스트는 새 시드 묶음, 두 전략 비교는 같은 묶음, 수정 전후 비교·재현은 저장 시드를 사용한다. 성공·실패 통계를 분리하고 예상 난이도 5단계와 근거를 표시한다. 오류가 있으면 판단을 보류한다. 원인 태그는 계획 요구·무작위 영향 큼·이동 여유 부족이며 근거가 있을 때 표시한다. 대표 사례 재생과 수정 전후 분석 이력을 지원한다. 등급·태그 기준 수치는 미정이다.
78. 자동 테스트는 진행률·중지·일시정지와 재개를 지원한다. 중지 시 완료된 기록을 보존하고 일부 실행으로 표시한다. 진행 중인 판의 정지 시점과 중지 처리 상세는 미정이다.
79. 대상별 반응·미션 기여 판단·목표 관리 매니저를 분리하고 실제 처리와 사전 조회가 같은 규칙을 공유한다. 조회는 실제 보드를 변경하지 않으며 반응·변화량·불가 이유를 반환한다. 매니저는 상태가 같으면 후보를 재사용하고 변하면 재조회하며 추천·예약 등록·해제를 담당한다. 개별 대상 규칙을 매니저에 집중시키지 않는다.
80. 드론은 실제 효과 범위로 후보를 평가하고, 조합 효과의 직접 범위 내 미션 대상까지 예약한다. 발전기는 본체 전체, 폐가전은 타격 칸 단위이며 직접 피해·충전·예상 미션 진행량도 예약에 반영한다. 추가 연쇄는 예측하지 않는다. 타격 완료·목표 무효화 시 예약을 풀되 피해 이력은 유지한다. 목표가 사라지면 미션 후보를 다시 찾고 없으면 일반 블록을 선택하며 둘 다 없을 때만 종료한다. 상세 구조는 규칙 조회와 목표 관리 문서를 따른다.
