# 24단계 개발 목표 — 수동 플레이 통합

- 작성일: 2026-09-28. 상태: 계획 작성, 구현·Goal 생성 미실행.
- 상세 계획: [24단계 작업 계획](59_24단계_수동플레이통합_작업계획.md).
- 선행: [23단계 목표](58_23단계_개발목표.md). 작성 당시 23단계 Goal 활성 상태이며 완료 확인 전에는 24단계에 착수하지 않는다.

## Goal 목표

기존 Match 에디터와 공통 실행기를 연결해 편집→검사→사본 플레이→판 종료→같은/새 시드 재시작→편집 복귀를 완성한다. 확정된 지원 요소를 통합 검증하고 원본 보존·재현·실제 UI 증거를 남긴다.

## 실행 지침

1. 현재 Goal과 23단계 완료 조건·실행 증거를 확인한다. 다른 활성 Goal을 덮어쓰거나 문서의 선행 상태를 임의로 완료 처리하지 않는다.
2. 23단계가 미완료이면 남은 선행 조건을 보고하고 24단계 구현은 시작하지 않는다. 이번 문서 작성 자체는 Goal 실행 요청이 아니다.
3. 명시적인 실행 요청과 선행 완료 확인 후 24단계 Goal을 생성한다. 동일한 24단계 Goal이 활성 상태이면 이어서 수행한다.
4. ponytail·프로젝트 Unity 지침에 따라 계획 T1→T6을 진행한다. 최신 코드와 실제 증거를 기준으로 기존 실행기·창·스타일·검증 방식을 재사용한다.
5. 스크립트는 `Assets/Scripts`의 기존 기능별 경계에 둔다. Editor 입력과 공통 규칙 실행 책임을 유지하며 별도 게임 엔진을 만들지 않는다.
6. 정의·GUID/meta·미저장 편집·연결/경로/합류 기능과 무관한 변경을 보존한다. 이전 단계 증거를 덮어쓰지 않는다.
7. 미지원 요소·실행 오류를 정상 패배로 취급하지 않는다. 완료 조건별 증거가 없으면 미검증으로 남긴다.
8. 25단계 봇·통계·난이도 평가, 출시용 UI·광고·재화·앱 복구는 구현하지 않는다. 이번 Goal은 24단계만 진행한다.

## 완료 조건

- [ ] 1. 23단계 완료와 최신 소스·원본 보존 기준을 확인했다.
- [ ] 2. 정의·검증기·실행기를 대조한 지원표와 사례별 증거를 기록했다.
- [ ] 3. 레벨 에디터에서 현재 레벨의 미저장 내용을 보존하며 테스트로 진입한다.
- [ ] 4. 구조 오류·잘못된 참조·미지원 요소가 시작을 막고 이유를 표시한다.
- [ ] 5. 시작 상태가 원본과 분리되고 최초/지정 시드·시작 부스터 설정을 확인할 수 있다.
- [ ] 6. 일반 교환·파워·조합은 공통 명령으로 실행하며 이동 수와 실패 처리를 보존한다.
- [ ] 7. 정상 입력 후 자동 연쇄가 안정/종료 경계까지 진행되고 중복 입력을 차단한다.
- [ ] 8. 단계별 진단과 기본 플레이가 같은 규칙 결과를 내며 동시에 상태를 변경하지 않는다.
- [ ] 9. 세 아이템·세 시작 부스터의 선택·대기·배치·종료 우선 계약을 보존한다.
- [ ] 10. 성공·이동 수 소진·진행 불가·실행 오류와 라스트팡 상태를 구분한다.
- [ ] 11. 같은 시드 재시작이 이전 실행 상태·선택·예약을 지우고 부스터 선택을 초기화한다.
- [ ] 12. 새 시드 재시작이 직전과 다른 시드를 사용하며 값을 확인할 수 있다.
- [ ] 13. 편집 복귀가 실행 예약을 해제하고 원본 배치·미저장 편집·공급 목록을 유지한다.
- [ ] 14. 원본 변경·레벨 전환·창 종료·재로드에서 낡은 세션과 콜백을 재사용하지 않는다.
- [ ] 15. 장애물·덮개·바닥·발전기·회수·공급·이동 경계의 대표 통합 사례를 통과했다.
- [ ] 16. 실제 UI 1000/680 폭·스크롤에서 시작·플레이·결과·재시작·복귀가 가능하다.
- [ ] 17. 같은 정의·시드·선택·행동으로 단계/자동 실행 및 독립 Unity 프로세스 재현을 검증했다.
- [ ] 18. 컴파일과 수정 영향 회귀, 기존 연결·통로·낙하 경로·합류 컨텍스트·Undo/Redo를 검증했다.
- [ ] 19. 원본 JSON·dirty 상태·GUID/meta·패키지·설정 보존과 소유 임시 자원 정리를 확인했다.
- [ ] 20. 조건별 증거·중복 없는 검사 집계·버전·파일 책임·최신 사용법·제외 범위를 기록했다.
