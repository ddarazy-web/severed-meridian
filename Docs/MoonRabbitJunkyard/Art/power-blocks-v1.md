- 청소로켓은 일반 달토끼 블록과 구분되도록 선명한 주황색, 넓은 크림색 띠, 남색 날개와 길쭉한 실루엣을 사용했다. 방향 화살표와 몸체 방향으로 가로·세로 효과를 구분한다.

- 상태: 생성 시안. 사용자 최종 승인 및 실제 보드 크기의 가독성 검수 전이다. 기존 이미지나 에디터·런타임 연결 코드는 변경하지 않았다.
- 다섯 파일 모두 1254×1254px, 32비트 알파 PNG 생성 원본이다. 원본과 동일한 해시로 프로젝트에 복사했으며 네 모서리 알파 0을 확인했다. 256px 게임용 축소본이나 Unity 임포트 설정은 이번 범위에 포함하지 않았다.
