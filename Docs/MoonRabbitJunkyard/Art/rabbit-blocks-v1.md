# 기본 달토끼 블록 추가 4종

- 내장 image_gen 도구로 기존 분홍 토끼를 참고하여 제작했다.
- 최종 게임용 파일은 모두 256×256px RGBA PNG다. 고품질 축소 후 크기·투명 모서리·본체 불투명 영역을 확인했다.
- 기존 분홍 토끼의 PNG는 변경하지 않았다. 후속 에디터 적용 작업에서 5종을 편집·테스트 보드에 연결하고 투명 배경·256px·비압축·밉맵 없음·Bilinear·Clamp 임포트 설정을 적용했다. 런타임 화면 연결은 별도다.
