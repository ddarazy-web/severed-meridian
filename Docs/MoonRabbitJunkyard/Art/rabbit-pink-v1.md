# 분홍 달토끼 기본 블록 시안 1

- 파일: [rabbit-pink-v1.png](rabbit-pink-v1.png)
- 게임용 256×256px: [Assets/Textures/Blocks/rabbit-pink-v1-256.png](../../../Assets/Textures/Blocks/rabbit-pink-v1-256.png). 사용자의 크기 변경 요청에 따라 원본 그림과 투명 배경을 유지한 축소본을 제작하고 해당 카테고리로 이동했다.
- 도구: 내장 image_gen, 투명 배경 요청.
- 참고: 사용자가 승인한 HTML 목업의 분홍 달토끼. 기본 블록 한 종류만 제작.
- 원본은 보관한다. 처음에는 게임용 512×512px를 권장했으나 사용자가 256×256px를 선택하여 해당 크기를 제작했다. 실제 표시 크기·압축·필터링과 작은 화면 식별성은 Unity 적용 시 검수한다. 런타임 스프라이트 연결은 아직 하지 않았다.
- 실제 출력: 1254×1254px, RGBA PNG. 알파 채널 최솟값 0·최댓값 255로 투명 배경을 확인했다. 생성 요청의 1024×1024와 실제 출력 크기는 다르므로 원본 크기를 그대로 기록한다.
