# 달 토끼 고물상 — 성장과 보상

## 확정 사항

- 고물상과 달 정거장은 주문 3건을 납품할 때마다 짧은 이야기 장면을 통해 조금씩 회복된다. 시설별 설치·개선 화면은 필수 진행 구조로 두지 않는다.
- 퍼즐 레벨 첫 클리어마다 별 1개를 지급한다.
- 모은 별을 단계별로 소비하여 작업을 진행한다.
- 별은 손님 주문의 작업 단계에만 사용한다. 시설 개선에는 별을 추가로 소비하지 않는다.
- 주문을 납품하면 해당 주문이 별도의 주문 내역 장부에 기록된다. 3건마다 정거장 복구 이야기를 보여준다.
- 일반 주문은 그림 10조각·작업당 별 5개로 총 별 50개다.
- 첫 로봇 주문은 예외적으로 5조각·총 별 20개다. 첫 묶음은 작업 1개에 별 1개, 두 번째 묶음은 작업 4개에 각각 별 4·5·5·5개다.
- 고물의 무게·상대적 비중으로 작업 비용을 정하던 방식은 사용하지 않는다.
- 자유 배치나 생산·판매 경영 시스템은 현재 확정된 범위에 포함하지 않는다.

## 기본 진행 흐름

퍼즐 레벨 첫 클리어 → 별 획득 → 공개된 작업 중 하나를 선택해 별 소비 → 그림 조각 추가 → 현재 묶음 완료 시 다음 묶음 공개 → 모든 작업 완료 → 완성 대사·주문 보상 → 장부 기록·다음 주문 자동 접수. 주문 3건을 납품할 때마다 정거장 복구 이야기가 나온다.

- 퍼즐은 점수·별 등급 없이 목표 달성 여부로 클리어를 판정한다. 라스트팡을 건너뛰어도 첫 클리어 별 1개는 동일하게 지급한다.
- 주문 작업에 필요한 별이 모여도 퍼즐을 계속 진행하여 별을 미리 쌓을 수 있다. 별을 쓰거나 주문을 실제로 완료해야 다음 퍼즐을 진행하는 구조는 사용하지 않는다.
- 장애물은 실제 주문 완료 여부가 아니라 지정된 퍼즐 레벨에서 해금한다. 첫 주문의 필요 별 20개에 대응하여 거미줄은 21레벨에서 해금한다.
- 시작 전 부스터는 실제 첫 주문 완료 시 청소로켓, 두 번째 완료 시 달 폭탄, 세 번째 완료 시 무지개 자석을 해금한다. 최초에는 세 종류 모두 잠겨 있다.
- 최초 해금한 부스터는 해금 순간부터 실제 시간 5분간 무한 사용한다. 앱 종료 중에도 시간은 흐른다. 퍼즐 시작 시 시간이 남아 있었다면 그 판의 배치가 지연되어 만료되더라도 보유 수량은 차감하지 않는다. 판당 해당 부스터 1개 제한은 유지한다.
- 게임 중 아이템은 고물 망치 7레벨, 자리 바꾸기 12레벨, 섞기 16레벨에 해금하고 최초 해금 시 각각 보유 수량 차감 없는 1회 체험 튜토리얼을 제공한다.
- 부스터와 게임 중 아이템 모두 잠긴 상태에서도 랜덤박스로 획득·보관할 수 있지만 해금 후에만 사용한다. 잠금 여부에 따라 기존 박스 확률을 바꾸지 않는다.

스테이지 하나는 손님 주문 하나에 해당한다. 정거장 복구 장면의 내용과 그 밖의 이야기 해금 조건은 미정이다.

## 스테이지와 작업 단계

- 용어: 매치3 한 판은 ‘퍼즐 레벨’, 별을 소비해 그림을 완성하는 큰 단위는 ‘스테이지’, 스테이지 내부 작업은 ‘단계’로 구분한다.
- 일반 스테이지는 10단계로 나누고, 첫 주문만 5단계로 구성한다.
- 각 단계에 지정된 별을 소비하면 해당 부분의 작업이 진행된다.
- 주문 자체는 정해진 순서대로 진행한다. 현재 주문의 공개된 작업 묶음 안에서는 플레이어가 원하는 작업을 선택한다.
- 일반 주문은 3개 → 3개 → 4개, 첫 주문은 1개 → 4개 묶음으로 공개한다. 현재 묶음을 모두 완료해야 다음 묶음이 열린다. 하나를 끝낼 때마다 다음 작업을 보충하지 않는다.
- 별이 충분해도 작업 버튼 한 번에 선택한 작업 하나만 완료하며, 여러 작업을 자동으로 연속 수행하지 않는다.
- 모든 단계를 완료하면 스테이지를 클리어한다.
- 스테이지를 클리어하면 해당 손님 주문을 납품한다.
- 일반 주문의 모든 작업은 별 5개씩이며 합계 50개다.
- 첫 주문은 상태 점검 별 1개, 다음 묶음은 부품 분류 별 4개와 고장 부품 교체·배선 정리·전원 점검 각 별 5개로 합계 20개다.
- 단계별 배분은 별을 정수 단위로 맞추며, 전체 단계 비용 합계가 그 스테이지의 총 별 비용과 같아야 한다.

## 그림 진행 방식 — 확정

- 주문 물품이 없는 빈 흑백 배경을 아래에 두고, 그 위에 완성 그림을 분할한 조각을 하나씩 채운다. 물품의 흑백 밑그림을 미리 보여주는 방식이 아니다.
- 페이지를 일반 주문 10조각, 첫 주문 5조각으로 나누고 작업마다 특정 조각을 연결한다. 정확한 분할 배치와 작업-조각 연결은 그림 제작 시 정한다.
- 작업명은 수리 등의 행동을 설명하고 그림 조각은 주문 전체의 완성도를 보여준다. 작업 내용과 그림 속 부위를 일대일로 대응시키지 않는다.
- 각 작업이 공개하는 조각 위치는 제작 시 지정하여 고정한다. 같은 묶음에는 서로 인접한 조각들을 배정한다. 실제 분할 위치는 완성 그림을 보고 정한다.
- 부품별 추가·고물별 제거를 별도 유형으로 제작하던 이전 방식은 이 공통 그림 조각 방식으로 대체한다.
- 모든 주문은 접수·완료 시에만 짧은 대사를 넣고, 중간 작업은 그림 변화와 효과음으로 표현한다.
- 마지막 작업이 끝나면 별도의 완료 버튼 없이 완성 대사와 주문 보상 화면으로 진행한다.
- 보상 수령 후 다음 주문을 자동 접수하고 메인 배경을 새 주문의 초기 그림으로 바꾼다. 완료된 그림과 짧은 기록은 장부에 남긴다.

## 정거장 복구 이야기 예시 — 제안

- 통신 안테나가 작동해 새로운 주문이 들어온다.
- 작업대를 쓸 수 있게 되어 손님의 물건을 수리한다.
- 착륙장에 여행자와 옛 이웃이 찾아온다.

## 수익 모델과 광고

- 아이템 판매와 선택형 보상 광고로 수익을 얻는 방향이다. 강제 광고는 사용하지 않는다.
- 재도전은 횟수 제한 없이 무료다. 이어하기 등 여러 상황에서 보상 광고를 제안할 수 있지만 시청은 선택 사항이다.
- 광고 종류마다 독립된 시청 횟수 제한을 두어 보상을 무한 지급하지 않는다. 하루 한도는 기기 현지 시간 기준 자정에 초기화한다.
- 아이템은 적게 지급하는 방향으로 설계하며, 광고·플레이 보상에 랜덤박스를 활용한다.
- 유료 판매는 구성과 수량이 명확한 아이템 묶음으로 한다. 랜덤박스는 광고·플레이 보상으로만 제공한다.
- 광고는 이어하기, 상점 보급함, 주문 납품 보너스에 제공한다. 구체적인 한도는 아래 표를 따른다.
- 판매 가격·묶음 구성, 추가 획득 경로, 플랫폼별 광고 제공 방식은 미정이다.
- 유료 결제의 세부 기획은 보류한다. 확정 구성의 아이템 묶음 판매라는 기존 방향은 유지하되, 유료 재화 유무·직접 결제 방식·가격·상품 구성은 결정하지 않았다.
- 보상 획득 조건을 충족하기 전에 광고를 닫거나 오류로 중단되면 보상을 지급하지 않고, 일일 횟수도 차감하지 않으며 보급함 대기시간도 시작하지 않는다.
- 광고 보상 획득이 확인되면 저장한다. 이후 앱이 종료되더라도 재접속 시 누락·중복 없이 한 번만 지급한다. 이는 설계 요구사항이며 아직 구현·검증하지 않았다.

| 광고 종류 | 보상 | 제한 |
| --- | --- | --- |
| 이어하기 | 이동 횟수 5회 추가 | 한 판 1회, 하루 최대 5회 |
| 상점 보급함 | 랜덤박스 1개 | 하루 최대 5회, 수령 후 10분 대기 |
| 주문 납품 보너스 | 기본 보상에 추가로 랜덤박스 1개 | 주문당 1회, 하루 최대 3회 |

- 이어하기 아이템은 아래 확정 규칙을 따른다. 광고의 하루 5회 제한을 아이템에 자동 적용하거나 기존 보급함 확률·유료 상품 구성을 변경하지 않는다.

- 보급함은 상점에 배치하고 남은 수령 횟수와 대기시간을 표시한다. 광고를 시청해야 수령할 수 있다.
- 보급함 대기시간은 게임을 종료한 동안에도 흐른다. 자정에 하루 한도가 초기화되어도 남은 10분 대기시간은 유지한다.

## 이어하기 아이템 — 2026-09-29 확정

| 수단 | 효과·비용 | 판당 제한 | 일일 제한 |
| --- | --- | --- | --- |
| 광고 이어하기 | 보상 광고 완료 시 이동 +5회 | 1회 | 최대 5회 |
| 아이템 이어하기 | 아이템 1개 소비, 이동 +5회 | 1회 | 유무 미정 |

- 두 수단의 판당 한도는 독립적이다. 둘 다 사용할 수 있는 판은 합계 최대 2회 이어갈 수 있다.
- 아이템 사용 전 확인창을 한 번 표시하며 확인 시에만 소비한다. 취소하면 수량과 사용 기회를 유지한다.
- 두 수단이 모두 가능하면 버튼을 나란히 표시한다. 아이템은 보유 수량을 표시하고, 수량 0 또는 판당 사용 완료 시 버튼을 숨긴다. 상세 화면 흐름은 [플랫폼과 화면](06_플랫폼과화면.md)을 따른다.
- 게임 중 아이템 3종과 구분하여 실패 패널에서 사용한다. 무료·무제한 재도전은 계속 제공한다.
- 획득 경로, 해금 조건, 일일 한도 유무, 유료 판매 여부는 미정이다. 현재 랜덤박스 구성·확률에 이어하기 아이템을 임의로 추가하지 않는다.
- 소비 직후 강제 종료·복원, 진행 불가 종료 시 반환 등 새 아이템의 구체적인 저장·예외 처리는 구현 계획 전에 정리한다. 확정하지 않은 예외를 이미 구현된 규칙으로 취급하지 않는다.

## 주문 완료 기본 보상과 추가 광고 보상

- 주문 완료 시 광고와 무관하게 기본 보상으로 랜덤박스 1개를 지급한다. 광고를 건너뛰거나 볼 수 없어도 기본 보상은 받는다.
- 납품 보너스 광고를 시청하면 랜덤박스 1개를 추가 지급하여 총 2개를 받는다. 광고의 일일 한도는 기본 보상에 적용하지 않는다.
- 광고는 해당 주문 완료 시점에 한 번만 제안한다. 넘기면 장부 등에 미수령 보상을 남기지 않으며 나중에 받을 수 없다.
- 선택 버튼은 ‘광고 보고 랜덤박스 1개 받기’와 ‘그냥 완료’로 표시한다. 닫으면 추가 확인 없이 완료한다.
- 납품 보너스 광고의 일일 한도를 채웠거나 광고를 불러올 수 없으면 광고 제안 없이 주문 완료로 진행한다. 이 경우에도 기본 랜덤박스는 지급한다.

## 랜덤박스

- 아이템 조각은 사용하지 않는다. 박스 획득 횟수를 제한하는 방식으로 지급량을 관리한다.
- 박스 하나에서 꽝 없이 완성 아이템 1개를 지급하고 종류만 무작위로 정한다.
- 획득 즉시 개봉하여 아이템을 지급한다. 미개봉 박스를 별도로 보관하지 않는다.
- 상점 보급함, 주문 완료 기본 보상, 납품 보너스 광고의 랜덤박스는 모두 아래의 같은 구성·확률을 사용한다. 합계는 100%이며, 향후 밸런스 조정이 가능한 초기 기준이다.

| --- | --- | --- |

| 달 폭탄 | 시작 전 부스터 | 25% |
| 무지개 자석 | 시작 전 부스터 | 15% |

## 용어와 표현상 주의점

주문 작업에 쓰는 보상 별과, 장애물 등에 활용할 수 있는 별 모양 소재는 별개다. 둘 다 채택한다면 생김새와 표시 위치로 구분해야 한다.

서사 속 판매 수익은 정거장 복구의 이유다. 시스템상 별은 주문 작업 진행에만 쓰는 보상이며, 실제 돈으로 취급하지 않는다.
