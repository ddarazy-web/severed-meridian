# 달 토끼 고물상 — 플랫폼과 화면

| 항목 | 확정 방향 |
| --- | --- |
| 지원 플랫폼 | 모바일·PC |
| 모바일 화면 | 세로 |
| PC 화면 | 가로 |
| 보드·규칙 | 공통 |
| UI | 기기 화면 비율에 따라 재배치 |

## 퍼즐 입력

- 퍼즐 화면의 미션은 아이콘과 남은 수량으로 표시하며, 완료하면 숫자 대신 체크 표시로 바꾼다. 시작 전 부스터 선택 화면에는 미션과 이동 횟수를 표시하지 않는다.
- 1레벨은 안내한 두 블록의 교환만 허용하고 게임 중 아이템은 사용하지 않는다. 시작 전 부스터 선택 화면도 건너뛴다.

- 모바일·PC 모두 드래그와 두 칸 순차 선택으로 블록을 교환할 수 있다.
- 파워 블록의 제자리 발동은 모바일 더블터치, PC 더블클릭으로 조작한다.
- 매칭·파워 효과·낙하·보충 등 전체 연쇄가 끝나 보드가 안정된 뒤에만 새 조작을 받는다.
- 조합 효과의 중심은 드래그로 놓은 칸 또는 순차 선택한 두 번째 칸이다.

## 자동 힌트

- 별도 켜기·끄기 설정 없이 기본 기능으로 제공한다.
- 보드가 안정된 상태에서 10초간 입력이 없으면, 가능한 교환이나 발동 가능한 파워 블록 중 행동 하나를 무작위로 안내한다. 최적의 수를 계산해 추천하지 않는다.
- 교환 힌트는 해당 블록을 교환 방향으로 살짝 이동하듯 흔든다. 제자리 파워 발동 힌트는 해당 블록이 살짝 커졌다 작아지도록 표현한다.
- 보드를 터치하거나 클릭하면 힌트를 즉시 숨기고, 다시 보드가 안정된 상태에서 10초간 입력이 없으면 표시한다. 매칭·연쇄 처리 중에는 시간을 세지 않는다.
- 게임 중 아이템의 대상 칸을 고르는 동안에는 힌트를 숨기고 타이머를 멈춘다. 사용 또는 취소가 끝나 보드가 안정되면 새로 10초를 센다.

## 게임 중 아이템 선택과 조작

- 잠긴 게임 중 아이템은 수량·해금 조건 없이 잠금 표시만 보여준다. 해금된 아이템의 보유 수량이 0이면 버튼을 비활성화하고 수량을 표시한다. 최초 해금의 무료 1회 체험은 보유 수량을 요구하지 않는다. 구매창 연결은 유료 결제 기획과 함께 보류한다.
- 아이템 선택 중에는 다른 아이템 버튼을 숨기지 않고 흐리게 표시해 선택을 막는다. 다른 아이템을 사용하려면 현재 선택을 먼저 취소해야 한다. 선택 중 즉시 다른 아이템으로 전환하는 방식은 사용하지 않는다.
- ‘취소’ 버튼을 표시하며, 선택한 아이템 버튼을 다시 눌러도 사용 모드를 취소한다. 실행 전 취소에는 아이템을 소모하지 않는다.
- 대상 선택 중에는 일반 교환·파워 블록 더블터치·더블클릭을 막고 아이템 대상 지정만 허용한다. 일시정지 메뉴도 열 수 없다.
- 유효하지 않은 칸을 누르면 선택 상태를 유지하고 아이템을 소모하지 않는다.
- 망치에는 ‘망치로 칠 칸을 선택하세요’, 자리 바꾸기에는 ‘바꿀 블록 두 개를 선택하세요’라는 짧은 안내를 표시한다.
- 자리 바꾸기의 첫 블록은 테두리로 표시하고, 교환 가능한 상하좌우 블록만 강조한다. 안내는 ‘강조된 블록을 선택하면 교환해요’로 바꾼다.
- 첫 블록을 다시 누르면 첫 선택만 해제하고 사용 모드는 유지한다. 인접하지 않은 다른 이동 가능 블록을 누르면 그 블록으로 첫 선택을 변경한다.
- 망치는 유효한 대상 칸을 한 번 누르면 추가 확인 없이 실행한다. 섞기는 사용 확인창에서 확인해야 실행하며 취소하면 소모하지 않는다.
- 아이템 효과와 후속 연쇄가 모두 끝나 보드가 안정된 뒤에만 다음 아이템을 사용할 수 있다.

## 시작 전 부스터 표시

- 1레벨을 제외하고 부스터 해금 전에도 진입 화면을 표시한다. 레벨 번호, 부스터 3칸, 시작 버튼과 닫기를 제공하며 미션·이동 횟수는 미리 표시하지 않는다.

- 잠긴 부스터는 수량·해금 조건 없이 잠금 표시만 보여준다. 획득한 수량은 보관하되 해금 후 사용한다.
- 최초 해금 시 ‘청소로켓 부스터 해금! 5분간 무한 사용’처럼 해당 이름과 혜택을 짧게 알린다. 긴 부스터 사용 튜토리얼은 추가하지 않는다.
- 무한 사용 중에는 보유 수량 대신 `∞`와 남은 시간을 표시한다. 퍼즐 시작 전에 시간이 만료되면 해당 선택을 해제하고, 보유 부스터 사용은 다시 선택하도록 한다.

## 퍼즐 클리어 화면

- 클리어 확정 후 라스트팡을 보여준다. 터치·클릭으로 건너뛸 수 있으며 보상은 동일하다.
- 결과 화면은 ‘다음 퍼즐’과 ‘메인으로’를 제공한다. 다음 퍼즐은 부스터 선택 화면으로 이동하며, 기존대로 부스터는 모두 해제된 상태다.
- 주문 작업에 필요한 별이 모였더라도 다음 퍼즐을 계속 진행하여 별을 모을 수 있다.
- 라스트팡 도중 강제 종료한 경우에는 일반 퍼즐 복원과 달리 결과 화면으로 이동하고 연출을 반복하지 않는다. 보상은 한 번만 지급한다.

## 메인 화면과 납품 기록

- 메인 화면의 배경은 현재 진행 중인 주문의 그림과 진행 상태를 보여준다.
- 그림을 넓게 보여주고, 스패너와 드라이버가 교차한 작업 아이콘을 누르면 작업 목록 패널을 연다. ‘작업하기’ 텍스트 버튼은 사용하지 않는다.
- 현재 공개된 작업 중 별이 충분해 실행 가능한 작업이 있으면 작업 아이콘에 작은 알림 점을 표시한다.
- 상점은 작은 가게, 주문 장부는 장부 아이콘으로 표시한다. 퍼즐 진입 버튼은 재생 아이콘과 다음 레벨 번호를 함께 표시한다.
- 상단에 별 아이콘과 보유 수량을 항상 표시한다. 주문 전체 진행도는 ‘완료 4/10’처럼 표시하며 첫 주문은 총 5개를 기준으로 한다.
- 주문 물품이 없는 빈 흑백 배경 위에 작업 완료에 따라 그림 조각을 채운다. 작업은 일반 주문 3→3→4개, 첫 주문 1→4개 묶음으로 제시하고 현재 묶음 안에서 자유롭게 선택한다. 모두 완료하면 다음 묶음을 공개한다.
- 작업별 이름과 필요한 별 수를 표시한다. 조각 미리보기는 제공하지 않는다. 작업 버튼을 한 번 누르면 하나만 진행한다.
- 별 소비로 완료한 작업은 즉시 목록에서 숨기고, 현재 묶음의 남은 작업을 빈칸 없이 당겨 정렬한다. 마지막 작업까지 끝내면 다음 묶음으로 교체한다.
- 작업을 선택하면 목록을 닫고 그림 조각이 채워지는 연출을 보여준다. 연출 중 다른 작업은 선택할 수 없다. 연출 후 남은 작업 목록을 다시 열며, 묶음 완료 시 다음 묶음을 보여준다. 주문 전체 완료 시에는 완료 연출·보상으로 진행한다.
- 필요한 별이 부족한 작업의 버튼은 ‘퍼즐로 별 모으기’로 바꾸고 다음 레벨 진입 화면에 연결한다.
- 마지막 작업 완료 후 짧은 완성 대사와 보상 화면으로 자동 진행한다. 보상 수령 후 다음 주문을 자동 접수하고 메인 배경도 새 주문 초기 상태로 바꾼다.
- 주문을 납품하면 별도의 주문 내역 장부에 완료 기록을 남기고 다시 볼 수 있게 한다. 화면 성격은 완성 그림을 나열하는 갤러리보다 기록장에 가깝다.
- 장부 한 건은 손님과 물건의 이름, 완료된 주문 그림, 납품 결과를 적은 짧은 메모로 구성한다. 주문 당시의 대화 전체를 다시 읽는 기능은 넣지 않는다.
- 정거장의 대형 시설 복구 화면은 핵심 보상 화면으로 구성하지 않는다. 정거장이 조금씩 회복되는 모습은 주문 누적에 따른 이야기에서 전달한다.
- 장부의 구체적인 배치 방식은 미정이다.
- 1레벨 첫 클리어 후에는 메인에서 작업 아이콘을 안내하고, 받은 별 1개로 ‘상태 점검’을 해보는 튜토리얼을 제공한다.

## 저장과 오프라인 진행

### 나가기·일시정지·재도전

- 퍼즐의 일시정지 메뉴에는 ‘계속하기 · 재시작 · 메인으로 나가기’를 제공한다.
- 게임 화면에서 메인으로 나가면 포기로 처리한다. 메인에서 진행 중 퍼즐을 보관하거나 ‘이어서 하기’ 버튼으로 돌아오는 기능은 제공하지 않는다.
- 포기·재시작·메인으로 나가기에는 확인창을 한 번 표시하고, 이미 사용한 아이템·부스터는 반환되지 않는다고 안내한다. 확인을 취소하면 진행을 유지한다.
- 재시작과 실패 후 ‘다시 도전’은 부스터 선택 화면으로 이동한다. 새 레벨 시작을 포함해 부스터는 매번 모두 해제된 상태로 보여준다.
- 전화 수신이나 홈 버튼 등으로 앱이 백그라운드로 이동하면 포기하지 않고 일시정지한다. 돌아오면 그대로 계속 진행한다.
- 단, 아이템 선택 중 홈 화면 등으로 앱을 벗어났다가 복귀하면 실행 전 선택을 해제한다. 아이템은 소모하지 않고 일반 조작 상태로 돌아간다.

### 오프라인 저장과 강제 종료 복원

- 현재 기획은 오프라인 플레이를 기준으로 한다. 퍼즐과 주문 진행에 필요한 기본 데이터와 그림을 기기에 보관한다.
- 진행 상태는 기기별로 독립 저장한다. 현재 범위에서 계정은 필수가 아니며, 모바일·PC 간 서버 동기화는 차후 검토 사항으로 남긴다.
- 앱 강제 종료 시에는 보드와 남은 이동 횟수를 복원한다. 재실행하면 메인을 거치지 않고 진행 중이던 퍼즐로 바로 복귀한다. 확인 후 게임 화면에서 나간 경우의 포기 처리와 구분한다.
- 효과·낙하·연쇄 처리 도중 앱이 강제 종료된 경우에는 해당 수 직전의 보드와 진행 상태, 입력 행동, 난수 상태를 바탕으로 같은 수를 재실행한다. 무작위 공급과 목표 선택을 포함한 결과가 동일해야 한다.
- 애니메이션의 정확한 중간 프레임 대신 해당 수의 시작부터 다시 보여준다. 복원으로 이동 횟수가 중복 차감되지 않도록 한다.
- 강제 종료 당시 아이템 효과를 실행하기 전이었다면 대상 선택 상태는 복원하지 않고 해제하며, 아이템 수량도 차감하지 않는다.
- 아이템 효과가 실행되기 시작한 뒤 강제 종료되었다면 해당 효과와 후속 연쇄를 복원하고 아이템은 중복 없이 한 번만 차감한다.
- 위 내용은 저장·복원의 설계 요구사항이며 아직 구현·검증하지 않았다.

모바일의 구체적인 운영체제, PC 배포 방식, 최소 화면 크기, 터치·마우스 입력 세부 동작은 미정이다.
