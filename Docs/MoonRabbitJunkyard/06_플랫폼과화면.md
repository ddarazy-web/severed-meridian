## 퍼즐 화면 구성 — 2026-09-29 결정 묶음

게임 화면 논의의 첫 결정 묶음이다. 기존 모바일 세로 전용 방향을 위 표처럼 변경한다. 아래 내용은 기획 확정 사항이며 런타임 화면 구현 완료를 뜻하지 않는다. 이후 결정도 20개 단위로 기록한다.

### 화면 배치와 배경

- 보드를 중심으로 구성하고 장식은 배경과 테두리에 제한한다.
- 가로 화면: 중앙에 보드, 왼쪽에 남은 이동 횟수와 미션 최대 4종, 오른쪽에 게임 중 아이템을 둔다. 모바일 가로와 PC에 같은 배치 방향을 적용한다.
- 세로 화면: 상단에 남은 이동 횟수와 미션, 중앙에 보드, 하단에 게임 중 아이템 3개를 둔다.
- 같은 화면 크기·방향에서는 10×10 기준의 블록 크기를 유지한다. 작은 맵을 별도로 확대하지 않고 중앙에 배치한다.
- 모든 레벨에 공통으로 쓰는 단순한 고물상 작업실 배경을 사용한다. 배경의 색과 장식은 블록보다 약하게 표현한다.
- 활성 칸에만 은은한 바닥을 표시한다. 비활성 칸에는 작업실 배경이 보이며 전체 10×10 사각 판을 깔지 않는다.
- 일시정지 버튼은 화면 방향과 관계없이 오른쪽 위에 둔다. 아이템 선택 중에는 비활성화한다.

### 방향 전환

- 모바일은 플레이 도중에도 가로·세로를 즉시 전환할 수 있다. UI와 보드의 화면상 위치를 재배치하며 보드 좌표나 낙하 방향을 회전시키지 않는다.
- 보드 상태, 남은 이동 횟수, 진행 중인 연쇄와 아이템 선택 상태를 유지한다. 아직 확정하지 않은 드래그만 취소한다.
- 화면 회전과 앱 백그라운드 이동은 구분한다. 백그라운드 복귀 시 아이템 선택 해제 규칙은 기존대로 유지한다.

### 미션과 이동 횟수

- 완료된 미션은 원래 자리를 유지한다. 남은 수량 대신 체크 표시를 보여주고 아이콘은 살짝 흐리게 표현한다.
- 남은 이동 횟수가 5회 이하이면 숫자를 주황색으로 표시한다. 처음 5회에 도달할 때 한 번만 살짝 커졌다 돌아온다. 시작부터 5회 이하인 레벨도 같은 기준을 적용한다.
- 퍼즐 시작 시 미션 아이콘과 수량을 한 번 강조한다. 별도 중앙 목표 패널이나 확인 입력은 추가하지 않는다.
- 미션에 기여한 목표를 제거하면 해당 목표마다 작은 수집 조각을 미션 아이콘으로 날린다. 대표 조각 하나로 묶지 않는다.
- 동시에 많이 제거되면 출발 시점을 조금씩 엇갈리게 한다. 비행 중에도 낙하·연쇄는 계속 진행한다.
- 화면에 표시하는 남은 수량은 조각이 도착할 때마다 감소한다. 실제 목표 달성 판정은 공통 게임 규칙대로 처리하며 표시 시점과 분리한다.
- 마지막 목표 달성 시 현재 연쇄가 끝나고 남아 있는 수집 조각이 모두 도착해 완료 체크가 표시된 다음 라스트팡을 시작한다.

### 선택과 아이템 표시

- 두 칸 순차 선택에서 첫 번째 블록은 밝은 바깥 테두리로 표시한다. 달토끼와 파워 블록에 공통 적용한다.
- 무효 교환은 두 블록이 교환 방향으로 살짝 움직였다가 원위치로 돌아오게 한다. 이동 횟수는 소모하지 않고 경고창은 띄우지 않는다.
- 게임 중 아이템은 이름을 상시 표시하지 않는다. 직관적인 아이콘과 모서리의 보유 수량으로 구분한다. 잠긴 아이템은 기존대로 잠금 표시만 보여준다.
- 아이템 선택 시 선택한 아이콘을 강조하고 다른 아이템은 흐리게 표시한다. 짧은 사용 안내와 취소 버튼을 함께 제공한다.
- 세로에서는 안내·취소를 보드 아래 아이템 버튼 바로 위에, 가로에서는 오른쪽 아이템 영역 안에 둔다. 보드 위에 안내 문구를 겹치지 않는다.

### 추가 확정 사항의 위치

화면 모드·안전 영역·결과 패널은 아래 절, 이후 확정한 이어하기·입력·연출은 ‘화면 기획 마무리’ 절을 따른다. 색감·글꼴·아이콘 방향은 [캐릭터와 아트](03_캐릭터와아트.md)의 퍼즐 UI 기준에 정리했다. 실제 최소 조작 크기와 미정 사항은 문서 끝의 후속 항목을 따른다.

## 화면·설정·결과 패널 — 두 번째 결정 묶음

첫 묶음 이후 확정한 내용을 기록한다. 아래는 설계이며 구현 완료를 뜻하지 않는다. Windows 가로 전용 제한은 가로·세로 선택 지원으로 변경한다.

### Windows 화면 모드

| 모드 순서 | 가로 뷰 | 세로 뷰 |
| --- | --- | --- |
| FULLSCREEN = 0 | 16:9 게임 영역 | 9:16 게임 영역 |
| 큰 창 | 1920×1080 | 1080×1920 |
| 중간 창 | 1600×900 | 900×1600 |
| 작은 창 | 1280×720 | 720×1280 |

- 창 테두리를 드래그해 임의 크기로 바꾸는 기능은 제공하지 않는다. 위 화면 모드와 가로·세로 뷰만 선택한다.
- 뷰 방향을 바꾸면 창 크기도 뒤집고 UI를 해당 방향으로 재배치한다. 전체 화면에서는 위 게임 영역 밖을 배경 이미지로 채우며 UI는 게임 영역을 벗어나지 않는다.
- 창 테두리와 작업 표시줄을 고려해 현재 화면에 들어가지 않는 창 크기는 설정에서 비활성화한다. Alt+Enter 순환에서도 건너뛴다. 세로 창 크기가 모두 맞지 않으면 세로 전체 화면을 사용한다.
- 첫 실행은 가로 뷰·전체 화면이다. 이후에는 마지막으로 적용한 뷰 방향과 화면 모드를 복원한다. 모니터가 바뀌어 저장된 창 크기를 사용할 수 없으면 뷰 방향은 유지하고 전체 화면으로 전환한다.
- 설정에서 화면 모드·뷰 방향 변경을 요청하면 적용 전에 확인 팝업을 한 번 표시한다. 확인하면 적용하고 취소하면 기존 값을 유지한다. 적용 후에도 설정창과 일시정지 상태를 유지한다.
- Alt+Enter는 현재 뷰 방향에서 전체 화면→큰 창→중간 창→작은 창→전체 화면 순서로 사용 가능한 모드를 즉시 순환한다. 확인 팝업은 띄우지 않는다.
- 설정창을 연 상태에서 Alt+Enter를 누르면 실제 모드와 설정창의 현재 선택값을 함께 갱신한다.
- 화면 변경 확인 팝업 중 Alt+Enter를 누르면 대기 요청을 취소하고 팝업을 닫은 뒤 단축키 전환을 적용한다. 취소된 이전 요청을 뒤늦게 적용하지 않는다.
- 모드·뷰 변경으로 퍼즐 진행 상태를 초기화하지 않는다.

### 모바일 화면 대응

- 모바일은 고정 16:9·9:16 비율을 강제하지 않고 기기의 사용 가능한 화면 비율에 맞춰 재배치·확대·축소한다.
- 노치·카메라 구멍·홈 표시줄을 피해 보드와 조작 UI를 배치한다. 배경은 화면 전체를 채운다.
- 블록은 정사각형으로 유지하며 10×10 보드가 잘리지 않도록 크기를 계산한다. 작은 맵의 칸 크기는 같은 화면 기준으로 유지한다.
- 모바일 방향은 기기의 자동 회전 설정을 따른다. 기기에서 회전을 잠갔다면 해당 방향을 유지하며 게임 안에는 별도 방향 선택 옵션을 두지 않는다.
- 최소 지원 화면 크기와 실제 기기별 가독성은 시안·검증에서 정한다. 모든 물리적 화면 크기의 조작성을 이미 보장한 것으로 해석하지 않는다.

### 미션 표시와 설명

- 세로 화면 상단은 왼쪽에 이동 횟수, 오른쪽에 미션을 둔다. 가로 화면의 왼쪽 영역은 위에 이동 횟수, 아래에 미션을 둔다.
- 미션 아이콘을 누르면 목표 이름과 짧은 해결 방법을 아이콘 근처의 작은 말풍선으로 보여준다.
- 별도 확인 버튼 없이 바깥을 누르면 닫는다. 닫기에 사용한 입력은 블록 교환이나 아이템 사용으로 전달하지 않는다.
- 곰팡이처럼 목표 수량이 증가하면 발생 즉시 화면의 남은 수량을 증가시키고 숫자를 한 번 강조한다. 수집 조각 도착 시 감소하는 표시 규칙과 함께 적용한다.

### 일시정지와 결과 패널

- 일시정지 메뉴는 계속하기 / 설정 / 재시작 / 메인으로 나가기 순서로 구성한다. 기존 재시작·나가기 확인 규칙을 유지한다.
- 설정은 별도 창으로 열고, 닫으면 일시정지 메뉴로 돌아온다. 계속하기를 누르기 전에는 플레이를 재개하지 않는다.
- 클리어·실패는 중앙의 큰 결과 패널로 보드 대부분을 가린다. 주변에 남은 보드는 어둡게 처리한다.
- 클리어 패널은 클리어 안내→획득 보상→행동 버튼 순서다. 다음 퍼즐을 큰 주 버튼, 메인으로를 작은 보조 버튼으로 둔다.
- 실패 패널은 남은 미션과 사용 가능한 이어하기 수단 / 무료 다시 도전 / 메인으로 선택을 제공한다. 이어하기 버튼의 표시 조건은 아래 확정 규칙을 따른다.
- 광고 이어하기는 한 판 1회·하루 5회 제한을 따른다. 사용 완료·하루 한도 소진·광고 불러오기 실패로 사용할 수 없으면 광고 버튼을 숨긴다.

## 화면 기획 마무리 — 2026-09-29

사용자의 기획 정리 요청에 따라 20개 단위 저장 시점 이전의 최근 결정까지 반영했다. 이번 정리는 첫 게임 화면 구현을 시작하기 위한 기획 기준이다. 런타임 UI 구현이나 모든 세부 연출의 확정을 뜻하지 않는다.

### 실패 화면과 이어하기

- 광고 이어하기와 이어하기 아이템은 각각 한 판에 1회씩 사용한다. 두 수단을 모두 사용할 수 있다면 합계 최대 2회 이어갈 수 있다. 광고를 사용해도 아이템의 판당 기회를 소모하지 않으며 반대도 같다.
- 이어하기 아이템 1개를 사용하면 이동 횟수 5회를 추가한다. 보상·한도의 기준 문서는 [성장과 보상](05_성장과보상.md)이다.
- 두 수단을 모두 사용할 수 있으면 ‘광고 보고 +5회’와 ‘아이템 사용 +5회’를 나란히 표시한다. 아이템 버튼에는 보유 수량도 표시한다.
- 아이템 수량이 0이거나 해당 판에서 이미 사용했다면 아이템 이어하기 버튼을 숨긴다. 사용할 수 있는 수단만 표시하며 하나만 남으면 그 버튼을 강조한다. 둘 다 없으면 ‘다시 도전’을 주 버튼으로 한다. ‘메인으로’는 작은 보조 버튼이다.
- 아이템 버튼을 누르면 ‘이어하기 아이템 1개를 사용해 이동 5회를 추가할까요?’라는 확인창을 한 번 표시한다. 확인 시에만 1개를 소비하고 이동 횟수를 추가한다. 취소하면 소비 없이 실패 패널로 돌아간다.
- 이어하기 후에는 실패 패널을 닫고 보드를 그대로 유지한다. 이동 횟수가 0에서 5로 늘어나는 짧은 강조 효과 후 조작을 허용한다. 추가 ‘계속하기’ 버튼은 두지 않는다.
- 이어하기 아이템은 실패 패널에서 사용한다. 플레이 화면의 게임 중 아이템 3개 영역에 네 번째 버튼을 추가하지 않는다.
- 클리어·실패 패널은 바깥을 눌러도 닫히지 않는다. 패널에 표시된 행동 버튼으로만 진행한다.

### Esc·모바일 뒤로가기

| 현재 상태 | 동작 |
| --- | --- |
| 일반 플레이 | 일시정지 메뉴 열기 |
| 아이템 선택 중 | 실행 전 선택만 취소, 아이템 소비 없음 |
| 확인창 표시 중 | 취소와 동일하게 처리 |
| 클리어·실패 패널 | 패널 유지 |

아이템 선택 중 Esc·뒤로가기는 일시정지 요청이 아니라 선택 취소다. 일시정지 버튼을 비활성화하는 기존 규칙과 함께 적용한다.

### 연쇄 중 일시정지 요청

- 블록이 터지거나 떨어지는 도중 수동 일시정지를 요청하면 요청을 받아두고 추가 게임 입력을 막는다.
- 진행 중인 연쇄 처리를 마치고 보드가 안정되면 일시정지 메뉴를 연다.
- 해당 연쇄로 성공·실패가 확정되면 일시정지 요청을 취소하고 결과 흐름을 우선한다. 성공은 기존 수집 조각 도착·완료 체크 후 라스트팡으로, 실패는 실패 패널로 진행한다.
- 이 규칙은 사용자의 수동 일시정지 요청에 관한 것이다. 앱 백그라운드 전환·강제 종료는 아래 저장·복원 규칙을 따른다.

### 화면 회전 중 수집 연출

- 목표로 날아가는 조각은 화면 회전 시 현재 위치에서 새로 배치된 목표 아이콘을 향하도록 경로를 바꾼다.
- 조각을 없애거나 출발점부터 다시 재생하지 않는다. 목표 아이콘에 도착했을 때 표시 수량을 줄이는 규칙을 유지한다.

### HTML 목업과 사용자 검토 결과

- HTML의 브라우저 검수에서 글꼴 포함, 세로 세 비율의 보드·목표·아이템 배치, 설명·취소·이어하기 버튼, 결과 패널의 Esc 유지, 좁은 브라우저에서의 가로 넘침 여부를 확인했다. 근거: [목업 검수 스크립트](Mockups/verify-mockup.cjs), [기본 화면](Mockups/preview.png), [클리어 화면](Mockups/preview-clear.png), [좁은 브라우저 화면](Mockups/preview-mobile.png).

### 후속 결정·실기 검수 항목

- 최소 지원 화면 크기, 터치 영역의 실제 크기, 노치·홈 표시줄이 있는 기기에서의 안전 영역과 다국어 문구 줄바꿈.
- 목업을 기준으로 한 최종 영역 비율과 여백, 아이템 수량 배지 수정, 최종 아이콘·숫자 에셋.
- 수집 조각의 비행 시간·출발 간격, 목표 수량 증가와 수집 도착이 동시에 일어날 때의 표시 세부 순서.
- 이어하기 아이템의 획득 경로·해금·일일 한도 유무 및 별도 예외 처리. 광고 한도를 그대로 적용하거나 무제한으로 확정하지 않는다.
- 실제 지원 언어 목록과 언어별 글꼴 구성. 일반 문구와 숫자 표현 원칙은 아트 문서에서 확정했다.

위 항목을 제외한 확정 규칙을 기준으로 다음 개발 계획을 작성할 수 있다. 다음 단계 계획서·Goal 문서 작성과 실제 구현은 이번 기획 정리 작업에 포함하지 않는다.

## 퍼즐 입력

- 퍼즐 화면의 미션은 아이콘과 남은 수량으로 표시하며, 완료하면 숫자 대신 체크 표시로 바꾼다. 시작 전 부스터 선택 화면에는 미션과 이동 횟수를 표시하지 않는다.
- 1레벨은 안내한 두 블록의 교환만 허용하고 게임 중 아이템은 사용하지 않는다. 시작 전 부스터 선택 화면도 건너뛴다.

- 모바일·PC 모두 드래그와 두 칸 순차 선택으로 블록을 교환할 수 있다.
- 파워 블록의 제자리 발동은 모바일 더블터치, PC 더블클릭으로 조작한다.
- 매칭·파워 효과·낙하·보충 등 전체 연쇄가 끝나 보드가 안정된 뒤에만 새 조작을 받는다.
- 조합 효과의 중심은 드래그로 놓은 칸 또는 순차 선택한 두 번째 칸이다.

## 자동 힌트

- 별도 켜기·끄기 설정 없이 기본 기능으로 제공한다.
- 보드가 안정된 상태에서 10초간 입력이 없으면, 가능한 교환이나 발동 가능한 파워 블록 중 행동 하나를 무작위로 안내한다. 최적의 수를 계산해 추천하지 않는다.
- 교환 힌트는 해당 블록을 교환 방향으로 살짝 이동하듯 흔든다. 제자리 파워 발동 힌트는 해당 블록이 살짝 커졌다 작아지도록 표현한다.
- 보드를 터치하거나 클릭하면 힌트를 즉시 숨기고, 다시 보드가 안정된 상태에서 10초간 입력이 없으면 표시한다. 매칭·연쇄 처리 중에는 시간을 세지 않는다.
- 게임 중 아이템의 대상 칸을 고르는 동안에는 힌트를 숨기고 타이머를 멈춘다. 사용 또는 취소가 끝나 보드가 안정되면 새로 10초를 센다.

## 게임 중 아이템 선택과 조작

- 잠긴 게임 중 아이템은 수량·해금 조건 없이 잠금 표시만 보여준다. 해금된 아이템의 보유 수량이 0이면 버튼을 비활성화하고 수량을 표시한다. 최초 해금의 무료 1회 체험은 보유 수량을 요구하지 않는다. 구매창 연결은 유료 결제 기획과 함께 보류한다.
- 아이템 선택 중에는 다른 아이템 버튼을 숨기지 않고 흐리게 표시해 선택을 막는다. 다른 아이템을 사용하려면 현재 선택을 먼저 취소해야 한다. 선택 중 즉시 다른 아이템으로 전환하는 방식은 사용하지 않는다.
- ‘취소’ 버튼을 표시하며, 선택한 아이템 버튼을 다시 눌러도 사용 모드를 취소한다. 실행 전 취소에는 아이템을 소모하지 않는다.
- 대상 선택 중에는 일반 교환·파워 블록 더블터치·더블클릭을 막고 아이템 대상 지정만 허용한다. 일시정지 메뉴도 열 수 없다.
- 유효하지 않은 칸을 누르면 선택 상태를 유지하고 아이템을 소모하지 않는다.
- 망치에는 ‘망치로 칠 칸을 선택하세요’, 자리 바꾸기에는 ‘바꿀 블록 두 개를 선택하세요’라는 짧은 안내를 표시한다.
- 자리 바꾸기의 첫 블록은 테두리로 표시하고, 교환 가능한 상하좌우 블록만 강조한다. 안내는 ‘강조된 블록을 선택하면 교환해요’로 바꾼다.
- 첫 블록을 다시 누르면 첫 선택만 해제하고 사용 모드는 유지한다. 인접하지 않은 다른 이동 가능 블록을 누르면 그 블록으로 첫 선택을 변경한다.
- 망치는 유효한 대상 칸을 한 번 누르면 추가 확인 없이 실행한다. 섞기는 사용 확인창에서 확인해야 실행하며 취소하면 소모하지 않는다.
- 아이템 효과와 후속 연쇄가 모두 끝나 보드가 안정된 뒤에만 다음 아이템을 사용할 수 있다.

## 시작 전 부스터 표시

- 1레벨을 제외하고 부스터 해금 전에도 진입 화면을 표시한다. 레벨 번호, 부스터 3칸, 시작 버튼과 닫기를 제공하며 미션·이동 횟수는 미리 표시하지 않는다.

- 잠긴 부스터는 수량·해금 조건 없이 잠금 표시만 보여준다. 획득한 수량은 보관하되 해금 후 사용한다.
- 최초 해금 시 ‘청소로켓 부스터 해금! 5분간 무한 사용’처럼 해당 이름과 혜택을 짧게 알린다. 긴 부스터 사용 튜토리얼은 추가하지 않는다.
- 무한 사용 중에는 보유 수량 대신 `∞`와 남은 시간을 표시한다. 퍼즐 시작 전에 시간이 만료되면 해당 선택을 해제하고, 보유 부스터 사용은 다시 선택하도록 한다.

## 퍼즐 클리어 화면

- 클리어 확정 후 라스트팡을 보여준다. 터치·클릭으로 건너뛸 수 있으며 보상은 동일하다.
- 결과 화면은 ‘다음 퍼즐’과 ‘메인으로’를 제공한다. 다음 퍼즐은 부스터 선택 화면으로 이동하며, 기존대로 부스터는 모두 해제된 상태다.
- 주문 작업에 필요한 별이 모였더라도 다음 퍼즐을 계속 진행하여 별을 모을 수 있다.
- 라스트팡 도중 강제 종료한 경우에는 일반 퍼즐 복원과 달리 결과 화면으로 이동하고 연출을 반복하지 않는다. 보상은 한 번만 지급한다.

## 메인 화면과 납품 기록

- 메인 화면의 배경은 현재 진행 중인 주문의 그림과 진행 상태를 보여준다.
- 그림을 넓게 보여주고, 스패너와 드라이버가 교차한 작업 아이콘을 누르면 작업 목록 패널을 연다. ‘작업하기’ 텍스트 버튼은 사용하지 않는다.
- 현재 공개된 작업 중 별이 충분해 실행 가능한 작업이 있으면 작업 아이콘에 작은 알림 점을 표시한다.
- 상점은 작은 가게, 주문 장부는 장부 아이콘으로 표시한다. 퍼즐 진입 버튼은 재생 아이콘과 다음 레벨 번호를 함께 표시한다.
- 상단에 별 아이콘과 보유 수량을 항상 표시한다. 주문 전체 진행도는 ‘완료 4/10’처럼 표시하며 첫 주문은 총 5개를 기준으로 한다.
- 주문 물품이 없는 빈 흑백 배경 위에 작업 완료에 따라 그림 조각을 채운다. 작업은 일반 주문 3→3→4개, 첫 주문 1→4개 묶음으로 제시하고 현재 묶음 안에서 자유롭게 선택한다. 모두 완료하면 다음 묶음을 공개한다.
- 작업별 이름과 필요한 별 수를 표시한다. 조각 미리보기는 제공하지 않는다. 작업 버튼을 한 번 누르면 하나만 진행한다.
- 별 소비로 완료한 작업은 즉시 목록에서 숨기고, 현재 묶음의 남은 작업을 빈칸 없이 당겨 정렬한다. 마지막 작업까지 끝내면 다음 묶음으로 교체한다.
- 작업을 선택하면 목록을 닫고 그림 조각이 채워지는 연출을 보여준다. 연출 중 다른 작업은 선택할 수 없다. 연출 후 남은 작업 목록을 다시 열며, 묶음 완료 시 다음 묶음을 보여준다. 주문 전체 완료 시에는 완료 연출·보상으로 진행한다.
- 필요한 별이 부족한 작업의 버튼은 ‘퍼즐로 별 모으기’로 바꾸고 다음 레벨 진입 화면에 연결한다.
- 마지막 작업 완료 후 짧은 완성 대사와 보상 화면으로 자동 진행한다. 보상 수령 후 다음 주문을 자동 접수하고 메인 배경도 새 주문 초기 상태로 바꾼다.
- 주문을 납품하면 별도의 주문 내역 장부에 완료 기록을 남기고 다시 볼 수 있게 한다. 화면 성격은 완성 그림을 나열하는 갤러리보다 기록장에 가깝다.
- 장부 한 건은 손님과 물건의 이름, 완료된 주문 그림, 납품 결과를 적은 짧은 메모로 구성한다. 주문 당시의 대화 전체를 다시 읽는 기능은 넣지 않는다.
- 정거장의 대형 시설 복구 화면은 핵심 보상 화면으로 구성하지 않는다. 정거장이 조금씩 회복되는 모습은 주문 누적에 따른 이야기에서 전달한다.
- 장부의 구체적인 배치 방식은 미정이다.
- 1레벨 첫 클리어 후에는 메인에서 작업 아이콘을 안내하고, 받은 별 1개로 ‘상태 점검’을 해보는 튜토리얼을 제공한다.

## 저장과 오프라인 진행

### 나가기·일시정지·재도전

- 퍼즐의 일시정지 메뉴에는 ‘계속하기 · 설정 · 재시작 · 메인으로 나가기’를 제공한다.
- 게임 화면에서 메인으로 나가면 포기로 처리한다. 메인에서 진행 중 퍼즐을 보관하거나 ‘이어서 하기’ 버튼으로 돌아오는 기능은 제공하지 않는다.
- 포기·재시작·메인으로 나가기에는 확인창을 한 번 표시하고, 이미 사용한 아이템·부스터는 반환되지 않는다고 안내한다. 확인을 취소하면 진행을 유지한다.
- 재시작과 실패 후 ‘다시 도전’은 부스터 선택 화면으로 이동한다. 새 레벨 시작을 포함해 부스터는 매번 모두 해제된 상태로 보여준다.
- 전화 수신이나 홈 버튼 등으로 앱이 백그라운드로 이동하면 포기하지 않고 일시정지한다. 돌아오면 그대로 계속 진행한다.
- 단, 아이템 선택 중 홈 화면 등으로 앱을 벗어났다가 복귀하면 실행 전 선택을 해제한다. 아이템은 소모하지 않고 일반 조작 상태로 돌아간다.

### 오프라인 저장과 강제 종료 복원

- 현재 기획은 오프라인 플레이를 기준으로 한다. 퍼즐과 주문 진행에 필요한 기본 데이터와 그림을 기기에 보관한다.
- 진행 상태는 기기별로 독립 저장한다. 현재 범위에서 계정은 필수가 아니며, 모바일·PC 간 서버 동기화는 차후 검토 사항으로 남긴다.
- 앱 강제 종료 시에는 보드와 남은 이동 횟수를 복원한다. 재실행하면 메인을 거치지 않고 진행 중이던 퍼즐로 바로 복귀한다. 확인 후 게임 화면에서 나간 경우의 포기 처리와 구분한다.
- 효과·낙하·연쇄 처리 도중 앱이 강제 종료된 경우에는 해당 수 직전의 보드와 진행 상태, 입력 행동, 난수 상태를 바탕으로 같은 수를 재실행한다. 무작위 공급과 목표 선택을 포함한 결과가 동일해야 한다.
- 애니메이션의 정확한 중간 프레임 대신 해당 수의 시작부터 다시 보여준다. 복원으로 이동 횟수가 중복 차감되지 않도록 한다.
- 강제 종료 당시 아이템 효과를 실행하기 전이었다면 대상 선택 상태는 복원하지 않고 해제하며, 아이템 수량도 차감하지 않는다.
- 아이템 효과가 실행되기 시작한 뒤 강제 종료되었다면 해당 효과와 후속 연쇄를 복원하고 아이템은 중복 없이 한 번만 차감한다.
- 위 내용은 저장·복원의 설계 요구사항이며 아직 구현·검증하지 않았다.

모바일의 구체적인 운영체제, PC 배포 방식, 최소 화면 크기, 터치·마우스 입력 세부 동작은 미정이다.
