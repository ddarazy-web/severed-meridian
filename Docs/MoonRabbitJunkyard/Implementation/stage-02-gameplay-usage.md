# 2단계 게임 플레이 사용법

상태: 2026-09-30 Editor Play Mode 검증 완료. 결과와 화면 증거는 [실행 기록](stage-02-progress.md)을 참조한다.

## 씬 준비와 실행

1. ServeredMeridian 프로젝트에서 `Tools > Match > 게임 플레이 씬 연결`을 실행한다. 기존 `PuzzleGame` 씬의 변경을 저장한 상태여야 한다.
2. `Assets/Scenes/PuzzleGame.unity`를 연다.
3. `PuzzleGameSession` 인스턴스에서 Level Number와 Seed를 설정한다. 기본값은 레벨 1, 시드 12345다.
4. Play를 누른다. MemoryPack 로드·시작판 탐색·이미지 로드가 끝나면 입력할 수 있다.

이 단계의 입력은 MemoryPack이다. 레벨 에디터에서 미저장 편집 데이터를 전달하는 기능은 3단계에 추가한다. 기존 `Puzzle Board Preview`는 씬에 보존하되 비활성화하며, 세션과 동시에 켜지 않는다.

## 조작

- 일반 블록: 인접한 두 칸을 차례로 클릭/탭하거나 상하좌우로 드래그한다.
- 드래그: 셀 폭의 25% 이상 이동한 뒤 놓으면 큰 이동 축의 인접 한 칸으로 교환을 요청한다.
- 파워 블록: 탭하면 제자리 발동, 드래그하면 인접 칸과 교환한다.
- 비인접 칸을 두 번째로 누르면 선택을 옮긴다. 보드 밖이나 비활성 칸은 선택을 취소한다.
- 로딩·연쇄·라스트팡·종료 중에는 입력할 수 없다. 포커스를 잃으면 진행 중인 드래그를 취소한다.

화면 상단은 검증용 텍스트다. 이동 수·미션·선택·진행 메시지·종료 종류를 확인할 수 있다. 정식 목업 HUD, 다시하기와 일시정지는 4단계 범위다.

## 검사와 오류 확인

- `Tools > Match > 게임 플레이 검증`은 검사 전용 빈 씬에서 Play Mode 검사를 수행한다. 작업 씬을 저장한 뒤 실행한다.
- 결과: `Logs/PuzzleGameplayVerification/results.txt`, `Logs/PuzzleBoardInputVerification/results.txt`.
- 실패한 초기화는 화면과 콘솔에 이유를 남기며 다른 레벨로 대체하지 않는다. 레벨 번호가 팩에 포함돼 있는지 확인한다.
- Android 실기기 확인과 최종 화면 증거는 실행 기록의 실제 결과를 따른다. 합성 터치 검사만으로 실기기 검증을 대신했다고 주장하지 않는다.
