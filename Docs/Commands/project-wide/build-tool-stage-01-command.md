```text
ServeredMeridian의 제품 빌드 도구 1단계를 구현·검증해.

메뉴는 Match → Build → 빌드 도구로 만들어.
Unity Editor UI Toolkit으로 프로필 목록·선택 제품 정보·읽기 전용 사전 검사 화면을 제공해.
기존 ProductProfiles 정의를 재사용하고 제품 정보를 별도로 중복 관리하지 마.
프로필은 GUID로 식별하고 미등록·손상·복제 프로필도 이유를 확인할 수 있게 해.

공통 검사와 Android/iOS/Windows 처리를 분리하고 등록된 플랫폼 처리기를 조회해 사용해.

프로필 목록 선택·새로고침·사전 검사로 활성 플랫폼·프로필·원본 설정을 바꾸지 마.
Configure/Select/콘텐츠 경로 동기화처럼 설정을 저장하는 API를 조회 경로에 연결하지 마.

신규 1단계 화면만 만드는 경우 빌드 버튼은 2단계 예정으로 비활성 표시해.
이미 후속 실행 UI가 있으면 이를 축소하지 말고 조회·선택·검사에서 실행 요청이 생기지 않는지 확인해.
실제 옵션 처리기가 등록되지 않았다면 등록된 추가 옵션 없음으로 표시해.
실행기·옵션 전후처리·GPG/플러그인 ON/OFF는 이번 단계에 구현하지 마.
다만 통합 계획의 공통 실행/플랫폼/제품/옵션 책임 분리와 확장 방향을 지켜.
현재 프로필·전역 PlayerSettings·Addressables 선택/경로·도구 포함 상태의 무변경을 검증해.
기존 ProductBoundaryVerification은 Configure를 호출하므로 무변경 검사로 무조건 실행하지 마.
외부 Tests와 기존 검사 연결 도구를 사용하고 실제 제품 빌드 없이 컴파일·관련 검사만 수행해.

질문은 제한시간 없는 일반 채팅으로 하고 Unity 작업은 동일 프로젝트에서 순차 실행해.
```
