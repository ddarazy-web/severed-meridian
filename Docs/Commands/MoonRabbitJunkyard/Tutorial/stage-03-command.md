Docs/Planning/MoonRabbitJunkyard/Tutorial/integration-guideline.md와 stage-03-game-integration-plan.md, Docs/Goals/MoonRabbitJunkyard/Tutorial/stage-03-game-integration-goal.md, Docs/Verification/MoonRabbitJunkyard/Tutorial/stage-02-progress.md, Docs/Contents/MoonRabbitJunkyard/13_레벨튜토리얼.md를 읽고 목표를 설정하여 이 세션에서 직접 수행해. 현재 HEAD·WIP·1/2단계 완료분·원본/GUID를 보존해.

승인 ticket에 실제 실행 성공/실패·생성/발동/제거 기록·연출 완료를 연결해. 결과는 실제 정의 ID·개체/발생 식별·좌표로 전달하고 2×2 피해 칸 수로 제거를 중복 집계하지 마. 양방향 파워 교환·재보충·뒤늦은 드론 결과를 원래 행동에 연결해. 튜토리얼에서 블록/장애물 기능을 재구현하지 마.

논리 연쇄와 드론/낙하/피해/수집 표시가 모두 완료되어야 다음 단계로 진행해. 일시정지/팝업 중에는 진행을 보류하고 나가기는 유지해. 공급 부족·누락 생성구·후속 대상 소실·불가능한 교환·결과 불충족을 단계별로 진단하고 무작위 공급·임의 시드·자동 섞기·가짜 성공으로 숨기지 마.

승리/라스트팡·이동 소진/자동 섞기는 필요한 동안 보류한 뒤 완료 시 한 번만 재평가해. 곰팡이 턴 종료·미션·턴을 중복 처리하지 마. 이동 0에서 마지막 설명/완료와 필요한 지정 무료 체험은 진행하고 추가 교환/일반 아이템 우회는 막아. 무료 체험은 단계 성공 시 1회 소진하며 전체 재고 시스템은 만들지 마.

완료 후 같은 보드/내구도/미션/이동/턴/난수를 유지하고 일반 공급으로 복귀해. 공급 전환으로 블록을 만들지 마. 재시작/다음 레벨/시작 실패/취소/파기에서 사본·엔진·ticket·구독·비동기 대기를 해제해.

실제 BoardActionExecutor를 사용하는 재생 검사를 소유한 사본에서 실행하고 에디터/실행 전 검사에 연결해. TutorialGameIntegrationVerification.Run과 기존 엔진·데이터·에디터·저장/팩 및 일반 플레이·드론·결과/팝업 회귀를 검사해. 실제 연출·게임 경계 검사와 모의 검사 범위를 구별해. 테스트 연결 해제 후 게임 소스만 컴파일하고 과거 검사 출력은 보관 후 복원해.
