# 조합형 튜토리얼 후속 실행문

코드 블록의 복사 버튼으로 복사한다. 실행 전에 사용자가 점검할 레벨 또는 불편한 작업 흐름을 지정한다.

```text
Docs/Planning/MoonRabbitJunkyard/Tutorial/composer-authoring-review-plan.md와
Docs/Goals/MoonRabbitJunkyard/Tutorial/composer-authoring-review-goal.md를 기준으로
튜토리얼 제작 흐름을 점검해.

내가 지정하는 레벨이나 임시 사본에서 샘플 선택, 보드 대상 연결,
조건 값 입력, 검사와 게임 실행을 확인하고 실제로 막히는 부분만 개선해.
실제 레벨의 튜토리얼을 대신 만들지 말고 기존 데이터와 완료 기록을 보존해.
질문은 일반 메시지로 하나씩 제시하고 내 답변을 기다려.
HTML 매뉴얼은 별도 요청 전에는 업데이트하지 마.
빌드·커밋·푸시하지 말고 검증 결과와 한계를 보고해.
```
