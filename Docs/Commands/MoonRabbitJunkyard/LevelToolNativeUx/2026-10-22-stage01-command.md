# 네이티브 레벨툴 UX 1단계 목표 실행문

아래 내용을 복사해 실행을 요청한다. 문서 작성만으로 구현을 시작하지 않는다.

```text
Android·Windows 레벨툴 UX 개선 1단계를 구현해.

다음 문서를 읽고 해당 범위만 진행해:
- Docs/Planning/MoonRabbitJunkyard/LevelToolNativeUx/2026-10-22-integrated-plan.md
- Docs/Planning/MoonRabbitJunkyard/LevelToolNativeUx/2026-10-22-stage01-plan.md
- Docs/Goals/MoonRabbitJunkyard/LevelToolNativeUx/2026-10-22-stage01-goal.md

확정 UX와 HTML 목업을 참고해 시작 화면, 이름 중심 프로젝트 생성,
빈 프로젝트와 첫 9×9 레벨 만들기, 기본/현재 레벨 복제,
기존 최근 목록·편집 버튼·미저장 전환 흐름을 연결해.
웹은 사용하지 말고 기존 네이티브 파일 저장·ZIP·편집 세션을 재사용해.
전체 레벨 JSON 로드, 반복 편집 자동 저장, 기존 사용자 데이터 변경을 피하고
현재 레벨 변경 버리기가 다른 레벨·공유 데이터에 영향을 주지 않게 해.

관련 자동 검사·컴파일·UI 검사를 수행하고 검증하지 못한 항목은 명확히 남겨.
실제 작업 데이터와 검증 결과는 보존하고 임시 검사 사본만 정리해.
제품 빌드·설치, 커밋·푸시, HTML 매뉴얼 갱신은 하지 마.
질문은 시간제한 없는 일반 문답으로 해.

1단계 종료 시 완료 내용·검증·미완료 항목을 보고하고,
결과를 반영한 2단계 계획서·목표 문서·복사용 목표 실행문을 작성해.
간략한 커밋 메시지도 복사 가능한 코드 블록으로 제시해.
2단계 구현은 자동으로 시작하지 마.
```
