# 경량 로비 2단계 실행 명령문

1단계 완료를 확인했다. 다음 단계 실행을 요청할 때 사용한다. 이 문서 작성 자체로 2단계를 시작하지 않는다.

```text
ServeredMeridian 경량 로비 2단계를 진행해줘.

위 문서를 기준으로 현재 구현과 1단계 완료 상태를 확인하고 구현·검증해줘.

로비의 선택 ID·번호·세대를 게임 씬에 전달하고, 해당 레벨의 구간 팩과 필요한 자원만 준비해서 시작해줘.
중복 클릭·실패·취소·로비 복귀와 비연속 다음 레벨을 처리해줘.
게임 프로필 3종은 로비 시작으로 연결하되 Windows/Android 레벨툴의 시험 실행은 보존해줘.
씬·프리팹은 임시 Editor 생성 스크립트로 수정하지 마.

제품 빌드·커밋·푸시·HTML 매뉴얼 갱신은 하지 마.
질문은 제한시간 없는 문답으로 해줘.
완료 후 검증 결과·미검증 항목·복사용 커밋 메시지와 3단계 계획·목표·실행 명령문을 제시해줘.
3단계 구현은 자동 시작하지 마.
```
