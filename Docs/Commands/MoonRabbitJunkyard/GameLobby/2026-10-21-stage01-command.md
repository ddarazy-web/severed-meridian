# 경량 로비 1단계 목표 실행 명령문

아래 명령문은 복사해 실행을 요청할 때 사용한다. 기존 부분 구현을 먼저 확인하고 남은 작업을 이어서 진행한다. 이 문서 작성 자체는 구현 실행 요청이 아니다.

```text
ServeredMeridian 경량 로비 1단계를 진행해줘.

Docs/Planning/MoonRabbitJunkyard/GameLobby/2026-10-21-lightweight-lobby-plan.md
Docs/Planning/MoonRabbitJunkyard/GameLobby/2026-10-21-stage01-plan.md
Docs/Goals/MoonRabbitJunkyard/GameLobby/2026-10-21-stage01-goal.md
위 문서를 기준으로 구현하고 검증해줘.
기존 인덱스·게시·로더 코드와 검증 기록을 확인하고, 완료된 부분은 보존하면서 남은 작업을 진행해줘.

등록 레벨의 번호·이름·ID를 담은 작은 목록 인덱스를 기존 MemoryPack 게시 경로와 같은 세대로 생성해줘.
로비에서는 목록 인덱스와 세대 정보, 최소 UI 리소스만 읽고 레벨 본문·요소 팩·게임 아틀라스·효과음은 로드하지 마.
인덱스가 없거나 손상되어도 전체 레벨 팩을 열어 목록을 만드는 우회는 하지 마.
1천/1만 레벨에서도 화면에 보이는 셀과 소수의 여유 셀만 생성하고 재사용해줘.
빈 목록·로딩·실패·재시도와 한글 표시, 화면 크기 변경, 재사용 셀의 올바른 선택을 확인해줘.
이번 단계는 선택 요청 이벤트까지이며 실제 게임 씬 전환과 게임 프로필 시작 씬 변경은 2단계로 남겨줘.
씬·프리팹은 임시 Editor 생성 스크립트로 편집하지 말고 지원되는 Unity 편집 도구를 사용해줘.
기존 사용자 변경과 실제 제작 데이터를 보존하고, 테스트 사본·임시 파일만 정리해줘.
제품 빌드·커밋·푸시·HTML 매뉴얼 갱신은 하지 마.
질문이 필요하면 제한시간 없는 문답으로 해줘.
완료 후 변경 내용·검증 결과·미검증 항목·성능 측정과 복사용 커밋 메시지를 보고해줘.
1단계 완료를 확인한 뒤 2단계 계획서·목표 문서·복사용 실행 명령문을 작성하고, 2단계 구현은 자동 시작하지 마.
```
