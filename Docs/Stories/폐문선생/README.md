# 폐문선생 (가제)

문파의 회생과 폐문을 돕는 주인공을 통해, 현대 자영업자가 사업을 계속하기도 접기도 어려운 사정을 무협 이야기로 다루는 기획이다.

현재 단계는 컨셉 정리다. 완성 원고, 확정 플롯, 상세 세계관은 아직 없다. 이 문서는 대화에서 정한 방향을 보존하기 위한 작업 문서이며, 새 사건을 확정하는 문서가 아니다.

## 독립 범위

이 작품은 같은 저장소의 Servered Meridian 기획 및 기존 스토리와 별개다. 저장 위치만 공유하며, 시대·인물·세력·무공·사건을 공유한다고 가정하지 않는다. 사용자는 기존 Docs 기획을 삭제하고 새로 시작하기로 했다.

## 문서 안내

- [현재 컨셉과 합의 사항](concept/brief.md): 가제, 핵심 방향, 주인공 역할, 미정 사항.
- [대화에서 나온 가안](concept/idea-notes.md): 사건과 인물 후보, 예시 대사, 보류·대체된 방향.
- [지침과 스킬 확인 기록](workflow.md): 확인한 공용 지침과 스토리 스킬, 이번 정리에 적용한 기준.
- [이 작품의 작업 지침](AGENTS.md): 기존 프로젝트와의 분리 및 설정 상태 관리.

## 다음 기획 단계

우선 주인공이 누구의 의뢰를 받고 어떤 권한으로 협상하는지 정하면, 그의 능력과 한계 및 사건의 갈등을 구체화할 수 있다. 이어 주인공의 개인적인 욕망과 첫 의뢰를 설계한다. 이는 다음 작업 제안이며 이번 정리에서 확정하거나 집필하지 않는다.
