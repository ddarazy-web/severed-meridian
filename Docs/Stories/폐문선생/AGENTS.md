# 폐문선생 작업 범위

- 이 디렉터리는 《폐문선생》(가제)의 독립 소설 기획 공간이다. 같은 저장소의 Servered Meridian 게임 기획·세계관·인물·스토리와 별개로 취급한다.
- 기존 프로젝트 자료는 사용자가 명시적으로 연결을 요청하지 않는 한 이 작품의 설정 근거로 사용하지 않는다. 범용 작업 지침과 스토리 스킬은 사용할 수 있다.
- 이 작품의 기획, 설정, 플롯, 원고는 `Docs/Stories/폐문선생/` 안에 저장한다. Assets에 편입하지 않는다.
- README.md와 concept/brief.md에서 현재 방향을 먼저 확인한다. concept/idea-notes.md의 제안은 확정 설정이 아니다.
- 상태는 canon(사용자가 승인한 사항), draft(제안), unknown(미정), deprecated(현재 채택하지 않는 이전 방향)으로 구분한다. 문서에 여러 상태가 섞이면 항목별 상태를 우선한다.
- 가제 선택은 인물·사건·세계관 전체에 대한 승인으로 해석하지 않는다. 회생을 돕는 역할을 폐문만 수행하는 역할로 되돌리지 않는다.
- 새 설정이나 원고 집필은 요청 범위에 맞춰 진행하고, 확정되지 않은 빈칸을 기존 게임 설정으로 채우지 않는다.

- 사용자는 기존 Docs 기획을 삭제하고 새로 시작하기로 했다. 삭제된 문서를 복원하거나 그 내용을 이 작품의 전제로 삼지 않는다.
