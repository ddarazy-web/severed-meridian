## 이번 정리의 완료 기준

- 모든 신규 문서를 `Docs/Stories/폐문선생/` 아래에 둔다.
- 사용자가 삭제한 기존 Docs 기획 및 스토리를 복원하거나 새 작품의 전제로 삼지 않는다.
- 사용자 발언으로 확인된 방향과 어시스턴트가 제안한 설정을 구분한다.
- 폐문만 돕는 초기 역할보다 회생도 돕는 최신 방향을 우선한다.
- Markdown 링크와 필수 메타데이터를 확인한다.

공용 지침이나 스킬 원본은 수정하거나 이 작품 전용 내용으로 덮어쓰지 않는다.
