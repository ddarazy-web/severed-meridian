# 컨셉과 합의 사항

## 합의된 방향 — canon

아래는 사용자의 발언을 근거로 정리한 방향이다. 세부 설정까지 승인됐다는 뜻은 아니다.

| 항목 | 현재 방향 | 대화 근거 |
| --- | --- | --- |
| 장르 | 신규 무협 이야기 | “신규 무협 아이디어” |
| 소재 | 폐문에 현대 자영업의 폐업 사정을 접목한다. 그만두고 싶어도 쉽게 그만둘 수 없다는 현실에 주목한다. | “요즘은 폐업을 하려고 해도 쉽지가 않거든.” |
| 주인공 역할 | 폐문 처리에만 한정하지 않고 회생을 돕는 변호사 같은 역할로 구상한다. | “일종의 회생을 위한 변호사 같은거잖아” |
| 제목 방향 | ‘폐문’이 들어가며 주인공을 일컫는 호칭을 선호한다. | “폐문사형 처럼 주인공을 일컫는 말이면 좋겠어” |
| 가제 | 《폐문선생》. 최종 제목은 추후 정한다. | “폐문선생이 좀 와 닿는다” 및 앞선 가제 논의 |
| 작품 범위 | 기존 프로젝트 기획과 스토리로부터 독립시켜 `Docs/Stories/폐문선생/`에 정리한다. 기존 Docs 삭제 후 새로 시작한다. | 2026-09-09 저장 요청 |

‘회생을 위한 변호사’는 역할을 이해하기 위한 현대적 비유다. 실제 변호사 자격, 현대 법제 또는 역사상의 특정 제도를 작품에 도입하기로 정한 것은 아니다.

## 컨셉 문장 — draft

빚과 의리 때문에 끝내지도, 계속하지도 못하는 문파를 찾아가 그 안의 사람들이 다시 살아갈 길을 마련하는 무협.

## 주인공의 업무 구체화 — draft

주인공은 문파의 사정을 살펴 회생할 길을 찾고, 회생이 어렵다면 폐문과 이후의 삶을 돕는다.

- 채권자와 빚의 규모 및 상환 시기를 협상한다.
- 문파가 생계를 이어갈 일감과 계약을 정리한다.
- 제자들의 거취와 받아야 할 몫을 조정한다.
- 폐문할 경우 재산, 비급, 남은 의무와 원한을 정리한다.

위 업무는 앞선 대화에서 제안한 범위다. 실제 권한, 보수, 의뢰 계약, 강제력과 관청의 관여는 미정이다. 모든 의뢰가 폐문으로 끝나는 구조는 아니다.

## 작품이 약속할 재미 — draft

1. 서로 다른 문파의 장부와 사연을 통해 위기의 실제 원인을 알아가는 재미.
2. 문주, 제자, 가족, 채권자의 요구가 부딪히는 협상과 선택.
3. 문파를 살릴 수 있는지, 닫아야 하는지 쉽게 판단할 수 없는 긴장.
4. 문파의 존속 여부와 함께 남은 사람들이 어떻게 다시 살아가는지 보는 여운.

## 현대의 폐업 사정과 무협의 접점 — draft

아래는 창작을 위한 대응 관계이며 현대 법률이나 역사 제도에 대한 사실 설명이 아니다.

| 현실에서 착안할 사정 | 무협에서 다룰 수 있는 갈등 |
| --- | --- |
| 생활과 생계가 사업체에 함께 묶여 있음 | 도장이 수련장인 동시에 제자와 가족의 삶터임 |
| 그만둬도 빚과 약속이 남음 | 현판을 내려도 채무, 호위 약속, 원한이 남음 |
| 함께 고생한 사람에게 그만두겠다고 말하기 어려움 | 사부와 제자가 서로의 의리 때문에 떠나거나 폐문하지 못함 |
| 오래 지킨 가게에 대한 자부심과 미련 | 선대의 현판과 문파의 명예를 포기하기 어려움 |
| 영업을 지속하는 것이 손실을 키울 수 있음 | 문파를 지키려는 노력이 식구들의 생활을 더 어렵게 만듦 |

## 주제적 질문 — draft

- 문파의 이름을 지키는 일과 그 안의 사람을 지키는 일이 어긋나면 무엇을 택할 것인가?
- 회생의 가능성을 믿는 마음은 언제 책임이고, 언제 미련이 되는가?
- 문을 닫은 뒤에도 사람의 삶과 배운 것은 어떻게 이어지는가?

## 범위와 주의점

- 기존 게임 세계관과의 연결은 하지 않는다. 이는 사용자가 요청한 분리 범위다.
- ‘사형’에 해당하는 사제 관계를 제목에 맞추려고 새로 만들지 않는다.
- 주인공을 단순한 문파 파괴자나 폐문 집행자로 해석하지 않는다.
- 모든 위기에 배후 악당이 있고 그를 쓰러뜨리면 회생한다는 구조는 현재 합의된 방향이 아니다.
- 구체적인 법률·역사 고증이 필요해지면 그때 조사한다. 현재 가안을 사실로 취급하지 않는다.

## 아직 정하지 않은 사항 — unknown

- 독자층, 연재 여부, 전체 분량, 시점, 문체와 유머의 비중.
- 시대·지역, 관청과 무림의 관계, 문파의 경제 및 채무 제도.
- 주인공의 이름, 성별, 나이, 과거, 욕망, 무공 수준과 약점.
- ‘폐문선생’이라는 호칭의 유래와 사회적 평판.
- 의뢰인은 누구이며 이해관계가 충돌할 때 누구를 대리하는가.
- 주인공의 협상이 지켜지게 하는 권한과 수단, 실패할 때 치르는 대가.
- 첫 사건의 문파와 인물, 회생 또는 폐문이라는 결말.
- 장기 갈등, 동료와 적대자, 전체 결말.
