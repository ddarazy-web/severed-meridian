# 생활과 제작

## 상한 돌파 재료 조달

- **확정**: 능력치 상한 돌파에는 특정 지역의 약초 채집, 벌목, 채광과 재료 가공 과정이 포함될 수 있다.
- **확정**: 재료마다 적합한 지역과 지형을 두되 필수 재료의 출현 지역 및 검색 범위는 명확히 안내한다.
- **확정**: 필수 재료를 낮은 확률의 무작위 출현만으로 획득하게 만들지 않는다.
- **확정**: 이미 가진 적합한 재료를 인정하며 과제 수락 후 새로 획득하도록 강제하지 않는다.
- **확정**: 단순 이동 시간을 콘텐츠 분량으로 계산하지 않고 빠른 이동과 같은 지역 내 목표 묶음으로 왕복을 줄인다.
- **가안**: 직접 상한 돌파 한 건의 재료 조사와 획득은 이동을 제외하고 5~10분을 목표로 한다.
- **확정**: 상한 돌파 실패 시 핵심 희귀·퀘스트 재료, 공용 소모재와 영구 훈련 도구를 모두 보존한다.
- **폐기**: 실패 후 공용 소모재를 25% 잃고 다시 채집하는 규칙은 사용하지 않는다.
- **확정**: 재료 재수집 대신 실패 원인을 수정하는 짧은 재정비 전용 임무를 수행한다.
- **수정**: 약초·벌목·채광은 거점 귀환 즉시 보충하거나 진행 사건으로 보충하지 않고 공통 맵별 자원 갱신 주기와 희귀도별 보장 규칙을 사용한다.
- **확정**: 상한 돌파 전용 자원은 최소 필요량을 보장하는 전용 지점을 제공한다.
- **확정**: 퀘스트 전용 자원은 해당 퀘스트 상태와 함께 등장·소멸하며 운명 각인 롤백 때 함께 복원된다.
- **확정**: 자원 보충은 완료된 비반복 퀘스트를 다시 열지 않는다.

## 확정

- 채집 기술로 영약 제조에 필요한 재료를 얻을 수 있다.
- 채광과 제련을 통해 필요한 도구를 직접 생산할 수 있다.
- 주인공은 게임 시작 시 기초 수준의 약초 채집 기술을 보유한다.
- 채광, 가공, 제련, 영약 제조와 도구 제작 등 손재주 계열 기술은 한 번 습득하면 신체 능력치가 약화되더라도 사라지거나 숙련도가 감소하지 않는다.
- 모든 생활 기술은 공통으로 1~50 숙련도를 사용하고 견습 1~10, 수련 11~20, 숙련 21~30, 장인 31~40, 대가 41~50의 다섯 단계로 구분한다.
- 주인공은 약초 채집 숙련도 5로 시작하고 다른 생활 기술은 습득 전 상태로 시작한다.
- 시작 장비로 개당 15회 사용할 수 있는 `범품 낡은 약초칼` 2개를 지급해 총 30회의 초기 채집을 보장한다.
- 첫 번째 약초칼은 약초 채집 도구 슬롯에 자동 장착한다.
- 작업 난도와 획득 품질에 따라 기술 경험치를 얻되 지나치게 쉬운 작업의 경험치는 크게 감소한다.
- 숙련도 10·20·30·40에서는 현재 단계 상한 달성과 실전·지식·인맥 증명 중 하나를 요구하는 숙련 돌파 후 다음 단계로 진입한다.
- 실전과 지식 증명은 별도 퀘스트가 아닌 생활 기술 화면의 체크 조건이고 인맥 증명을 선택할 때만 전문 NPC의 짧은 의뢰를 진행한다.
- 모든 돌파에 전용 퀘스트를 만들지 않으며 대가 진입이나 주요 장인 서사 등 일부 중요한 돌파에만 전용 퀘스트를 사용한다.
- 세 증명 경로는 공통 데이터 틀을 쓰고 기술·단계별 대상과 요구 수치만 교체한다.
- 실전·지식 증명의 진행도는 현재 숙련 단계에 진입한 순간부터 누적하고 이전 단계나 계정 기록을 소급하지 않는다.
- 상한 도달 시 이미 충족한 경로가 있으면 즉시 돌파 가능 상태로 표시하며, 그렇지 않으면 원하는 경로만 추가로 진행한다.
- 일반 숙련 돌파는 자동 적용하지 않고 생활 기술 화면의 버튼으로 직접 확정한다.
- 확인 화면은 달성 증명, 현재·다음 단계, 새 상한, 대표 해금 대상과 개선 정보만 표시하며 미니게임과 경로별 추가 보상을 두지 않는다.
- 단계 상한에서 추가 기술 경험치는 저장하지 않지만 필요한 재료와 결과물을 얻기 위한 생활 활동은 계속 허용한다.
- 단계 상한 최초 도달과 상한 상태의 최초 활동에는 안내·확인 팝업을 한 번씩 표시한다.
- 이후 같은 단계에서는 팝업을 반복하지 않고 HUD·생활 기술 아이콘의 `상한` 표시와 상호작용 정보의 획득 경험치 `0` 표기를 유지한다.
- 숙련 돌파가 가능해지면 알림을 제공하며 설정에서 상한 경고를 다시 표시할 수 있다.
- 이전에 사용한 `연공`이라는 표현은 무공 수련이 아니라 연금·가공·제작을 뜻한 것이므로 생활 기술 명칭에서는 사용하지 않는다.
- 영약 제조 생활 기술의 공식 명칭은 `제약`이며 탕약, 고약, 환약과 단약을 제작한다.
- 치료제는 임시 상태 회복, 영약은 네 기본 능력치의 영구 성장과 성장 한계 준비로 역할을 분리한다.
- **수정**: 영약의 종류별 1회 제한은 폐기하고 경지별 약성 흡수 한도 안에서 반복 복용할 수 있다.
- 같은 경지 영약은 100%, 한 경지 낮은 영약은 50%, 두 경지 이상 낮은 영약은 0% 효과이며 상위 경지 영약은 복용할 수 없다.
- 네 능력치마다 경지별 약성 흡수 한도를 두고 미사용 한도는 다음 경지로 이월하지 않는다.
- 남은 흡수 한도가 0이거나 현재 경지에서 약효가 0인 영약은 복용할 수 없다.
- 유효 약성이 남은 한도를 일부 초과하면 명목 약성·경지 보정 후 유효 약성·실제 흡수량·소멸량을 확인한 뒤 복용할 수 있으며, 초과분은 이월되지 않고 소멸한다.
- 하급 영약은 같은 능력치 계열의 상급 영약 제조에 기반 재료로 재사용하며 현재 단계의 신규 약재와 촉매도 요구한다.
- 하급 영약은 바로 다음 단계의 같은 능력치 영약으로만 승급할 수 있으며 두 단계 이상 건너뛸 수 없다.
- 승급에는 직전 단계 완성 영약 1개와 현재 단계의 신규 핵심 약재, 촉매 및 제약 숙련도 조건이 필요하다.
- 영약도 범품, 양품, 상품, 명품, 절품의 공통 5단계 품질을 사용한다.
- 품질은 복용 1회당 약성 성장량에 영향을 주지만 경지별 약성 흡수 한도를 높이지 않는다.
- 낮은 품질 영약도 반복 복용과 승급 재료로 사용할 수 있다.
- 승급 재료로 사용한 직전 단계 영약의 품질은 상급 영약 결과물의 최소 품질로 보장한다.
- 제약 숙련도, 도구와 신규 재료가 충분하면 더 높은 품질이 나올 수 있으며 낮은 재료 영약 품질이 결과 품질의 상한을 제한하지 않는다.
- 영약 약성은 제조법 기본 약성에 범품·양품·상품·명품·절품 공통 품질 보정 `+0·+1·+2·+3·+4`를 더해 계산한다.
- 재료별 약성 합산이나 품질별 퍼센트 배율은 추가하지 않는다.
- 한 경지 낮은 영약의 50% 효과는 반올림하지 않고 0.5 단위까지 유지하며 UI에는 소수점 한 자리로 표시한다.
- 기본 영약은 `4개 능력치 계열 × 불입류부터 생사경까지 9개 단계`로 총 36종을 구성한다.
- 각 단계에는 생명력·힘·민첩·스태미너 또는 내공 계열 제조법을 1종씩 두며, 불입류에서는 스태미너로, 21레벨 이후에는 내공으로 표시한다.
- 36종은 제조법과 아이템 종류의 기준 수이고 각 종류는 범품부터 절품까지 5개 품질로 제작할 수 있다.
- 36종 모두 서로 다른 무협식 고유 이름을 사용하고, UI에는 `고유 이름 · 영약 단계 [효과 능력치]`를 함께 표시한다.
- 능력치별 대표 작명 어휘는 생명력 `보명·양혈·회생·연수`, 힘 `금강·패력·용력·철골`, 민첩 `경신·비연·유풍·축영`, 스태미너·내공 `보원·익기·응진·귀원`으로 구분한다.
- 대표 어휘는 계열 식별을 돕는 기준으로 사용하되 모든 이름에 동일 접두어를 강제하지 않으며 각 영약의 완성 명칭은 고유하게 만든다.
- 제형은 불입류~이류의 탕·고·산·환에서 일류~초절정의 환·단을 거쳐 화경~생사경의 단 중심으로 발전시킨다.
- 제형별 이름, 재료 구성과 아이콘에는 차이를 두되 복용 조작과 약성 적용 규칙은 동일하게 유지한다.
- 영약 제조법은 경지별 핵심 약재, 능력치별 보조 약재와 공통 약재·촉매의 조합으로 구성한다.
- 핵심 약재는 해당 경지의 특정 지역과 소수 맵에서만 획득하게 하고, 보조 약재는 주산지 1곳과 부산지 1~2곳의 총 2~3개 지역에 분산한다.
- 필수 성장 약재는 획득 지역 중 한 곳을 안정 서식지로 지정해 매 생태 주기에 최소 수량을 보장하고, 선택형 희귀·기연 약초에는 안정 서식지를 두지 않는다.
- 안정 서식지의 최소 생성량은 해당 약재를 사용하는 표준 제조법 1회분으로 정한다.
- 필수 퀘스트 한 단계의 요구량은 현재 개방된 안정 서식지의 한 주기 보장 총량을 넘지 않으며, 여러 회분이 필요하면 단계를 나누거나 다른 확정 획득처를 병행한다.
- 반복 복용과 대량 자유 제작은 한 생태 주기 내 완성을 보장하지 않는다.
- 현재 단계의 보조 약재는 현재까지 개방 가능한 지역 중 최소 1곳에서 반드시 얻을 수 있어야 하며 미래 지역을 필수 선행 조건으로 삼지 않는다.
- 보조 약재의 1회 채집량은 지역에 따라 바꾸지 않는다. 주산지는 출현 지점과 고품질 확률이 높고 부산지는 두 수치가 낮다.
- 영약과 치료약 제조법 UI는 `재료 아이콘 + 재료 아이콘 + 촉매 아이콘 → 결과물 아이콘` 구조로 조합 정보를 보여준다.
- 각 재료 아이콘을 누르면 약재 설명, 주요 용도와 획득 가능한 지역 정보를 툴팁으로 표시한다.
- 개방된 획득 지역은 지역명을 표시하고 실제로 발견한 채집 지점은 맵 이름까지 표시한다.
- 미개방 주산지와 부산지는 `미발견 지역`으로 감추되, 제조법 획득 시점에 현재 접근할 수 있는 구체적인 획득처를 최소 한 곳 안내한다.
- 새로운 지역이나 채집 지점을 발견하면 해당 약재 툴팁의 획득처 정보를 자동으로 갱신한다.
- 별도의 제조법 추적 기능은 두지 않는다. 자유 제작은 제조법 화면에서 확인하고, 생존·경지 돌파 등에 필요한 제조는 관련 퀘스트의 활성 추적으로 안내한다.
- 일반 제조법의 재료 툴팁에서 알려진 획득 맵을 선택할 수 있으며, 현재 맵을 선택하면 이번 생태의 존재 여부만 표시하고 넓은 탐색 구역은 자동 표시하지 않는다.
- 도감이나 획득처에 등록되지 않은 약초는 일반 툴팁에서 존재 여부를 조회할 수 없다.
- 특정 약재를 요구하는 활성 퀘스트에 한해 지역·맵과 미니맵의 넓은 탐색 구역까지 안내하고, 퀘스트가 끝나면 해당 안내를 해제한다.
- 채집물 가까이 접근하면 실제 화면과 미니맵에 아이콘 또는 은은한 강조가 나타나며, 최초 채집 후 해당 지점을 발견 정보로 기록한다.
- 발견한 채집 지점은 이후 방문부터 미니맵에 작은 자원 표식으로 표시한다.
- 여러 진행 중 퀘스트 가운데 하나만 활성 추적할 수 있고, 변경 시 진행도는 유지한 채 HUD·지도 안내만 교체한다.
- 활성 추적 퀘스트가 없으면 새 퀘스트를 자동 추적하고, 이미 추적 중이면 기존 대상을 유지한 채 수락 알림에 `추적 전환` 버튼을 제공한다.
- 필수 생존·경지 돌파 퀘스트도 추적을 강제로 바꾸지 않지만 치명적 위험과 직접 관련되면 강한 알림을 한 번 표시한다.
- 약재 퀘스트는 개방·발견된 지역 중 목표 약재가 현재 생성된 가까운 지역을 최대 2곳까지 추천하고, 첫 지역에서 부족하면 남은 수량과 다음 지역을 안내한다.
- 미개방 지역은 추천하지 않으며 일반 약재 퀘스트를 위해 부족분 전용 채집 지점을 동적으로 생성하지 않는다.
- 제조 목표 퀘스트의 HUD는 결과물·목표 수량, 재료별 보유량/필요량, 부족 재료와 알려진 획득 지역을 표시하고 재료를 모두 확보하면 `제조 가능`을 알린다.
- 재료·제조 목표는 기존 보유품을 인정하는 `보유 인정형`과 수락 후 직접 수행해야 하는 `수락 후 행동형`으로 구분해 설명에 명시한다.
- 전달·확보·준비는 기존 보유품을 인정하고, 직접 채집·직접 제조·첫 제작은 수락 이후의 행동만 인정한다.
- 생존·경지 돌파 준비는 보유 인정형을 원칙으로 하고 기술 튜토리얼·숙련 증명·특별 서사만 수락 후 행동형을 사용한다.
- 퀘스트 필요 재료는 자동 잠금하지 않고 판매·사용·다른 제작 투입을 허용하되, 감소 후 보유량과 부족 예상량을 경고하고 확인을 받는다.
- 확보·준비·전달 진행도는 현재 보유량에 따라 실시간으로 오르내리며, 직접 채집·직접 제조의 행동 기록은 결과물을 소비해도 유지한다.
- 실제 제출이 필요한 퀘스트는 행동 조건과 제출 수량을 별도 목표로 표시한다.
- 퀘스트 추적 여부와 관계없이 맵별 약초 생태표에 포함된 모든 약초의 종류·수량·위치를 채집 주기마다 결정한다.
- 약초는 생태에 맞는 후보 지점에 무작위 배치하며, 결정된 생성 결과는 단순한 맵 이탈과 재입장으로 다시 판정하지 않는다.
- 맵마다 실제 경과 시간 기준의 독립 생태 갱신 주기를 가지며 게임 종료 중에도 시간이 흐른다.
- 주기 도중 마을·도시를 왕복해도 기존 약초 상태를 유지하고, 주기가 지난 뒤 정식 마을·도시를 거쳐 다시 야외로 출발할 때 새 생태를 생성한다.
- 야외 체류 중 주기가 지나더라도 눈앞의 약초를 즉시 교체하지 않는다.
- 생태 갱신 시간은 소형 15분·중형 20분·대형 30분의 세 표준 주기를 사용한다.
- 벌목·채광도 약초와 동일한 갱신 시간, 정식 거점 경유, 오프라인 진행, 희귀도, 안정 산지와 지역 추천 규칙을 사용한다.
- 갱신 연출은 약초의 새 생육 지점, 벌목 가능한 나무·쓰러진 목재, 새로 드러난 광물 노두·광맥처럼 자원별로 다르게 표현한다.
- 맵 크기, 평균 총 채집량과 희귀 약초 후보 수를 함께 고려해 갱신 주기를 분류하고, 월드맵의 맵 정보에서 남은 시간 또는 다음 출발 시 갱신 상태를 확인할 수 있다.
- 약초 종류의 출현 희귀도는 일반·귀한·희귀·기연의 네 단계로 구분한다.
- 출현 가안은 일반 최소 1개 보장, 귀한 40%와 2회 실패 후 다음 주기 보장, 희귀 20%와 4회 실패 후 다음 주기 보장, 기연 5%와 9회 실패 후 다음 주기 보장이다.
- 필수 보조 약재는 일반·귀한까지만, 경지별 핵심 약재는 귀한 중심으로 사용하며 희귀를 요구할 때는 확정 획득처를 병행한다.
- 기연 약초는 필수 성장에 사용하지 않고 절품 제작·숨은 제조법·고급 카드 승급·판매·수집에 사용한다.
- 연속 미출현은 약초 종류와 주산지 맵별로 기록하고, 생성 순간 실제 발견 여부와 무관하게 0으로 초기화한다.
- 시간대 한정 생성은 사용하지 않고 특수 퀘스트와 비경만 희귀 약초 확정 출현의 예외로 둔다.
- 약초 종류의 희귀도와 채집 결과물의 범품~절품 품질은 별도로 판정한다.
- 약초 품질은 지역·약초 종류의 최고 품질을 먼저 정하고, `채집 기술 수준 + 도구 보정 - 약초 채집 난도`로 구한 유효 채집 실력에 따라 별도로 판정한다.
- 유효 채집 실력은 매우 부족·부족·적정·숙련·달인의 5개 확률 구간을 사용한다. 도구는 기술을 대체하지 않는 보조 수치만 주며 지역과 약초의 품질 상한을 넘길 수 없다.
- 상한 밖의 품질 확률은 최고 허용 품질에 집중시키지 않고 허용된 아래 품질들에 재분배한다.
- 초기 품질 확률표는 매우 부족 `90/10/0/0/0`, 부족 `70/25/5/0/0`, 적정 `45/35/17/3/0`, 숙련 `25/35/28/10/2`, 달인 `10/25/35/25/5`를 가안으로 사용한다.
- 각 약초의 최소 채집 요구 수준보다 낮으면 상호작용을 차단하고 필요한 기술 수준을 표시한다.
- 최소 요구 수준은 도구 보정을 제외한 순수 채집 기술 수준으로만 판정한다.
- 최소 요구 수준을 충족한 채집은 실패 없이 정해진 수량을 획득하고 기술 차이는 품질 확률과 채집 시간에 반영한다.
- 채집 도구는 약초 접근 조건을 대신하지 않고 품질 확률과 채집 시간만 보정한다.
- 생활 활동별 전용 도구 슬롯에 현재 사용하는 도구 한 개를 장착한다.
- 작업 도구는 수리형 내구도 대신 사용 횟수를 가지며 작업 완료마다 1회 차감한다.
- 같은 제조법 단계·품질의 예비 도구는 한 인벤토리 스택에서 수량으로 관리한다.
- 스택형 도구도 수량만큼 휴대 중량을 모두 합산하고 장착 도구를 포함한다.
- 부분 사용 도구는 원래 중량을 유지하며 완전 소진으로 한 개가 사라지는 즉시 해당 중량을 차감한다.
- 도구 스택에는 보유 수량, 총 남은 사용 횟수와 총중량을 표시한다.
- 작업 도구의 개당 중량은 도구 종류, 재료와 제조법 단계로 정하고 동일 제조법의 품질 차이는 중량에 영향을 주지 않는다.
- 이 품질·중량 분리 원칙은 약초·광물·목재·가공 재료·부품·치료제·영약 등 모든 아이템에 공통 적용한다.
- 같은 스택에 예비 도구가 남아 있으면 현재 도구 소진 후 다음 동일 도구를 자동 장착하며 교체창을 띄우지 않는다.
- 장착한 동일 도구 스택 전체가 소진되어 다른 단계나 품질을 골라야 할 때만 추천 교체창을 표시한다.
- 마지막 사용 횟수의 작업은 정상 완료하고 결과물을 지급한 뒤 도구가 소멸한다.
- 소진 후 교체창은 현재 자원에 가장 경제적인 호환 도구 3~5개와 추천 이유를 먼저 보여주고 전체 보기와 수동 선택을 제공한다. 자동 교체는 기본값으로 사용하지 않는다.
- 더 경제적인 도구가 있어도 팝업 없이 상호작용 UI에 추천과 즉시 변경 버튼만 표시하며, 무시하면 현재 호환 도구로 그대로 작업할 수 있다.
- 비효율 도구는 성공·접근·기본 수량을 제한하지 않고 품질 확률과 작업 시간에만 영향을 준다.
- 슬롯이 비어 작업이 불가능할 때만 교체창을 강제로 열고, 맨손 가능한 초급 약초는 낮은 효율 경고 후 허용한다.
- 품질별 사용 횟수 가안은 범품 15·양품 20·상품 25·명품 35·절품 50회다.
- 소모성 작업 도구에는 개별 경험치·레벨·사용 성장을 두지 않고 제조법 단계와 결과 품질만으로 성능을 정한다.
- 영구 성장은 주인공의 채취·도구 제작·제련 숙련도가 담당하며 각 활동은 관련 기술 경험치를 제공한다.
- 요구 수준 미달로 채집하지 못한 약초는 사라지거나 손상되지 않는다.
- 고급 단약 제작은 제약의 상위 분야인 `연단`으로 구분한다.
- 도구 제작에는 채집·채광용 도구와 전투에 사용하는 무기 제작이 포함된다.
- 무기 제작으로 기본 완성품을 만들고 제련으로 품질과 부가 효과를 강화한다.
- 생활 기술의 숙련도와 제작물은 전투 카드의 레벨 상승 및 승급 조건에 활용된다.
- 직접 카드 승급은 관련 기술 숙련도와 재료를 요구하며 부가 효과를 선택할 수 있다.
- NPC 대행은 기술 숙련도를 대신하는 우회 수단이지만 더 많은 재료·은전과 호감도 또는 선행 의뢰를 요구한다.
- 명장급 NPC에게 최고 등급 카드 승급을 맡기려면 높은 호감도와 전용 의뢰 완료가 필수다.
- 명장급 NPC의 호감도는 선물이 아니라 전용 퀘스트와 신뢰를 얻는 행동으로 상승한다.
- 명장급 제작과 최고 등급 카드 승급 대행에는 반드시 희귀 재료가 포함된다.

## 기술 해금 순서

- 시작: 기초 약초 채집, 기초 약재 가공
- 5레벨: 상위 약초 채집, 제약, 탕약·고약·환약
- 2~3레벨: 첫 생존 준비 과정에서 생활용 도구 제작, 도구 제작 숙련도 1과 낡은 약초칼 제조법
- 10레벨: 채광, 제련, 무기 제작
- 15레벨: 연단, 단약, 상위 가공·제련, 카드 승급 재료 제작
- 20레벨 이후: 상위 교본, 명장, 희귀 재료, 최고 등급 제작

각 기술은 해당 구역의 짧은 튜토리얼 퀘스트를 완료해야 실제로 해금된다. 완료 시 기술 1레벨과 기본 제작법을 함께 얻는다.

생활용 도구 제작은 시작 약초칼이 대략 절반 남는 2~3레벨 진행 시점에 튜토리얼을 안내한다. 잔여 사용 횟수를 엄격한 발생 조건으로 삼지는 않으며, 해금 전후에도 약방이나 잡화점에서 범품 초급 채집 도구를 구매할 수 있다.

`낡은 약초칼`의 제조법은 `조잡한 칼날 1 + 나무 손잡이 1 + 질긴 끈 1`이다. 10레벨 이전에는 약방·잡화점에서 구입하거나 퀘스트로 받은 완성 부품을 조립한다. 10레벨 이후에는 채광·가공·제련으로 부품을 직접 생산해 구입 비용을 줄이고 상위 품질 도구 제작을 준비할 수 있다.

상점에서 상시 판매하는 초급 도구 부품은 범품으로 제한하고 첫 튜토리얼 결과도 범품으로 확정한다. 직접 생산한 부품은 범품~절품 품질을 가질 수 있으며 부품 품질과 도구 제작 숙련도가 완성 도구의 품질 확률을 높인다. 최저 품질 부품이 완성품 품질이나 상한을 고정하지는 않지만, 낮은 품질 부품이 섞이면 상위 품질 확률이 낮아진다. 양품 이상 생활 도구는 직접 생산한 부품과 제작 숙련도를 통한 획득을 기본으로 한다.

생활용 도구 제작은 제조법의 숙련도와 재료 조건을 충족하면 실패하지 않는다. 숙련도와 부품 품질은 완성 도구의 범품~절품 품질 확률에만 반영하며, 제작 실패로 부품을 잃거나 진행이 중단되는 구조는 사용하지 않는다.

가공·제련·제약·연단을 포함한 모든 일반 생산도 숙련도·제조법·시설·재료 조건을 충족하면 반드시 완성된다. 조건이 부족하면 생산 시작 전에 차단하고 부족 조건을 표시한다. 일반 생산은 실패로 재료를 소실하거나 제작 사고를 일으키지 않으며 숙련도와 재료 품질은 결과 등급 확률에 반영한다. 특별 서사 제작이나 선택형 위험 연단은 추후 일반 생산과 분리된 예외 콘텐츠로 검토한다.

초기 제작 시스템에는 선택형 위험 제작과 위험 연단을 포함하지 않는다. 일반 생산과 최고급 서사 콘텐츠의 요구가 확인된 뒤에만 별도 예외 규칙으로 재검토한다.

## 제조법 획득

- 재료를 임의로 조합해 제조법을 우연히 발견하는 방식은 사용하지 않는다.
- 기초 제조법은 생활 기술 해금 튜토리얼에서 자동 습득한다.
- 일반 제조법은 약방·대장간·서점 등에서 교본을 구매해 습득한다.
- 상급 제조법은 전문 NPC 의뢰, 관계 조건과 문파 전수로 습득한다.
- 희귀 제조법은 비경 탐색, 강적 보상과 숨겨진 기록으로 습득한다.
- 필수 제조법은 무작위 드롭만을 요구하지 않고 지정 경로에서 확정적으로 얻을 수 있게 한다.
- 미습득 제조법은 도감에 실루엣으로 표시하고 생산 계열·단계, 대략적인 용도, 획득 경로 유형과 대략적인 지역, 현재 조건 충족 여부만 공개한다.
- 정확한 이름, 재료 구성, 완성품 수치와 품질별 효과는 습득 후 공개한다.
- 구음절맥 생존이나 필수 경지 상승 제조법은 예외로 두고 관련 퀘스트에서 정확한 이름과 획득처를 안내한다.
- 교본은 인벤토리에 쌓이는 수집품이 아니라 획득·사용 연출 후 즉시 소비되어 제조법을 해금하는 수단이다.
- 현재 습득한 교본은 상점에서 `습득 완료`로 표시해 재구매를 막고 의뢰·문파 전수의 중복 보상에서도 제외한다.
- 비경·강적 보상에서 현재 습득한 교본이 중복되면 해당 출처에 지정된 대체 보상으로 교체한다.
- 운명 각인 롤백으로 실제 제조법 습득 상태가 사라졌다면 원래 획득 조건을 다시 충족해 재습득할 수 있다.
- 모든 제조법은 조기 습득 예외 없이 최소 습득 조건을 충족한 뒤에만 획득하는 단계별 습득 방식으로 통일한다.
- 최소 조건은 관련 생활 기술·숙련 수준, 지역·NPC 개방과 필요한 선행 의뢰·경지 조건으로 구성한다.
- 제조법마다 관련 생활 기술의 정확한 1~50 요구 숙련도를 지정하며 10레벨 단위 숙련 단계만으로 일괄 해금하지 않는다.
- 같은 숙련 단계 안에서도 제조법 획득 시점을 여러 숙련도에 분산하고, 도감과 획득처에는 `제약 17 필요`처럼 정확한 요구 수치를 표시한다.
- 요구 숙련도에 도달하면 해당 제조법의 지정 획득 경로가 활성화된다.
- 숙련도 도달만으로 자동 지급하지 않고 상점 구매·NPC 전수·의뢰·탐색 등 지정된 획득 과정을 완료해야 실제 습득한다.
- 조건 충족 시 HUD에 `새 제조법 획득 가능` 알림을 표시하고 도감에서 해당 제조법과 알고 있는 접근 가능한 획득처를 강조한다.
- 필수 제조법은 관련 퀘스트가 직접 안내하며 선택 제조법은 플레이어가 원하는 때 찾아간다.
- 동시에 여러 선택 제조법이 열리면 `새 제조법 N종 획득 가능` 통합 알림 하나만 표시하고, 누르면 도감의 신규 목록과 획득처를 연다.
- 알림을 열지 않아도 도감 아이콘과 목록의 신규 표시는 유지한다.
- 필수 제조법은 통합 알림과 별개로 관련 퀘스트 안내를 유지한다.
- 각 10레벨 숙련 단계의 선택 제조법 획득 기회는 초반·중반·후반의 기본 3회로 배치하고 한 시점에 원칙적으로 1~2종을 활성화한다.
- 모든 숙련도 상승마다 제조법을 추가하지 않으며 필수 제조법은 진행상 필요한 시점에 기본 3회와 별도로 활성화할 수 있다.
- 단계별 실제 수량과 해금 숙련도는 제작 공수와 성장 체감 테스트에서 조정한다.
- 선택 제조법은 각 숙련 단계의 첫째·다섯째·아홉째 수치인 `1·5·9` 패턴을 기본 해금 기준으로 사용한다.
- 전체 기준은 `1·5·9 / 11·15·19 / 21·25·29 / 31·35·39 / 41·45·49`다.
- 지역·NPC·선행 콘텐츠와 맞추기 위해 기준에서 ±1만 조정할 수 있으며 사유를 데이터에 기록하고 같은 기술의 해금 사이에는 최소 2 숙련도 간격을 둔다.
- 진행 시점에 별도로 열리는 필수 제조법은 ±1 제한의 예외다.
- 각 숙련 단계의 선택 제조법에는 상점·교본, NPC·의뢰, 탐색·비경·강적 계열의 획득 경로를 최소 한 번씩 배정한다.
- 경로 순서는 기술과 지역 동선에 따라 바꿀 수 있지만 한 단계 전체를 같은 경로로만 채우지 않는다.
- 20레벨 이전의 탐색 경로는 전투 대신 지역 조사, 숨겨진 기록과 채집 발견으로 구성한다.
- 필수 제조법은 이 배분보다 생존·경지 상승 퀘스트의 흐름을 우선한다.
- 조건 전에는 상점·NPC·비경에서 제조법을 지급하지 않고 도감 실루엣과 해금 조건만 표시한다.
- 미래 제조법을 이미 접근 가능한 일회성 상자에 넣어 나중에 재방문시키지 않으며, 획득처를 진행 단계에 맞춰 습득 직후 사용 가능한 흐름으로 배치한다.
- 돌파용 제조법은 해당 돌파 준비가 시작된 뒤 확정 획득 경로가 활성화되고 관련 퀘스트가 안내한다.

## 생산 시간과 일괄 제작

- 생활용 도구는 한 번에 1~10개까지 일괄 제작할 수 있다.
- 재료·부품·치료제·영약·소모성 생활 도구처럼 스택되는 생산품은 한 번에 최대 10개까지 일괄 생산할 수 있다.
- 전투용 무기의 일괄 생산 한도는 무기의 보유·장착·카드 연동과 실제 사용 방식이 정해질 때 함께 확정한다.
- 일괄 제작한 도구의 품질은 개별 판정하고, 결과와 인벤토리에서는 동일 품질끼리 자동으로 합친다.
- 가공·제련·제약·연단·도구 제작·무기 제작 등 모든 생산품은 한 개당 기본 3~5초의 제작 시간을 가진다.
- 생산 중에는 현재 한 개의 진행 상태를 나타내는 진행 막대를 표시한다.
- 일괄 생산은 한 개가 완성된 뒤 다음 한 개를 순서대로 제작하며 여러 개를 동시에 완성하지 않는다.
- 품질은 각 생산품의 진행 막대가 끝난 순간 공개하고, 완성 결과와 등급을 보여주는 짧은 연출 뒤 다음 생산을 시작한다.
- 재료는 일괄 생산 전체를 미리 소비하지 않고 각 결과물의 제작이 시작될 때 한 개분씩 소비한다.
- 생산 중단을 요청하면 현재 진행 중인 한 개까지 정상적으로 완성한 뒤 다음 생산부터 중단한다.
- 중단된 나머지 수량에는 재료를 소비하거나 품질을 판정하지 않는다.
- 결과물 한 개의 제작이 시작될 때 재료 소비와 숨겨진 품질 결과를 생산 복구 기록에 함께 확정한다.
- 게임이 종료되면 생산 시간은 흐르지 않고 현재 진행도를 정지하며, 재접속 시 같은 진행도와 같은 품질 결과로 이어서 제작한다.
- 생산 복구 기록은 일반 진행을 이어가기 위한 거래 정보이며 사망 시점을 정하는 운명 각인으로 취급하지 않는다.
- 생산 중에는 주인공이 해당 시설에 고정되어 이동, 채집, 전투와 다른 상호작용을 동시에 할 수 없다.
- 생산 화면에는 현재 진행 막대, 완성품 목록, 남은 수량, 예상 종료 시간과 중단 버튼을 표시한다.
- 제조법 단계와 복잡도에 따라 3~5초 범위에서 시간을 배정하고 세부값은 체감 테스트로 조정한다.

## 생산 시설

- 모든 제작·가공·제련·제약·연단은 인벤토리나 야외가 아니라 마을·도시의 지정 생산 시설에서 주인공이 직접 수행한다.
- 생활 도구·금속 부품·무기 제작과 제련은 대장간의 작업 공간을 사용한다.
- 약재 가공·치료제·영약·연단은 약방, 의원 또는 연단 시설의 조제실을 사용한다.
- 목재 부품과 목재 가공은 목공방을 사용하고 범용 가공은 제조법에 지정된 공방을 사용한다.
- 시작 마을에는 상주 의원이 없으므로 초반 약재·치료제 생산 장소는 약방의 조제실이다. 유랑 의원은 제조법과 지식을 전수하지만 상시 시설을 운영하지 않는다.
- 시설을 빌려 직접 생산하는 기능과 명장 NPC에게 완제품 제작·승급을 의뢰하는 기능은 구분한다.
- 직접 생산의 시설 이용료는 생산품 개수가 아니라 일괄 작업 한 번을 기준으로 부과해 여러 개를 함께 만들수록 개당 비용이 낮아지게 한다.
- 생산 시작 전에 총 시설 이용료와 개당 환산 비용을 공개한다.
- 생산 시작 화면에는 현재 숙련도와 선택 재료에 따른 예상 품질 범위를 표시한다.
- 품질 정보 아이콘을 누르면 범품부터 절품까지 각 등급의 정확한 제작 확률을 볼 수 있다.
- 재료 구성이나 투입 품질이 바뀌면 예상 범위와 품질별 확률을 실시간으로 갱신한다.
- 제작 전에는 결과 등급이 아니라 확률만 공개해 완성 순간의 등급 확인 연출을 유지한다.
- 모든 생산 계열은 `생산 기술 숙련도 - 제조법 난도 + 투입 재료 품질 보정`의 공통 품질 판정 골격을 사용한다.
- 계산 결과를 매우 부족·부족·적정·숙련·달인의 다섯 구간으로 바꾸고 해당 범품~절품 확률표를 적용한다.
- 계열별 별도 공식 대신 제조법 난도와 재료 품질 영향도를 데이터로 조정하며 시설 단계는 품질 계산에 포함하지 않는다.
- 모든 제조법의 투입 재료를 주재료와 보조 재료로 구분하고, 품질 보정은 두 재료군의 슬롯별 품질 평균을 기본 70:30으로 합산한다.
- 한쪽 재료군만 있으면 해당 재료군의 평균을 100% 반영한다.
- 요구 수량이 아니라 제조법의 재료 슬롯을 기준으로 평균을 내어 한 재료의 많은 수량이 품질 영향력을 과도하게 키우지 않게 한다.
- 낮은 품질 재료는 상위 결과 확률을 낮추지만 완성품 품질이나 등급 상한을 직접 고정하지 않는다.
- 재료 품질 평균과 70:30 가중치의 소수점은 판정 구간을 선택할 때까지 반올림하지 않고 유지한다.
- 내부 보정 점수는 숨기고 최종 품질별 확률만 정수 퍼센트로 표시하며 반올림 후 합계가 항상 100%가 되게 보정한다.
- 제조법을 열면 대표 예상 등급을 유지할 수 있는 가장 낮은 품질 조합을 `균형 선택`으로 자동 배치한다.
- 균형 선택은 가장 확률이 높은 대표 결과 등급을 낮추지 않는 선에서 희귀한 고품질 재료 소비를 최소화한다.
- 각 재료 슬롯의 품질 스택은 직접 교체할 수 있고 예상 범위와 품질별 확률을 즉시 갱신한다.
- 생산 시작 전에는 자동 선택 여부와 관계없이 실제 소비 품질과 수량을 모두 표시한다.
- 일괄 생산을 시작할 때 선택한 재료 종류와 품질 조합은 해당 작업 전체에 고정한다.
- 선택 가능한 수량은 그 품질 조합을 반복할 수 있는 재고 수량과 생산품별 일괄 상한 중 더 작은 값이다.
- 작업 도중 다른 품질 재료로 자동 대체하지 않으며, 다른 조합은 품질 확률과 시설 이용료를 별도로 확인하는 새로운 일괄 작업으로 구분한다.
- 생산 기술 경험치는 결과물 한 개가 완성될 때마다 즉시 지급한다.
- 개당 경험치는 제조법 난도의 기본 경험치에 실제 완성 품질 보너스를 더해 계산한다.
- 제작을 시작하지 않은 중단 수량에는 경험치를 주지 않으며 현재 숙련도보다 지나치게 쉬운 제조법은 경험치를 크게 낮추거나 0으로 처리한다.
- 생산 수량을 선택할 때 각 완성 단계마다 투입 재료가 빠지고 결과물이 추가된 예상 휴대 중량을 계산한다.
- 생산 도중 한 번이라도 휴대 중량 120%를 넘는 수량은 선택할 수 없으며 중량 기준 최대 수량을 재고·일괄 상한과 함께 적용한다.
- 한 개도 수용할 수 없으면 생산을 차단하고 필요한 여유 중량을 안내하며, 시설 임시 보관함으로 초과분을 보내는 기능은 기본 제공하지 않는다.
- 다섯 구간의 세부 확률과 경계는 제작 경제 테스트에서 확정한다.
- 첫 생산 튜토리얼은 무료이며 이후 시설 이용료는 생산 시작 시 지불하고 중도 중단해도 환불하지 않는다.
- 시설 수준과 생산 계열에 따라 일괄 이용료를 다르게 책정하며 세부 금액은 지역 경제 밸런스에서 조정한다.
- 생산 시설은 기초·숙련·명장의 3단계로 나눈다.
- 기초 시설은 초급 제조법, 숙련 시설은 중급 이하 제조법, 명장 시설은 상급 이하 제조법을 지원한다.
- 상위 시설에서는 하위 제조법도 모두 사용할 수 있다.
- 이용료는 실제 시설 단계가 아니라 선택한 제조법의 최소 요구 시설 단계를 기준으로 계산하므로 명장 시설에서 초급 제조법을 사용해도 기초 시설 이용료만 낸다.
- 작은 마을에는 주로 기초 시설, 주요 도시에는 숙련 시설, 대도시·문파·특수 거점에는 명장 시설을 배치한다.
- 시설 단계가 부족하면 생산을 차단하고 필요한 시설 단계와 플레이어가 알고 있는 해당 시설의 위치를 안내한다.
- 시설 단계는 제조법 사용 조건이며 결과물의 품질 확률에는 직접 보너스를 주지 않는다.

## 숙련도 성장

- 현재 숙련도에 맞는 작업 성공 시 정상 숙련 경험치를 얻는다.
- 새로운 재료나 제작법의 최초 성공과 상위 등급 결과물에는 추가 경험치를 지급한다.
- 현재 수준보다 낮은 작업을 반복하면 숙련 경험치가 점차 감소하고 결국 0이 된다.
- 채집과 채광에서는 낮은 확률로 상위 등급 재료가 나오며, 실제 획득 등급에 따라 추가 숙련 경험치를 지급한다.
- 어려운 작업 성공과 희귀 결과물 획득은 결과물 등급 기반 보너스 경험치 규칙으로 함께 처리한다.
- 희귀 재료 확률은 기술 숙련도, 도구 품질과 지역 등급에 따라 상승한다.
- 채집·벌목·채광 숙련도가 높아져도 한 지점에서 얻는 재료의 기본 수량은 증가하지 않는다.
- 상위 숙련자는 같은 종류와 수량의 재료를 얻되 품질 등급이 조금 높게 결정될 확률이 상승한다.
- 숙련도에 따른 품질 보정은 해당 지역과 재료가 허용하는 등급 범위를 벗어나지 않는다.
- 현재 숙련도가 작업 요구 숙련도보다 높으면 채집·벌목·채광의 소요 시간이 단축된다.
- 시간 단축은 획득 수량, 재료 종류와 지역별 최대 품질 등급을 바꾸지 않는다.
- 숙련도 차이에 따른 채집·벌목·채광 시간 단축은 원래 소요 시간의 최대 50%로 제한한다.
- 약재·치료제는 판매가와 별개로 공개된 `약효` 수치를 가진다.
- 약효는 현장에서 부상 회복 시간을 단축하고 의원에게 제공할 때 치료비 할인액으로 환산한다.
- 부상 유형에 적합한 약재는 약효를 온전히 인정하고 부분 적합 약재는 일부만 인정하며 무관한 재료는 치료에 사용할 수 없다.
- 치료제 제작 계열은 외상 치료제, 골절 치료제, 내상 치료제와 해독제의 네 종류로 구성한다.
- 각 계열은 재료, 품질 등급과 약효 차이로 성장하며 별도의 세부 부상 종류를 추가하지 않는다.
- 완성 치료제는 지정된 외상·골절·내상·중독 계열 하나에 표시 약효의 100%를 적용한다.
- 가공하지 않은 원재료를 직접 사용하면 기초 약효의 30%만 적용하며, 부분 적합이면 적합도 보정을 추가로 적용한다.
- 의원에게 적합한 원재료를 제공하면 전문 조제를 전제로 기초 약효의 100%를 치료비 할인 계산에 사용한다.
- 사용 전 UI에 실제 적용 약효를 정확히 표시한다.
- 완성 치료제의 약효는 제조법의 기본 약효와 결과물 품질 등급만으로 계산한다.
- 재료별 약효 합산이나 복합 배율은 적용하지 않는다.
- 치료제 품질은 다른 제작물과 같은 범품, 양품, 상품, 명품, 절품의 5단계를 사용한다.
- 외상 치료제, 골절 치료제, 내상 치료제와 해독제는 각각 초급·중급·상급의 제조법 3단계만 사용한다.
- 치료제 제조법은 총 12개를 기본 규모로 하며 동일 계열에 불필요한 중간 제조법을 추가하지 않는다.
- 각 제조법은 범품부터 절품까지 공통 5단계 품질 결과를 가질 수 있다.
- 네 계열의 초급 제조법은 20레벨 이전, 중급은 21레벨 삼류 진입 후 강남 이동 전, 상급은 60레벨 초절정 진입 전후에 습득할 수 있다.
- 상위 제조법이 없어도 하위 치료제를 여러 개 사용하거나 의원을 이용해 모든 심각도의 부상과 중독을 해소할 수 있다.
- 중급·상급 치료제는 더 적은 재료와 사용 횟수로 회복하는 성장 보상이다.
- 치료제 사용 팝업에서 같은 치료제의 사용 수량을 한 번에 선택할 수 있다.
- 최대 선택 수량은 남은 회복 시간을 모두 제거하는 데 필요한 최소 개수로 제한한다.
- 마지막 한 개의 일부 초과 약효는 허용하지만 완치에 필요하지 않은 추가 치료제는 선택할 수 없다.
- 팝업에 선택 수량, 총 약효, 치료 후 남는 시간과 초과 약효를 표시한다.
- 치료제 사용 팝업의 기본 수량은 1개이며 `-`·`+`, `MAX`와 수량 슬라이더를 제공한다.
- `MAX`는 완치에 필요한 최소 수량과 보유 수량 중 더 작은 값을 선택한다.
- 수량 변경에 따라 총약효, 감소 시간, 치료 후 남은 시간, 완치 여부와 초과 약효를 실시간으로 갱신한다.
- 최대 수량이 적어도 `-`·`+`, `MAX`와 슬라이더를 항상 같은 위치에 표시한다.
- 실제 최대 선택 수량은 완치 필요 최소 수량과 현재 보유 수량 중 더 작은 값이다.
- 보유량이 부족하면 `MAX`는 보유 치료제를 모두 선택하고 부분 치료 결과를 표시한다.
- 한 번의 치료제 사용 팝업에서는 동일 제조법과 동일 품질 등급의 한 인벤토리 스택만 선택한다.
- 서로 다른 품질이나 제조법의 치료제는 혼합하지 않고 갱신된 남은 회복 시간을 기준으로 각각 사용한다.
- 치료제와 원재료는 카드 전투 중 인벤토리에서 직접 사용할 수 없으며 전투 밖에서만 사용한다.
- 전투 밖이고 캐릭터를 직접 조작할 수 있는 상태라면 야외와 안전 거점 모두에서 치료제와 적합한 원재료를 사용할 수 있다.
- 이동·대화·연출과 다른 상호작용 중에는 사용할 수 없으며 야외 사용을 위해 거점 귀환을 요구하지 않는다.
- 전투 밖에서 사용을 확인하면 아이템을 즉시 소비하고 효과를 적용하며 별도 대기 시간이나 재사용 대기시간을 두지 않는다.
- 낮은 단계 지역에서는 획득 가능한 결과물의 최고 품질이 제한된다.
- 모든 채집·채광 재료와 가공·제련·제약·도구·무기 제작 결과물은 품질 등급을 가진다.

## 재료 단계와 품질

- 공통 품질은 범품, 양품, 상품, 명품, 절품의 5단계다.
- 약초와 광석은 여러 종류가 있으며 종류마다 기본 채집 난도, 출현 지역, 가치와 제작 용도가 다르다.
- `재료 단계`는 약초·광석 종류 자체의 희귀성과 난도를 나타낸다.
- `품질`은 같은 종류 안에서 개체가 얼마나 좋은지를 나타낸다.
- 예를 들어 구하기 쉬운 약초의 절품과 희귀 약초의 범품은 서로 다른 재료로 취급한다.
- 주요 원재료 분야는 각각 기본 10종의 재료 종류를 가진다.
- 각 종류에는 개별 획득 난도, 숙련도·도구·지역 조건과 제작 용도를 지정한다.
- 초기 원재료는 약초, 광석, 목재의 세 계열이며 각 계열에 10종씩 구성한다.
- 가죽, 독물, 보석과 특수 생물 소재는 20레벨 이후 필요에 따라 추가한다.
- 재료는 종류와 품질이 모두 같을 때만 같은 스택으로 합친다.
- 같은 종류의 서로 다른 품질은 평균으로 통합하지 않고 별도 스택으로 보관한다.
- 재료는 일반 인벤토리 안의 전용 탭에서 관리하며 장비·소모품 탭과 화면을 공유한다.
- 주인공은 초기 휴대 한도가 낮고 가방·바구니 등 운반 도구를 제작·강화해 한도를 높일 수 있다.
- 휴대 한도는 슬롯 수가 아니라 단순화된 중량 포인트로 계산한다.
- 같은 아이템 종류 또는 같은 제조법의 결과물은 품질이 달라도 개당 중량이 같으며, 중량은 아이템 종류와 제조법 단계로 정한다.
- 힘 능력치는 휴대 한도에 소폭 보너스를 주며 운반 도구의 레벨과 품질이 주된 증가 수단이다.
- 최대 중량의 120%까지 과적할 수 있으며 초과 구간에 따라 이동 및 행동 패널티가 커진다.
- 110% 초과 시 달리기와 빠른 이동이 잠기고, 120%에서는 추가 아이템 획득이 차단된다.
- 과적 상태에서도 기존 아이템은 강제로 버려지지 않으며 퀘스트 필수품에는 중량을 적용하지 않는다.
- 창고는 초반에 정착지별로 분리하며 제작 시 현재 소지품과 현재 정착지 창고만 참조한다.
- 후반에는 상단과의 관계 및 운송 비용을 통해 주요 거점 창고 사이의 재료 운송을 개방한다.
