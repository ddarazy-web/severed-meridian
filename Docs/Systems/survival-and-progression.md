# 생존과 성장

## 돌파 용어

- **확정**: 매 숫자 레벨의 상승은 `경지 상승`이다.
- **확정**: 삼류에서 이류처럼 무림 평가가 바뀌는 단계 상승은 `경지 돌파`다.
- **확정**: 능력치 상한은 생명력 `기혈 한계 돌파`, 힘 `근골 한계 돌파`, 민첩 `신법 한계 돌파`, 내공 `단전 한계 돌파`로 부른다.

## 목표 플레이 시간

- **확정**: 영구 사망으로 인한 재시작 시간을 제외한 일반적인 첫 완주 목표는 약 60시간이다.
- **가안**: 숙련자의 빠른 진행은 40~45시간, 선택 콘텐츠를 충실히 수행하는 플레이는 80시간 이상이 될 수 있다.
- **검증 필요**: 실제 완주 시간과 구간별 체류 시간은 플레이 테스트에서 조정한다.
- **확정**: 1~20레벨의 첫 플레이 목표는 5~6시간, 계정 정보 계승 이후 재시작 목표는 2~3시간이다.
- **확정**: 21~100레벨의 목표 플레이 시간은 약 54~55시간이다.
- **가안**: 삼류 6시간, 이류·일류·절정·초절정·화경 각 7시간, 현경 6시간, 생사경과 천마 8시간을 초기 구간별 목표로 사용한다.
- **확정**: 목표 시간은 콘텐츠 밀도를 산정하는 제작 기준이며 플레이어의 실제 소요 시간을 강제하지 않는다.

## 기본 능력치

- 생명력
- 힘
- 민첩
- 스태미너

- **확정**: 첫 번째 기본 능력치의 공식 명칭은 `생명력`이다.
- **확정**: 생명력은 전투 진입 시 최대 전투 체력을 산정하는 기반 능력치다.
- **확정**: 전투 체력은 기본 생명력과 분리된 전투 중 자원이며 전투 체력이 0이 되면 전투 패배로 처리하되 기본 생명력을 0으로 만들지 않는다.
- **확정**: 전투 패배 시에는 기본 능력치를 영구 감소시키지 않고 기존 부상 규칙에 따라 외상·골절·내상 중 하나를 적용한다.
- **확정**: 힘은 강공·권법·중병기 계열, 민첩은 신법·회피·연격 계열, 내공은 심법·장법·비기 계열의 상위 카드 사용 조건과 단계형 부가 효과에 관여한다.
- **확정**: 기본 초식은 능력치 조건 없이 사용할 수 있게 하고 상위 초식과 비기에 주로 능력치 기준을 적용한다.
- **확정**: 힘·민첩·내공 1점마다 카드 위력이 연속적으로 증가하는 직접 배율은 기본 규칙으로 사용하지 않는다.
- **검증 필요**: 생명력에서 최대 전투 체력을 산정하는 정확한 환산식과 카드별 능력치 기준은 카드 전투 프로토타입에서 조정한다.

## 1~20레벨

- **확정**: 레벨이 오를수록 생존과 관련된 기본 능력치가 정량적으로 감소한다.
- **확정**: 레벨과 관계없이 네 능력치 중 하나라도 0이 되는 즉시 주인공은 사망한다.
- **수정**: 20레벨은 일반 감소를 견딘 뒤 20→21 특별 돌파를 준비하는 첫 번째 죽음의 고비다. 20레벨 도달만으로 특별 감소나 자동 사망을 적용하지 않는다.
- **수정**: 수련과 영약 등으로 감소분을 상쇄하고 20→21 특별 돌파의 마지막에 적용되는 -25를 생존해야 한다.
- **수정**: 20→21 특별 돌파에 성공해 21레벨·삼류가 되면 스태미너가 내공으로 전환된다.
- **확정**: 정확한 명칭 전환 시점은 20→21 특별 돌파가 완료되어 삼류에 진입한 직후다.
- **확정**: 이 시점부터 플레이어 UI와 이후 시스템 표기에서는 `스태미너` 대신 `내공`을 사용한다.
- **수정**: 20→21 특별 돌파의 사망 조건은 게임 시작부부터 플레이어에게 공개한다.
- **확정**: 20→21 특별 돌파의 최종 처리는 `네 능력치 -25 적용 → 0 이하 사망 판정 → 생존 시 21레벨·삼류 진입 → 스태미너를 내공으로 전환 → 삼류 진입 보너스 적용` 순서로 고정한다.
- **확정**: 삼류 진입 보너스는 생명력 +1, 힘 +1, 민첩 +1, 내공 +3의 일회성 영구 상승이다.
- **확정**: 삼류 진입 보너스는 사망 판정이 끝난 뒤에만 적용되므로 20→21 특별 돌파에서 0 이하가 된 능력치를 구제할 수 없다.
- **확정**: 이 보너스는 최초로 내공이 형성되는 삼류 진입에만 적용하며, 이후 경지 진입에서는 반복 지급하지 않는다.
- **확정**: 이후 경지의 진입 보상은 무료 능력치 상승 대신 새로운 능력치 상한, 무공, 지역과 성장 수단의 개방으로 구성한다.
- **확정**: 공개는 의원의 진단 장면을 통해 서사적으로 전달하며, 플레이어의 초기 목표를 생존으로 설정한다.
- **확정**: 레벨과 능력치 수치는 플레이어만 확인할 수 있으며 등장인물은 직접 인식하지 못한다.
- **확정**: 의원은 `구음절맥`, 아홉 음맥의 폐색, 몸과 기혈이 성장할 때마다 음기가 생명·근력·몸놀림·원기를 잠식하며 다가올 큰 고비에서 죽을 수 있다는 사실만 무협식 표현으로 설명한다.
- **수정**: 의원과 주인공은 `20레벨`이나 능력치 수치를 말하거나 직접 인식하지 않는다. 진단 직후 플레이어 전용 시스템 UI가 `20→21 특별 돌파에서 네 능력치가 각각 25 감소하며 하나라도 0 이하이면 사망`이라는 정확한 규칙과 예상 수치를 별도로 공개한다.
- **수정**: 상태 정보에서는 현재 성장 상태로 20레벨에 도달했을 때의 값과 20→21 특별 돌파 감소 후 예상값을 구분해 정확한 수치로 제공한다.
- **확정**: 플레이어는 예상값을 통해 현재 준비 상태로 생존할 수 있는지 미리 판단할 수 있다.
- **수정**: 첫 진단 직후 `구음절맥 진단`이라는 한 장의 필수 확인 화면을 보여준다. 이 화면에는 네 능력치의 현재 수치, 무준비 상태의 20레벨 도달 예상값과 20→21 특별 돌파 후 예상값, 하나라도 0 이하이면 사망한다는 규칙과 21레벨 진입 전 사망 시 캐릭터가 삭제된다는 결과를 함께 표시한다.
- **확정**: 첫 진단 화면에서는 수련법·영약·제작법의 상세 해법을 한꺼번에 설명하지 않는다. 한 번 확인하면 구음절맥 HUD 아이콘과 상시 상세 정보가 개방되고, 구체적인 생존 수단은 이후 목표를 통해 순차적으로 가르친다.
- **확정**: 첫 진단 뒤에는 `집으로 돌아가 하룻밤 쉬기`를 첫 목표로 제시하고, 다음 날 의원이 떠난 뒤 약방 주인에게 진료 기록과 첫 생존 지침을 받으면서 마을 시설과 첫 준비 과제를 개방한다.
- **확정**: 첫 준비 과제는 흔한 약초 2종의 위치 확인·채집·약방 조제실 제조·복용을 거쳐 생명력 영구 상승을 한 번 체험하는 기초 탕약 과제로 구성한다.
- **확정**: 영구 생명력 상승은 기초 탕약 아이템의 반복 효과가 아니라 의원의 첫 처방 과정을 완료한 캐릭터당 일회성 보상으로 지급한다.
- **가안**: 첫 처방 완료의 일회성 영구 보상은 생명력 +2로 시작하고, 20레벨 전체 성장표와 프로토타입에서 최종 조정한다.
- **확정**: 첫 복용 결과에서는 탕약 자체의 효과와 `첫 처방 완료`에 따른 영구 생명력 상승을 서로 구분해 표시한다.
- **확정**: 첫 처방의 기초 탕약 제조법은 과제 완료 후에도 남으며 반복 제작 가능한 초급 내상 치료제로 사용한다.
- **확정**: 기초 탕약은 전투 밖에서만 사용할 수 있고 경미한 내상의 회복 시간을 소폭 줄이며, 완성품 품질이 높을수록 치료 효율이 증가한다. 반복 제조·복용해도 영구 생명력은 추가로 상승하지 않는다.
- **확정**: 첫 처방에서 즉시 복용하는 기초 탕약만 범품으로 고정하고, 과제 완료 이후의 반복 제작부터 일반 품질 판정을 적용한다.
- **확정**: 이 안내형 과제 완료 후 힘·민첩·스태미너의 독립 성장 과제와 선택 가능한 준비 경로를 개방한다.
- **확정**: 첫 처방 과제를 완료하면 1레벨 경험치와 필수 경지 상승 조건을 모두 충족하며 HUD에 `경지 상승 가능`을 표시한다.
- **확정**: 1→2 경지 상승은 자동 실행하지 않는다. 첫 경지 상승 화면에서 네 능력치의 현재값·감소량·상승 후 예상값을 확인하고 플레이어가 직접 실행한다.
- **확정**: 1→2 경지 상승의 첫 구음절맥 감소량은 생명력 -3, 힘 -2, 민첩 -3, 스태미너 -2로 시작한다.
- **확정**: 2레벨 도달 후 힘·민첩·스태미너의 독립 성장 과제와 추가 선택 과제를 본격적으로 개방한다.
- **미정**: 레벨별 감소량과 각 능력치의 최솟값
- **확정**: 경험치가 가득 차도 자동으로 레벨이 오르지 않으며 플레이어가 `경지 상승`을 실행해야 한다.
- **확정**: 1~20레벨의 경지 상승은 전투가 아닌 수련, 생존, 탐색, 생활 기술 등의 조건으로 구성한다.
- **확정**: 1~20레벨은 구음절맥의 진행과 이를 견디기 위한 생존·수련의 적응 단계를 나타낸다.
- **확정**: 레벨이 오를수록 신체 능력은 약해질 수 있지만 지식, 기술 숙련도, 자원과 생존 수단은 축적된다.
- **확정**: 각 레벨의 돌파 조건은 공통 필수 조건과 선택 과제로 구성한다.
- **확정**: 선택 과제를 통해 수련, 채집, 제조, 탐색 등 서로 다른 생존 경로로 돌파할 수 있다.
- **확정**: 선택하지 않은 과제와 관련 기술도 이후 플레이에서 모두 습득할 수 있다.
- **확정**: 선택 과제는 콘텐츠를 영구 잠그지 않으며 성장 순서와 효율에 차이를 만든다.
- **수정**: 21레벨 진입 전의 내공법 수련은 스태미너와 운기 숙련도를 높이지만 실제 내공을 생성하지 못한다.
- **수정**: 20→21 특별 돌파로 막힌 음맥의 첫 죽음 고비를 넘긴 직후 축적한 스태미너가 실제 내공으로 전환된다.
- **확정**: 하나의 활동은 생명력, 힘, 민첩, 스태미너 중 하나의 능력치만 직접 성장시킨다.
- **확정**: 능력치 보상을 독립시켜 각 생존 수치의 획득량과 소모량을 개별 조정한다.
- **확정**: 각 훈련법에는 해당 방법으로 올릴 수 있는 능력치 성장 상한이 존재한다.
- **확정**: 상한에 도달한 훈련을 반복해도 능력치가 더 이상 성장하지 않는다.
- **확정**: 성장 상한에 도달하면 이를 돌파할 수 있는 다음 방법을 플레이어에게 안내한다.
- **확정**: 여러 저급 훈련법을 번갈아 사용해 성장 상한을 우회할 수 없다.
- **확정**: 개별 훈련법의 상한과 별개로 현재 신체 단계에 따른 종합 성장 상한이 존재한다.
- **확정**: 생명력, 힘, 민첩, 스태미너는 각각 독립된 성장 단계와 종합 상한을 가진다.
- **확정**: 한 능력치의 성장 단계 돌파는 다른 능력치의 상한을 높이지 않는다.
- **수정**: 21레벨에 진입하기 전에 사망하면 캐릭터가 삭제되며 새 게임으로 다시 시작한다.
- **확정**: 21레벨부터 사망하면 마지막 저장 시점으로 롤백된다.
- **확정**: 저장은 수동으로 수시 실행할 수 없으며 지정된 시기나 사건에서만 갱신된다.
- **확정**: 종료·재개를 위한 일반 저장과 사망 롤백 기준인 `운명 각인`을 분리한다.
- **확정**: 초기 출시 기준은 서버 접속을 요구하지 않는 로컬 저장형 싱글플레이다.
- **확정**: 로컬 저장·메모리의 고의적 개조는 공식 지원하지 않지만 완전 차단을 목표로 하지 않으며, 체크섬과 버전 정보는 주로 저장 손상과 단순 변조 감지에 사용한다.
- **확정**: 일반 진행 자동 저장은 최신본과 이전 정상본 3세대를 순환 보관한다.

- **확정**: 환골탈태에 성공하면 구음절맥에 의한 레벨 상승 시 정량 능력치 감소는 영구히 종료된다.
- **확정**: 환골탈태 이후의 주인공은 병을 견디는 생존 단계에서 벗어나 온전한 무인으로서 추가 성장을 시작할 수 있다.
- **보류**: 환골탈태 이후 상위 경지, 추가 성장 규칙과 101레벨 이상의 확장 여부는 본편 기획이 충분히 정리된 뒤 검토한다.
- **미정**: 서로 다른 사고 패널티의 중첩과 최대 불이익
- **확정**: 운명 각인 이후 발견한 적 정보, 재료·제조법 도감 정보, 이야기와 튜토리얼 열람 기록은 계정 단위로 유지한다.
- **확정**: 레벨, 경험치, 능력치, 무공·생활 숙련도, 획득 카드, 아이템, 장비와 퀘스트 진행은 운명 각인 시점으로 돌아간다.
- **확정**: 제조법 자체, 적 약점에 따른 실질 보너스와 퀘스트 보상은 유지하지 않으며 조건을 다시 충족해야 한다.
