# 경량 로비 2단계 최종 보고서

상태: 2026-10-21 Editor 범위 완료. 2026-10-22 사용자 요청으로 중간 실행 기록을 정리하고 최종 결과와 대표 전후 측정만 보존했다. 이번 정리는 재검사가 아니다.

## 구현 결과

- 로비에서 선택 ID·번호·콘텐츠 세대를 검증해 게임으로 전달한다. 비연속 다음 레벨도 등록 인덱스로 찾는다.
- 선택 구간 팩을 한 번 해석하고 선택한 레벨만 실행 객체로 만든다. 같은 구간 재시작은 팩을 재사용한다.
- 필요한 아틀라스만 최대 4개씩 준비한다. 실패·취소 시 진행 중인 핸들의 완료 후 해제를 보장한다.
- 게임 진입 후 로비 UI·셀을 해제하고 복귀 시 로비를 재생성한다. 스크롤·선택 상태를 복원한다.
- 게임 3종 프로필은 Lobby → PuzzleGame으로 연결했으며 레벨툴 2종 경계를 유지했다.

## 최종 검증 요약

아래는 당시 최종 보고와 개별 검사 기록에서 옮긴 요약이다. 중복 PASS 출력과 일회성 원본은 이번 정리에서 제거했으므로 별도 원본 링크를 제공하지 않는다.

- 1/2/15 선택·중복 클릭·10회 왕복, 로비 UI/셀 해제·재생성·스크롤 복원 통과. 최종 실행 `20261021-204623-608-Run.log` exit 0.
- 복귀 후 게임 세션 0, Addressables 작업 캐시는 취소된 읽기 완료 후 0. 중복 EventSystem/NullReference/MissingReference 오류 없음.
- 초기 로비는 세대와 인덱스만 조회하며 게임 팩·세션을 미리 만들지 않음.
- 선택 구간 총 읽기 3건·동일 구간 재사용·선택 사본 격리, 손상 해시·세대/버전·필수 공급 정의 누락 거절 통과.
- 실제 게임 팩 읽기 실패와 씬 진입 실패 후 오류 안내·정상 경로 재선택, 취소 복귀 통과. 원본 팩 대신 검사 경로만 치환함.
- 아틀라스 실패/취소·Dispose 후 핸들 반환 확인. 같은 프레임 잔류를 누수로 오판하지 않고 완료/해제를 기다림.
- 정식 튜토리얼 동작 완료→기록 저장→재진입 생략 통과. 검사 전 사용자 키를 백업하고 복원함.
- Editor 직접 진입과 레벨툴 JSON/MemoryPack 시험·복귀 및 원본/초안/히스토리 보존 회귀 통과.
- 리뷰에서 발견한 로비 UI 미해제 문제를 수정하고 재현 검사 통과. 두 번째 리뷰는 수행하지 않음.
- 검사 사본 Detach, `Assets/__ProjectTests`와 연결 기록 부재 확인. 원본 JSON/SO 검사 및 사용자 기록 복원 확인.

## 당시 미검증·남은 문제

- 제품 빌드·기기 설치 미실시. Android/iOS 시작 시간·제품 번들·최대 메모리·실제 터치 배치는 검증하지 않음.
- 기존 종합 레벨툴 검사의 미션 수량 표시 복원 실패는 남음. 독립 게임 진입 회귀 통과와 구분한다.
- Editor 직접 실행은 도메인 리로드 비활성 조건. Unity 저장 YAML의 빈 값 후행 공백 때문에 전체 diff 검사를 clean으로 표현하지 않음.
- 커밋·푸시·HTML 갱신 없음. 이 문서는 당시 결과이며 이후 수정 전체의 재검증을 의미하지 않음.
