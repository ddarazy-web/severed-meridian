# 네이티브 레벨툴 UX 3단계 — 미션·튜토리얼 조립

상태: 2026-10-23 완료. 승인된 Editor 검증 범위의 3단계를 마쳤다. 제품 빌드·설치와 Android 실기기 검사는 하지 않았다.

## 구현 내용

- 제작 안내에서 보드 구성, 이동 횟수·미션, 실제 플레이 조작 확인, 파일 저장을 구분하고 해당 화면으로 연결한다. 보드 항목은 사용 칸의 지정 여부이며 전체 구조 검사나 클리어 가능성 보증이 아니다.
- 미션은 목적·대상·수량을 고른 뒤 적용한다. 실제 프로젝트 Sprite, 요약·수정·삭제, 잘못된 수량/중복 대상 거절, 단일 Undo를 제공한다.
- 튜토리얼은 교환·매칭 / 파워 생성 / 사용 / 조합 / 내구도 / 직접 조립으로 시작한다. 기존 동작·조건·공통 구성·공급·시험 엔진과 JSON 계약을 재사용한다.
- 목적별 교환은 필요한 칸을 고르면 필수 설정을 연다. 직접 조립도 교환 두 칸, 망치 한 칸, 개체 한 칸, 레벨별 좌표 한 칸을 구분한다. 자유 영역은 명시적 선택 완료, 설명·섞기·보드 전체·생성 결과 자체에는 불필요한 칸 선택을 요구하지 않는다.
- 활성 칸·초기 배치의 적합성·인접/벽·첫 파워 종류를 확인하고 유효 후보를 강조한다. 이후 행동으로 바뀔 개체 위치는 추측하지 않으며 전체 조건·연결 검사는 작성 완료 시 수행한다.
- 선택과 필수 설정은 적용 전 초안이다. 취소·팝업 재활성화 시 입력을 보존하거나 폐기하는 경계를 구분하며, 고정 칸을 다시 골라도 기존 생성 결과 연결은 유지한다.
- 단계 요약은 동작, 대상·층, 수량, 색/방향, 집계, 인정 원인, 생성 연결을 표시한다. 망치·섞기를 두 칸 교환으로 설명하지 않는다. 위치 보기·상세 수정·여기까지 시험을 연결했다.
- ‘다음에 내려올 블록 지정’은 기존 열·순서 공급 편집을 연다. ‘여기까지 시험’은 초기 보드와 첫 단계부터 선택 단계까지 JSON 사본으로 실행한다. 일반 시험의 MemoryPack 선호값과 분리한다.
- 작업 중 일반 전환·저장은 계속 작성/전체 취소로 안내한다. 내부 보드·공급·시험은 허용한다. 전체 취소는 해당 레벨의 튜토리얼·보드·공급을 시작 상태로 되돌리고 이전 dirty·다른 레벨·공유 데이터·무관한 레벨 설정을 유지한다.
- 작성 완료는 필수값·연결 확인 후 메모리에만 반영한다. 플레이하지 않았으면 확인 필요로 표시하며 파일 저장은 별도다. 취소한 작업이 Undo/Redo로 되살아나지 않도록 이력을 정리한다.

## 성능과 남은 제한

[대표 원본 측정](NativeLevelToolStage03/tutorial-costs.jsonl)은 Editor의 38문서 fixture에서 같은 실행 안에 전체 그래프와 선택 범위 그래프 비용을 비교한 진단이다. 전체 372~401ms, 선택 범위 118~157ms, 패널 156~168ms, 미리보기 120~123ms였다. 여러 측정을 연속 수행한 총 840~883ms를 일반 클릭 응답 시간으로 해석하지 않는다. Android 속도 개선율도 주장하지 않는다.

변경 없는 표시 갱신은 본문 추가 읽기/정의 재구성 0이며, 한 레벨 수정은 해당 본문 한 번만 읽는다. 공유 구성의 전체 사용처는 접혀 있을 때 조회하지 않고 사용자가 펼칠 때 조회한다. 큰 공통 구성의 실제 편집 비용은 여전히 존재하며 4단계의 통합 성능 검사에서 함께 확인한다.

Android 실제 터치·뒤로가기·키보드·백그라운드 전환, Windows/Android 제품 빌드·설치는 미검증이다. 이번 승인 범위인 Editor 컴파일·시뮬레이션과 구분한다. HTML 매뉴얼, 커밋·푸시, 게임 제품 빌드 설정은 변경하지 않았다.

## 검토와 정리

한 번의 독립 읽기 전용 검토에서 지적한 직접 선택 UX, 요약 누락, 팝업 재활성화, 대상 변경 입력 손실을 모두 보완하고 관련 회귀를 실행했다. 추가 감사에서 첫 파워 후보와 부분 시험 체크리스트, 전체 취소 후 상태 문구도 보완했다. 재검토 에이전트는 추가 실행하지 않았다.

최종 보고서·대표 화면·측정·검사 결과만 이 폴더에 보존한다. 검사 연결 및 소유한 임시 사본은 실행 종료 후 해제한다. 기존 사용자 프로젝트·로그·다른 작업의 사본은 삭제하지 않는다.
