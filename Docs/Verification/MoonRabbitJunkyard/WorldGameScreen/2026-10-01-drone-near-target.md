# 3기 이하 드론 표적 근처 선회

2026-10-01. 보드 중앙의 큰 원을 한 바퀴 도는 소수 드론 연출이 어색하다는 피드백에 따라 표적 주변 접근·선회·돌진으로 변경했다. 이전 한 바퀴 방식은 더 이상 적용하지 않는다.

- 단독 및 드론+드론의 실제 비행 수가 3 이하일 때 확정된 표적 주변으로 곡선 이동한다. 반지름 1~1.4칸의 보통 원을 0.55~0.8바퀴 돈 뒤 마지막 선회 위치에서 돌진한다.
- 이동 0.32초, 이동과 선회를 합친 최소 시간 1초. 필요한 선행 공격·재탐색 대기는 선회 시간에 포함한다.
- 가까운 표적의 드론들에도 대기 원의 간격을 확보한다. 가장자리에서는 보드 안쪽으로 보정하며, 서로 겹치면 표적 주변의 다른 중심을 탐색한다.
- 표적 예고 이미지는 표시하지 않는다. 이미 확정된 표적 좌표를 접근 연출에만 사용하고 게임의 표적·피해·난수를 재계산하지 않는다.
- 로켓+드론·폭탄+드론·자석+드론과 4기 이상은 기존 대형 선회 방식을 유지한다. 낙하 속도 변경도 유지한다.

검사는 실제 보드·아틀라스에서 반지름과 회전량, 표적 예고 부재, 드론 간격, 종료·자원 반환을 확인한다. 실행 로그와 결과는 `Logs/Stage08/drone-near-*` 및 각 결과 파일에 남긴다. 현재 동작은 [8단계 사용 안내](../../../Guides/MoonRabbitJunkyard/WorldGameScreen/stage-08-power-effects-usage.md)를 따른다. 빌드는 실행하지 않는다.
