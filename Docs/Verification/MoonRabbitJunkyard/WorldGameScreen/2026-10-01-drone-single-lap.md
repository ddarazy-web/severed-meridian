# 3기 이하 드론 한 바퀴 후 돌진

2026-10-01. 단독 드론과 드론+드론의 3기 이하 비행은 공중 이동 후 큰 원을 정확히 한 바퀴 돌고 바로 돌진하도록 변경했다.

한 행동의 실제 비행 기록 수가 3 이하이며 조합이 로켓+드론·폭탄+드론·자석+드론이 아닐 때 적용한다. 반지름 2·3·4칸을 서로 나누어 사용하므로 각 드론의 회전 주기가 달라도 겹치지 않는다. 선행 공격이나 재탐색을 기다리는 시간을 회전 주기에 포함해 한 바퀴 종료 시각과 돌진 시작을 맞춘다. 다른 파워와 조합한 드론과 4기 이상은 기존 선회 방식을 유지한다. 표적 예고는 계속 표시하지 않으며 표적·피해·난수를 재계산하지 않는다.

단독 드론과 드론+드론 fixture에서 `대기 시간 - 이동 시간 0.32초 = 회전 주기`와 반지름 2칸 이상을 검사한다. 수정 전 새 검사가 실패했고(`drone-lap-red.log`), 수정 후 표시 검사에 통과했다(`drone-lap-green.log`). 기본 공격·조합·재탐색·표적 예고 제거·다중 드론 간격 검사를 함께 수행했다.

검증 결과: 표시 `Run` 324 PASS, 기록·시간표 `Data` 102 PASS, 실제 게임 씬 `RunScene` 868 PASS. 총 1,294 PASS, FAIL 0. 세 실행 모두 Editor 종료 코드 0. 실제 게임 씬에서는 4종 파워·10개 조합의 기존 실행기와 최종 상태·난수 동등성 및 일시정지·취소·재시작을 확인했다. `git diff --check` 통과.

로그는 `drone-lap-green.log`, `drone-lap-data.log`, `drone-lap-scene.log`와 각 결과 파일로 `Logs/Stage08`에 남겼다. 플레이어·Addressables 콘텐츠 빌드와 실기기 검증은 실행하지 않았다. 현재 동작은 [8단계 사용 안내](../../../Guides/MoonRabbitJunkyard/WorldGameScreen/stage-08-power-effects-usage.md)를 따른다.
