# 드론 선회·분리 궤도·빠른 곡선 돌진

2026-10-01. 선행 공격을 기다리는 드론은 작은 원을 선회하고, 표적 확정 후 현재 선회 위치에서 곡선을 따라 가속하며 돌진한다.

## 적용 내용

- 선회 반경 0.12칸, 주기 0.70초. 이륙 후 0.12초 동안 대기 위치로 펼쳐진다.
- 대기 시간이 겹치는 드론들의 궤도 중심을 최소 0.96칸 분리한다. 같은 출발점에서도 각 대기 위치로 나뉘며, 이미 배정된 다른 출발점의 대기 궤도도 고려한다. 공통 생성점에서 펼쳐지는 이륙 구간은 분리된 대기 선회와 구분한다.
- 돌진은 3차 곡선과 가속 시간 비율을 사용한다. 거리 × 0.045초를 0.18~0.38초로 제한하고 착탄 직전 감속하지 않는다. 표시 도착 시각과 실제 피해 반응 시간표에 같은 비행 시간을 적용한다.
- 규칙 처리 중 실제 재탐색이 있었다는 기록을 표시 기록에 전달한다. 해당 드론은 선행 공격 종료 후 추가 0.18초 선회하고 새 표적으로 출발한다. 규칙은 기존처럼 먼저 결과를 확정하며 표시 중 재추첨하지 않는다.
- 기존 프로펠러 4컷·효과 풀·Addressables 아틀라스를 사용한다. 새 이미지나 저장 데이터 형식 변경은 없다.
