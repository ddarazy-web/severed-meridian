### 미검증 및 이번 단계의 한계

- Android/iOS 실기기, 물리 터치·물리 키보드, 기기별 노치/안전 영역은 미검증이다. 입력 검사는 합성 키와 EventSystem 이벤트이며 실제 하드웨어 검사로 표현하지 않는다.
- 제품 빌드를 하지 않아 실제 번들 용량/의존성·GPU 메모리·APK 최초 시작 시간은 미검증이다. Editor에서는 PackSeparately 등록, 논리 의존성과 실제 읽은 주소를 확인했다.
- 관리 힙 증감은 총 할당 바이트가 아니며, 이번 성능 수치는 게임 진입 시간이나 모바일 성능 보장이 아니다.
- 실제 매치 게임 진입과 프로필 시작 씬 변경은 2단계다. 1단계 플레이 버튼은 선택 요청 및 미연결 안내까지만 제공한다.
- 기존 게임/툴 전체 UI 시나리오를 재실행한 것은 아니다. 변경하지 않은 진입/편집 코드는 diff로, 공통 데이터 변환은 기존 전체 레벨 팩 해석과 회귀 검사로 확인했다.
