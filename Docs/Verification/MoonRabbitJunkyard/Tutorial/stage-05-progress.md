- 실제 에디터 Run을 확장하여 기존 에디터 기록 콜백 호출 수를 관찰했다. 신규 자동 실행의 완료 기록은 1회, 완료 뒤 중복 다음은 0회 추가, 이미 완료된 항상 실행은 0회 추가였다. 실제 플레이어의 MoonRabbit.Tutorial.Completed.1/2 키 존재 여부와 값은 검사 전후 동일했다.

- 실제 미션 진행값과 MissionProgressRecords의 합계가 일치했고, 마지막 설명 완료 전후 같은 상태 객체·보드·미션·이동·난수가 보존됐다.
- 손가락이 지정 교환 칸을 가리는 조건은 실제 좌표 검사에서 실패했다. 실패 근거는 finger-overlap-red-results.txt다. PuzzleTutorialBinding의 손가락 크기/경로 옆 위치 계산만 수정했다. 프리팹/이미지/입력 판정은 변경하지 않았다. 같은 Run 재검사 exit 0, PASS 248, 런타임 예외 0. 두 비율에서 손가락/말풍선이 지정 칸을 가리지 않고 강조/손가락 raycast가 꺼져 있음을 확인했다. 최신 세로 캡처를 직접 확인했다.
- 신규 Level_02 GUID를 씬·프리팹·Addressables·Resources에서 검색했으며 직접 참조가 없었다. 최종 보존 감사와 게임 소스 컴파일은 회귀 종료 후 다시 확인한다.
- 현재 변경된 손가락 표시를 포함해 기존 안내/데이터/일반 게임/팝업 회귀를 순차 실행 중이다.
## 회귀 및 완료 감사 보강

- 기존 데이터 회귀는 출시 팩에 1레벨만 있다고 가정하여 실패했다. 현재 팩의 모든 레벨 번호를 읽고 전체를 재인코딩해 바이트가 같은지 확인하도록 시험만 수정했다. 같은 검사 exit 0, PASS 63. 실패/성공 결과를 Stage05에 보관하고 원래 출력을 복원했다.
- 일반 게임, 팝업 RunScene/RunRestore, BoardActionVerification.Data, PowerEffectVerification.Data 회귀는 exit 0이다. 이번 결과는 regression-results에 보관하고 기존 출력은 복원했다.
- 추가 실행한 PuzzlePowerAnimationVerification.Data는 기존 드론의 재탐색 선회 시간 단정에서 실패했다. 현 구현은 .85초+HoverDelay를 쓰지만 검사는 1초+.18초 선회를 기대한다. 이 검사/시간표/DroneFlightMotion 관련 14개 파일은 시작 기준 해시와 같으며(unrelated-animation-baseline.json), 이번 2레벨/손가락 변경은 순수 시간표 계산에 관여하지 않는다. 이번 범위의 게임 동작이나 해당 드론 검사는 변경하지 않았다. 통과한 로켓 발사/반응 시간표 조건과 종합 검사의 실패를 구분해 보고한다. 해당 실패 결과도 보관하고 과거 출력은 복원했다. 이후에 있던 로켓 본체 도착 검사는 독립 엔트리로 실행할 예정이다.
- 감사 중 로켓 생성 결정/보드 개수 1, 부족한 고정 공급 거절, 정상 무작위 공급 9개 복귀, 중단 뒤 새 에디터 게임 세션의 첫 단계/고정 보드 재현을 직접 검사하도록 보강했다.
- 추가 검사 작성 과정의 컴파일 실패 2건(내부 실행 기록 접근/BoardCoordinate == 비교)은 출시 결함 재현으로 취급하지 않는다. 공개된 실제 매칭 결정 및 Equals 비교로 수정했다. 종료된 검사 연결의 소유 폴더 메타만 GUID를 보존해 정상 폴더로 표시한 뒤 Detach했다. 현재 최종 소스로 Run 전체 재검증 중이다.
