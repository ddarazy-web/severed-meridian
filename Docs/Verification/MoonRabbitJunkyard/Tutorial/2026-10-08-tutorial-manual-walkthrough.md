## 확인 결과
- 임시 시험 보드 match, follow, damage, 설명용 인접 매칭+상자 예제: 논리 재생 오류 0.
- 3매칭: 기존 단계 삭제 → 두 칸 선택 → 직접 3매칭 적용 → 논리 검사 버튼 결과 확인.
- 캡처는 Unity 실제 EditorWindow의 ReadScreenPixel로 확보. 다른 앱이 찍힌 초기 시도는 문서에 사용하지 않고, 검사 창을 맨 앞으로 올려 다시 촬영한 안전한 이미지 8장만 사용.
- 최종 Unity 실행 로그: Logs/TestHarness/20261008-181025-742-Run.log (exit 0, 테스트 연결 해제 완료).
- UI 문구는 제작 패널/샘플 보드 코드와 대조. 파워 생성 예제의 방향은 임시 사본에서 가로로 지정해 캡처.
- Chrome headless: 6개 HTML × 1440px/390px, 누락 이미지/내부 링크/앵커/중복 ID/페이지 가로 넘침 0.
- 전체 Manual 폴더를 별도 Logs 경로로 복사, offline=true 상태에서 파일 URL로 인덱스→3매칭→인덱스 왕복 확인.
- 실제 렌더링 이미지 검토: PC/좁은 화면 제목·순서, 모바일 내구도 조건 표.
- 기록: Logs/Tutorial/Manual/validation.txt, browser-verification.json.
- 일회성 캡처 도구는 Tests에서 분리하여 같은 Logs 폴더에 보관. 게임 소스나 실제 레벨 데이터 변경 없음. 플레이어 빌드/커밋/푸시 없음.

## 범위
- 이 작업은 문서와 임시 보드 검증이다. 실기기 입력 검사는 수행하지 않았다.
- 모든 매뉴얼 절차를 수동 클릭으로 다시 수행한 것은 아니다. 샘플 논리와 대표 셀 선택 동작을 실제 편집기에서 확인하고 나머지 메뉴·저장 동작은 현재 구현 및 기존 검사 결과와 대조했다.
