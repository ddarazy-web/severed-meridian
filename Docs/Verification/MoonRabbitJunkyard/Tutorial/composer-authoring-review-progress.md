# 튜토리얼 제작 흐름 점검 기록

상태: 완료 · 2026-10-08 · 사용자가 1번 임시 3매칭 샘플 선택
기준: composer-authoring-review-plan.md / composer-authoring-review-goal.md

## 범위

- 기존 3단계 작업을 보존한다. 이번 점검에서는 아직 제품 소스를 수정하지 않았다.
- HTML 매뉴얼·실제 레벨·출시 팩·플레이어 기록을 수정하지 않는다. 빌드·커밋·푸시하지 않는다.
- 사용자에게 1) 임시 3매칭 샘플, 2) 지정 레벨의 사본을 제시했다. 답변 전 대상별 실행을 시작하지 않는다.

## 현재 소스에서 확인한 내용

- 공통 구성 선택, 이 레벨의 설정, 공통 원본 편집, 독립 복사, 학습 완료 ID의 메뉴와 툴팁이 존재한다.
- 공유 값은 SerializedProperty 기반 입력, 보드 선택은 BeginBindingPick을 사용한다.
- 독립 조건 편집과 달리 공유 대상·파워 종류는 일반 PropertyField로 표시한다. 실제 초보자 제작 흐름에서 대상 종류/정의 ID가 이해 가능한지 확인할 후보이며, 아직 실행해 재현한 UX 결함으로 판정하지 않는다.
- 기존 TutorialSharedFlowEditorVerification은 공유 연결·셀 지정·Undo/Redo·원본 적용·독립 복사·샘플 재로드/소유권을 검사한다.
- 기존 TutorialComposerWorkflowVerification은 임시 레벨을 생성해 실제 UI 포인터 입력과 조립 과정을 검사한다. 이 과거 검사만으로 이번 사용자의 제작 흐름이 완료됐다고 판단하지 않는다.

## 선택 후 확인할 증거

1. 선택한 사본에서 샘플 선택 → 셀 연결 → 수치 설정 → 검사 → 게임 실행을 실제 조작으로 확인한다.
2. 공통 구성 연결/독립 복사/완료 ID 안내의 의미와 입력 실수를 확인한다.
3. 관찰된 불편만 재현 검사와 함께 수정한다. 문제가 없다면 변경 없이 결과를 남긴다.
4. 이번 실행 전후 데이터 해시와 실행 결과, 미확인 범위를 기록한다.

아직 목표 완료로 판정하지 않는다.
