## 제약과 별도 발견

- 기존 PuzzlePowerAnimationVerification.Data 종합의 드론 대기 기대값 실패는 이번 단계에서 고치지 않았다. 해당14개 파일은 이전 실패 시점과 동일하다(known-drone-failure-source-audit.json). 이번 단독 폭탄 표시 검사의 통과를 전체 애니메이션 검사 통과로 표현하지 않는다.
- Unity 배치 에디터 종료 로그의 JobTempAlloc 경고는 이전 FocusShade 실제 게임 검사에도 존재한다. 이번에도 기록되어 있으며 해결했다고 주장하지 않는다. 런타임 예외0과 별개의 네이티브 종료 경고다.
- 실제 UI는 별도 배치 에디터의 실제 씬/입력 경로로 검사했다. Android/iOS 실기기·물리 터치/노치 영역은 미검증이다.
- 2→3 전환은 시험 인스턴스 미션을 완료 상태로 만들어 경계만 검사했다. 실제2레벨 승리 밸런스 검사가 아니다.
- 초기 후보의 시작3매칭, schema5 공급 읽기, 폭탄 소모/피해 묶음에 대한 검사 가정은 후보/시험만 수정했다. 게임 소스를 변경하지 않았다. 실패 근거와 최종 성공을 구분해 보관했다.
- 빌드·번들·커밋·푸시·하위 에이전트·사용자 Unity 종료·임의 씬 저장을 하지 않았다.
