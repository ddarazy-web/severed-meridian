## 첫 연결 경계

- `TutorialProgress.CanApprove`로 조회와 예약을 분리했다. 실제 승인도 동일 규칙을 호출하며 선택 미리보기는 ticket·진행·무료 권한을 소비하지 않는다.
- 실제 `BoardActionExecutor.EndStableTurn`에서 턴 효과와 종료 결정을 분리했다. `SetEndingDeferred`가 활성화되어도 곰팡이 턴 효과는 적용하고 승패·라스트팡·자동 재배치 판단만 보류한다.
- `ResumeDeferredEnding`은 보류 해제 후 안정 상태에서 종료 결정만 한 번 재개한다. 새로운 성공 행동은 이전 보류 판단을 폐기한다. 일반 레벨의 기본 경로는 유지한다.
- `TutorialBoardAdapter`는 전체 레벨 정적 검사 후 고정 공급의 실행 사본과 기존 일반 공급 사본을 소유한다. 실제 상태의 공급만 교체하며 완료 후 동일 상태에서 일반 공급으로 복귀한다. 단계/공급 작성 값을 바꾸거나 레벨을 파기해도 실행 사본은 유지된다.
- 위 항목은 초기 연결 경계의 기록이다. 이후 게임 세션과 이동 0 무료 체험을 연결했다. 아래 후속 구현·검사 기록을 함께 확인한다.

## 실제 실행·게임 연결 후속 구현

- 실제 매칭·파워·공급·덮개/바닥/장애물 제거에서 정의 ID, 논리 개체 식별, 좌표를 기록한다. 교환·낙하·섞기는 기존 개체 식별을 유지하고 새 생성은 새 식별을 받는다. Unity instance ID와 게임 난수를 사용하지 않는다.
- `TutorialBoardAdapter.Prepare`가 초기 실행기 정착보다 먼저 고정 공급을 적용한다. 시작·재시작·다음 레벨은 고정 시드를 사용하며, 준비 사본이 실패하면 기존 세션을 유지한다.
- 세션 선택/스와이프/아이템/직접 실행 승인과 실제 결과를 연결했다. 일반 레벨의 선택·발동 시도 경로는 보존한다. 승인된 무료 체험만 이동 0에서 실행할 수 있다.
- 논리 결과 종료 신호를 추가했다. 결과 부족은 단계/조건 경로와 실제 수량으로 진단한다. 연쇄가 끝나도 실제 시작/낙하/드론/피해/수집 표시와 팝업 정지가 끝나기 전에는 단계가 진행되지 않는다.
- 실제 실행기를 사용하는 `LevelTutorialReplayValidator`를 소유 사본에서 실행한다. 에디터 재생 검사 버튼과 게임 시작·재시작·다음 레벨 준비 검사에 연결했다. 정적 검사, 논리 재생, 실제 화면 검사의 범위를 구분해 표시한다.
- 고정 일반 블록의 초기 정의가 무작위 일반 공급으로 보고되던 경로를 수정했다. 작성·팩 데이터는 변경하지 않는다.
