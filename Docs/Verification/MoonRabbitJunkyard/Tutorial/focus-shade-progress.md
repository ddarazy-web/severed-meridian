# 튜토리얼 투명 포커스와 화면 어둠 막

완료: 2026-10-07.

사용자 요청에 따라 노란 칸 덮개/테두리를 없애고, 지정 보드 칸과 체험 아이템 영역을 투명하게 뚫은 검정 55% 불투명 막을 화면 전체에 표시했다. HUD·보드 밖 여백도 포함한다. 설명 말풍선·다음 버튼·손가락은 위에 표시하며, 어둠 막은 보드 터치를 가로채지 않는다. 팝업/안내 숨김·완료 시 기존 Content 수명과 함께 사라진다.

## 변경

- TutorialFocusGraphic: 화면 범위에서 지정 사각 영역을 빼는 uGUI 메시. 겹치는 구멍과 화면 경계를 처리하고 겹친 어둠 막을 만들지 않는다.
- TutorialOverlayView: 기존 칸 이미지/노란 테두리를 투명하게 하고 Content의 기존 자식보다 뒤에서 막을 그린다. 프리팹 재생성 없이 기존 안내 프리팹에 적용한다.
- PuzzleTutorialBinding: 전체 화면 좌표와 보드 지정 칸/아이템 버튼 영역을 전달한다. 튜토리얼 진행·입력 허용 규칙은 변경하지 않는다.
- Tests/Editor의 TutorialFocusVerification: 실제 uGUI 메시의 투명/어둠 범위·겹침·화면 끝·단계 교체·raycast·종료 조건 검사.

## 확인한 결과

근거 위치: Logs/Tutorial/FocusShade.

- red-results.txt: 기존 노란 덮개/테두리 잔존 실패 재현.
- results.txt: 6개 검사 통과. 1280×720/720×1280에서 전체 화면 어둠, 지정 칸/아이템 투명, 겹침/화면 끝, 이전 구멍 제거, 입력 통과, 안내 숨김 검사.
- rocket/run-results.txt와 verification.log: 실제 출시2레벨 Asset/MemoryPack 및 모드/재진입/완료 기록/1→2 경계 포함 262 PASS, native exit0. 실행 예외0.
- rocket/rocket-step1·step3의 가로/세로 캡처를 확인했다. 지정 블록의 원래 색과 이미지가 보이고 HUD/나머지 보드/여백은 어두워졌다.
- game-only-compile.log 및 결과: 테스트 연결 해제 후 native Unity 소스 컴파일 정상 종료0. 최초 shell 반환은 GUI 프로세스 완료를 기다리지 않아 exit 값을 확보하지 못했으며, 실제 프로세스70572와 정상 종료 로그를 확인했다. 컴파일 오류가 발생한 것은 아니다.
- 기존 Stage04/05 출력51개는 prior-outputs.json의 해시로 복원 확인했다. 이번 결과/캡처는 별도 보관했다.

임시 검사의 종료 호출을 정리 이전에 실행하여 첫 실패 때 임시 프리팹이 남았던 문제, 검사 리플렉션의 uGUI 메서드 overload 조회 오류는 검사 코드에서 정리했다. 최종 임시 프리팹/연결 기록은 남아 있지 않다.

레벨/팩·기존 프리팹·게임 규칙·패키지/Addressables·HEAD를 변경하지 않았다. 빌드·커밋·푸시는 하지 않았다. Android/iOS 실기기와 노치 영역은 별도 미검증이다.
