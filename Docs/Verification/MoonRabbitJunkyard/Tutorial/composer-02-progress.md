## 확인한 연결 위치

- PuzzlePlay/Runtime/State/ElementExecutionRecord: Generated/Activated/Removed, 정의ID·Occurrence·좌표 제공. 피해량/구체 공격 원인은 아직 없음.
- LevelRuntimeState: 일반/파워 ContentOccurrence, CoverOccurrence, DustOccurrence, 장애물 본체 Occurrence 제공. 이동 추적에 좌표 대신 기존 식별자를 재사용할 수 있다.
- PowerBlocks/Runtime/PowerEffectResolution: EffectRecord에 실제 before/after와 cause를 기록하며, 2×2 제거 기록은 점유 칸마다 동일 본체 Occurrence를 사용한다. 제거 집계는 개체로 중복 제외해야 한다.
- 현재 DamageCause는 AdjacentMatch/Power/MagnetAdjacent/Hammer라 로켓·폭탄·조합을 직접 구분하지 못한다. 피해 허용 정책 enum 자체를 바꾸기보다 사건 발생 지점에 학습 판정용 출처 정보를 보강하는 방향을 검토한다.
- PowerCombinationKind는 10개 조합을 구분한다. 턴 전체의 Combination만으로 이후 연쇄 파워 제거 원인을 판정하면 잘못 분류될 수 있으므로 각 타격의 출처를 추적해야 한다.
