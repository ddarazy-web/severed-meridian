## 확장 방법과 제약

- 새 안내 콘텐츠는 레벨의 단계/대상/요소 ID/결과 조건으로 작성하고 실제 재생 검사를 통과시킨다. 같은 행동의 블록/장애물마다 새 중앙 분기를 만들지 않는다.
- 새 행동/조건이 필요할 때만 기존 TutorialHandlerRegistry에 해당 처리기를 등록한다. 표현은 TutorialProgressSnapshot → PuzzleTutorialBinding → TutorialOverlayView로 연결하며 권한/진행을 다시 구현하지 않는다.
- 완료 저장 수단은 TutorialExecutionContext의 조회/기록 콜백으로 바꿀 수 있다. 완료 시점과 레벨 문맥은 세션이 계속 소유한다. 계정·클라우드·전체 재고 시스템은 추가하지 않았다.
- 현재 일반 아이템은 기존 시험용 무제한 흐름이다. 무료 체험은 기존 선택/대상 입력 및 승인된 무료 사용 API를 이용한다. 새 보유량 저장소나 실제 수량 차감은 만들지 않았다.
- 확인 환경은 Windows Unity6000.3.10f1의 실제 Editor/Play Mode다. 두 화면 비율과 인셋 Safe Area는 검증했지만 Android/iOS 실기기·실제 터치/노치·기기별 배치 검사는 수행하지 않았다. 플랫폼 설정은 변경하지 않았다.
- 상세 매뉴얼은 요청대로 추후 정리한다. 없는 2~5/9 출시 레벨, 새 이미지, 고물탑은 만들지 않았다.

다음 제안은 실제 2레벨 제작 시 로켓 생성→교환 발동 안내를 같은 패턴으로 작성하는 것이다. 이번 단계의 임시 fixture를 그대로 출시 레벨로 복사하지 않는다. 다음 작업은 시작하지 않았다.
