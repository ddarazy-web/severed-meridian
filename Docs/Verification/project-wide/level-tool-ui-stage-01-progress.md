## 실행 기록

- 초기 조사: 기존 OnEnable이 버튼과 세 패널을 구성하며 Refresh가 모든 편집 컨테이너를 다시 만든다. 키 처리는 튜토리얼 Enter/Esc만 등록되어 있다.
- RED 확인: 창 설정(`125534-007`), 공통 명령 부재(`125727-463`), 작업 탭 부재(`125829-991`). 모두 컴파일 오류가 아닌 요구사항 실패로 재현했다.
- GREEN: 화면 구조·기존 기능 이동·선택/미저장/Undo/Redo 유지(`130352-356`), 공통 명령 경계(`130455-857`), 도구 전용 프로필 설정·재구성 및 다른 프로필/전역/GUID 보존(`130534-919`). 모두 Unity 종료 코드 0.
- 입력 저장 재현에서 숫자 필드 Change 이벤트 처리 전에 저장이 시작되는 문제를 발견했다. UI 이벤트 큐의 입력 확정이 끝난 뒤 명령을 실행하도록 수정했다. 지연 텍스트/숫자 최종값·잘못된 숫자 보존·공유 사본 Undo·외부 저장 충돌 검사 통과(`131445-262`, 종료 코드 0). 추가 단축키·실제 컴포넌트 재활성화·게임 복귀 검사를 확장 중이다.
- 첫 뷰포트 검사에서 검사 결과를 펼친 뒤 보드 최소 크기 검사가 실패했다. 캡처에서 불필요하게 큰 스크롤바·중앙 정렬 미적용을 확인하여 수정했다. 재검사 진행 중이다.
- 위 괄호 값은 `Logs/TestHarness/20261009-<값>-Run.log`의 실행 ID다. 작업별 요약 로그는 `Logs/LevelToolUiStage01/`에 있다.
- 모든 Unity 검사는 순차 실행하고 실행 중 Assets C# 수정은 보류한다.

## 최종 보완 및 재검사

- 전선 갱신 수정 후 공급/흐름/연결/모양 회귀 통과(`134702-389`), 튜토리얼 샘플·논리 재생·오류 위치 이동 통과(`134809-745`), 최종 화면/이력/재활성화 회귀 통과(`134957-204`). 모두 종료 코드 0.

- 실제 편집/저장/복구 전체 회귀(`134230-948`) 통과. 폴더 전환 취소, 저장/버리기 재열기, 외부 충돌, 사본 저장, 이전 정상본 보호, 종료 확인, 작은 창 보드 스크롤을 포함한다. 실제 스크립트 재로드와 Play 재시작 복구도 통과했다(`134448-382`).
- 추가 공급/흐름/연결 검사에서 전선 그리기 시작 상태가 보드 캐시 키에 누락된 회귀를 재현했다(`134543-819`, Missing wire vertex). `wireDrawing`을 키에 포함해 연결점 표시가 즉시 갱신되도록 수정했다. 최종 재검사 결과는 아래에 기록한다.

- 뷰포트 최종 검사(`134119-213`)는 4개 해상도의 기본/검사/모달, 작은 화면 패널 접기, 한국어 도움말 검색·메뉴 키 표시까지 16개 캡처와 범위 검사를 통과했다. 도움말 제목/검색 라벨 겹침을 보완하고 재캡처로 확인했다.
- 필수 회귀 통과: 기존 창 인계·원본 보호(`133500-077`), 시험 중 스크립트 재로드/Play 중지/씬 해제와 미저장·이력 복구(`133546-781`), MemoryPack 실제 게임 시험(`133654-240`), 제품 프로필 경계(`133731-595`).
- 기존 실제 UI 회귀의 첫 실행(`133812-968`)은 저장·충돌·사본·복구본 보호까지 통과했으나 단순 컴포넌트 재활성화를 새 세션 복구로 간주하는 검사에서 중단됐다. 메모리 편집본 유지 규칙에 맞춰 재활성화 검사를 바꾸고, 실제 스크립트 재로드 검사는 별도로 유지한다.

- 독립 검토에서 화면 재활성화 시 편집 층 드롭다운이 Block으로 돌아가는 표시 오류와 검사 오류 이동 시 속성 패널이 숨겨지는 문제를 확인했다. 현재 층 복원 및 오류 대상 패널 열기를 적용했고, 데이터/Undo 보존 회귀와 함께 통과했다(`133042-145`).
- 최종 입력 검사(`133319-937`)는 실제 PointerDown/PointerUp을 통한 헤더 저장·파일 메뉴 저장, 잘못된 숫자 입력 중 버튼/메뉴 차단, Ctrl+C/V 한국어 텍스트 클립보드, Tab/Shift+Tab, 컴포넌트 재활성화, F5 실제 게임 시작/복귀까지 통과했다. 키 경로만 호출한 결과로 클릭 동작을 추정하지 않았다.
- Unity 입력 이벤트 주입은 실제 물리 키보드·Windows IME 조합기의 검증과 다르다. 조합 문자열 가드와 입력 소유권 검사는 있지만 물리 IME, Unity 호스트가 먼저 소비하는 키, Windows 독립 Player 창 조작은 미검증으로 남긴다.
- 전체 diff 검사에는 기존 AddressableAssetSettings.asset의 생성된 공백 4건이 남아 있다. 이번 UI 작업 범위 밖의 설정을 공백 정리 목적으로 수정하지 않았다.
- 후속 2단계 [계획](../../Planning/project-wide/level-tool-ui-stage-02-plan.md)·[목표](../../Goals/project-wide/level-tool-ui-stage-02-goal.md)·[실행문](../../Commands/project-wide/level-tool-ui-stage-02-command.md)을 작성했다. 구현은 시작하지 않았다.

실제 Windows Player의 창 크기 조절·최대화·OS 스냅은 빌드 승인 후 확인할 항목이다. 물리 한글 IME와 Unity 호스트의 키 선점도 실기 검증이 남았다. 자동 검사에서 확인한 범위를 넘어 통과했다고 주장하지 않는다.

## 화면 근거와 UX 개선

- `Logs/LevelToolUiStage01/viewport-1024x768-default.png`: 작은 화면에서도 9×9 보드와 좌우 패널을 유지한다. 좁을 때 Shift+Space로 보드에 집중한다.
- `Logs/LevelToolUiStage01/viewport-1366x768-menu.png`: 메뉴 이름과 오른쪽 단축키 표시, 실제 가용성.
- `Logs/LevelToolUiStage01/viewport-1366x768-help.png`, `viewport-1366x768-help-search.png`: 검색 가능한 한국어 설명과 텍스트/보드 클립보드 범위 구분.
- `Logs/LevelToolUiStage01/viewport-1280x800-modal.png`: 폴더 경로 입력·탐색·선택·취소와 배경 차단.
- 자동 맞춤 보드는 중앙에 배치하며 스크롤바 때문에 마지막 행이 잘리지 않도록 여유를 둔다. 모달 종료와 게임 시험 복귀 시 포커스를 복원한다. 검사 오류 선택은 필요한 패널을 열어 수정 위치가 숨지 않게 한다.
