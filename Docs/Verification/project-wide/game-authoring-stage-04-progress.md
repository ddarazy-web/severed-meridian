# 게임·제작 도구 분리 4단계 검증 기록

> 2026-10-09 구현·검증 완료. Unity Play Mode에서 확인한 실행용 기본판.

## 구현 결과

- `MATCH/레벨툴 씬 실행`으로 공통 `LevelTool` 씬에 진입한다. 기존 미저장 Unity 씬과 실행 시작 씬 설정을 보존한다.
- 실행용 화면에서 JSON 작업 폴더 탐색, 레벨 선택·생성·복제, 저장·사본·재열기·이전 정상본 복구를 제공한다. 디렉터리 조회와 저장 작업은 작업 스레드로 분리했다.
- 공통 편집 세션으로 9×9 보드 선택·영역 배치·층 교체·삭제·2×2 이동, 기본 속성·미션·생성구와 Undo/Redo를 처리한다.
- 런타임 시각 카탈로그와 기존 아틀라스 로더로 배치 이미지를 표시한다. 누락은 `!`와 원인 툴팁으로 알린다.
- schema4는 읽기 미리보기와 명시적 단일 이력 형식 전환을 제공한다. schema1–3은 작업 공간 교체 전에 거절한다. 고급 필드와 공유 참조는 보존한다.
- 현재 미저장 스냅샷·시드·튜토리얼 정책으로 기존 실제 게임 프리팹을 실행한다. 복귀 후 폴더·선택·스크롤·초안·이력을 유지하고 임시 게임 객체를 해제한다.
- Windows Level Editor 프로필에 LevelTool 시작 씬을 연결했다. 게임 프로필·기존 게임 씬·기본 SO 편집 창은 유지한다.

## 독립 리뷰와 보완

- Important 2건을 수용했다. 수정 전 `review-scene-red.log`에서 부분 카탈로그 누락, `review-portable-red.log`에서 구형 형식 수용을 재현했다. 기본 정의 보충/제작 정의 우선/내장 정의 우선 및 세션 교체 전 도구 버전 검사를 한 수정 묶음으로 반영했다.
- Minor 2건은 5단계 UX 보완으로 명시했다. 팔레트 클릭 직후 선택 테두리 갱신, 거절된 입력 필드를 실제 초안 값으로 복원하는 표시 개선이다. 현재 오류 메시지는 나오고 실제 초안에는 거절된 값이 반영되지 않는다.
- 도구 전용 UI Toolkit은 1단계 기술 확인을 따른다. 게임 UI를 전환하지 않았다. 테스트의 작은 화면 확대 실패는 스크롤바 Slider를 선택한 검사 오류였으며 보드 확대 컨트롤을 명시하여 수정했다.
- 사용자 지시대로 커밋 없이 작업 분기와 검증 기록을 유지한다. 단계 검증을 위한 빈 배치 씬 생성만 Single로 처리하고 사용자의 기존 씬은 보존했다.

## 남은 범위

- 5단계: 튜토리얼·고급 공급·흐름·모양·다중 레벨·자동 시험/결과 UI, 종료/씬 이동/도메인 재로드의 미저장 초안 복구, 기능 동등성 검증 후 기본 편집 메뉴 전환.
- 6단계: 전체 SO 원본 이관, 정식 MemoryPack/Addressables 입력 전환과 제품별 격리 검수.
- 현재 도구 종료 전에 저장해야 한다. 폴더 전환의 미저장 보호와 시험 복귀 보존은 검증했으나 도구 자체 종료 복구는 아직 구현하지 않았다.
- Player/Addressables 빌드·Windows exe/실기 검증·커밋·푸시·HTML 갱신은 하지 않았다. 이번 완료 범위는 Unity Play Mode에서 검증한 실행용 기본판이다.
