# 레벨 탐색 개선 2단계 목표

상태: 완료 — 2026-10-21. 실제 1천/1만 최초+정상 3회 계측, 원본 참조형 복구 v2, 렌더 UI 및 호환 회귀 통과. 물리 입력·Android 실기기는 미검증이며 제품 빌드는 하지 않았다.

실제 대량 레벨 프로젝트에서 문서 읽기·준비·복사 비용을 줄이고, 기존 편집과 저장의 안전성을 유지한다.

- [x] 1천/1만 실제 문서 fixture, 실행 환경, 문서 크기, 측정 구간을 기록한다.
- [x] 목록 표시·검색은 전체 파일 본문 읽기 0건으로 처리한다. 파일 목록·목록용 정보만 사용한다.
- [x] 편집 레벨과 필요한 참조만 읽으며, 목록 정보가 없는 기존 프로젝트를 자동 전체 스캔하지 않는다.
- [x] 전체 검사는 열기와 분리한다. 아직 읽지 않은 파일을 검사 완료로 표시하지 않는다.
- [x] 최초 실행과 정상 3회 실행의 시간·메모리·할당량 기준값을 확보한다.
- [x] 개선 대상과 시간 목표를 측정 근거로 확정한다.
- [x] 확인된 병목만 수정하고 동일한 원본 잠금 조건의 RED/GREEN으로 읽기 제거를 입증한다. 과거 전체 백업과 참조형 복구의 시간 배율은 주장하지 않는다(사용자 후속 승인 기준).
- [x] 검색·최근 목록·부분 취소·공유 참조·Undo/Redo·저장·복구 회귀를 통과한다.
- [x] ZIP 전달 및 MemoryPack 변환 입력의 호환성이 유지된다.
- [x] 실제 화면의 첫 표시·편집 전환과 긴 처리의 안내를 확인한다.
- [x] 소유한 테스트 사본만 정리하고 실제 데이터·검증 결과를 보존한다.
- [x] 변경 내용, 측정 결과, 제한과 남은 항목을 보고하고 복사용 커밋 메시지를 제시한다.

제품 빌드·커밋·푸시·HTML 매뉴얼 수정은 하지 않는다. 1단계 메타데이터 측정으로 전체 문서 성능을 입증했다고 보고하지 않는다.
