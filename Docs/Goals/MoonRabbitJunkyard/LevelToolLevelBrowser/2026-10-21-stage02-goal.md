# 레벨 탐색 개선 2단계 목표

상태: 계획 확정 / 미착수. 별도 실행 요청 후 진행한다.

실제 대량 레벨 프로젝트에서 문서 읽기·준비·복사 비용을 줄이고, 기존 편집과 저장의 안전성을 유지한다.

- [ ] 1천/1만 실제 문서 fixture, 실행 환경, 문서 크기, 측정 구간을 기록한다.
- [ ] 최초 실행과 정상 3회 실행의 시간·메모리·할당량 기준값을 확보한다.
- [ ] 개선 대상과 시간 목표를 측정 근거로 확정한다.
- [ ] 확인된 병목에 필요한 범위만 수정하고 동일 조건에서 전후 개선을 입증한다.
- [ ] 검색·최근 목록·부분 취소·공유 참조·Undo/Redo·저장·복구 회귀를 통과한다.
- [ ] ZIP 전달 및 MemoryPack 변환 입력의 호환성이 유지된다.
- [ ] 실제 화면의 첫 표시·편집 전환과 긴 처리의 안내를 확인한다.
- [ ] 소유한 테스트 사본만 정리하고 실제 데이터·검증 결과를 보존한다.
- [ ] 변경 내용, 측정 결과, 제한과 남은 항목을 보고하고 복사용 커밋 메시지를 제시한다.

제품 빌드·커밋·푸시·HTML 매뉴얼 수정은 하지 않는다. 1단계 메타데이터 측정으로 전체 문서 성능을 입증했다고 보고하지 않는다.
