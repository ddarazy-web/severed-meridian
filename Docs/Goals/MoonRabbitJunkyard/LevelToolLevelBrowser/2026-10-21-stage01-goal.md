# 레벨 탐색 개선 1단계 목표·완료 조건

상태: **1단계 완료 / Editor 검증 완료 · 실기기 제외** · 작성일: 2026-10-21

## 목표

수천·수만 레벨을 검색하고, 행의 **편집** 버튼 또는 최근 편집 목록으로 안전하게 연다. 현재 레벨 변경을 버릴 때 다른 레벨과 공유 데이터는 보존한다.

## 완료 조건

- [x] 숫자 정확 검색 / `시작~끝` 범위 / 이름 부분 검색과 번호 오름차순 정렬을 제공한다.
- [x] 행 클릭은 편집 대상을 바꾸지 않으며 편집 버튼으로만 연다. Enter 검색도 레벨을 열지 않는다.
- [x] 현재 편집 표시와 탐색 강조가 다르며 현재 레벨 찾기로 검색 해제·위치 표시가 된다.
- [x] 전체/검색 결과 개수, 검색 오류와 0건 안내를 제공하고 편집 중인 데이터는 유지한다.
- [x] 미저장 확인에 **저장하고 다른 레벨 열기 / 변경 버리고 다른 레벨 열기 / 계속 편집하기**를 사용한다.
- [x] 기존 프로젝트 단위 저장 범위를 안내하며 성공 후에만 연다. 실패·취소는 입력과 편집 상태를 유지한다.
- [x] 변경 버리기는 현재 레벨만 복원한다. 다른 레벨/공유 값·dirty 및 유효한 Undo/Redo를 보존한다.
- [x] Undo/Redo·복구로 버린 변경이 되살아나지 않는다. 신규 레벨·혼합 문서 작업·공유 참조 경계도 검증한다.
- [x] 지연 입력과 공유 초안 제한을 처리하며 공통 열기 경로로 모든 진입점을 통일한다.
- [x] 최근 20개는 성공한 열기만 ID로 기록한다. 중복 제거·최근순·프로젝트 격리·재시작 복원·삭제 필터가 동작한다.
- [x] 최근 목록은 콘텐츠·ZIP에 포함되지 않으며 편집 데이터 dirty를 만들지 않는다.
- [x] 1천/1만 건 측정 결과가 있고 가상 행 수/검색 시간/목록 재구성 횟수 목표를 충족한다.
- [x] 1만 건 검색 중앙값 200ms 이내, 지정 창 크기에서 생성 행 40개 이내, 보드 선택·줌에서 목록/인덱스 재구성 0회를 검증한다.
- [x] Editor UI와 기존 저장·복구·튜토리얼·공유 적용 회귀 검증을 수행한다. 실기기 등 미검증 항목은 구분한다.
- [x] 테스트 임시 파일만 정리하고 실제 작업 데이터·검증 결과를 보존한다.
- [x] 완료 보고와 2단계 계획·목표·복사용 실행문을 제공한다. 2단계 구현은 자동 시작하지 않는다.

## 제외·제약

전체 대량 문서 로딩·복사 최적화는 2단계다. 1만 건 메타데이터 검사를 실제 1만 문서 프로젝트 전체 성능 검증으로 표현하지 않는다. 제품 빌드, 커밋·푸시, 요청하지 않은 HTML 매뉴얼 수정은 하지 않는다. 질문은 시간제한 없는 문답으로 제시한다.
