## 목표

고정 장애물의 현재 피해 단위와 제거/미션 결과를 재현 가능한 비교 기준으로 만든다. 다음 단계 리팩토링에서 관찰값을 비교할 수 있어야 한다.

## 필수 완료 조건

- [x] 검사 진입점의 빌드·종료·원본 저장 여부를 확인하고 안전한 실행 방법을 기록했다.
- [x] 회수캡슐의 피해 원인 제한, 색 제한 장애물의 색 일치/불일치, 일반 본체의 턴당 제한을 직접 검증했다.
- [x] 2×2의 가로/세로 로켓 2칸, 폭탄 부분 중첩, 확대 조합 중첩, 자석+자석 4칸 피해와 같은 공격/같은 칸 중복 제외를 직접 검증했다.
- [x] 제거 시 점유 전체 해제·미션 단일 완료와 비제거 시 본체 유지·실행 전 원본 보존을 검증했다.
- [x] 사례별 종류 숫자·초기값·시드·행동/타격과 실제 내구도·점유·미션·효과 결과가 남아 있다.
- [x] 이번 실행의 로그·결과 파일·실행 명령·종료 코드가 확인되고 필수 사례의 FAIL/예외가 없다. 기존 실패 또는 검사 미실행을 PASS로 처리하지 않았다.
- [x] 런타임 규칙·enum 숫자·저장 포맷·원본 에셋·기존 작업을 변경하지 않았고 빌드하지 않았다.
- [x] 단계 검증 기록과 필수 완료 보고를 작성했다. 완료 후 EF-02 계획/목표/명령문을 작성하고 복사 가능한 실행문을 제시했다.

## 범위 제외와 미완료 판정

새 요소 프레임워크 구현, 드론 정책/비행 변경, 발전기·번식·공급 전환, 원본/팩 변환, 카탈로그 UI는 제외한다. 소스 변경이 필요하다면 현재 사례를 확보하는 기존 검사 보완만 허용한다.

필수 검사를 실행할 수 없거나 실제 실패가 남으면 이 단계는 미완료다. 조사·검사 보완 성과와 재개 조건을 보고하고, EF-02 착수를 현재 단계 완료로 대신하지 않는다.
