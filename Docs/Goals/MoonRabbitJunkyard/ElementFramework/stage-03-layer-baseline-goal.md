- [x] 거미줄 1~3의 피해/내용물 보존·제거 미션·동일 턴 제한/다음 턴 허용을 실제 사례로 확인했다.
- [x] 먼지 1~3의 실제 일반 블록 소비/변환 피해와 접촉만으로 무피해·제거 미션을 확인했다.
- [x] 매칭/파워 조합·색 변환/후속 효과의 중복 피해 제한을 확인했다.
- [x] 낙하 뒤 덮개/바닥/내용물 관계와 바닥 잔류를 확인했다.
- [x] 사례별 시드/입력/행동·타격 순서와 실제 내구도/내용물/미션/효과를 기록했다.
- [x] 안전한 실제 Editor 검사 종료 코드/새 결과 파일을 확인했고 필수 FAIL/예외가 없다.
- [x] 생산 규칙/원본/저장/기존 작업을 보존하고 빌드하지 않았다.
- [x] 완료 보고/검증 기록과 EF-04 계획·목표·복사용 명령문을 제공했다. EF-04 구현은 시작하지 않았다.
