# 큰 구간 1단계 — 목표와 완료 조건

상태: 완료. 최종34종 실제 종료0/687830 PASS/0 FAIL, 실행 데이터·보호 감사와 다음2단계 문서 인계 완료. 2026-10-06.

연결: [계획](../../../Planning/MoonRabbitJunkyard/ElementFramework/phase-01-common-element-rules-plan.md) · [실행문](../../../Commands/MoonRabbitJunkyard/ElementFramework/phase-01-command.md).

## 목표

기존 장애물·거미줄·먼지·곰팡이·발전기·공급의 정의와 공통 규칙 연결을 완결한다. 같은 행동의 다른 콘텐츠를 처리하기 위해 종류별 피해/제거/미션 분기를 추가하지 않아야 한다. 기존 플레이 결과와 저장 원본은 보존한다.

## 관찰 가능한 완료 조건

- [x] 기존6종과 Web/Mold/Dust가 안정적인 정의 조회로 연결되고 필수 정의/행동 누락은 식별 가능한 오류로 거절된다. ID 등록만으로 완료 처리하지 않는다.
- [x] 거미줄의 배치→피해→제거→미션과 먼지의 실제 일반 블록 소비/변환→피해→미션이 등록 규칙으로 연결된다. 턴당 중복 피해와 내용물 보존 검사를 통과한다.
- [x] 곰팡이 제거/턴 종료 번식 및 발전기 충전/활성화/연결 해제/퇴역이 정의와 해당 수명주기 행동을 사용한다. 벽·후보·난수·실패 원복·미션 변화가 기준과 같다.
- [x] 최초·고정·유지 공급 및 회수의 실제 생성 경로가 정의를 소비하고 선택 순서·소진·초기 상태·미션·난수를 보존한다.
- [x] 기존 장애물의 2×2 중첩 피해·본체당 미션·색 제한·캡슐 거부가 유지된다. 기존 블록 대각선 이동 금지·상단 직선 우선·동시 낙하도 유지된다.
- [x] 같은 행동을 가진 다른 ID의 내구도형·덮개형 테스트 정의가 종류별 실행 분기 추가 없이 실제 반응과 적용·제거/미션까지 수행한다. 정의 값을 바꾸었을 때 실제 소비 경로가 이를 반영한다.
- [x] 행동 선택은 등록 키 직접 조회이며 전체 등록 정책 탐색이 없다. 조회는 상태를 변경하지 않고 적용은 기존 상태/턴 소유권을 유지한다.
- [x] 최종 변경 상태에서 관련 신규 검사 및 기존30개 메서드의 실제 종료0/FAIL0을 확인한다. 같은 입력/시드의 전체18182행·188팩·225팩 상태 비교와 의도적 메타데이터 차이를 기록한다. 미검증 항목은 통과로 표시하지 않는다.
- [x] 원본/GUID/enum 숫자/저장 버전1·50레벨 구간/기존 WIP/과거 증거를 보존하고 기존 검사 출력을 원문 복원한다. 커밋·푸시·빌드·팩 파일 재생성은 없다.
- [x] 완료 보고와 검증 기록에 변경 범위·검사·제약·미완료를 명시하고, 다음 큰 구간2의 계획/목표/복사 가능한 실행문을 제공한다. 다음 구현은 시작하지 않는다.

## 완료로 보지 않는 상태

카탈로그에 ID만 추가한 상태, 기존 종류 분기를 다른 파일로 옮긴 상태, 동일 규칙을 새 타입마다 복사한 상태, 정의 값이 실제 실행에 반영되지 않는 상태는 완료가 아니다. 테스트 카탈로그로 재사용을 입증하는 것과 실제 제작 UI/배포 정의 지원은 구분한다. 제작 UI·저장 전환·드론·표현은 후속 구간이며 이번 완료에 포함하지 않는다.
