# EF-18 — 나무상자 피해 원인 허용 정책 연결 목표

상태: 준비 완료, 미실행.

연결: [계획](../../../Planning/MoonRabbitJunkyard/ElementFramework/stage-18-crate-damage-policy-plan.md) · [가이드라인](../../../Planning/MoonRabbitJunkyard/ElementFramework/integration-guideline.md).

- [ ] 실제 피해/미션/예약 호출부·전환 전 결과와 기존 변경/원본/GUID를 보호했다.
- [ ] 불변 원인 허용 정책을 정의에 조합하고 기존 생성/배치/충전 계약을 유지했다.
- [ ] crate 정책을 한 번 준비했고 누락 정책은 ID 오류로 거절한다. 다른 메모리 정책도 같은 조회에 반영된다.
- [ ] 상자 읽기 전용 허용 조회만 연결하고 다른5종/미지원·외부 경계·반응/메시지/피해량/턴 집계를 보존했다.
- [ ] Query가 상태/턴 문맥/난수를 변경하지 않으며 실제 피해/제거/미션/발전기 철거·예약 피해/효과·저장 바이트/배치 ID가 전후 일치한다.
- [ ] 계획의 안전한 새/기존 검사 각 종료0·필수 FAIL0과 실제 입력/반응을 기록했다.
- [ ] EF-05/09/11·원본/GUID/기존 작업 보존·미검증/남은 문제를 stage-18-progress.md에 기록했다.
- [ ] 완료 보고와 다음 한 단계 계획/목표·전체 복사용 명령문을 제공하고 다음 구현은 시작하지 않았다.

상자 피해 원인 허용 조회만 완료 대상이다. 공통 피해 실행·모든 종류 행동 전환은 별도다.
