- [x] 제작 원본→불변 정의→배포 DTO/카탈로그가 연결된다. ID와 표시명·정렬·Unity GUID가 분리되고 중복/누락/잘못된 프로필은 ID를 포함한 오류로 거절된다.
- [x] 새 레벨 스키마5와 팩 포맷2를 구형4/1과 명시적으로 구분한다. 기존 enum 숫자·v1 DTO 순서·9×9·50레벨 주소 계약을 유지하고 구형 바이너리의 자동 호환을 가정하지 않는다.
- [x] 구형/신형 목록의 실행 원본이 하나로 정해진다. 미리보기는 읽기 전용이며 선택 변환만 SerializedObject/Undo로 적용한다. 자동 저장·전체 에셋 일괄 변환이 없다.
- [x] 정의 ID와 본체 인스턴스 ID가 분리되어 2×2 점유·발전기 연결·미션·공급 참조가 보존된다. 누락/중복/잘못된 ID를 일반 블록 대체로 숨기지 않는다.
- [x] 서로 다른 두 신규 ID가 같은 등록 행동을 재사용해 실제 배치·타격·미션·드론 조회까지 실행된다. 새 종류 enum/종류별 분기 없이 카탈로그의 선택 정의를 사용한다.

## 완료로 보지 않는 상태

ID 필드만 저장한 상태, 새 ID를 실행할 때 enum으로 되돌려 카탈로그 정의를 버리는 상태, 검색 창만 추가하고 실제 편집/게임 진입을 연결하지 않은 상태, 기존 팩이나 원본을 덮어써 비교 기준을 없앤 상태는 완료가 아니다. 바이트·ID 메타데이터 변화와 실제 게임 논리 차이를 같은 것으로 다루지 않는다.
