# EF-23 — 발전기 반응 원인 허용 조회 연결 목표

상태: 준비 완료, 미실행.

연결: [계획](../../../Planning/MoonRabbitJunkyard/ElementFramework/stage-23-generator-reaction-policy-plan.md) · [EF-22 결과](../../../Verification/MoonRabbitJunkyard/ElementFramework/stage-22-progress.md).

- [ ] 실제 호출부·충전/4칸/원인/null/문맥/경계·내부/외부의 전환 전 입력/응답 및 기존 작업/원본/GUID를 확보했다.
- [ ] 기존 불변 정책의 네 값 true를 한 번 등록하고 같은 필수 조회 뒤, 색/내구도 검사 전 위임을 연결했다. 누락은 ID 오류이고 기본값 대체가 없다.
- [ ] Charge/AlreadyDamaged·내부 자석 인접 허용/외부 거절·미정의 원인·본체별 턴당1충전·반응/양/메시지·기존5종 정책/배치/충전을 보존했다.
- [ ] Query 상태/비공개 문맥/난수와 실제 충전/작동·연결 제거/철거/미션/효과/예약·복수 연결·바이트/ID/버전1/50구간의 전후 일치를 확인했다.
- [ ] 계획의 안전한 새/기존 검사 각각 종료0·필수 FAIL0·실제 결과·과거 출력 복원을 확인했다.
- [ ] EF-05/09/11·기존 작업/원본/GUID·미검증·남은 문제를 stage-23-progress.md에 기록했다.
- [ ] 완료 보고와 다음 한 단계 계획/목표/전체 복사용 명령문을 제공하고 다음 구현은 시작하지 않았다.

발전기 허용 조회만 완료 대상이다. 충전/피해 실행이나 연결 규칙의 정책 전환은 포함하지 않는다.
