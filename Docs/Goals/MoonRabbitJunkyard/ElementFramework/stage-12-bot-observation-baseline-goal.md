# EF-12 — 봇 공개 관찰·숨은 정보 차단 기준 목표

상태: 준비 완료, 미실행.

연결: [계획](../../../Planning/MoonRabbitJunkyard/ElementFramework/stage-12-bot-observation-baseline-plan.md) · [가이드라인](../../../Planning/MoonRabbitJunkyard/ElementFramework/integration-guideline.md).

- [ ] DTO/Capture/공개 행동 후보/전략 소비 경계를 실제 코드로 확인했다.
- [ ] 실제 공개 값·좌표·색·내구도·충전·점유·미션과 행동 후보를 기록했다.
- [ ] 숨은 정보만 다른 입력 쌍의 공개 관찰·후보 동일성을 실제 확인했다.
- [ ] 관찰/후보 조회 전후 원본/난수 보존과 DTO 스냅샷 독립성을 확인했다.
- [ ] 정의/내부 ID/공급/예약/난수 등 숨은 참조 노출 여부를 검증하고 정적 검토와 실제 결과를 구분했다.
- [ ] 실제 입력/관찰/후보/수치·검사 종료0/필수 FAIL0·한계와 원본/GUID/기존 변경 보존을 기록했다.
- [ ] 완료 보고·다음 한 단계 계획/목표·전체 복사용 명령문을 제공하고 다음 구현은 시작하지 않았다.

필수 실패나 실제 비교 누락은 완료로 표시하지 않는다. 전략 개선·전체 승률·새 관찰 시스템은 이번 범위가 아니다.
