# 2단계 실제 게임 플레이 — 목표 및 완료 조건

상태: 2026-09-30 구현·검증 완료. 결과는 [실행 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-02-progress.md)을 참조한다. 선행 단계: [1단계 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-01-progress.md). 전체 범위는 [5단계 계획](../../../Planning/MoonRabbitJunkyard/WorldGameScreen/2026-09-30-world-game-screen.md)을 따른다.

## 목표

`PuzzleGame` 씬에서 MemoryPack 레벨을 불러와 시작 조건을 만족하는 보드를 구성하고, 월드 보드에서 마우스·터치로 교환과 파워 발동을 수행한다. 기존 규칙으로 낙하·연쇄·미션·이동 수·승패·라스트팡을 끝까지 처리한다.

## 현재 기반과 보존 사항

- 1단계의 `PuzzleWorldBoard`, `PuzzleArtwork`, 게임 프리팹 4종과 `PuzzleGame.unity`를 재사용한다. 문제가 없는 코드는 유지하며 전체 복원하지 않는다.
- 현재 `PuzzleBoardPreview`는 `LevelStateBuilder.Build` 결과를 정적으로 표시한다. 플레이 시작에는 `StartingBoardSearch`가 필요하다.
- 게임 규칙의 소유자는 `BoardActionExecutor`다. 세션이나 입력 코드에서 매칭·이동 수·승패 규칙을 재구현하지 않는다.
- 설치된 Input System 1.18.0을 사용한다. 현재 `activeInputHandler: 1`이므로 구형 `UnityEngine.Input`으로 입력을 구현하지 않는다.
- Addressables 아틀라스 분할, 50레벨 MemoryPack, 레벨 에셋 빌드 제외 정책을 유지한다. 씬/프리팹에 레벨 에셋을 직접 참조하지 않는다.
- 최근 편집 보드의 색상 상자 표시는 에디터 새로고침 뒤 정상화됐지만 최초 원인은 미확정이다. 이를 해결된 회귀 결함으로 기록하지 않는다. 이번 검증도 사전 Warmup 결과만으로 화면 표시 성공을 판정하지 않는다.

## 플레이 계약

1. 씬의 레벨 번호와 시드로 팩을 로드한다. 기본값은 기존과 같은 1, 12345다. 잘못된 팩·레벨·시작 조건은 이유를 표시하고 입력을 막으며 다른 레벨로 대체하지 않는다.
2. 시작 탐색은 프레임마다 `Advance(128)`을 호출하고 프레임을 양보한다. 탐색 성공 후에만 실행기를 만들고 아틀라스 로드·최초 그리기가 끝난 뒤 입력을 허용한다.
3. 일반 블록은 두 칸을 차례로 누르거나 상하좌우로 드래그하여 교환한다. 드래그는 셀 폭의 25% 이상일 때 큰 이동 축의 인접 한 칸으로 한 번만 요청한다. 동일 축 크기이면 가로를 우선한다.
4. 파워 블록은 이동 없이 한 번 탭하면 제자리 발동한다. 파워에서 드래그하면 인접 칸과 교환을 요청한다. 파워 결합 판정은 실행기에 맡긴다.
5. 두 번째 탭이 인접하지 않으면 새 칸으로 선택만 옮긴다. 보드 밖·비활성 칸 입력은 선택을 취소한다. 거부된 행동은 이동 수와 난수 상태를 바꾸지 않는다.
6. 터치는 첫 포인터 하나만 추적한다. 터치와 마우스의 중복 처리, 연쇄 중 입력, 포커스 상실 후 남은 드래그를 차단한다. EventSystem이 있으면 UI 위에서 시작한 입력을 무시한다.
7. 실행기가 `HasPendingCascade`인 동안 프레임당 `AdvanceCascade()`를 한 번 호출하고 각 결과 상태를 다시 그린다. 입력은 `Phase == Ready`, `Outcome == null`, 표시 준비 완료일 때만 허용한다.
8. 성공 판정 뒤에도 라스트팡이 남으면 계속 실행한다. 종료 표시는 `Phase == Stopped`에서 확정한다. 이동 소진·진행 불가·실행 중단을 서로 구분한다.
9. 검증용 최소 표시로 로딩/오류, 이동 수, 미션 진행, 선택 칸, 결과를 보여준다. 정식 목업 HUD와 애니메이션 보간은 이번 범위가 아니다.
10. 씬 종료 시 진행 중인 로드와 입력을 취소한다. 뒤늦게 완료된 비동기 작업이 사라진 보드를 갱신하지 않으며, 생성한 레벨 사본·아틀라스를 소유자가 한 번만 반환한다.

- 게임 세션, 월드 입력, 검증용 표시를 기능별 파일로 분리한다.
- `Assets/Prefabs/Game/Puzzle/PuzzleGameSession.prefab` 및 기존 씬의 연결을 Unity Editor API로 구성한다. UI 프리팹은 4단계에 만든다.
- `Docs/Verification/MoonRabbitJunkyard/WorldGameScreen/stage-02-progress.md`: 실제 변경, 검사 결과, 실패/수정, 미검증 사항.
- `Docs/Guides/MoonRabbitJunkyard/WorldGameScreen/stage-02-gameplay-usage.md`: 씬 실행, 조작, 검증 레벨/시드, 오류 확인 방법.

## 제외 범위

3단계의 레벨 에디터 실행 버튼·에셋/팩 선택 전달, 4단계의 목업 UI·아이템·일시정지·다시하기, 5단계의 전체 빌드 검증은 구현하지 않는다. 상세 효과·사운드·새 이미지·새 게임 규칙·자동 커밋도 제외한다. 2단계 완료 후 멈춘다.
