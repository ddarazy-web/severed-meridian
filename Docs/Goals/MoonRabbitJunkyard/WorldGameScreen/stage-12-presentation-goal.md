## 목표와 시작 조건

자동 검사에서 확인한 상태·시간·수명과 별도로, 실제 Game View에서 화면을 보고 연출의 식별성과 사용성을 검수한다. 확인한 표시 결함만 최소 수정한다. 새 메인 화면·진행 저장·콘텐츠 확장은 이번 범위에 넣지 않는다.

11단계의 목표 12개와 [완료 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-11-progress.md)을 먼저 감사한다. 11단계는 새 안정화699개·별도 회귀3607개, 실제 Update19131프레임 관찰과 독립 리뷰 수정을 완료했다. 착수할 때 실제 현재 코드와 증거를 다시 감사하고 미완료 조건이 있으면 12단계 Goal을 만들거나 구현을 시작하지 않고 남은 조건을 보고한다. 11단계 이후의 실제 코드와 증거를 기준으로 이 계획의 파일·검사를 재확인한다.

## 결정과 범위

다음 단계는 실제 화면 검수로 제안한다. 이전 단계의 무음 Editor 검사로 실제 이미지·움직임·음질이 좋은지 판단할 수 없기 때문이다. 자동 검사를 재실행한 것과 사람이 화면을 관찰한 것을 구분한다. 기존 목업의 보상·광고·저장 예시는 구현 요구사항으로 해석하지 않는다.

## 보존·제외 기준

ServeredMeridian만 대상으로 한다. 원본 레벨·씬·GUID·무관 dirty 변경과 사용자 Unity를 보존한다. 기능별 UI/Game 프리팹 분리를 유지하며 전체 씬·아이템 바를 재생성하지 않는다.

9×9, 블록/2×2/가로 로켓 크기와 중심, 스와이프 최상위 order와 복원, 중첩 칸 수에 따른 2×2 피해, 낙하/공급 시간 /1.44, 동시 낙하·신규 대각선·상단 우선, 최신 소수 드론 상승/대기/돌파·조합 드론 반지름 1~4칸·표적 예고 없음, 미션/라스트팡, 14종 효과음·최대8음성·.06초 제한, 교환/섞기 256×256 투명 아이콘과 GUID를 유지한다. 착수 시 11단계에서 합의된 수정도 보존한다.

50레벨 MemoryPack·Asset 실행과 필요한 종류만 Addressables 아틀라스를 로드하는 구조를 유지한다. 진동, 새 규칙/DTO/패키지/BGM/상용 음원/설정 창/광고/과금/저장/레벨 진행 기능을 추가하지 않는다. 플레이어·Addressables 콘텐츠 빌드와 내부 빌드 호출 검사를 실행하지 않는다. 커밋·푸시·사용자 Editor 강제 종료·자동 씬 저장·다음 목표 자동 진행도 하지 않는다.

11단계의 background/pause 결과음 수정도 유지한다. 결과가 background에서 표시되더라도 미소비 결과음은 복귀/재개에 한 번 나오며 이미 재생한 결과는 다시 재생하지 않는다.

## 산출물
