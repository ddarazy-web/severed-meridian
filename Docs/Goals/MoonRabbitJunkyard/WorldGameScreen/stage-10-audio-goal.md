# 10단계 목표·완료 조건 — 소리

상태: 작업 1~4 및 완료 조건 12개 검증·최종 리뷰 수정 완료 (2026-10-01). [실행 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-10-progress.md). 실제 청취·실기기 출력은 미검증으로 기록했다.

[작업 계획](../../../Planning/MoonRabbitJunkyard/WorldGameScreen/stage-10-audio-plan.md) · [목표 명령문](../../../Commands/MoonRabbitJunkyard/WorldGameScreen/stage-10-goal-command.md)

## 목표

실제 교환·제거·파워 타격·착지·미션 도착·승패에 소리를 연결한다. 화면 연출과 같은 시간 경계를 사용하며 게임 규칙·결정 시점·난수를 바꾸지 않는다.

## 시작 조건과 확인된 사실

- 기존 로드맵의 후속 단계는 효과음 적용이다. 조사 범위인 `Assets`에서 재사용할 게임 음원 파일을 확인하지 못했고, `GameScreen`에는 효과음 재생기 구현이 확인되지 않았다. 10단계는 목표 실행 요청에 따라 착수했다.
- 9단계 실제 진행 기록·수집 모델·세션·HUD 연결은 완료 조건 15개별 Editor 검증과 최종 리뷰 수정을 마쳤다. 실행자는 최신 코드·로그가 완료 기록과 일치하는지 먼저 감사하고, 새 미완료가 발견되면 해결한 뒤 10단계를 시작한다. 과거 문서의 ‘작업 1 진행 중’만으로 현재 코드를 되돌리지 않는다.
- 외부 음원 도입은 이번 목표의 선행 조건으로 삼지 않는다. 우선 런타임 PCM 합성으로 만든 짧은 검증용 효과음을 사용한다. 상용 음원 선정·BGM·음원 구매·다운로드는 별도 작업이다.

## 적용 결정

| 항목 | 기준 |
| --- | --- |
| 음원 | 세션 준비 시 44,100Hz 모노의 짧은 PCM 클립을 한 번 생성한다. 프레임마다 만들지 않는다. 출처는 프로젝트 코드에 의한 합성으로 기록하며 상용 음원 확정으로 표현하지 않는다 |
| 재생 | 월드 위치와 관계없이 명확히 들리는 2D 효과음. `spatialBlend=0`, `loop=false`, 동시에 최대 8개 AudioSource 재사용. 외부 Mixer·패키지는 추가하지 않는다 |
| 기본 음량 | 개별 효과음 0.35부터 시작. 같은 시각에 여러 소리가 겹쳐도 음량이 과도하게 커지지 않도록 전체 활성 음성 수에 따라 이득을 줄인다. 최종 청감값은 실제 청취 후 기록한다 |
| 밀집 타격 | 같은 종류는 표시 시간 0.06초 안에 최대 1회. 8개가 찼으면 저우선순위 요청을 생략하고, 결과음은 가장 오래된 저우선순위 음성을 교체한다. 소리를 위한 대기열로 화면을 늦추지 않는다 |
| 설정 | Inspector의 소리 활성값으로 끌 수 있게 한다. 새 설정 창·영구 설정 저장은 추가하지 않는다 |
| pause | 세션 pause 시 재생 중 음성을 Pause/UnPause하며 표시 시간과 함께 이어간다. 새 소리 요청은 발생하지 않는다. |
| 반환 | 다시하기·취소·오류·씬 종료에는 즉시 Stop, 예약 및 중복 판정 기록 초기화. 소유한 클립·재생 객체는 씬 소유자가 반환한다. 앱 백그라운드에서는 Stop하고 복귀 시 과거 요청을 재생하지 않는다 |

## 소리 대응표

| 종류 | 발생 근거 | 제외 조건 |
| --- | --- | --- |
| 교환 | 유효 교환 화면 이동 시작 | 드래그 매 프레임, 거절된 입력 |
| 무효 복귀 | 실행 결과 무효이며 실제 복귀 표시 시작 | 입력 자체가 차단된 경우 |
| 매칭 제거 | 실제 소비 블록 제거 표시 시점 | 예측 매칭, 빈 변경 목록 |
| 파워 | 로켓 발사·폭탄 폭발·드론 실제 돌파/타격·자석 유효 타격의 표시 경계 | 드론 목표 예고, 선회 중 임의 재생, 무효/보호 반응을 유효 피해로 취급 |
| 착지 | 정착 기록의 실제 착지 경계, 같은 시각은 묶음 | 중력 Batch마다 시작 즉시 재생, 공급 대기 중 |
| 미션 도착 | 표시 진행이 실제로 증가한 도착 | 단순 HUD Refresh, 증가량 0 |
| 미션 완료 | 도착으로 목표를 처음 달성 | 초기 완료·목표 0·초과 진행의 반복 완료 |
| 시작·승리·실패 | 시작 표시 진입 및 `ResultReady` 이후 결과 표시 최초 진입 | Refresh마다 반복, 라스트팡·수집 정리 전 결과음 |

미션 도착과 완료가 같은 시각이면 완료음만 사용한다. 착지보다 미션·파워·결과 소리를 우선한다. 실제 소리 스타일은 짧고 부드러운 전자 효과음으로 시작하며 정식 아트 방향 확정과 구분한다.

## 보존·제외 범위

사용자 요청에 따라 진동 기능·진동 설정·플랫폼 진동 호출은 구현하지 않는다.

최근 수정한 교환·섞기 아이콘은 256×256 투명 이미지와 기존 프리팹 GUID 연결을 유지한다. 문서 작성만으로 실행하지 않으며, 별도의 목표 실행 요청에 따라 구현·검증을 완료했다.

ServeredMeridian만 대상으로 한다. 9×9, 블록·2×2 크기, 가로 로켓 보정, 스와이프 order 복원, 공격 범위당 2×2 내구도 피해, 최신 드론 상승·대기·돌파와 대형 선회, 낙하 시간 /1.44, 동시 낙하·공급 대기열·신규 블록만 대각선·상단 공급 우선, 50레벨 MemoryPack·Asset 시험, 필요한 이미지 종류만 Addressables 로드하는 구조를 보존한다.

UI 프리팹은 `Assets/Prefabs/UI/Puzzle`, 게임용 소리 재생 프리팹은 `Assets/Prefabs/Game/Puzzle/Feedback`에 구분한다. 새 월드 효과·설정 화면·저장 DTO·게임 규칙·BGM·광고·과금·플랫폼 플러그인은 추가하지 않는다. 빌드, Addressables 콘텐츠 빌드, 이를 내부 호출하는 검사, 자동 커밋·푸시는 금지한다. 사용자 에디터를 강제 종료하거나 미저장 씬을 자동 저장하지 않는다.
