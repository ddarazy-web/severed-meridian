# 13단계 목표·완료 조건 — 승리 후 다음 레벨 연결

상태: 2026-10-02 제안 계획 작성, 구현·목표 실행 미착수. 12단계가 완료되어야 시작한다.

[작업 계획](../../../Planning/MoonRabbitJunkyard/WorldGameScreen/stage-13-level-transition-plan.md) · [복사용 목표 명령문](../../../Commands/MoonRabbitJunkyard/WorldGameScreen/stage-13-goal-command.md)

## 목표와 근거

에디터에서 선택한 레벨을 플레이한 후, MemoryPack 모드의 승리 화면에서 다음 레벨을 이어서 플레이한다. 현재 PuzzleResultView는 Retry만 제공하며 PuzzleGameSession의 InitializeAsync는 같은 세션의 두 번째 시작을 거부한다. 기존 세션을 임의 재초기화하지 않고 명시적인 레벨 전환 경로를 마련한다.

사용자가 요청한 것은 다음 단계 문서다. 다음 레벨 연결은 이 문서에서 제안하는 후속 범위이며 구현은 아직 승인/실행하지 않았다. 기존 에디터 레벨 선택을 유지하고 메인 화면·레벨 목록·저장·해금은 추가하지 않는 것으로 계획한다.

## 시작 조건

12단계는 독립 리뷰의 복원 오류를 수정하고17개 회귀·추가InsetUI67PASS·10개 조건을 감사했다. [완료 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-12-progress.md)과 현재 목표 상태를 착수 때 확인한다. 미완료 또는 회귀가 재현되면12단계를 먼저 처리하며, 완료한 수정은 반복하지 않는다. 다른 활성 목표가 남으면13단계 목표를 중복 생성하지 않는다.

## 동작 결정

| 상황 | 기대 동작 |
| --- | --- |
| MemoryPack 승리 + ResultReady | `다음 레벨`과 기존 Retry 표시. n+1로 이동하며 시드는 기존 값을 유지 |
| 실패 또는 결과 연출 진행 중 | 다음 레벨 전환 불가. 기존 라스트팡·수집·결과 시점을 유지 |
| 다음 레벨 준비 중 | 현재 승리 화면을 유지하고 준비 안내. 보드/아이템/Retry/중복 전환 차단 |
| 새 데이터·시작 보드·아틀라스 준비 성공 | 이전 예약/표시를 정리하고 새 레벨로 한 번 교체. HUD/미션/이동/재시작 기준 갱신 |
| 다음 번호 누락·팩/아틀라스 로드 실패 | 이전 승리 상태·번호·재시작 기준을 유지. 오류 안내와 Retry 제공. 임의 번호 건너뛰기 없음 |
| 준비 중 종료·취소 | 후보 리소스 반환. 파괴된 화면/세션 갱신 없음 |
| Asset 에디터 실행 | 초기 미저장 사본과 Retry 유지. 다음 버튼 대신 MemoryPack 모드 안내 |
| MemoryPack 에디터 실행 | 선택 번호에서 시작하고 다음 번호로 이동. 종료하면 기존 편집 흐름으로 복귀 |

50레벨 팩 구간은 기존 LevelPackCodec을 따른다. 50→51에서 요청 주소가 변경된다. 새 레벨 정보/진행 저장 포맷과 전체 카탈로그는 만들지 않는다.

## 보존·제외

ServeredMeridian만 수정한다. 사용자 Unity·원본 레벨/씬·무관 dirty·GUID·UI/Game 프리팹 구분과 기존 Asset/MemoryPack 실행 경계를 보존한다. 9×9·크기/중심·order·2×2 중첩 피해·낙하/공급 시간 /1.44·동시 낙하·신규 대각선/상단 우선·최신 드론·미션/라스트팡·14종 효과음/8음성/.06초 제한·background/pause 결과음 복귀1회/중복0·256×256 교환/섞기 아이콘·필요 아틀라스 로드를 유지한다.

플레이어/Addressables 콘텐츠 빌드, 진동, 저장/해금·별·보상·메인 화면·광고·과금·BGM·새 패키지·전체 씬 재생성·커밋·푸시·사용자 Editor 강제 종료·자동 씬 저장·다음 목표 자동 실행은 제외한다. Editor 검사와 실제 청취/실기기 검증을 구분한다.

## 완료 조건

- [ ] 1. 12단계 복원 오류와 완료 조건을 감사하고 실제 수정/회귀/보존 증거로 완료를 확인했다. 13단계 착수 기준을 기록했다.
- [ ] 2. MemoryPack 승리의 ResultReady 이후에만 다음 레벨이 허용된다. 실패·진행 중·Asset 모드에서 불가하며 안내가 정확하다.
- [ ] 3. n+1의 데이터·시작 보드·필요 아틀라스를 준비하고 한 번 전환한다. 새 번호·미션·이동 수·시작 피드백이 올바르다.
- [ ] 4. 실패/취소 시 기존 승리 상태·번호·bytes·시드·Retry 기준을 보존한다. 다음 번호를 건너뛰거나 원본/팩을 자동 수정하지 않는다.
- [ ] 5. 연속 클릭·중복 UI 이벤트·회전 중 요청이 한 번만 처리되며 준비 중 보드/아이템/Retry 입력이 차단된다.
- [ ] 6. 새 레벨의 Retry가 해당 레벨 초기 상태로 돌아가며 이전 선택·연출·수집·결과음·음성 예약이 남지 않는다.
- [ ] 7. 준비 중 종료·취소·background/pause에서 후보와 기존 자원의 소유권이 정확하고 늦은 완료/결과음 중복이 없다.
- [ ] 8. 50→51 주소와 팩 경계, 번호 누락·잘못된 파일·아틀라스 실패를 검사했다. 실제 번들 미제공이면 실물 로드 미검증을 명시했다.
- [ ] 9. Asset 미저장 사본/MemoryPack 선택 번호와 시드, Play Mode 종료 복귀를 보존하고 Runtime에 Editor 참조·레벨 Asset 직접 참조가 없다.
- [ ] 10. 네 해상도 실제 버튼·결과/로딩/오류 화면에서 잘림·겹침·보드 입력 침투가 없고 이미지 보드를 유지한다.
- [ ] 11. 새 Data/RunScene과 영향받은 기존 빌드 없는 회귀의 새 PASS/FAIL/실제 Exit·cleanup 결과, 원본/해시/GUID 보존과 독립 리뷰 한 번을 기록했다.
- [ ] 12. 조건별 검증 기록·사용 안내·미청취/실기기 한계를 작성했다. 필수 결함/미검증이 남으면 완료하지 않았고 빌드/커밋/푸시/다음 목표는 실행하지 않았다.
