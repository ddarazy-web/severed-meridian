## 목표

[확정 목업](../../../MoonRabbitJunkyard/Mockups/puzzle-screen.html)을 기준으로 실제 게임 화면에 uGUI HUD, 아이템, 일시정지, 결과 화면을 적용한다. 보드는 월드 SpriteRenderer를 유지한다. 레벨 에디터에서 실행한 데이터로 플레이하고, 화면 회전·일시정지·다시하기에서도 선택 레벨이 유지되어야 한다.

## 확인한 기반과 계획상 결정

- 1~3단계는 완료 상태로 유지한다. 기존 `PuzzlePlayDebugView`는 임시 IMGUI 표시이며 이번 단계에서 실제 게임 UI로 대체한다.
- `PuzzleGameSession`은 초기화한 LevelDefinition 사본을 반환하며 재초기화를 막는다. 다시하기는 씬의 기본 레벨을 다시 여는 방식이 아니라, 최초 입력의 직렬화 스냅샷과 같은 시드로 세션 내부에서 보드를 재구성한다.
- 기존 `BoardActionExecutor.UseItem`과 대상 선택 규칙을 재사용한다. 고물 망치·자리 바꾸기·섞기는 이번 단계에서 시험용 수량 무제한으로 명시한다. 상용 재고나 목업의 예시 수량을 실제 보유량처럼 표시하지 않는다.
- 가로는 좌측 이동 수/미션, 중앙 보드, 우측 아이템, 세로는 상단 이동 수/미션, 중앙 보드, 하단 아이템을 따른다. 안전 영역과 실제 보드 크기에 맞춰 여백·크기를 조절한다.
- 목업의 광고·보상·상점·다음 레벨 등 연결되지 않은 기능은 실행 버튼으로 제공하지 않는다. 이번 결과 화면의 실제 행동은 같은 레벨 다시하기다. Editor 복귀는 기존 Unity Play 종료를 사용한다.

## 사용자 흐름

1. 기존 게임 플레이 진입 후 로딩/오류를 UI로 확인한다. 준비가 끝나면 레벨 번호, 남은 이동 수, 미션 이미지·진행/목표가 실제 상태와 일치한다. 미션 설명은 눌러 확인할 수 있고 닫을 수 있다.
2. 망치는 한 칸, 자리 바꾸기는 두 칸을 선택한다. 유효 대상 판정은 기존 실행기를 따른다. 섞기는 버튼으로 한 번 실행한다. 선택 안내·취소·선택 강조를 제공하고 선택 중 일반 교환/파워 발동을 겹쳐 실행하지 않는다.
3. 일시정지는 진행 중 연쇄 처리까지 멈춘다. 재개는 그 상태에서 이어진다. 선택/드래그는 팝업 진입 시 취소한다. 전역 Time.timeScale을 바꿔 UI까지 멈추지 않는다.
4. 승리/실패 결과는 실행기의 종료가 확정되고 라스트팡 등 후속 처리가 끝난 뒤 한 번 표시한다. 결과 뒤 보드 입력은 차단한다.
5. 일시정지/결과 화면에서 다시하기를 누르면 최초 선택 데이터와 같은 시드로 시작한다. 외부 에셋/팩이 변경돼도 현재 판의 재시작 입력은 바뀌지 않는다. 초기화 중 연타는 한 번만 처리한다.
6. 회전/크기 변경은 UI와 카메라 배치만 갱신한다. 이동 수·미션·보드·난수 진행·일시정지 상태는 유지하고 진행 중 포인터는 취소한다.

## 산출물

- `Assets/Prefabs/UI/Puzzle/` 아래 화면 루트·HUD·미션 항목·아이템 바·일시정지 팝업·결과 팝업을 기능별 프리팹으로 구성한다.
- 기존 `Assets/Prefabs/Game/Puzzle/` 월드 보드·셀·세션은 역할을 유지한다. UI 프리팹에 게임 규칙이나 레벨 에셋을 넣지 않는다.
- `Assets/Scripts/Features/GameScreen/Runtime/UI/` 표시/배치 코드, 기존 세션/입력의 필요한 연결, 반복 실행 가능한 Editor 생성 및 검증 코드.
- 구현 시 `Docs/Verification/MoonRabbitJunkyard/WorldGameScreen/stage-04-progress.md`와 `Docs/Guides/MoonRabbitJunkyard/WorldGameScreen/stage-04-mockup-ui-usage.md`를 작성한다.

## 완료 조건

- [x] Unity 컴파일 오류 없이 기능별 UI/Game 프리팹과 씬 연결이 완성된다. 기존 GUID를 보존한다.
- [x] 확정 이미지·한국어 글꼴을 사용하고 HUD가 실제 이동 수/미션을 표시한다. 임시 IMGUI와 중복되지 않는다.
- [x] 1280×720, 450×800, 450×975, 600×800에서 UI/보드가 잘리거나 겹치지 않는다. 안전 영역 모의 검사와 가로↔세로 실제 Game View 변경 증거가 있다.
- [x] 버튼·팝업·미션 설명을 누르거나 보드에서 UI 위로 드래그를 끝내도 게임 행동이 실행되지 않는다. 마우스/터치와 다중 포인터 중복을 확인한다.
- [x] 세 아이템의 성공·잘못된 대상·취소·연타를 확인한다. 이동 수와 피해/교환/섞기 규칙은 기존 실행기 결과와 같다.
- [x] 연쇄 처리 도중 일시정지한 상태가 여러 프레임 유지되고 재개 후 동일한 결과로 끝난다.
- [x] 승리/이동 소진 실패가 각각 올바르게 표시되고 라스트팡 완료 전 결과 팝업이 뜨지 않는다.
- [x] 에셋/MemoryPack 각각 다시하기가 최초 입력·시드를 재현한다. 원본 파일/미저장 편집값은 보존되고 UI 구독·아틀라스·사본이 누적되지 않는다.
- [x] 기존 게임 실행·편집창 왕복·이미지 수명 검사를 통과한다. 보드의 일반/파워/장애물 이미지가 유지된다.
- [x] 가로·세로, 아이템 선택, 일시정지, 승리/실패의 실제 화면 증거와 검증 기록이 있다. 실행하지 않은 빌드/실기기 항목을 명시한다.

## 제외 범위

신규 게임 규칙, 새 이미지 생성, 상세 이펙트/애니메이션, 상용 아이템 재고, 광고·결제·보상 지급, 메인 메뉴·다음 레벨 이동·앱 재시작 복구, 5단계 전체 빌드/실기기 통합 검증은 제외한다. 50레벨 MemoryPack과 Addressables 분할을 유지한다. 이 문서 작성으로 목표를 활성화하거나 구현하지 않는다.
