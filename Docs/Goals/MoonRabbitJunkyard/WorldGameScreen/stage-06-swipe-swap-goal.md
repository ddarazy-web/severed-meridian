## 목표와 현재 근거

월드 게임 화면에서 손가락 또는 마우스로 블록을 밀면 손을 떼기 전에 인접 칸과 교환하고, 실제 움직임과 실패 복귀를 보여준다. 게임 규칙과 같은 시드의 결과를 유지하면서 다음 단계의 낙하 연출을 연결할 최소 재생 경계를 마련한다.

현재 PuzzleBoardInput은 EndPointer에서 0.25칸 이상 드래그를 판정한다. PuzzleGameSession.TrySwap은 실행기 결과를 즉시 Draw하고 Update마다 다음 연쇄를 진행한다. PuzzleWorldBoard는 칸에 고정된 표시를 갱신한다. 따라서 입력 구현 전체를 대체하거나 규칙 실행기를 다시 만들지 않는다.

## 확정 동작

1. 블록을 누른 뒤 보드 로컬 좌표에서 우세한 축으로 움직인다. 최대 축 변위가 **0.25칸 이상**이면 인접 한 칸 교환을 한 번 요청한다. 같은 크기의 대각선은 기존대로 가로를 우선한다. 확정 전 이동 표시는 최대 0.24칸으로 제한한다.
2. 임계값 전에 놓으면 표시를 원위치로 돌리고 기존 탭 선택/두 칸 탭 교환/파워 탭 발동을 유지한다. 마지막 위치가 Ended에서만 전달되는 짧은 제스처도 처리한다. 확정 후 Ended·합성 마우스·추가 손가락이 같은 행동을 재실행하지 않는다.
3. 유효 교환은 두 점유자가 약 **0.15초** 동안 반대 칸으로 이동한다. 앞서 이동한 미리보기 위치에서 이어져야 한다. 수치는 초기 조정값이며 판정 규칙이 아니다. 한 번의 교환은 이동 수를 한 번 소비한다.
4. ActionQuery의 **NoNewMatch**만 두 블록이 교환 위치까지 갔다가 약 0.15초에 돌아오는 실패 연출을 사용한다. 벽·비활성 칸·빈칸·고정 장애물·덮인 블록·자석 제한은 넘어가는 연출 없이 짧은 거절 반응을 준다. 실패는 보드·이동 수·난수·미션을 바꾸지 않는다. 거절 판단에 메시지 문자열을 사용하지 않는다.
5. 일반 블록·파워뿐 아니라 기존 규칙이 교환을 허용하는 고철과 회수 부품도 처리한다. 바닥·먼지·덮개·벽·2×2 고정 장애물은 따라 움직이지 않는다. 장애물 본체가 별도 렌더러인 경우도 점유자 표시를 정확히 찾는다.
6. 실행기의 교환·첫 매칭 결과는 기존처럼 한 번 계산한다. 계산 전 표시를 보존해 교환부터 보여주고, 재생 완료 후 계산 결과를 화면에 반영한 다음 연쇄를 진행한다. 연출 코드에서 규칙·난수를 재계산하거나 복구용 역교환을 실행하지 않는다.
7. 교환·실패 복귀 중 보드와 아이템 입력을 잠근다. 입력 예약은 하지 않는다. CanAcceptInput은 규칙상 Ready와 표시상 재생 완료를 모두 확인한다. 미션·승패 표시가 교환 연출보다 먼저 튀어나오지 않게 Changed 통지를 정렬한다.
8. 일시정지는 재생 시간도 멈추고 재개 시 이어진다. 확정 전 포커스 상실·UI 진입·회전은 제스처와 미리보기만 취소한다. 확정된 행동은 취소 입력으로 롤백하지 않는다. 회전 중 확정된 연출은 로컬 좌표로 유지하고, 재시작·씬 종료는 재생을 종료해 이전 세션의 콜백이 새 세션을 건드리지 못하게 한다.

## 범위와 제약

- ServeredMeridian만 사용한다. 기존 변경·미저장 씬/레벨·meta/GUID를 보존하고 자동 커밋·푸시하지 않는다.
- **플레이어 빌드와 Addressables 콘텐츠 빌드를 모두 금지한다.** 빌드를 호출하는 통합 검사나 콘텐츠 생성 진입점도 실행하지 않는다. Unity의 일반 스크립트 컴파일과 Editor Play Mode 검증만 사용한다.
- 필요한 기존 번들이 없으면 빌드로 우회하지 않는다. 부작용을 확인한 AssetDatabase 기반 재생 등 안전한 Editor 경로를 사용하고, 불가능한 검증은 미검증으로 남긴다. 사용자 설정을 변경했다면 복원한다.
- MemoryPack 50레벨 묶음, 분할 아틀라스, 데이터 포맷, 기존 UI/Game 프리팹 구분을 유지한다. 새 패키지·이미지·Physics2D 낙하·범용 연출 프레임워크는 추가하지 않는다.
- 적용 대상은 게임 씬의 월드 보드다. 배치·수정용 에디터 보드와 기존 IMGUI 플레이 테스트에 스와이프 연출을 이식하지 않는다.
- 낙하·공급·매칭 제거의 시간 연출은 **7단계**, 파워 상세 효과는 **8단계**, 소리·진동·미션 수집 연출은 **9단계**다. 6단계 교환 후에는 기존 결과 갱신·연쇄 방식을 유지한다.

## 완료 조건

- [x] 마우스와 Input System 터치에서 4방향, 0.24/0.25칸 경계, 같은 크기의 대각선, 빠른 Ended-only 이동을 확인한다. 손을 떼기 전에 한 번 확정된다.
- [x] 미리보기→교환→결과 표시를 중간 프레임에서 관찰할 수 있다. 두 탭 교환과 파워 탭·스와이프의 구분도 유지된다.
- [x] NoNewMatch는 왕복하고 다른 거절 사유는 통과하지 않는다. 모든 거절에서 보드·RNG·이동 수·미션이 동일하다.
- [x] 일반/파워 조합/이동 가능한 고철/회수 부품과 고정된 레이어를 확인한다. 기존 실행기로 같은 입력을 처리한 최종 결과와 일치한다.
- [x] 손을 계속 누르기, 연타, 두 번째 터치, 합성 마우스, UI 시작·이동, 재생 중 아이템 선택이 중복 행동을 만들지 않는다.
- [x] 일시정지 중 위치·재생 시간이 유지되고 재개 시 이어진다. 회전·포커스 상실·5회 다시하기·씬 종료 후 표시 잔상, 잠금 잔류, 이전 콜백이 없다.
- [x] 영향받는 기존 검사와 신규 시간/입력 검사가 Editor에서 통과한다. 실제 화면의 유효/무효 교환을 연속 캡처 또는 영상으로 남기고 육안 확인한다. 정지 화면 한 장을 움직임 검증으로 대신하지 않는다.
- [x] 가로·세로에서 입력과 표시를 확인하고 데이터/GUID·설정 보존 및 문서 링크를 검사한다. 검사 환경·실행 시각·실패/미검증 항목을 기록한다. 실기기 검증은 별도로 구분한다.
