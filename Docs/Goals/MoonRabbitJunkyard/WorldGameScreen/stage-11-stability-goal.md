# 11단계 목표·완료 조건 — 반복 플레이와 성능 안정화

상태: 4개 작업·12개 완료 조건·독립 리뷰 처리 완료 (2026-10-02). [실행 증거](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-11-progress.md). 실제 청취·실기기 검증은 제외/미수행으로 기록한다.

[작업 계획](../../../Planning/MoonRabbitJunkyard/WorldGameScreen/stage-11-stability-plan.md) · [복사용 목표 명령문](../../../Commands/MoonRabbitJunkyard/WorldGameScreen/stage-11-goal-command.md)

## 목표

1~10단계의 실제 게임 화면을 반복 플레이해도 입력 잠금·표시 잔류·오래된 소리·리소스 누적 없이 사용할 수 있게 안정화한다. 연출 시간과 재사용 현황을 먼저 측정하고, 재현된 결함과 측정으로 확인한 병목만 최소 수정한다.

## 시작 근거와 결정

- 10단계는 완료 조건 12개 감사와 독립 리뷰 수정을 끝냈다. 새 효과음 1617 PASS, 같은 실행 시기의 관련 회귀 1875 PASS다. 시작 시 [실행 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-10-progress.md)과 현재 코드·로그가 일치하는지 확인한다. 과거 실적을 11단계 검사 수로 합산하지 않는다.
- `PuzzleWorldBoard`는 cells/bodies/decorations/supplyImages/supplyClips/effects를 재사용한다. HUD 수집과 소리는 이미 재사용 구조가 있다. 새 범용 풀·전역 Manager를 만들지 않는다.
- 로드맵의 속도 조정은 현재 연출의 시간·대기 원인을 관찰하는 것으로 시작한다. 사용자 확정 낙하·드론 속도를 임의로 변경하지 않는다. 불필요한 정지가 실제로 재현될 때 해당 원인만 수정한다.
- 재사용 수용 기준은 동일 레벨·시드·동일 행동 시퀀스의 5회 워밍업 이후 추가 5회에서 풀 용량이 계속 증가하지 않는 것이다. 다른 맵의 최대 동시 표시량이 늘면서 풀 용량이 증가하는 것은 누수로 단정하지 않는다.
- 성능은 Editor 기준 관찰이다. 기기 FPS·메모리 예산을 새로 정하거나 Editor 결과로 모바일 성능을 보장하지 않는다. 실제 소리 청취는 가능하면 별도 기록하되 수행하지 못하면 미검증으로 남긴다.

## 보존·제외 기준

ServeredMeridian만 작업한다. 9×9, 일반 블록·2×2 크기, 가로 로켓 크기/중앙 보정, 스와이프 최상위 order 및 복원, 범위 칸 수에 따른 2×2 피해를 보존한다.

낙하·공급 시간 /1.44, 기존/신규 블록 동시 낙하·공급 대기, 신규 생성 블록만 대각선·상단 공급 우선, 소수 드론 상승/대기/돌파와 조합 드론 반지름 1~4칸 선회·경로 분산·표적 예고 없음도 유지한다. 비교 기준은 과거 문서가 아닌 착수 시 최신 코드다.

14종 합성 효과음·최대 8음성·같은 종류 .06초 제한·결과/미션 우선·실제 드론/자석 타격 시각·다중 미션 완료음 우선·교환 아이템음·백그라운드 복귀의 미래 결과음을 보존한다. 수정한 교환·섞기 아이콘의 256×256 투명 이미지와 기존 GUID도 보존한다.

50레벨 MemoryPack/Asset 시험, 필요한 이미지 종류만 Addressables 로드하는 구조를 유지한다. UI 프리팹은 Assets/Prefabs/UI/Puzzle, 게임 프리팹은 Assets/Prefabs/Game/Puzzle 아래 기능별로 유지한다. 전체 씬·아이템 바를 재생성하지 않는다.

진동·새 게임 규칙·저장 DTO·BGM·설정 창·상용 음원·광고·과금·플랫폼 설정·새 패키지·새 성능 프레임워크·앱 종료 복구를 추가하지 않는다. 플레이어/Addressables 콘텐츠 빌드와 이를 내부 호출하는 검사는 실행하지 않는다. 커밋·푸시·사용자 Unity 강제 종료·미저장 씬 자동 저장·원본 레벨 변경은 금지한다. 다음 목표를 자동 생성하지 않는다.
