# 레벨 튜토리얼 4단계 — 목표·완료 조건

상태: 준비. 3단계 완료 후 다음 사용자 실행 지시로 착수한다.

[계획](../../../Planning/MoonRabbitJunkyard/Tutorial/stage-04-guidance-plan.md) · [실행문](../../../Commands/MoonRabbitJunkyard/Tutorial/stage-04-command.md).

## 목표

기존 실제 게임 연결 위에 안내 화면·레벨별 완료 기록·시험 3모드를 추가한다. 기존 1레벨에 기본 매칭 안내를 적용하고 Asset/MemoryPack 진입에서 같은 동작을 확인한다.

## 완료 조건

- [ ] 기존 Canvas/uGUI의 강조·말풍선·손가락·다음·무료 체험이 실제 화면에 표시된다. UI는 공통 엔진/세션 권한을 재구현하지 않는다.
- [ ] 장식이 지정 보드 입력을 가로채지 않는다. 설명/행동/연출 대기, 임의 입력 거절, 지정 아이템 선택·대상 입력을 실제 UI로 확인한다. 드론 목적지를 미리 노출하지 않는다.
- [ ] 가로/세로·화면 크기·Safe Area·카메라 변경에 좌표/배치가 맞는다. 팝업·정지 중 진행 보류, 최상위 키 이벤트, 일시정지/나가기를 유지한다.
- [ ] 마지막 단계와 관련 표시 완료 후 레벨별 완료를 1회 저장한다. 중단/실패/취소는 저장하지 않고 재진입은 처음부터 고정 재현한다.
- [ ] 완료한 자동 실행은 원본 데이터를 바꾸지 않고 일반 시드/공급으로 생략한다. 재시작·다음 레벨에도 정책과 저장 문맥을 유지한다.
- [ ] 에디터 자동/항상 실행/실행 안 함을 전달한다. 시험 기록은 실제 기록과 분리되며 시험 전후 실제 완료/보유량이 같다.
- [ ] 재시작·전환·실패·취소·파기의 UI/구독/기록 대기를 정리한다. 이전 완료 신호가 새 레벨/기록을 변경하지 않는다.
- [ ] 기존 1레벨에 기본 매칭 튜토리얼만 적용한다. 보드/미션/이동/흐름/색상/GUID와 기획 소개 순서를 유지하고 없는 출시 레벨은 생성하지 않는다.
- [ ] 해당 구간 팩만 기존 도구로 갱신하고 구간 내 기존 레벨·팩1/2/3·주소·50레벨 분할·ECPK·제작 SO 배포 제외를 보존한다. Asset/팩3 실제 안내와 진행이 같다.
- [ ] 신규 `TutorialGuidanceVerification.Run`, 기존 튜토리얼/일반 게임/드론/결과·팝업 회귀와 테스트 해제 후 게임 소스 컴파일을 확인한다. 실제 UI/저장 검사를 모의/논리 검사와 구분한다.
- [ ] 실제 검증 근거·제약·등록/표현/기록 확장 방법을 보고하고 4단계 진행 기록에 저장한다. 다음 작업을 자동 시작하지 않는다.

빌드·번들·커밋·푸시는 하지 않는다. 상세 매뉴얼·없는 소개 레벨 제작·계정/재고 시스템·고물탑은 이 목표에 포함하지 않는다.
