## 목표

기획의 네 단계와 조건・고정 공급을 레벨 에디터에서 작성하고 SO/MemoryPack/실행 요청에서 동일하게 보존한다. 게임 내 진행/안내는 포함하지 않는다.

## 완료 조건

- [x] 네 단계 종류·설명·강조/행동/결과 조건·고정 시드/공급을 저장한다.
- [x] 단계 추가·삭제·정렬·보드 대상 선택·방향 표시가 동작하며 선택이 일반 배치/삭제로 오작동하지 않는다.
- [x] 저장/재로드·Undo/Redo의 값 보존과 레벨/단계/창 전환의 선택·구독 수명을 검증한다.
- [x] 정적 오류의 단계 경로·원인을 표시한다. 후속 생성 대상과 초기 대상을 구분하고 미래 보드 재생은 미검증으로 명시한다.
- [x] 팩3의 전체 값 왕복, 팩1/2 읽기와 잘못된 데이터 거절을 확인한다. 튜토리얼 없는 기존 결과·지문·팩 바이트는 같다.
- [x] 초기 미배치의 튜토리얼 공급/결과 참조와 생성되는 정의도 팩에 포함되고 복원 시 누락 ID를 거절한다.
- [x] Copy/Snapshot/JSON/실행 요청·입력 식별에서 메타데이터가 빠지지 않는다. 구형 쓰기로 조용히 버리지 않는다.
- [x] 1/50/51/100/101·혼합 구간·중복/누락 메타데이터와 Asset/MemoryPack 동등을 검증한다. 기존 주소·50레벨·ECPK·제작 SO 배포 제외를 유지한다.
- [x] 원본 레벨·디스크 팩·GUID·WIP·과거 출력을 보존하고 관련 검사/게임 소스 컴파일의 실제 성공을 확인한다.
- [x] 빌드·커밋·푸시·사용자 Unity 종료·임의 씬 저장이 없으며 완료 보고/검증 기록/다음2단계 계획·목표·복사용 실행문을 작성한다.

필드만 추가하고 편집/저장에서 값을 버리는 상태, 미래 파워를 초기 보드에 없다고 거절하는 상태, 원본을 덮어써 비교 기준을 없애는 상태는 완료가 아니다.
