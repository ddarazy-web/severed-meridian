## 목표

등록식 튜토리얼 엔진을 실제 퍼즐에 연결한다. 지정 행동·고정 공급·실제 결과·연출·종료를 제어하고 같은 보드에서 일반 플레이로 복귀한다.

## 완료 조건

- [x] 레벨 파기 전 실행 사본을 확보하고 고정 시드/공급으로 재진입·재시작을 재현한다. 원본은 유지한다.
- [x] 선택/스와이프/아이템과 세션 직접 명령에 동일 허용 검사를 적용한다. 거절은 이동/미션/난수/권한을 바꾸지 않는다.
- [x] 실제 행동/연쇄에서 종류·정의 ID·개체/발생 식별·좌표를 전달한다. 로켓 생성→발동, 2×2 중복·재보충·뒤늦은 드론·양방향 교환을 검사한다.
- [x] 실제 연쇄·드론·낙하·피해·수집 표시 완료를 기다린다. 일시정지/팝업/나가기와 이전 세션 신호 격리를 유지한다.
- [x] 공급 부족/누락·후속 대상 소실·불가능한 교환·결과 불충족을 단계별로 진단한다. 무작위/자동 섞기/가짜 성공으로 숨기지 않는다.
- [x] 조기 승리·라스트팡·이동 소진·자동 섞기를 보류하고 튜토리얼 완료 후 한 번 재평가한다. 곰팡이 턴 종료를 중복 적용하지 않는다.
- [x] 이동 0의 마지막 설명과 필요한 무료 체험을 허용하되 추가 교환·일반 아이템의 우회는 막는다. 무료 체험은 성공 시 한 번 소진하고 실제 재고 시스템은 새로 만들지 않는다.
- [x] 일반 공급 복귀 때 보드/내구도/미션/이동/턴/난수를 보존한다. 전환 자체로 생성하지 않는다.
- [x] 시작 실패·재시작·다음 레벨·취소/파기의 엔진·사본·ticket·구독·대기를 정리한다.
- [x] 실제 재생 검사와 에디터/실행 전 오류 표시를 연결하고 원본은 수정하지 않는다.
- [x] Asset/팩3 동등·실제 게임 경계·관련 회귀·테스트 해제 후 게임 소스 컴파일·원본/GUID/HEAD/WIP 보존을 확인한다.
- [x] 검증 근거와 제약을 보고하고 4단계 계획·목표·복사용 실행문을 작성한다. 다음 구현은 자동 시작하지 않는다.

안내 UI·영구 완료 기록·시험 3모드·대표 레벨 적용은 4단계다. 빌드·커밋·푸시·출시 데이터 덮어쓰기는 하지 않는다.
