## 목표

제작자가 대상 셀/개체/종류/영역을 선택해 내구도·제거·파워·아이템·미션 조건과 샘플을 조립할 수 있게 한다.

## 완료 조건

- [x] 남은 내구도 비교와 조합 공격 제거 원인의 미확정 의미를 먼저 확정.
- [x] 대상 추적과 영역 사건 필터가 동작하고 대상 소실/불가능한 요구를 진단.
- [x] 내구도 합계/각각, 지정 원인 제거, 생성 위치/종류, 직접 단독 발동/조합, 아이템/미션 조건 제공.
- [x] 생성 결과를 다음 단계에서 동일 개체로 연결.
- [x] 영역 조작·유효 안내 갱신·무료 체험·이동 소진/안내 오류 종료 처리 검증.
- [x] 대응 기본 샘플과 예상 결과가 있으며 실제 레벨 튜토리얼은 임의 제작하지 않음.
- [x] 새 형식과 기존 팩 호환, Asset/MemoryPack 동등성, 1단계 회귀 검사 통과.
- [x] 실제 에디터/게임 결과와 미검증 사항 보고, 3단계 계획·목표·실행문 제공.

빌드·커밋·푸시·하위 에이전트 없이 진행한다. 공유 흐름 일괄 편집과 기존 전체 콘텐츠 전환/구형 경로 제거는 3단계다.
