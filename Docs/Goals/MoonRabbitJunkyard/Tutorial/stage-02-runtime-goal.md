상태: 완료. 2026-10-07 구현·검증 완료. 실제 게임 연결은 새 3단계다.

## 목표

공통 진행과 종류별 행동/완료 조건을 분리한다. 기존 데이터·저장·제작을 보존하며 필요한 처리기만 등록·조회하고 중앙 진행 수정 없이 추가/교체할 수 있음을 검사한다.

## 완료 조건

- [x] 네 단계·세 결과를 등록한다. 망치/교환/섞기 규칙도 중앙 진행부 밖에서 선택한다.
- [x] 현재 행동/명시된 조건만 조회하고 미사용 처리기 호출은 0이다. 중복/미등록을 진단하고 전역 가변 목록·실행별 상태 공유가 없다.
- [x] 엔진은 진행·승인·결과/연출 대기·완료/오류/취소만 소유하며 게임 실행·UI·Addressables를 직접 참조하지 않는다.
- [x] 승인과 성공을 구별하고 관련 성공·조건·연출 완료 후 한 번만 진행한다. 지연/중복/과거/취소 신호는 다른 단계에 영향을 주지 않는다.
- [x] ID·좌표·수량과 개체 식별로 판정하고 2×2 중복·재보충을 처리한다. 같은 특성의 서로 다른 장애물 ID에 동일 판정기를 사용한다.
- [x] 체험 권한은 해당 단계 성공 시 1회 소진하고 거절/실패/취소에는 소진하지 않는다. 다른 단계/세션에 남기지 않는다.
- [x] 설명 다음·일시정지/재개·튜토리얼 없음·동시 세션 격리·취소/해제와 읽기 전용 상태/진단을 검사한다.
- [x] 종류별 검사·참조 수집을 실행 규칙과 공유한다. validator 공개 API·에디터 오류·최초 대상 검사·팩 참조 폐쇄를 보존한다.
- [x] 시험 전용 처리기/판정기를 별도 목록에 등록하여 중앙 엔진 수정 없이 실행한다. 기본 목록의 미등록은 오류이며 전체 검색으로 대체하지 않는다.
- [x] enum 값·MemoryPack 필드·팩1/2/3·50레벨 주소를 유지한다. 데이터/에디터/저장 회귀·원본/GUID·테스트 해제 후 게임 소스 컴파일을 확인한다.
- [x] 실제 검사 기록과 변경·제약·확장 방법을 보고한다. 3단계 계획·목표·복사용 실행문을 작성하되 자동 착수하지 않는다.

새 저장 항목/제작 입력이 필요한 확장은 별도 호환성 작업이 필요하다. 처리기 추가 검사를 모든 기능의 데이터만으로 추가 가능하다는 의미로 해석하지 않는다.

실제 게임 연결·고정 공급 적용·승리 보류·실제 행동 재생은 3단계, 안내 UI·영구 기록·시험 3모드·대표 레벨 적용은 4단계다. 모의 신호 검사를 실제 게임 검증으로 보고하지 않는다. 빌드·커밋·푸시·출시 데이터 변경은 없다.
