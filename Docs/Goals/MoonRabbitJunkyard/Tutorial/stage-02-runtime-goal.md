# 레벨 튜토리얼 2단계 — 목표·완료 조건

상태: 준비, 구현 미착수.

[계획](../../../Planning/MoonRabbitJunkyard/Tutorial/stage-02-runtime-plan.md) · [실행문](../../../Commands/MoonRabbitJunkyard/Tutorial/stage-02-command.md).

## 목표

레벨에 등록된 안내를 기존 실제 퍼즐에서 지정 행동·결과·연출 완료에 따라 진행한다. 완료하면 같은 보드의 상태를 유지한 채 자유 플레이 또는 기존 승리 흐름으로 이어간다.

## 완료 조건

- [ ] 설명/교환/파워 교환/아이템의 진행 상태·현재 단계·허용 입력·오류를 조회한다.
- [ ] 지정 입력만 허용하며 세션 직접 호출로도 우회하지 못한다. 거절은 게임/단계/체험 권한을 변경하지 않는다.
- [ ] 고정 시드와 공급이 재현되고 원본은 보존된다. 부족/누락 공급과 불가능한 후속 대상을 진단하며 무작위/자동 섞기로 숨기지 않는다.
- [ ] 실제 생성·발동·제거 기록의 ID/좌표/수량을 검사한다. 2×2 제거 중복·재보충·후속 파워를 올바르게 처리한다.
- [ ] 논리 연쇄와 드론·낙하·피해·수집 표시를 기다리고 완료 신호 중복에 안전하다. 팝업·일시정지·나가기를 유지한다.
- [ ] 조기 목표 달성/라스트팡을 마지막 단계와 연출 완료까지 보류하고 한 번만 종료한다. 이동 0의 마지막 안내를 진행하고 추가 교환을 막는다.
- [ ] 지정 아이템 무료 권한은 성공 시 1회 소진되고 다른 단계/일반 플레이로 남지 않는다. 전체 인벤토리를 새로 만들지 않는다.
- [ ] 종료 후 셀·내구도·미션·이동·턴·난수를 유지하며 일반 공급으로 전환한다. 재시작/다음 레벨/취소/파기의 대기·구독을 정리한다.
- [ ] 실제 재생 검사를 에디터/실행 전 검사에 연결하고 소유한 입력으로 Asset/MemoryPack·성공/거절/중단/연출 지연·기존 일반 플레이 회귀를 검증한다.
- [ ] 실제 검증과 게임 소스 컴파일을 기록하고 완료 보고 및 3단계 계획·목표·복사용 실행문을 작성한다. 빌드·커밋·푸시·출시 데이터 변경과 3단계 자동 착수는 없다.

안내 화면·영구 완료 저장·에디터 시험 3모드·출시 레벨 적용은 3단계다. 화면을 숨기기만 하고 종료 판정/라스트팡이 먼저 실행되는 상태는 완료가 아니다.
