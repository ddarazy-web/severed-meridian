# 조합형 튜토리얼 3단계 목표

상태: 계획 수립 · 미실행

[계획](../../../Planning/MoonRabbitJunkyard/Tutorial/composer-03-plan.md) · [기획](../../../Contents/MoonRabbitJunkyard/15_조합형튜토리얼.md) · [실행문](../../../Commands/MoonRabbitJunkyard/Tutorial/composer-03-command.md)

## 목표

공유 튜토리얼 흐름을 레벨별 대상·수치에 연결하고 사용자 샘플을 재사용할 수 있게 한다. 완료 기록은 전체 튜토리얼 ID로 분리하며, 기존 자료를 검증 가능한 사본으로 전환해 하나의 진행 엔진으로 정리한다.

## 완료 조건

- [ ] 연결 계약·완료 ID 매핑·기존 의미 보존 방식을 구현 전에 확정한다.
- [ ] 같은 흐름을 두 레벨에 서로 다른 값으로 연결하고 서로의 데이터가 변경되지 않는다.
- [ ] 공유 흐름 편집 시 참조 레벨 목록/영향 검증/오류 이동이 동작한다.
- [ ] 사용자 샘플 저장·미리보기·복사 적용·취소·Undo/Redo·재로드가 동작한다.
- [ ] 튜토리얼 ID와 템플릿/단계/생성 연결 ID가 구분되며 에디터 기록은 플레이어 기록을 바꾸지 않는다.
- [ ] 팩에는 해석된 실행 데이터만 저장하며 기존 팩3/4/5를 읽을 수 있다.50레벨 묶음과 Addressables 정책 유지.
- [ ] 실제1~4레벨을 덮어쓰지 않은 전환 사본에서 이전/새 실행 결과와 공급·이동·연출 경계가 같다.
- [ ] 중복된 구형 진행 코드를 제거하고 호환 읽기만 유지한다. 실제 에셋은 별도 반영 요청 없이는 변경하지 않는다.
- [ ] 실제 편집/게임 통합, 일반 플레이 회귀, 테스트 제외 에디터 컴파일과 데이터 보존 확인을 통과한다.
- [ ] 결과와 한계를 보고하고 후속 작업이 있다면 다음 계획·목표·복사 가능한 실행문을 제공한다.

빌드·커밋·푸시·하위 에이전트는 실행하지 않는다. 실제 레벨의 새 튜토리얼을 대신 제작하지 않는다.
