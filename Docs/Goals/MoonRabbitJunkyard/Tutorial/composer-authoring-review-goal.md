# 조합형 튜토리얼 후속 목표 — 사용자 제작 흐름 점검

상태: 대기. [계획](../../../Planning/MoonRabbitJunkyard/Tutorial/composer-authoring-review-plan.md)

## 목표와 완료 조건

사용자가 레벨 에디터에서 직접 조립하면서 겪는 문제를 실제 사례로 확인하고 필요한 부분만 개선한다.

- [ ] 사용자가 선택한 대상에서 샘플 → 셀 연결 → 수치 설정 → 검사/게임 시험의 결과를 확인한다.
- [ ] 공통 원본과 레벨별 값의 소유권, 독립 복사, 완료 ID의 의미가 메뉴와 툴팁에서 구분되는지 확인한다.
- [ ] 확인된 문제는 재현 후 수정하고 해당 경로를 재검증한다. 문제가 없다면 불필요한 소스 변경을 하지 않는다.
- [ ] 실제 레벨·출시 팩·플레이어 기록 보존과 검사 범위를 보고한다.

HTML 매뉴얼은 별도 요청 전에는 수정하지 않는다. 실제 튜토리얼을 대신 제작하지 않는다. 빌드·커밋·푸시는 금지한다.
