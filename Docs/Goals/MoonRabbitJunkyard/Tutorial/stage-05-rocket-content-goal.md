# 튜토리얼 후속 5단계 — 목표·완료 조건

상태: 완료. 2026-10-07. 실제 2레벨 적용과 완료 감사를 마쳤다. 관련 회귀 통과와 기존 드론 종합 검사 실패의 구분은 진행 문서를 따른다.

[계획](../../../Planning/MoonRabbitJunkyard/Tutorial/stage-05-rocket-content-plan.md) · [실행문](../../../Commands/MoonRabbitJunkyard/Tutorial/stage-05-command.md).

## 목표

실제 레벨 2에서 직선 4매칭으로 청소로켓을 만들고 교환 발동을 체험한 뒤 같은 보드로 자유 플레이를 이어간다. Asset과 MemoryPack에서 동일하게 동작하며 레벨별 완료 기록/시험 정책을 재사용한다.

## 완료 조건

- [x] 현재 제작 스키마/요소 카탈로그를 사용하는 `Level_02.asset`과 신규 메타가 존재한다. 레벨 번호 2, 전체 9×9 보드이며 기존 1레벨·사용자 변경·GUID를 보존한다.
- [x] 설명→로켓 생성 교환→생성 설명→로켓 교환 발동→종료 설명의 5단계가 실제 보드에서 진행된다. 더블터치·제자리 발동을 안내로 추가하지 않는다.
- [x] 가로 4매칭의 실제 생성 결과가 세로 로켓 하나임을 확인한다. 지정 교환 발동의 실제 줄 제거와 문구/표시 방향이 일치한다.
- [x] 고정 좌표·시드·생성구·공급이 실제 재생 검사에서 성공한다. 낙하/연쇄 후 생성 로켓과 교환 대상이 유지되고 공급 누락/불가능한 안내는 거절한다.
- [x] 두 교환이 각각 이동 1회를 차감하며 미션은 실제 결과만 집계한다. 단계 진행과 마지막 완료 기록은 관련 표시 종료를 기다린다.
- [x] 실제 다음 버튼/보드 포인터만으로 진행한다. 비지정 교환/발동은 거절하고 장식은 입력을 가로채지 않는다. 두 화면 비율에서 강조/손가락/말풍선이 대상과 교환 경로를 가리지 않는다.
- [x] 완료 후 같은 보드·누적 미션·이동·난수를 보존하며 일반 공급으로 돌아가고 정상 일반 조작이 가능하다. 튜토리얼만으로 미션 전체가 끝나는 후보는 채택하지 않는다.
- [x] 실제 에디터의 2레벨 선택→게임 플레이로 Asset/MemoryPack 진입이 가능하고 실제 생성·발동·최종 상태가 동등하다.
- [x] 미완료 자동 실행/중단 재진입/완료 1회/자동 생략/시험 3모드·레벨 1과의 기록 분리가 실제 검사에서 확인된다. 1→2 전환의 수명·늦은 신호 격리를 유지한다.
- [x] 승인된 1~50 구간 팩만 기존 인코더로 갱신하고 기존 구간 레벨을 누락하지 않는다. 팩 호환/주소/50레벨 분할/ECPK/제작 SO 배포 제외를 보존한다.
- [x] 신규 콘텐츠 검사와 관련 기존 회귀가 통과하고 과거 검사 출력은 복원된다. 테스트 분리 후 게임 소스 단독 컴파일과 기존 데이터/GUID/HEAD/WIP 보존을 확인한다.
- [x] 진행 문서에 실제 논리/UI/기록 검사 근거와 제약을 구분해 기록하고 보고한다. 완료 후 다음 단계 계획·목표·복사용 실행문을 제공하되 구현은 시작하지 않는다.

## 범위 제한

빌드·번들·커밋·푸시를 하지 않는다. 변경 허용은 신규 2레벨 및 해당 팩, 필요한 검사/문서와 실제 재현된 직접 관련 결함의 최소 수정이다. 다른 출시 레벨·새 이미지·전체 난이도/해금/재고/계정 시스템·상세 매뉴얼·고물탑은 포함하지 않는다. Android/iOS 실기기 미검증은 별도 제약으로 보고한다.
