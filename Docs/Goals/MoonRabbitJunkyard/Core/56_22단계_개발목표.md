## Goal 목표

현재 Unity 프로젝트의 공통 실행기와 Match 수동 시험에 성공/이동 수 소진/진행 불가/실행 중단의 구분, 자동 재배치, 성공 후 라스트팡을 구현한다. 게임 규칙과 기존 편집 기능을 보존하고 실제 UI·결정적 재현·영향 회귀로 아래 완료 조건을 검증한다.

## 실행 지침

1. Goal 상태와 21단계 완료 증거를 먼저 확인한다. 21단계가 미완료이면 이 문서를 실행하지 말고 미완료 선행 조건을 보고한다. 다른 활성 Goal을 덮어쓰거나 임의 완료 처리하지 않는다. 동일한 22단계 Goal이 활성 상태면 이어서 수행한다.
2. 문서 작성 요청만으로 Goal을 만들지 않는다. 이 문서를 지정한 실행 요청은 상세 계획의 범위·기술 설계에 대한 승인이다.
3. ponytail 및 프로젝트 Unity 지침을 적용하고 T1→T6 순서로 진행한다. 스크립트는 기존 `Assets/Scripts` 구성별로 배치한다.
4. 게임·수동 시험·향후 봇이 공통 실행 규칙을 사용하도록 한다. 현재 레벨 원본, v4 형식, GUID/meta 및 무관 변경을 보존한다.
5. 무작위 재배치 실패와 증명된 진행 불가를 구분한다. 실행 오류·탐색 한도를 일반 패배로 기록하지 않는다.
6. 성공 결과는 라스트팡 전에 한 번 확정한다. 건너뛰기·연출 오류로 성공을 취소하거나 중복 확정하지 않는다. 경제/저장 기능이 구현됐다고 표현하지 않는다.
7. 실제 UI와 독립 Unity 프로세스 재현을 검사한다. 완료 조건별로 증거를 남기고 미검증 항목을 완료로 표시하지 않는다.
8. 22단계만 완료한다. 23단계 아이템/부스터와 봇·통계로 자동 확장하지 않는다.
9. 21단계의 초기 회수 정규화와 공급/드론 경계를 보존한다. 승패 미지원 시절의 회귀 기대값은 새 종료 계약에 맞게 갱신하되 상태·원자성 검사를 삭제하지 않는다.

버전: `board-action-ending-v12`, `shuffle-v1`; 기존 `settlement-recovery-v8`, `recovery-v1` 유지. 재배치 예산은 무작위 256회, 대상 8칸 이하에서만 중복 없는 순열을 최대 4,096개 검사한다. 예산 소진은 불가능의 증명이 아니므로 실행 중단으로 기록한다. 예산을 사용자 설정으로 노출하지 않았다.

### 남은 범위

22단계 완료 조건에 미검증 항목은 없다. 아이템·시작 부스터는 23단계, 전체 수동 플레이 통합은 24단계이며 자동 시작하지 않는다. 실제 재화 지급/반환, 광고, 앱 저장/복구, 출시용 화면·연출, 봇·통계는 이번 단계에서 구현하거나 검증하지 않았다.
