# 27단계 개발 목표 — 반복 실행과 실행 제어

- 상세 계획: [27단계 작업 계획](../../../Planning/MoonRabbitJunkyard/Core/71_27단계_반복실행과제어_작업계획.md).

## Goal 목표

Match에서 기본·계획 봇을 같은 시드 묶음으로 반복 실행한다. 전략별 기본 100회, 합계 200회를 제공하고 횟수 변경·진행률·일시정지·재개·중지·완료 기록 보존·같은 조건 재시험을 구현한다. 기존 공개 관찰과 공통 실행 규칙을 유지하고 제어 경계·재현·UI·기록·원본 보존을 검증한다.

## 실행 지침

1. 현재 Goal과 26단계 완료 증거부터 확인한다. 같은 27단계 Goal이면 이어서 진행하고 다른 활성 Goal은 덮어쓰지 않는다. 26단계 완료 확인 전에는 27단계 구현을 시작하지 않는다.
2. ponytail과 프로젝트 Unity 지침을 적용한다. 미확정 제품 결정만 grill-me로 확인하고 deep-planning은 사용하지 않는다. 이미 합의되었거나 코드로 확인할 내용은 반복 질문하지 않는다.
3. 계획 T1→T6을 진행한다. 기존 한 판 세션을 순차 실행하고 공개 관찰·전략·공통 실행기를 재사용한다. 실제 시드와 내부 기록을 봇 입력으로 전달하지 않는다.
4. 한 묶음의 정의·시드를 고정하고 두 전략에 독립된 같은 시작 조건을 제공한다. 새 시험과 같은 조건 재시험을 구분한다.
5. 일시정지는 처리 객체를 유지하고, 중지는 미완료 판과 완료 기록을 구분한다. 기존 한 판 시험의 안전 중지 규칙을 변경하지 않는다.
6. 판 종료와 후속 처리를 확인한 뒤 기록을 한 번만 확정한다. 오류·중단·미실행을 일반 패배로 처리하지 않는다. 저장 실패와 손상 기록을 숨기지 않는다.
7. 화면 갱신에 실행을 나눠 처리하고 실제 Unity UI에서 제어와 응답성을 검증한다. 26단계의 10×10 계획 한 수 약 9.92초와 단일 처리 지연을 기준으로 갱신 지연·일시정지·중지 반응 시간을 측정한다. 속도를 위해 전략의 탐색 정책을 임의로 줄이지 않는다. 프로세스 종료 후 진행 중 판 복원은 범위에 넣지 않는다.
8. 기본 200판 실행, 독립 프로세스 재현, 제어 경계와 영향 회귀, 원본 보존을 증거로 남긴다. 이전 단계 검사 수를 이번 신규 검증 실적으로 재사용하지 않는다.
9. 복잡한 수명·순서·소유권 로직에 한국어 주석을 작성하고 매뉴얼·툴팁·완료 문서를 갱신한다. 사용자 변경과 Unity 작업을 보존한다.
10. 28~30단계 상세 통계·사례 재생·분석 이력·난이도 추천·전체 통합 검수는 구현하지 않는다. 아래 조건을 증거와 대조한 뒤에만 Goal을 완료한다.

## 완료 조건

- [x] 2. 반복 실행/한 판 세션/전략/화면/기록의 소유권과 정보 경계를 기록했다.
- [x] 3. 전략별 기본 100회와 횟수 변경을 제공하며 입력 범위를 검증한다.

- [x] 5. 두 전략이 같은 정의·시드에서 독립적으로 시작하고 판 사이 상태가 섞이지 않는다.
- [x] 6. 봇은 기존 공개 정보만 보고 공통 규칙·비용·종료 처리로 실행한다.
- [x] 7. 시작 준비·계획 탐색·연쇄·라스트팡·판 사이에서 일시정지하고 같은 상태로 재개한다.

- [x] 9. 실행 중 중지와 종료 직전 중지에서 완료/중단 기록이 중복·누락되지 않는다.
- [x] 10. 성공·정상 패배·막힘·오류·사용자 중단·미실행을 구분하고 일부 실행을 표시한다.
- [x] 11. 판별 확정 기록과 정의·시드·버전을 보존하며 저장 실패를 명시적으로 처리한다.
- [x] 12. 탭 이동·원본 변경·레벨 변경·창 종료·실제 도메인 재로드를 처리하고 완료 기록을 보존한다.
- [x] 13. 원본 또는 버전이 달라진 결과를 현재 조건의 결과로 오인시키지 않는다.
- [x] 14. 실제 Match UI의 실행·일시정지·재개·중지·같은 조건 재시험·진행률을 확인했다.
- [x] 15. 최소 창 크기·도움말·중복 입력·수동 시험과의 입력 소유권을 확인했다.
- [x] 16. 같은 조건의 독립 프로세스에서 행동 기록과 결과를 재현했다.
- [x] 17. 일반/고속·갱신 분할·일시정지 유무가 같은 조건의 결과를 바꾸지 않는다.
- [x] 18. 기본 100개 시드×두 전략의 실제 실행과 대표 경계 사례를 검증하고 총 시간·최대 갱신 지연·일시정지/중지 반응 시간·메모리를 측정했다.
