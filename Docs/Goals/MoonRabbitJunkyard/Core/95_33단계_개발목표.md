# 33단계 개발 목표 — 메뉴 통합 후 사용 흐름 검수

- 상태: 2026-09-29 T1~T5 검수 완료. [13조건 증거·실패 이력·보존 결과](../../../Verification/MoonRabbitJunkyard/Core/96_33단계_검증진행기록.md).
- 계획: [33단계 작업 계획](../../../Planning/MoonRabbitJunkyard/Core/94_33단계_메뉴통합사용흐름검수_작업계획.md).

## 목표

현재 Match 통합창의 상단 메뉴와 네 작업 탭에서 레벨 편집·저장·시험·결과 조회를 연속으로 사용할 수 있음을 검증한다. 재현된 문제만 수정하고 기존 레벨, 등록 맵, 실제 시험 기록과 실행 규칙을 보존한다.

## 실행 원칙

1. 현재 Goal을 확인한다. 같은 미완료 33단계 Goal은 이어가고 활성 Goal이 없을 때만 생성한다. 다른 활성 Goal은 덮어쓰거나 완료하지 않는다.
2. AGENTS, unity-project-conventions, ponytail과 계획의 실행 규칙을 따른다. 중요한 미확정 설계만 grill-me로 확인하고 deep-planning은 사용하지 않는다.
3. T1~T5를 순서대로 수행한다. 이미 구현된 메뉴·기록 기능을 다시 만들거나 전체 게임 규칙 검사를 반복하지 않는다.
4. 기능 중심·내부 역할별 스크립트 구조를 유지한다. 변경 이유와 복잡한 상태 처리는 한국어 주석으로 설명한다.
5. 실패를 먼저 재현하고 관련 코드만 수정한다. 사용자 변경, GUID/meta, 원본 레벨과 실제 기록을 보존한다.
6. 저장·이름 변경·삭제 검사는 임시 자료에서 한다. 시작·종료 해시를 대조하며 검사 소유 자료 외에는 정리하지 않는다.
7. 신규 플레이는 계획 표본 4판을 기본으로 한다. 추가 재현이 꼭 필요하면 이유와 판 수를 기록한다. 20,000판 전체 시험은 실행하지 않는다.
8. Unity 검증 중 Assets 변경과 중복 검증 프로세스를 금지한다. 사용자가 다른 프로젝트에서 실행한 Unity는 종료하지 않는다.
9. 실제 UI, 자동 검사, 합성 상태, 기존 기록 사본 결과를 구분한다. HTML 브라우저 배치 검수는 기존 후속 이관을 유지한다.
10. 아래 조건에 증거를 연결한 후에만 Goal을 완료한다. 미검증을 통과로 간주하거나 후속 게임 개발을 자동 시작하지 않는다.

## 완료 조건

- [x] 1. 최신 메뉴 구현과 선행 증거를 확인하고 신규 검사 범위·보존 기준을 확보했다.
- [x] 2. 레벨 미선택 시 메뉴의 실행 가능 여부가 올바르다.
- [x] 3. 임시 레벨의 생성·변경·메뉴 저장·Ctrl+S·dirty 해제·재조회가 일치한다.
- [x] 4. 이름 변경·복제·맵 목록 및 취소가 기존 계약을 따르고 원본을 잘못 변경하지 않는다.
- [x] 5. 두 임시 레벨의 소규모 반복 시험과 각 결과 연결을 확인했다. 표본 부족은 판단 보류로 표시한다.
- [x] 6. 메뉴/탭 이동 시 시험 일시정지·복귀·재개·중지·중복 실행 잠금을 확인했다.
- [x] 7. 개별 결과·통계·지난 시험·추천 사본의 표시가 선택한 실행/레벨과 일치한다.
- [x] 8. 기록 조회가 실제 기록·최근 포인터를 변경하거나 자동 재개하지 않는다.
- [x] 9. 삭제 메뉴의 확인·취소·잠금·삭제 후 갱신을 임시 기록으로 확인했다.
- [x] 10. 최소 창과 좁은 도킹에서 메뉴·필수 조작·도움말에 접근할 수 있고 실제 메뉴 펼침을 확인했다.
- [x] 11. 창 재열기와 재로드 이후 중단 상태·기록 조회가 정상이며 자동 시험을 시작하지 않는다.
- [x] 12. 관련 컴파일·회귀·문서 링크를 확인하고 시작 대비 원본/실제 기록 보존을 대조했다.
- [x] 13. 검증 기록과 매뉴얼에 조건별 증거·실제 판 수·사본/합성 검사·남은 제한을 구분했다.
