## Goal 목표

공개 관찰만으로 가정 보드를 만들고 공통 규칙 실행기로 두 수 앞을 살펴보는 계획 전략을 구현한다. Match에서 기본/계획 전략 선택, 한 수·한 판 실행·안전 중지와 같은 시작 조건 재시험을 제공한다. 실제 숨은 정보 차단·가정/실제 상태 분리·두 수 탐색의 효과·독립 재현·영향 회귀·원본 보존을 검증한다.

## 실행 지침

1. 현재 Goal, 25단계 최종 완료 증거, 최신 소스와 사용자 변경을 먼저 확인한다. 같은 26단계 목표가 활성 상태면 이어서 진행하고 다른 활성 목표는 덮어쓰지 않는다.
2. ponytail 및 프로젝트 Unity 지침을 적용하고 T1→T6을 진행한다. 미확정 제품 결정은 grill-me로 한 쟁점씩 확인한다. deep-planning은 사용하지 않는다. 코드로 확인할 내용과 기존 합의는 다시 묻지 않는다.
3. `Assets/Scripts/Features/AutoPlay`의 기능/역할 구조를 유지한다. 기존 관찰·기본 전략·실제 실행기·Match 창을 재사용하고 게임 규칙 엔진을 복제하지 않는다.
4. 실제 판 복사본을 계획 전략에 전달하지 않는다. 가정은 공개 관찰에서 새로 구성하고 가정 난수·분기·기록은 실제 판과 분리한다. 실제 시드/공급/지문/로그에서 가정 시드를 만들지 않는다.
5. 계획서의 두 수·후보/표본 제한안을 출발점으로 측정하고 최종 정책과 버전을 기록한다. 적어도 두 번째 행동을 실제 가정 실행으로 평가해야 한다. 기본 점수 재정렬만으로 완료하지 않는다.
6. 가정 생성·연쇄·후보 확장에 처리량 한도를 두고 Editor 갱신에 나눠 처리한다. 시간/기기 속도에 따라 선택이 달라지지 않게 한다. 탐색 중 중지와 이미 적용한 행동의 안정 경계를 구분한다.
7. 가정 실패/예산 소진의 명시적 기본 전략 전환과 실제 오류를 구분한다. 가정 종료를 실제 판 결과로 사용하지 않는다. 오래된 탐색 결과와 위조 요청을 실제 세션에서 거절한다.
8. 실제 UI에서 전략·한 수·한 판·중지·같은 조건 재시험·이유를 확인한다. 기본 봇과 수동 시험의 기존 기능을 유지한다. 봇에는 아이템·부스터·광고를 사용하지 않는다.
9. 원본 JSON·dirty·에셋·GUID/meta·등록 맵·설정/패키지와 기존 편집 개선을 보존한다. 사용자 Unity를 임의 종료하지 않고 동일 프로젝트를 중복 실행하지 않는다. 소유 임시 자원만 정리한다.
10. 실제 Unity 실행·독립 프로세스 재현·대표 규칙 통합·영향 회귀를 수행하고 근거를 남긴다. 검증하지 못한 항목은 완료로 표시하지 않는다. 복잡한 경계와 계산에는 한국어 주석을 작성한다.
11. 27~30단계 반복 실행·일시정지/재개 관리·통계·난이도 추천·전체 통합 검수는 시작하지 않는다. 20조건 감사가 끝난 후에만 목표를 완료한다.
