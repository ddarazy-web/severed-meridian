## 실행 지침

1. 프로젝트 AGENTS와 `ponytail`, Unity 프로젝트 규칙, 관련 UI Toolkit 지침을 적용한다. 현재 사용자 변경과 기존 meta를 보존한다.
2. 상세 계획·최신 에디터 기획·현재 코드를 대조한다. 이 문서를 참조한 실행 요청은 계획에 명시된 구현 제안까지 포함한다. 새 규칙 충돌이 발견되면 조용히 규칙을 바꾸지 말고 근거를 확인한다.
3. 기존 선택/Undo/직렬화/검증을 재사용하고 스크립트는 `Assets/Scripts` 아래 기능별로 분리한다. 저장 모델은 v4를 유지하며 새로운 패키지·게임명 폴더·범용 프레임워크를 추가하지 않는다.
4. Match 메뉴, 왼쪽 카테고리/탭/한 줄 드롭다운, 오른쪽 탭과 USS 스타일을 유지한다. 넓은/좁은 창에서 실제 조작한다.
5. 일반 설정 붙여넣기는 다른 종류를 제외하고 같은 종류 대상에만 적용한다. 유효 대상 중 실패가 있으면 변경 전체를 거절한다. 생성구 공급 목록은 기존의 모든 대상 사전 검사·전체 거절 정책을 유지한다.
6. 레벨 복제는 현재 메모리 데이터를 기준으로 하며 원본을 강제 저장하지 않는다. 새 GUID/새 번호 외 값과 내부 연결·오류를 보존한다. 복제 파일 생성은 속성 Undo와 구분하고 독자 파일 Undo 기능을 추가하지 않는다.
7. 검사/읽기/복제에서 자동 정규화·형식 전환·기존 오류 삭제를 하지 않는다. 구버전/미래 형식을 손실 없이 복제할 수 없으면 명시적으로 거절한다.
8. 실제 수행한 검사만 기록한다. 증거가 부족한 완료 항목은 남겨두고 보강한다. 검증용 파일·대기 상태를 정리하고 무관한 씬·패키지·프로젝트 설정·문서를 수정하지 않는다.
9. 아래 실행 기록에 작업 의존성, 변경 책임, 증거를 실행 전에 구체화한다. 커밋·배포·새 Goal 생성은 이 문서 작성 범위가 아니다.

## 사용 순서

1. **Match → 레벨 에디터**에서 레벨을 열고 왼쪽 **편집 층**을 선택한다. **선택** 도구에서 클릭은 단일 선택, Ctrl/Cmd+클릭은 추가/해제다. 2×2 본체는 어느 점유 칸을 눌러도 하나로 취급한다.
2. 같은 종류를 여러 개 선택하면 오른쪽 **선택 속성**에 공통 값이 나온다. 다른 값은 `—`/혼합 상태다. 내구도 등 바꿀 필드만 수정하면 나머지 색·위치·ID·연결은 유지된다. 층을 바꾸면 이전 선택은 정리된다.
3. 한 요소를 우클릭하여 **설정 복사** 후 다른 요소들을 선택하고 우클릭 메뉴에서 **설정 붙여넣기**를 선택한다. 같은 종류에만 적용하며 다른 종류 제외 수와 변경/무변경 수를 표시한다. 여러 종류가 섞였을 때 공통 필드 입력이나 단일 전용 이동/삭제/연결 수정은 제공하지 않는다.
4. 생성구 또는 선택 속성 영역의 우클릭 메뉴에서 **공급 목록 복사**, **공급 목록 교체 붙여넣기**, **공급 목록 뒤에 추가**를 사용한다. 일반 설정 복사와 다르게 선택 대상 하나라도 부적합하면 전체 붙여넣기를 취소한다. 두 종류의 클립보드는 서로 사용할 수 없다.
5. 상단 **복제**에서 새 레벨 번호를 입력하고 **경로 선택·복제**로 Assets 안의 새 파일을 지정한다. 현재 미저장 내용도 사본에 반영하고 원본은 강제 저장하지 않는다. **취소**는 원본과 선택 레벨을 유지한다. 성공하면 사본이 열린다.
6. 복제 에셋은 새로운 GUID를 갖지만 내부 장애물 ID·연결·공급·미션·오류 값은 보존한다. 저장 번호는 중복 없이 지정한다. 구버전은 자동 전환하지 않고 미래 버전은 손실 위험 때문에 거절한다. 생성한 에셋 파일 삭제는 Unity Project 창을 사용한다. Undo/Redo는 편집 값 변경에 적용한다.

원본 Inspector에서 잘못된 데이터를 수정할 수 있으며 이번 기능도 기존 미완성/오류 저장을 자동 보정하지 않는다. 일반/무작위 블록과 파워/회수 부품 중 가변 설정이 없는 종류에는 새 속성을 만들지 않는다.

### 후속 UX 변경 — 복사·붙여넣기 컨텍스트 메뉴

- 보드 대상 또는 선택 속성 영역 우클릭으로 설정/공급 목록 복사·붙여넣기를 실행한다. 기존 버튼 행은 제거했다.
- 이미 선택된 대상 우클릭은 다중 선택을 유지하며, 다른 대상 우클릭은 해당 대상을 선택한다. 고정 공급 목록은 교체/뒤에 추가를 구분한다.
- 메뉴 실행 전 에셋·원본 내용·선택·도구·층을 다시 확인한다. 적용 규칙과 Undo는 기존 편집 로직을 사용한다.
- 검증: 공통 편집 데이터/UI 68개 + 재시작 14개, 공급 데이터/UI 122개 + 재시작 8개, 총 212개 통과. 컨텍스트 메뉴 구성 이벤트 및 액션을 실행했으며 자동 검증에서는 네이티브 팝업 표시만 생략했다.
- 최종 로그: `Logs/LevelContextMenuVerification/common-final.log`, `common-restart.log`, `supply.log`, `supply-restart.log`. 최종 컴파일 오류/경고와 테스트 실패 없음. 임시 테스트 에셋 정리 완료.

### 컨텍스트 메뉴 추가 검증

- 기존 버튼을 유지하고 요소 삭제/2×2 이동, 생성구 삭제, 공급 항목 추가·복제·삭제·순서 변경과 목록 비우기, 단일 칸 바닥·연결 작업을 우클릭에서도 제공했다. 세부 사용법은 `Docs/Contents/MoonRabbitJunkyard/09_레벨에디터.md` 참조.
- 공급 행은 실제 우클릭 PointerDown에서 선택한다. 오른쪽 버튼은 드래그 시작으로 처리하지 않으며, 메뉴 포커스 전환 시 목록을 재생성하지 않는다. 메뉴가 열린 뒤 선택 항목 변경 시 실행을 거절한다.
- 공통 데이터/UI 71개 + 재시작 14개, 공급 데이터/UI 127개 + 재시작 8개 = 220개 통과. 메뉴 본체 이동·삭제/Undo, 공급 항목 작업, 행 우클릭·오래된 메뉴 거절·포커스 취소, 중력 초기화/Undo 포함.
- 로그: `Logs/LevelContextMenuVerification/extended-common.log`, `extended-common-restart.log`, `extended-supply-verified.log`, `extended-supply-verified-restart.log`. 임시 테스트 에셋 정리 완료.
