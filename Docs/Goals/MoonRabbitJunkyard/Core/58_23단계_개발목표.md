## Goal 목표

공통 실행기에 고물 망치·자리 바꾸기·섞기와 청소로켓·달 폭탄·무지개 자석 시작 부스터를 구현하고 Match 수동 시험에 연결한다. 시험은 수량 무제한으로 제공하되 실제 사용·배치·대기·취소·실패 경계를 보존한다. 기존 판 종료·자동 재배치·라스트팡과 편집 기능을 보존하고 실제 UI·재현·영향 회귀로 검증한다.

## 실행 지침

1. 현재 Goal과 22단계 완료 증거를 먼저 확인한다. 선행 미완료이면 23단계 구현을 시작하지 않고 남은 선행 조건을 보고한다. 다른 활성 Goal을 덮어쓰거나 임의 완료 처리하지 않는다.
2. 문서 작성 요청만으로 Goal을 생성하지 않는다. 명시적 실행 요청과 선행 완료 확인 후 생성하며 동일한 23단계 Goal이 활성 상태이면 이어서 수행한다.
3. ponytail 및 프로젝트 Unity 지침에 따라 상세 계획 T1→T6을 수행한다. `Assets/Scripts`의 기존 책임 경계를 사용하고 별도 게임 규칙 엔진을 만들지 않는다.
4. 아이템의 독립된 피해 처리 단위와 이동 수 소비를 구분한다. 곰팡이 확산, 먼지의 피해 원인, 파워 보호와 종료 우선순위를 보존한다.
5. 레벨 원본·형식·GUID/meta, 연결·이동통로·낙하 경로·합류 컨텍스트 메뉴를 보존한다. 무관한 변경을 수정하지 않는다.
6. 실제 재화·해금 타이머·광고·상점·앱 복구와 24단계 통합·봇·분석은 구현하지 않는다.
7. 완료 조건별 증거를 기록하고 미검증 항목을 완료로 표시하지 않는다. 이번 Goal은 23단계만 수행한다.
