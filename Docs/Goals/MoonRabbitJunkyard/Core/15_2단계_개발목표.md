## 목표

기존 LevelDefinition 에셋을 전용 Unity 편집 창에서 열어, 10×10 보드의 칸 활성 여부와 초기 일반 블록을 클릭·드래그로 편집하고 저장·재로딩할 수 있게 한다. 기존 오류 데이터를 보존하며 Unity Undo/Redo와 오류 위치 확인을 지원한다.

이 문서의 Goal 실행문을 제출하면 연결된 계획의 세부 조작 제안을 포함하여 2단계 구현·검증을 승인한 것으로 진행한다. 문서를 작성하거나 열어 보는 것만으로 구현을 시작하지 않는다.

## 실행 원칙

1. 적용되는 프로젝트 규칙과 `deep-planning`, `unity-project-conventions`, `ponytail` 스킬을 읽고, 현재 소스·선행 결과·Unity 실행 상태를 확인한다.
2. 연결된 계획서의 범위를 유지한다. 구현에 필요한 작업 순서·의존 관계와 완료 증거를 이 문서에 기록하고 작은 단위로 구현·검증한다.
3. 스크립트는 `Assets/Scripts/Editor/Levels` 등 기존 기능별 경로에 둔다. `MoonRabbitJunkyard` 중간 폴더를 만들지 않는다.
4. 기존 ScriptableObject 저장 모델·검사기·Unity 직렬화·Undo·UI Toolkit을 재사용한다. 새 저장 형식·런타임 보드·빈 확장 구조·별도 Undo 체계·새 패키지·asmdef를 추가하지 않는다.
5. 실제 창의 입력과 저장 결과를 검증한다. 실패는 원인을 수정하고 다시 검사하며 미실행 항목을 통과로 보고하지 않는다.
6. 사용자 파일과 관련 없는 변경을 보존한다. 완료 후 임시 검증 에셋을 정리한다. 커밋·배포·3단계 구현은 이 목표에 포함하지 않는다.

### 검증 중 수정한 문제

- 캡처 상실 통지가 지연될 때 미완료 드래그가 적용될 수 있어 이동·놓기 시 캡처 소유권을 다시 확인한다.
- 외부 변경 감지는 Unity 객체 변경 이벤트를 사용한다. 드래그 시작 당시 데이터와 적용 직전 데이터를 비교하여 변경 전 미리보기를 뒤늦게 적용하지 않는다.
- 변경 알림 후 `delayCall` 갱신이 실행되지 않는 재열기 경로를 추적으로 확인했다. 다음 Editor 업데이트에 한 번 실행하고 구독을 해제하는 방식으로 수정했다. 매 프레임 전체 에셋을 검색하지 않는다.
- 숫자 입력 중 필드 재생성으로 포커스를 잃지 않도록 입력 확정 시 반영한다.
- 검증 창의 포커스·캡처와 캡처 이미지의 실제 창 크기를 명시적으로 확인하도록 검증 절차를 보완했다.

### 사용 방법

1. Unity 메뉴 **Match → 레벨 에디터**를 열거나 레벨 에셋 Inspector의 **보드 편집 창 열기**를 누른다. 게임 전용 도구는 최상위 **Match** 메뉴에 모은다.
2. 상단에서 레벨 에셋을 지정하거나 **새 레벨**을 누른다. 새 에셋은 `Assets/Data/Levels`에 생성된다.
3. 왼쪽 도구로 칸 활성/비활성, 고정 종류, 무작위, 일반 블록 지우기를 선택한 뒤 클릭·드래그한다. 놓을 때 적용되며 Undo 한 번으로 되돌릴 수 있다.
4. **선택** 도구로 칸을 누르면 오른쪽에서 해당 칸을 편집한다. 레벨 번호·이동 횟수는 Enter 또는 포커스 이동으로 확정한다.
5. **검사**로 오류를 확인한다. 보드 안 오류를 클릭하면 해당 칸으로 이동하며, 범위 밖 오류는 원래 좌표와 필드 경로를 표시한다.
6. **저장**으로 현재 에셋을 저장한다. 오류가 있어도 저장할 수 있으며, 비활성화는 블록 삭제와 다르다.

창을 닫거나 대상을 전환하면 진행 중인 드래그만 취소한다. 완료된 미저장 편집은 에셋 메모리에 유지되며 Unity 저장 흐름을 따른다. 다른 Project 항목 선택만으로 편집 대상이 자동 전환되지 않는다.

### 제한 사항과 다음 단계 연결점

- 편집 적용은 `LevelBoardEditing`, 포인터·미리보기는 `LevelBoardView`, 창 수명주기·검사·속성은 `LevelEditorWindow`에서 변경한다.
- 일반 블록 외 요소를 위한 빈 매니저나 등록소는 만들지 않았다. 장애물 등은 해당 단계에서 같은 저장 에셋에 필요한 정의와 편집 기능을 추가한다.
- 현재 10×10과 단일 칸 선택만 지원한다. 임시 색상과 번호는 최종 캐릭터 아트가 아니다.
- 미리보기의 방문 경로를 강조하고 실제 배치는 놓을 때 적용한다. 중복 배치는 임의로 고치지 않으며 기존 Inspector에서 원본 목록을 확인한다.
- 구조 검사 통과가 게임 플레이 가능 판정은 아니다. 3단계는 시작하지 않았다.
