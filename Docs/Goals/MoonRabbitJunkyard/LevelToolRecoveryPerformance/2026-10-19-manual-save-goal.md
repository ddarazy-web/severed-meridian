# 레벨툴 메모리 편집·수동 저장 전환 — 목표

상태: 1단계 구현·검증 완료(2026-10-19). [통합 계획 및 1단계 작업](../../../Planning/MoonRabbitJunkyard/LevelToolRecoveryPerformance/2026-10-19-manual-save-plan.md)을 따른다.

## 전체 목표

편집·Undo/Redo는 메모리에서 처리하고, 변경 상태를 표시해 사용자 저장을 유도한다. 자동 복구 저장을 다른 자동 저장 기법으로 대체하지 않는다. 저장하지 않은 변경은 비정상 종료 시 유실될 수 있다는 정책을 명확히 안내한다.

## 1단계 완료 조건

- [x] 편집·Refresh·유휴·포커스 이탈·Pause·OnDisable·프로젝트 전환·종료에서 자동 checkpoint 기록과 전체 이력 Export가 발생하지 않는다.
- [x] 시작 시 과거 복구본을 자동 파싱하거나 적용하지 않는다. 사용자 선택으로 확인할 수 있고 기존 파일은 보존한다.
- [x] 저장/Ctrl+S는 미확정 입력 검증 후 현재 제작 JSON을 저장한다. 전체 Undo 기록을 별도 저장하지 않는다.
- [x] 기본 미저장 표시가 문서/미확정 입력/공유 사본 상태를 누락하지 않는다. 선택·줌만 바꾸면 문서 dirty가 되지 않는다.
- [x] 저장 성공 후 clean, 실패 후 dirty 보존 및 원인 표시가 확인된다. 동일 세션의 전체 Undo/Redo가 유지된다.
- [x] 종료·프로젝트 전환·다시 불러오기에서 저장/버리기/취소가 동작한다. 무효 입력과 공유 사본을 조용히 잃지 않는다.
- [x] 저장하지 않은 종료/취소는 파일을 추가로 쓰지 않는다. ZIP 등 사용자가 명시한 작업의 쓰기는 정책과 안내에 일치한다.
- [x] 격리된 자동 검사, 관련 컴파일, 보호 해시, 하네스 해제와 diff 확인을 완료한다.
- [x] 제품 빌드·커밋·푸시·HTML 갱신·코드로 프리팹/씬 편집 없이 결과를 보고한다.

## 후속 단계 판정

2단계는 저장 상태·툴팁·이탈 안내의 UX를 정리한다. 3단계는 반복 성능과 JSON/ZIP/MemoryPack/게임 시험 회귀를 확인한다. 실제 실행 결과 없이 100ms나 특정 메모리 목표를 달성했다고 표현하지 않는다. 각 단계 완료 후 다음 상세 계획을 갱신하며 자동 진행하지 않는다.
