# 네이티브 레벨툴 UX 3단계 목표

상태: 2026-10-23 완료. [완료 보고](../../../Verification/MoonRabbitJunkyard/2026-10-23-native-level-tool-ux-stage03.md)의 항목별 검사 근거 기준이다. 실제 Android 기기는 미검증이며 제품 빌드·설치는 제외했다.

## 완료 조건

- [x] 제작 체크리스트에서 설정 위치로 이동하며 설정·시험 확인·저장을 구분한다.
- [x] 미션 목적·대상·수량과 쉬운 요약·수정·삭제를 제공한다.
- [x] 기존 조립식 동작·조건·공급을 재사용하고 목적별 작성과 직접 조립을 제공한다.
- [x] 적절한 보드 선택 뒤 필수값 팝업을 열며 오류 설명·적용 제한·취소를 제공한다.
- [x] 기존 튜토리얼의 단계 목적·위치·연결을 쉽게 보여주며 여기까지 시험은 처음부터 진행한다.
- [x] 앞 단계 변경으로 깨진 연결을 표시하고 완료 전에 해결한다.
- [x] 완료/전체 취소 전 일반 작업 전환을 막고 내부 보드·공급·시험은 허용한다.
- [x] 전체 취소는 해당 작업의 튜토리얼·보드·공급만 복원하고 이전 dirty·다른 레벨·공유 데이터는 보존한다.
- [x] 완료와 파일 저장을 구분하고 미시험 상태를 명시한다.
- [x] 기존 레벨 1~15, JSON·저장·Undo/Redo·검색·대량 목록·미저장 확인을 보존한다.
- [x] 지정 화면 크기의 UI·팝업·회전·키보드 및 대표 조립 사례를 검사하고 실기기 미검증을 구분한다.
- [x] 결과 보고와 4단계 계획/목표/복사용 실행문, 간략한 커밋 메시지를 제공한다.

제품 빌드·설치, 커밋·푸시, HTML 매뉴얼 갱신, 4단계 구현은 제외한다.
