# 네이티브 레벨툴 UX 4단계 목표

상태: 2026-10-23 승인된 Editor 범위 완료. [최종 보고](../../../Verification/MoonRabbitJunkyard/2026-10-23-native-level-tool-ux-stage04.md)의 항목별 근거와 검증 한계를 기준으로 판정했다. 실기기·제품 빌드는 미검증이다.

- [x] 일반 시험 시작·실패·취소·복귀를 이해할 수 있고 편집 내용·Undo/Redo를 보존한다.
- [x] 현재 시험 원본과 정식 진행 기록의 격리를 확인한다.
- [x] 프로젝트 위치·미저장·저장 결과와 실패 후 다음 동작을 명확히 표시한다.
- [x] JSON 저장·재열기 및 ZIP 전달 왕복에서 원본과 기존 작업을 보존한다.
- [x] 파일 선택 취소·충돌·손상·쓰기 실패가 작업을 덮어쓰지 않는다.
- [x] 시작→편집→튜토리얼→시험→저장 대표 흐름을 검사한다.
- [x] 지정 5개 화면 크기, 키보드·회전·뒤로가기·단축키 접근을 확인한다.
- [x] 대량 목록·선택 문서 조회·화면 재사용·수동 저장의 성능 회귀를 확인한다.
- [x] 최종 보고·대표 증거·미검증 항목을 정리하고 소유한 임시 검사 사본을 제거한다.
- [x] 전체 4단계 완료 조건을 감사하고 복사용 커밋 메시지를 제시한다.

제품 빌드·설치·실기기 시험, 커밋·푸시, HTML 매뉴얼 갱신은 별도 승인 전 제외한다. 다른 단계 구현을 자동으로 시작하지 않는다.
