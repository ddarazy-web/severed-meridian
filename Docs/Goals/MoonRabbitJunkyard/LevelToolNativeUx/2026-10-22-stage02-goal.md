# 네이티브 레벨툴 UX 2단계 목표

상태: 2026-10-22 Editor 범위 완료. Android 실기기·제품 빌드는 미검증.

## 완료 조건

- [x] 보드 중심 상단·패널 구조에서 현재 레벨, 저장 상태, 사용 도구를 바로 알 수 있다.
- [x] Windows 두 화면 크기와 휴대폰 세로/가로·태블릿 영역에서 주요 명령과 닫기 버튼이 접근 가능하다.
- [x] 패널 숨김·집중·회전·키보드 표시에도 선택·입력·스크롤·undo 기록을 보존한다.
- [x] 소재 분류·검색·최근 사용에 실제 이미지·이름과 현재 편집 층을 표시한다.
- [x] 현재 층 지우기와 전체 삭제가 구분되고 같은 층 교체·2×2 배치·실행 취소가 유지된다.
- [x] 우클릭/롱터치의 작업 메뉴가 일관되고 스크롤·핀치에 의한 오배치가 없다.
- [x] Ctrl+휠/핀치는 보드만 확대하며 메뉴 크기는 유지된다. 화면 맞춤과 배율 표시가 동작한다.
- [x] 단축키가 메뉴에 보이고 모바일에도 같은 작업의 터치 경로가 있다. 기존 창 정책을 보존한다.
- [x] 1천·1만 목록은 가상화와 메타데이터 검색을 유지하며 전체 JSON 로드나 편집 자동 저장을 추가하지 않는다.
- [x] 관련 자동 검사·컴파일·UI 캡처·성능 비교를 기록하고 실기기 미검증을 구분한다.
- [x] 실제 작업 데이터와 최종 증거를 보존하고 임시 사본을 정리한다.
- [x] 완료 보고, 3단계 계획/목표/복사용 실행문, 간략한 커밋 메시지를 제공한다.

제품 빌드·설치, 커밋·푸시, HTML 매뉴얼 갱신, 3단계 구현은 제외한다.
