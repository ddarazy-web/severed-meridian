# 레벨툴 리팩토링 4단계 목표

상태: 계획 작성 완료, 구현·검증 미착수. [4단계 계획](../../../Planning/MoonRabbitJunkyard/LevelToolRefactoring/2026-10-19-stage04-plan.md)을 따른다.

## 목표

분리된 레벨툴의 편집·저장·ZIP 전달·MemoryPack 변환·시험 연결을 검증하고, 복구 비용과 확장 위치를 명확하게 기록한다.

## 완료 조건

- [ ] 검사의 입력/출력과 삭제 대상이 격리되어 실제 사용자 원본·선택 원본 설정·정식 팩 리소스·이력이 보존된다.
- [ ] 기본 속성·공급·독립/공유 튜토리얼 편집의 Undo/Redo와 저장·재로드 의미가 유지된다.
- [ ] ZIP 왕복과 취소/실패의 상태 보존을 확인한다.
- [ ] 동일 스냅샷의 팩 변환·50레벨 구간·콘텐츠 참조·게시 실패 복원을 검사한다.
- [ ] JSON/팩 시험 결과와 공식 진행 상태 보존을 확인한다.
- [ ] 히스토리 정리의 보호 규칙을 격리된 시험 데이터로 확인한다.
- [ ] 복구 저장·재구성의 시간/메모리/기록 크기를 측정하고, 보호 한도 초과와 미측정 표본을 구분한다. 최적화를 하지 않았다면 성능 해결로 보고하지 않는다.
- [ ] 실제 코드와 맞는 의존 다이어그램·상태 소유권·수명주기·확장 위치 문서가 있다.
- [ ] 관련 검사·diff·GUID·변경 범위를 확인하고 실제 기기 및 제품 빌드 미검증을 명시한다.
- [ ] 결과와 남은 항목, 복사 가능한 간략한 커밋 메시지를 제공한다. 커밋·푸시는 하지 않는다.
