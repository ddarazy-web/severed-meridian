# 레벨툴 리팩토링 2단계 목표

상태: 계획 / 구현 미착수.

## 목표

레벨툴 화면의 JSON 변경 규칙을 공통 문서 편집 기능으로 이동한다. 저장 형식, 데이터 의미, Undo/Redo와 오류 처리 시점을 보존한다.

## 완료 조건

- [ ] 화면의 JSON 쓰기 호출 목록과 처리 위치가 기록되어 있다.
- [ ] 레벨 기본 속성과 선택 요소 속성 수정이 문서 편집 함수에 위임된다.
- [ ] 선택 배치·교체·삭제가 기존 공통 규칙을 사용한다.
- [ ] 스키마 제한을 화면마다 중복 판정하지 않는다.
- [ ] 동일 사용자 동작의 변경 결과와 Undo/Redo 단위가 유지된다.
- [ ] 영역 편집 실패가 문서에 부분 변경을 남기지 않는다.
- [ ] 2×2 교체·다른 층 보존·클립보드 의미가 유지된다.
- [ ] 공유 튜토리얼과 레벨별 설정의 수정 대상이 유지된다.
- [ ] 저장·재로드 결과와 관련 입력 회귀 검사가 통과한다.
- [ ] 사용자 원본·설정·리소스 변경 없이 격리된 데이터로 검증한다.
- [ ] 결과와 미검증 항목, 간단한 커밋 메시지를 보고하고 3단계 문서를 작성한다.

## 복사 가능한 실행 명령문
