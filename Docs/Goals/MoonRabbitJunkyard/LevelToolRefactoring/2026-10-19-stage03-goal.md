# 레벨툴 리팩토링 3단계 목표

상태: 완료. 보드·속성/공급·튜토리얼/조건 분리, 관련 자동 회귀 및 최종 컴파일을 확인했다. 실기기·제품 실행 파일은 미검증이며, 대량 이력 복구 비용은 4단계 확인 항목이다.

## 목표

보드 표시·기본 속성·공급·튜토리얼 화면의 책임을 분리하고 화면 조립자가 수명주기와 연결을 관리하게 한다. UI 동작·스타일·데이터 의미는 유지한다.

## 완료 조건

- [x] 패널별 소유 상태와 실제 생성자/API 계약을 기록한다.
- [x] 보드 표시와 기존 입력 객체가 분리된 책임으로 연결된다.
- [x] 기본 속성·공급·튜토리얼 패널이 화면 전체나 다른 패널 내부 상태를 받지 않는다.
- [x] 문서 쓰기는 2단계 공통 편집 기능을 사용하고 문서·선택·Undo 상태를 중복 보관하지 않는다.
- [x] 레벨/프로젝트 전환·탭 복귀·재활성화 때 이벤트 중복이나 이전 문서 쓰기가 없다.
- [x] 비동기 보드 표시 결과가 이전 화면에 적용되지 않는다.
- [x] 지연 입력·포커스·모바일 패널 이동·공유 튜토리얼 편집 결과가 유지된다.
- [x] 보드 확대·단축키·창 크기·모바일 viewport·관련 편집 회귀 검사가 통과한다.
- [x] 실제 기기·제품 실행 파일 등 미검증 영역을 명시한다.
- [x] 결과와 간략한 커밋 메시지를 보고하고 4단계 계획·목표·실행문을 작성한다.
