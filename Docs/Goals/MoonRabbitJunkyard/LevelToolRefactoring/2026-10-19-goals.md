# 레벨툴 리팩토링 목표와 완료 조건

상태: 1단계 구현·자동 검증 완료. 2~4단계 구현 미착수. 상세 증거는 [1단계 검증 기록](../../../Verification/MoonRabbitJunkyard/2026-10-19-level-tool-refactor-stage01.md)에 기록했다.

## 전체 목표

기존 데이터와 편집 동작을 유지하면서 입력·표시·문서 편집의 상태 소유권과 의존 방향을 명확히 한다. 파일 수나 줄 수 감소만으로 완료를 판정하지 않는다.

## 단계별 완료 조건

| 단계 | 관찰 가능한 완료 조건 |
|---|---|
| 1 입력 | 입력 객체에 제스처 상태가 모이고, 화면 해제 시 구독·예약 작업이 해제된다. 마우스·휠·터치·취소 회귀 검사 통과. |
| 2 편집 | 대상 UI의 JSON 쓰기가 문서 편집 기능으로 이동한다. 같은 사용자 동작의 JSON 의미·Undo/Redo·재로드 결과가 유지된다. |
| 3 패널 | 패널이 화면 전체나 다른 패널 내부 상태를 참조하지 않는다. 주요 창 크기·탭 복귀·모바일 패널 검사가 통과한다. |
| 4 통합 | 편집·저장·전달·변환·시험과 데이터 보호 검사가 통과하고 상태 소유권 및 확장 위치가 문서화된다. |

## 1단계 필수 확인표

- [x] 기존과 동일한 보드 선택·배치·롱터치·핀치 동작.
- [x] 보드 내 Ctrl+휠만 확대/축소하고 일반 휠은 스크롤 유지.
- [x] 32~144 확대 범위와 화면 맞춤·보드 넓게 동작 유지.
- [x] 입력 중 모달·레벨 전환·포인터 취소 시 후속 문서 수정 없음.
- [x] 화면 재활성화 후 이벤트 중복 실행 없음.
- [x] 세션과 입력 객체에 선택·문서 상태 중복 저장 없음.
- [x] 기존 사용자 JSON, 선택 원본 설정, MemoryPack 리소스 변경 없음.
- [x] 실제 실행한 검사 명령·결과와 미검증 항목을 구분해 보고.
- [x] 2단계 상세 계획·목표·복사 가능한 실행문 제시.

## 복사 가능한 1단계 실행 명령문

```text
Docs/Planning/MoonRabbitJunkyard/LevelToolRefactoring/2026-10-19-integrated-plan.md와 2026-10-19-stage01-plan.md, Docs/Goals/MoonRabbitJunkyard/LevelToolRefactoring/2026-10-19-goals.md를 기준으로 레벨툴 리팩토링 1단계를 진행해. 기존 입력 동작과 데이터 형식을 유지하면서 보드 입력 및 수명주기를 분리하고 관련 회귀 검사를 실행해. 제품 빌드, 커밋·푸시, HTML 매뉴얼 갱신, 실제 사용자 이력 삭제는 하지 마. 확인이 필요한 사항은 제한시간 없는 문답으로 질문해. 완료 후 변경·검증·남은 항목과 간략한 커밋 메시지를 보고하고, 2단계 계획·목표 및 복사 가능한 실행 명령문을 작성해. 2단계 구현은 자동으로 시작하지 마.
```
