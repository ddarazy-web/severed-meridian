# 경량 로비 1단계 목표

상태: 1단계 완료 (2026-10-21). 항목별 근거와 미검증 범위는 검증 기록의 최종 완료 감사를 따른다. 실기기·제품 번들·게임 씬 전환 완료를 의미하지 않는다.

## 목표

등록된 레벨의 작은 목록 인덱스만 읽어 가벼운 로비에 표시하고, 1천/1만 개에서도 화면에 보이는 셀만 재사용한다. 선택은 요청 이벤트까지 제공하며 실제 매치 게임 씬 전환은 2단계다.

## 완료 조건

- [x] 채택 원본에서 인덱스가 생성되고 원본 ID·번호·이름 및 실제 레벨 팩 번호와 일치한다.
- [x] 인덱스가 generation 해시와 동일한 게시 트랜잭션에 포함되며 손상/누락/다른 세대와 게시 실패를 안전하게 처리한다.
- [x] 로비에서 레벨 본문·요소 팩·게임 보드/장애물 아틀라스·효과음 로드 0건.
- [x] 로비 씬·프리팹에 게임/레벨툴 리소스의 불필요한 직접·간접 의존성이 없다. 폰트 크기·의존성과 한글 표시를 확인한다.
- [x] 0/1/15/1천/1만 항목에서 셀 수가 min(N, ceil(뷰포트 높이/행 높이)+4) 이하다.
- [x] 정상 스크롤 중 셀 생성/파괴 0회이며 전체 항목 순회·정렬·전체 레이아웃 갱신을 하지 않는다.
- [x] 재사용 셀은 현재 ID/번호/세대를 정확히 전달하고 이전 항목 클릭·중복 이벤트·드래그 후 오클릭이 없다.
- [x] 로딩·빈 목록·오류·재시도·취소·씬 종료 뒤 완료 도착이 정상 처리되고 핸들이 누적되지 않는다.
- [x] 실제 로비 씬에서 화면 크기/방향·첫/중간/마지막 행·긴 한글 이름·상태 안내를 검사한다.
- [x] 실제 인덱스 1천/1만 최초 1회+정상 3회 시간·할당·셀 수를 기록하고 계측 한계를 밝힌다.
- [x] 기존 게임/레벨툴 프로필 시작 씬과 편집/시험 동작을 유지한다.
- [x] 테스트 사본·임시 스크립트는 정리하고 실제 작업 데이터와 검증 결과는 보존한다.
- [x] 결과·미검증 범위·복사용 커밋 메시지 및 다음 단계 문서를 보고한다.

## 완료로 간주하지 않는 것

- 전체 레벨 본문을 읽은 뒤 목록에 일부만 표시하는 구현.
- 1만 셀을 만든 뒤 숨기는 구현.
- 목록 인덱스가 없다고 전체 팩을 스캔하는 우회.
- 글자 누락·게임 리소스 선로드를 숨긴 경량화.
- Editor 검사만으로 Android 시작 지연 해결·최종 번들 의존성·실기기 조작 검증을 완료했다고 보고하는 것.

제품 빌드·커밋·푸시·HTML 매뉴얼 갱신 금지. 현재 단계에서는 실제 게임 씬 전환과 APK 시작 시간 단축이 완료 조건이 아니다.
