## 완료 조건

- [x] 최초 실행과 정상 3회에 대해 로비·목록·게임 표시·조작 가능 시간을 분리 기록한다.
- [x] 15/1천/1만 목록의 셀 수·스크롤 할당·메모리와 선택 정확성을 검사한다.
- [x] 선택 전 게임 팩·보드 아틀라스·효과음 로드 0건을 유지한다.
- [x] 대표 장애물/공급/미션 레벨의 실제 자원과 필요 자원 계획이 일치한다.
- [x] 한 구간 재사용과 구간 교체, 10회 왕복·실패·취소 후 소유 자원 해제를 확인한다.
- [x] 수정한 병목은 같은 조건의 전후 측정과 관련 회귀 검사를 통과한다.

- [x] 실제 작업 데이터·검증 결과 보존과 검사 사본 정리를 확인한다.
- [x] 결과·제약·미검증·복사용 커밋 메시지를 보고한다.
