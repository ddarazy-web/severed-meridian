# 경량 로비 2단계 목표

상태: 2단계 완료. 전체 변경 리뷰 지적 수정과 완료 조건별 Editor 검증을 마쳤다. 제품/실기기 검증은 수행하지 않았다.

## 목표

로비에서 선택한 레벨을 필요한 데이터·자원만 준비해 플레이하고, 종료 시 가벼운 로비로 복귀한다.

## 완료 조건

- [x] ID·번호·세대 요청이 1·2·15 및 비연속 레벨에서 정확히 반영된다.
- [x] 중복 선택은 한 번만 시작하며 로딩·실패·취소·재선택 상태가 명확하다.
- [x] 선택 구간 팩만 읽으며 중복 해석과 비선택 레벨 실행 준비를 제거한다.
- [x] 게임 진입 전 로비의 게임 데이터·아틀라스·효과음 로드 0건을 유지한다.
- [x] 선택 레벨의 배치·공급·매칭 생성·미션 자원은 누락 없고, 무관한 장애물/툴 자원을 읽지 않는다.
- [x] 제작 검증과 정식 런타임 검증을 분리해도 데이터 손상·버전·세대·참조 보호를 유지한다.
- [x] 게임 프로필 3종만 로비 시작으로 변경하며 레벨툴 2종의 시작 씬과 옵션을 유지한다.
- [x] 재시작·비연속 다음 레벨·마지막 레벨 복귀·튜토리얼 기록·편집기/툴 시험 회귀를 통과한다.
- [x] 10회 왕복과 실패/취소 후 게임 객체·이벤트·Addressables 작업이 누적되지 않는다.
- [x] 로비 준비/게임 데이터/게임 자원/조작 가능 시점을 구분한 계측을 남긴다.
- [x] 실제 데이터와 검증 증거를 보존하고 소유한 검사 사본을 정리한다.
- [x] 결과·미검증 범위·복사용 커밋 메시지와 3단계 문서를 보고한다.

제품 빌드·커밋·푸시·HTML 갱신 금지. Editor 결과를 Android 실기기 시작 성능 또는 제품 번들 검증으로 표현하지 않는다.

근거와 범위는 [2단계 검증 기록](../../../Verification/MoonRabbitJunkyard/2026-10-21-lobby-stage02.md)을 따른다. 편집기 실행은 도메인 리로드 비활성 조건이며, 기존 레벨툴 종합 편집 UI 검사의 미션 입력 표시 실패는 별도 미해결이다. 이번 게임 진입 회귀 통과로 해당 실패를 덮지 않는다.
