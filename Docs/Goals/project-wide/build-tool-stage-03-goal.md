# 제품 빌드 도구 3단계 — 목표·완료 조건

2026-10-16 · 공통 구조 구현·모의/재로드/조회 회귀 검사 완료. 실제 SDK/제품 빌드 미수행.

[계획](../../Planning/project-wide/build-tool-stage-03-plan.md) · [실행문](../../Commands/project-wide/build-tool-stage-03-command.md)

## 목표

제품·플랫폼에 맞는 옵션을 등록하고 실행 요청별 ON/OFF 값에 따라 컴파일 준비·전후처리·정리를 안전하게 수행한다.

## 완료 조건

- [x] 옵션 ID·버전·설명·기본값·대상·의존·충돌을 등록한다. 지원 항목만 표시한다.
- [x] 실제 SDK 처리기가 없으면 동작하는 GPG/플러그인 토글처럼 표시하지 않는다.
- [x] GUID별 개인 선택과 확정 실행값을 구분하고 실행 중 UI 변경으로 요청이 변하지 않는다.
- [x] 의존 누락·순환·충돌·필수 제품 계약 침범을 변경 전에 거절한다.
- [x] 컴파일 준비·빌드 전처리·빌드 후처리·종료 정리를 한 옵션에 조합한다.
- [x] ON 다음 OFF 및 제품 전환에서 설정이 남지 않는다. 공유 의존성을 임의 제거하지 않는다.
- [x] 단계별 소유 상태를 먼저 기록하고 같은 세션 재로드 이후 실제 상태와 대조해 이어간다.
- [x] 자신의 옵션 변경과 외부 수정의 지문을 구별한다. 외부 변경은 덮어쓰지 않는다.
- [x] 실패·취소·로그 오류에서도 역순 정리를 시도하며 복원 실패와 원래 오류를 함께 보여준다.
- [x] Player 결과·후처리 결과·정리 결과를 구별하고 최종 산출물은 임의 삭제하지 않는다.
- [x] 재시작 자동 실행·동일 요청 중복 빌드를 방지한다.
- [x] 모의 옵션·재로드 검사와 기존 1/2단계 회귀 검사를 통과한다.
- [x] 진행 보고·미검증·후속 SDK 범위를 기록하고 자동 후속 구현을 하지 않는다.
- [x] 실제 Player/Addressables 빌드·SDK 설치·커밋·푸시·HTML 매뉴얼 갱신을 하지 않는다.

## 완료 근거

[진행 기록](../../Verification/project-wide/build-tool-stage-03-progress.md)의 최종 여섯 검사 로그와 요구사항별 완료 감사표를 따른다. 체크는 공통 옵션 구조와 모의 검증의 완료이며 실제 SDK 어댑터·빌드·기기 동작을 검증했다는 뜻이 아니다.
