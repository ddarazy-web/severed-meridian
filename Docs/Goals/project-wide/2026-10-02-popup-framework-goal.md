## 목표와 단계

팝업을 공통 정책과 등록 패턴으로 관리하고 원래 씬/동일 문맥에서 필요한 경우만 복원한다. 공통 시스템 독립 3단계이며 WorldGameScreen 14단계를 자동 시작하지 않는다.

| 단계 | 납품 결과 | 완료 조건 |
| --- | --- | --- |
| 1 | 공통 서비스·표시·등록·입력·정지 요청 | 1~4 |
| 2 | 선택적 보관·문맥 검증·원래 씬 복원 | 5~8 |
| 3 | 관리 도구·추가 패턴·실제 세 팝업 전환 | 9~12 |

## 완료 조건

- [x] 1. A→B→C에서 B만 제거하면 A→C, Top=C다. 닫힌 핸들은 다른 인스턴스를 제거하지 않는다.
- [x] 2. 같은 종류 기본은 동일 핸들/기존 내용 갱신/맨 위 이동이며 허용 종류만 복수 핸들을 갖는다.
- [x] 3. 실제 클릭·터치 경로·Submit·Cancel·포커스에서 최상위만 반응한다. 입력 한 번당 한 동작이며 아래 팝업과 보드/일반 UI에 누출되지 않는다.
- [x] 4. 정지 요청 팝업이 모두 닫힐 때 팝업 소유 정지만 해제한다. 다른 입력 차단·외부 정지·백그라운드를 보존한다.
- [ ] 5. 호출자가 보관을 선택한 이동만 복원 가능 팝업의 상태/순서를 캡처한다. 선택하지 않은 이동은 오래된 해당 문맥 데이터도 폐기한다.
- [ ] 6. 실제 씬 왕복 후 같은 문맥에서 내용·입력·선택·탭·스크롤·순서를 새 뷰에 복원하고 최상위 포커스를 적용한다. 복원 성공 후 재복원하지 않는다.
- [ ] 7. 다른 씬/기능/게임 세션 문맥은 복원하지 않고 폐기한다. 레벨 번호만 같은 새 게임도 구분한다. 구매/재시작/Next/결과음은 복원 중 재실행하지 않는다.
- [ ] 8. 값 깊은 복사·씬 이동 실패 rollback·복원 예외·씬 종료에서 후보/뷰/구독 정리가 입증된다. 부분 복원은 조작 불가하고 재시도는 명시적이다.
- [ ] 9. 관리 창의 등록·정책 편집·검증·실시간 순서/입력 권한/정지/보관 조회·시험 열기/닫기가 실제 서비스와 일치한다.
- [ ] 10. 템플릿으로 새 시험 팝업을 생성/컴파일/등록/표시/캡처할 수 있다. 기존 파일을 덮어쓰지 않고 설정 오류를 검출한다.
- [ ] 11. 기존 일시정지·결과·설명을 공통 관리로 전환한다. 기존 재시작/Next/Asset 안내/연출·오디오·화면 비율을 보존하고 생성 도구 재실행도 연결을 보존한다.
- [ ] 12. 마지막 수정 후 관련 검사·실제 UI 증거·리뷰 수정·diff/GUID/원본 보존 감사를 기록한다. 수행하지 않은 물리 기기 검사는 명시하고 빌드·커밋·푸시는 하지 않는다.

## 증거 위치와 완료 판정

실행 결과는 `Logs/PopupFramework/`, 단계별 기록은 `Docs/Verification/project-wide/popup-framework-stage-01.md` 등, 사용 안내는 `Docs/Guides/project-wide/popup-framework-usage.md`에 구현 중 작성한다. 1단계는 8회 검사/97 PASS와 별도 조건9·원본/GUID 감사를 완료했다. 후속 단계 검증 기록은 아직 없다.

각 조건의 검사명·실행 시각·실제 exit·관련 화면/정리 근거를 연결한 뒤 체크한다. 전체 완료는 세 단계 조건이 모두 입증된 때다. 한 단계 명령으로 실행하면 그 단계만 목표로 삼고 이후 단계를 자동 수행하지 않는다.
