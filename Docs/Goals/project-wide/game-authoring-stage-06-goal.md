# 게임·제작 도구 분리 6단계 — 목표·완료 조건

> 2026-10-09 구조·데이터·프로필 검증 완료. 근거는 검증 기록의 최종 실행 결과를 따른다.

[계획](../../Planning/project-wide/game-authoring-stage-06-plan.md) · [실행문](../../Commands/project-wide/game-authoring-stage-06-command.md)

- [x] G1. 5단계 필수 기능과 기본 편집 경로 전환이 검증됐으며 미완료를 떠넘기지 않았다.
- [x] G2. 전체 제작 원본 목록·해시·ID/참조 보고서와 복구 자료가 있다. 기존 자료를 삭제하지 않았다.
- [x] G3. 후보 JSON의 수량·필드·ID·공유/학습 의미·동작이 보존되며 실패한 후보는 기본 원본으로 채택되지 않는다.
- [x] G4. 재이관·폴더 이동·외부 변경·재시작에도 안정 ID와 저장 충돌 보호가 유지된다.
- [x] G5. 동일 스냅샷에서 레벨/요소 팩을 생성하고 검증 후 교체한다. 실패 시 이전 정상 산출물을 복구한다.
- [x] G6. 50레벨 구간, 50/51·100/101, 결번·중복·정의 충돌, 튜토리얼, 기존 로더 호환을 검증했다.
- [x] G7. JSON/팩 시험 입력과 오래된 산출물 표시가 명확하며 옛 SO로 자동 대체하지 않는다.
- [x] G8. Android/iOS/Steam/레벨툴 프로필·심볼·씬·설정 및 리소스/코드/플러그인 포함 경계를 대조했다.
- [x] G9. 일반 제작·변환 기본 입력은 검증된 JSON이며 구형 가져오기와 복구 경로가 남는다. 게임은 MemoryPack을 사용한다.
- [x] G10. 실행한 검사·남은 배포 검증·복구 절차를 보고하고 복사 가능한 커밋 메시지를 제공했다.

커밋·푸시·Player/Addressables 빌드·HTML 수정 금지. 현재 승인 범위의 완료는 **구조·데이터·프로필 검증 완료**다. 실제 네 제품 빌드·다른 PC/모바일 실행은 별도 승인 후 확인할 미완료 배포 게이트이며 출시 완료로 표현하지 않는다.
