## 목표

독립 WPF 창에서 기존 Unity 빌드 도구와 같은 설정을 조작하고, 검사·실행 요청·진행·로그 정리를 수행한다. 이 단계의 제품 실행 검증은 모의이며 실제 산출물 배포 검증과 구분한다.

- [ ] Windows 앱이 컴파일되고 독립 창으로 실행된다. Unity 게임 빌드에 포함되지 않는다.
- [ ] 5개 제품의 지원 필드와 옵션이 공통 계약에 따라 표시된다.
- [ ] 앱 버전은 제품 정보에 통합되고 Android 서명은 먼저 표시된다.
- [ ] 설정 저장·충돌·미저장 변경 처리와 마지막 작업 위치/창 상태 기억이 동작한다.
- [ ] 기존 옵션과 실제 실행값이 일치하며 추가 플랫폼 switch를 UI에 만들지 않는다.
- [ ] 검사·실행·취소가 기존 Runner로 연결되고 UI가 장시간 작업 중 응답한다.
- [ ] 비밀번호 평문 파일/인자/로그 노출 없이 기존 DPAPI 저장 호환을 fixture로 검증한다.
- [ ] 로그 후보·용량·보관 기간·삭제/보호/실패 결과가 표시되고 Busy는 보류로 표현된다.
- [ ] 작은 창·고배율·키보드 조작에서 핵심 입력과 버튼에 접근할 수 있다.
- [ ] 실패·취소·응답 지연·프로젝트 사용 중·결과 없음에 대한 모의 검사가 통과한다.
- [ ] 실제 제품 빌드·비밀번호 사용·실제 로그 삭제·커밋·푸시·HTML 갱신을 하지 않는다.
- [ ] 완료 보고, Markdown 안내, 3단계 계획·목표·복사용 실행문을 제공한다.
