## 목표

손가락만으로 고급 레벨 제작, JSON 저장, 게임 시험, 결과 확인, 편집 복귀와 ZIP 전송까지 이어지게 한다. 같은 공통 편집·게임 로직과 ID/참조를 유지한다.

## 자동 검증 범위의 완료 조건

- [x] 이전 단계 결과와 실제 구현을 대조해 추가 작업 범위를 기록한다.
- [x] 흐름/공급/벽/포털/연결/모양과 튜토리얼 대상·신규 공급을 모바일 UI로 조립하고 확정·취소할 수 있다.
- [x] 작은/겹치는 선택 대상과 좁은 화면의 확인 버튼을 사용할 수 있으며 핀치·롱터치·중단이 원치 않는 편집을 만들지 않는다.
- [x] 고급 편집의 문서·선택·Undo/Redo 결과를 공통 명령과 비교한다.
- [x] 게임 시험·튜토리얼·봇/여러 레벨·기록/결과·복귀의 필수 조작을 키보드 없이 사용할 수 있다.
- [x] 시험 종료·취소·팝업·중단 후 프로젝트/레벨/선택/편집 이력을 유지한다.
- [x] 대표 프로젝트의 제작→저장→시험→복귀→ZIP→새 프로젝트→재열기에서 JSON 의미·ID·참조를 보존한다.
- [x] 같은 seed의 JSON와 MemoryPack 시험에서 초기 보드와 결과 의미를 비교한다.
- [x] 관련 Windows/모바일 회귀와 가능한 Android 스크립트 컴파일을 확인하고 임시 연결·프로필·콘텐츠 선택을 복원한다.
- [x] 검사 로그와 미검증을 구분해 완료 보고하고 커밋·푸시·빌드·HTML 갱신 없이 복사용 커밋 메시지를 제공한다.

## 별도 실제 플랫폼 확인

실기기의 시스템 선택기/SAF, OS 뒤로가기, 터치 키보드/한글 IME, 강제 종료, PC↔Android 왕복, 게임/툴 동시 설치·저장 격리는 미검증 목록으로 유지한다. 자동 검증 범위를 완료해도 실제 출시 준비 완료로 표현하지 않는다. 실제 플랫폼 검증은 사용자 요청·허용 범위에 따라 별도로 진행한다.

자동 검사별 근거와 제한은 [완료 기록](../../Verification/project-wide/android-level-tool-stage-05-progress.md)을 참고한다.
