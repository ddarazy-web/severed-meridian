# Windows 외부 빌드 앱 3단계 — 목표·완료 조건

2026-10-16 · 사용자 요청에 따라 현 작업 정리 완료. 200% 배율·물리 모니터 분리 검사는 미검증으로 보류한다. 전체 운영 검증 완료를 뜻하지 않으며 아래 남은 조건은 후속 검증으로 유지한다.

[계획](../../Planning/project-wide/external-build-app-stage-03-plan.md) · [실행문](../../Commands/project-wide/external-build-app-stage-03-command.md)

목표는 외부 앱의 중단·재실행 안전성과 Windows 배포 실행을 검증하는 것이다. 실제 제품 빌드 검증은 별도 승인 범위로 수행한다.

- [x] 앱 재시작 시 기존 작업 상태를 식별하고 자동 중복 실행하지 않는다.
- [x] 취소·결과 누락·손상된 상태·미완료 Runner 기록을 안전하게 표시한다.
- [x] 일회성 암호화 파일의 정상/실패/중단 정리가 진행 중 요청을 침범하지 않는다.
- [ ] 실제 OS 배율·다중 모니터·작은 화면을 검증한다. 200% 배율·물리 모니터 분리는 사용자 요청으로 보류.
- [x] 실제 키보드로 임시 데이터의 설정 편집·저장·재조회·탭 이동을 검증한다. 실제 제품 빌드·실제 비밀번호는 사용하지 않는다.
- [x] 런타임 지원 조건을 확인하고 로컬 패키지 실행과 도움말을 검증한다.
- [ ] 버전·옵션·서명 저장 원본이 기존 도구와 동일하게 유지된다.
- [x] 승인된 Android Game APK 산출물·후처리·저장된 서명을 검증했다. 제품 전환 및 Unity 직렬화 변경 4개는 작업 후 수동 복원했으므로 자동 복원은 미완료로 남긴다. 다른 제품·AAB·실기기 설치 검증을 대신하지 않는다.
- [x] 사용자 로그와 비밀을 보호하며 커밋·푸시·공개 배포·HTML 갱신을 하지 않는다.
- [x] 증거·제약·사용법을 Markdown으로 남기고 완료 작업의 복사용 커밋 메시지를 제공한다.

미검증 항목의 범위와 기존 검사 증거는 [3단계 정리](../../Verification/project-wide/external-build-app-stage-03-progress.md)의 작업 정리 절을 기준으로 한다. 보류한 두 화면 검사의 환경 준비를 지금 다시 요청하지 않는다.
