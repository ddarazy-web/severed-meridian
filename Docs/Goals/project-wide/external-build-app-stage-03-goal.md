# Windows 외부 빌드 앱 3단계 — 목표·완료 조건

2026-10-16 · 미착수

[계획](../../Planning/project-wide/external-build-app-stage-03-plan.md) · [실행문](../../Commands/project-wide/external-build-app-stage-03-command.md)

목표는 외부 앱의 중단·재실행 안전성과 Windows 배포 실행을 검증하는 것이다. 실제 제품 빌드 검증은 별도 승인 범위로 수행한다.

- [ ] 앱 재시작 시 기존 작업 상태를 식별하고 자동 중복 실행하지 않는다.
- [ ] 취소·결과 누락·손상된 상태·미완료 Runner 기록을 안전하게 표시한다.
- [ ] 일회성 암호화 파일의 정상/실패/중단 정리가 진행 중 요청을 침범하지 않는다.
- [ ] 실제 OS 배율·다중 모니터·작은 화면·키보드 조작을 검증한다.
- [ ] 런타임 지원 조건을 확인하고 로컬 패키지 실행과 도움말을 검증한다.
- [ ] 버전·옵션·서명 저장 원본이 기존 도구와 동일하게 유지된다.
- [ ] 승인된 실제 제품 빌드의 산출물·후처리·복원을 검증하거나, 미승인으로 미검증임을 명확히 보고한다. 미검증 상태를 전체 운영 검증 완료로 판정하지 않는다.
- [ ] 사용자 로그와 비밀을 보호하며 커밋·푸시·공개 배포·HTML 갱신을 하지 않는다.
- [ ] 증거·제약·사용법을 Markdown으로 남기고 완료 작업의 복사용 커밋 메시지를 제공한다.
