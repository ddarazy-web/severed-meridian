# 제품 빌드 도구 2단계 — 목표·완료 조건

2026-10-16 · 상태: 구현·모의/재로드/조회 회귀 검사 완료. 실제 제품 빌드 미수행.

[통합 계획](../../Planning/project-wide/2026-10-15-build-tool-plan.md) · [2단계 계획](../../Planning/project-wide/build-tool-stage-02-plan.md) · [실행 명령문](../../Commands/project-wide/build-tool-stage-02-command.md)

## 목표

1단계 화면에서 선택한 정규 제품 프로필을 명시적인 요청으로 빌드하고, 프로필 전환·재컴파일 대기·결과·실패 정리를 공통 실행 흐름으로 관리한다.

위 목표의 구현 검증은 모의 백엔드를 기본으로 하며, 실제 제품 빌드는 별도 승인 전까지 실행하지 않는다. 구현 완료와 실배포 검증을 혼동하지 않는다.

## 완료 조건

- [x] 조회·선택·사전 검사는 계속 활성 프로필·플랫폼·프로젝트 설정을 바꾸지 않는다.
- [x] 빌드 요청만 실행 흐름을 시작하고 대상·고정 출력·실행 내용을 보여준다.
- [x] 최신 GUID·정규 제품 프로필·타깃·설정·환경을 검사하며, 복제 프로필과 차단 오류는 실행 전에 거절한다.
- [x] 공통 실행기·플랫폼 등록 처리·제품 정보가 분리된다. UI와 실행기에 플랫폼 switch를 늘리지 않는다.
- [x] 프로필 전환과 재컴파일 대기를 로컬 요청 기록으로 이어가고, 실행 중 화면 조작으로 요청 대상이 달라지지 않는다.
- [x] 같은 세션의 재로드와 에디터 재시작을 구분한다. 재시작 후 빌드 자동 재개는 하지 않는다.
- [x] 같은 요청이 빌드 API를 두 번 호출하지 않는다. 이미 호출을 시작했으나 완료 증거가 없는 요청은 재호출하거나 성공으로 간주하지 않는다.
- [x] 기존 MemoryPack·아틀라스·매뉴얼·Addressables 처리와 BuildGuard를 연결하고 중복 실행·우회를 하지 않는다.
- [x] 결과에 제품·프로필·타깃·출력·시간·상태·오류·로그가 남고 모의 결과는 실제 빌드 결과와 구분된다.
- [x] 안전한 취소 시점과 동기 빌드 중 취소 제약을 설명한다. 부분 산출물을 임의 삭제하지 않는다.
- [x] 준비·선택·실행·정리의 실패를 보고하고 소유 임시 설정을 정리한다. 복원 실패나 상태 충돌은 숨기지 않는다.
- [x] 모의 성공·실패·중복 클릭·삭제 GUID·전환 대기·재로드·재시작·취소·부분 실패 검사를 통과한다.
- [x] 1단계의 조회 무변경 검사도 계속 통과한다.
- [x] 진행 결과와 실제 빌드 미수행 범위를 기록하고 3단계 계획·목표·복사용 실행문을 제공한다. 3단계는 자동 구현하지 않는다.
- [x] 별도 승인 없는 Player/Addressables 빌드·배포·SDK 설치·HTML 매뉴얼 갱신·커밋·푸시를 하지 않는다.

## 이번 단계에 포함하지 않는 것

GPG·플러그인 옵션의 실제 적용, 옵션 전처리/후처리/복원, APK/AAB 선택, 임의 출력 변경, 자동 배포, 복수 제품 연속 빌드는 3단계 이후 실제 요구에 맞춰 정한다.

## 완료 근거

[진행 기록](../../Verification/project-wide/build-tool-stage-02-progress.md)의 최종 네 검사 로그와 요구사항 감사표를 따른다. 아래 완료 표시는 실제 백엔드 소스 연결과 허용된 모의·컴파일·재로드 검증의 완료다. 실제 제품/콘텐츠 빌드·기기·서명·스토어 검증을 완료했다는 뜻이 아니다.
