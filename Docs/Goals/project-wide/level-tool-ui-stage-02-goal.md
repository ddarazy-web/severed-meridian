# 레벨툴 UI 개선 2단계 — 목표·완료 조건

상태: 계획 수립, 구현 미착수.

[계획](../../Planning/project-wide/level-tool-ui-stage-02-plan.md) · [실행문](../../Commands/project-wide/level-tool-ui-stage-02-command.md)

- [ ] 이미지·이름·종류·검색으로 소재를 찾고 현재 층/도구/선택을 구분한다.
- [ ] 선택/배치/지우개·전체 선택·삭제가 기존 교체 및 참조 보호 규칙을 지킨다.
- [ ] 현재 층의 보드 복사/잘라내기/붙여넣기, 2×2 정규화, 새 ID, 위치 미리보기와 취소가 동작한다.
- [ ] 확정은 전체 성공 또는 무변경이며 한 번 Undo/Redo로 복구한다. 클립보드·참조·경계·충돌 실패에서 원본을 보존한다.
- [ ] 확대/이동/맞춤과 보드 명령이 입력 필드·한글 조합·모달·다른 패널에 간섭하지 않는다.
- [ ] 메뉴·키 표시·툴팁·한국어 도움말이 실제 구현과 일치한다.
- [ ] 네 해상도, 저장/재열기, 게임 시험 왕복, 선택/미저장/이력 보호에 검사 근거가 있다.
- [ ] 커밋·푸시·빌드·HTML 수정 없이 검증 로그/화면/제약을 보고하고 테스트 연결을 해제한다.
- [ ] 3단계 계획·목표·복사용 실행문과 완료된 변경의 커밋 메시지를 제공한다. 다음 단계는 자동 구현하지 않는다.
