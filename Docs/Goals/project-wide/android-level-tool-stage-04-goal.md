## 목표

Windows와 Android에서 같은 JSON 프로젝트 ZIP을 가져오고 내보내며 앱 내부 사본을 편집한다. 잘못된 전송·취소·중단에서 원본과 편집 이력을 유지하고 최근 프로젝트·미저장 초안을 다시 연다.

## 완료 조건

- [x] 정상 저장본의 프로젝트·참조 JSON만 ZIP에 포함하고 복구 기록·Undo·PC 절대 경로·임시/미공개 저장 세대는 제외한다. JSON 스키마와 ID·정의/튜토리얼 참조를 유지한다.
- [x] ZIP을 임시 내부 폴더에서 전체 형식/참조 검증 후 새 프로젝트로 등록한다. 기존 프로젝트를 병합하거나 덮어쓰지 않는다.
- [x] 경로 탈출·절대/드라이브/UNC 경로·역슬래시·중복/대소문자 충돌·링크 엔트리·누락/추가 문서·잘린 ZIP·손상 JSON/참조를 거절한다.
- [x] 압축 입력 128 MiB·전체 해제 512 MiB·10,000 엔트리·개별 JSON 16 MiB의 초기 상한을 실제 읽은 양에도 적용하고 정상 fixture/한글/Unicode와 경계 실패를 검사한다. 조정 시 근거를 기록한다.
- [x] 취소·읽기/쓰기 실패·등록 이름 충돌에서 기존 프로젝트 JSON·현재 세션·dirty·선택·Undo/Redo를 보존하고 생성한 임시 폴더만 정리한다.
- [x] Windows 시스템 파일 선택기와 Android 시스템 문서 선택기의 스트림 경계를 연결한다. `content://`를 일반 파일 경로로 변환하지 않고 seek 불가능한 스트림도 처리한다.
- [x] 지연/중복 선택기 결과·권한 오류·pause/resume 이후 결과를 안전하게 처리하고 반환 스트림·플랫폼 자원을 해제한다.
- [x] 내부 저장 완료와 ZIP 내보내기 완료를 구분한다. 전송 취소/실패 시 내부 저장본을 유지하고 외부 쓰기·flush·close 성공 전 완료를 알리지 않는다.
- [x] 성공적으로 연 내부 프로젝트의 최근 목록을 중복 없이 최신순 최대 10개 보관한다. 누락·손상 기록이 현재 프로젝트와 복구 초안을 덮지 않는다.
- [x] 기존 복구 계약으로 current/saved 문서·미완성 초안·선택·편집 층/도구·뷰·Undo/Redo를 유지한다. 프로젝트 전환 실패와 복구본 손상에서도 원본을 보호한다.
- [x] pause/focus loss에서 미확정 제스처를 취소하고 확정 작업과 입력 초안을 기록한다. 중복/역순 체크포인트를 검사하고 resume에서 살아 있는 세션을 덮지 않는다.
- [x] 뒤로가기에서 진행 중 조작·작업 메뉴/패널·파일 선택 요청을 먼저 취소하고, 종료 시 저장/버리기/취소를 제공한다. 저장 실패는 종료를 막고 편집을 유지한다.
- [x] 대표 요소·내부 연결·튜토리얼 프로젝트의 편집→Undo/Redo→내부 저장→ZIP→새 프로젝트 가져오기→재열기 결과와 공통 시험 변환을 비교한다.
- [x] Windows 기존 열기/저장·마우스/단축키·16:10과 2·3단계 모바일 패널/회전/입력/팝업/터치 취소의 관련 회귀를 통과한다.
- [x] Portable/Editor 모의 스트림 검사와 실제 UI 연결을 기록한다. 가능한 Android 스크립트 컴파일을 검사하고 임시 연결·프로필·콘텐츠 선택을 복원한다.
- [x] 실제 시스템 선택기·SAF 제공자·OS 뒤로가기·프로세스 종료·PC→Android→PC 왕복은 실행 근거 없으면 미검증으로 남긴다. OS 강제 종료 전 마지막 체크포인트 이후 손실 가능 구간을 기록한다.
- [x] 커밋·푸시·Player/APK/번들/Addressables 빌드·HTML 매뉴얼 갱신·임의 플러그인/SDK 설치 없이 진행하고 질문은 제한시간 없는 일반 채팅으로 한다.
- [x] 진행 기록에 자동 검사와 플랫폼 미검증을 구분하고 완료 후 5단계 계획·목표·복사용 실행문을 작성한다. 5단계 구현은 자동 시작하지 않는다.

## 완료 표시의 한계

사용자가 실기기·빌드를 제외한 진행을 요청해 이번 단계의 완료 판정은 구현·자동 검증 범위로 한다. 네이티브 선택기·실기기 왕복·실제 OS 중단 복구는 완료로 주장하지 않으며 출시 전 별도 확인 항목이다. Portable 401개, Editor 전송·복구 13케이스, 게임/MemoryPack 입력 비교와 관련 회귀·Android 스크립트 컴파일의 통과 근거는 진행 기록에서 확인한다.
