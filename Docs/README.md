# 구음절맥 기획 문서

이 디렉터리는 게임 기획 과정에서 합의된 내용과 검토 중인 내용을 카테고리별로 관리한다.

## 문서 구분

- [전체 기획](Planning/project-wide/README.md): 게임의 방향, 핵심 경험, 전체 진행 구조
- [콘텐츠](Contents/README.md): 세계관, 인물, 무공, 아이템, 적, 지역, 이야기
- [시스템](Systems/README.md): 레벨, 능력치, 생존, 전투, 수련, 제작 규칙
- [의사결정](Decisions/project-wide/README.md): 확정된 주요 결정과 변경 사유
- `Handover/`: 개발 단계의 인수인계 문서

## 상태 표기

- **확정**: 기획 세션에서 합의되었으며 후속 설계의 기준으로 사용한다.
- **가안**: 현재의 권장 방향이지만 추가 논의가 필요하다.
- **미정**: 선택지가 남아 있거나 아직 논의하지 않았다.
- **폐기**: 검토했으나 채택하지 않았다. 폐기 이유를 함께 기록한다.

중요한 결정은 관련 기획 문서에 반영한 뒤 `Decisions/project-wide/`에도 결정 기록을 남긴다.
