# 고물탑 화면 목업 사용 안내

- 작성일: 2026-10-03
- 상태: 확정 기획을 화면으로 확인하는 검토용 목업. Unity 게임 구현과 화면 승인 완료를 뜻하지 않는다.
- [목업 HTML](../../MoonRabbitJunkyard/Mockups/junk-tower.html) · [고물탑 기획서](../../Contents/MoonRabbitJunkyard/12_고물탑쌓기.md)

## 열기와 조작

HTML 파일을 브라우저에서 열면 된다. 이미지·폰트·스크립트를 외부에서 받지 않으며 네트워크 연결 없이 동작한다. 글꼴은 운영체제의 한글 글꼴과 숫자용 시스템 글꼴을 사용한다.

- 화면 위의 세로·가로 버튼과 세로 비율 선택으로 배치를 비교한다.
- 크레인이 움직일 때 게임 영역 또는 `고물 떨어뜨리기` 버튼을 누른다. 키보드로 버튼을 선택해 실행할 수도 있다.
- 성공하면 고정하고 명목 높이를 더한다. `별 5개로 뽑기`를 직접 눌러 다음 고물을 받는다.
- 실패하면 같은 고물로 무료 재도전한다.
- 책 모양 버튼은 도감 팝업이다. 고물 목록과 조합·보상 탭을 확인하며, 팝업을 닫거나 Esc를 누르면 돌아온다.
- 탑 모양 버튼은 전체 감상 모드다. 확대·축소, 위아래 드래그, 고물 선택으로 정보를 확인한다. `쌓기 계속`으로 돌아온다.
- 이미 발견한 고물은 인양 중 `연출 건너뛰기`를 사용할 수 있다.

## 확인용 도구

목업 주변의 도구는 실제 게임 UI에 포함하지 않는다.

| 도구 | 목적 |
| --- | --- |
| 인양 연출 보기 | 미배치 고물을 교체해 고물 더미 인양부터 쌓기 준비까지 바로 확인 |
| 도감 보기 | 도감 팝업 바로 확인 |
| 큰 고물 확인 | 냉장고로 교체해 가장 큰 고물 기준의 화면 배율과 낙하 간격 확인 |
| 별 부족 확인 | 미배치 고물이 없고 별이 부족한 화면 확인 |
| 예시 상태로 초기화 | 높이 2.04m, 쌓인 고물 6개, 별 35개의 예시 상태로 복귀 |

실제 게임에는 미배치 고물이 있으면 다음 뽑기를 막는다. 확인 도구의 강제 교체는 목업 비교용 예외다.

## 표시와 한계

- 물건 그림은 Canvas 도형으로 만든 임시 시안이다. 최종 이미지 생성이나 Unity 에셋 등록은 하지 않았다.
- 전체 폭 120cm와 낙하 간격 120cm는 비교용 수치다. 낙하 간격을 기존 시안의 3배로 늘리고 탑 꼭대기를 놀이 영역 아래쪽으로 옮겼다. 기획의 최종 수치로 확정하지 않는다.
- 가장 큰 고물의 높이를 세로 화면에서는 놀이 영역 높이의 26%, 가로 화면에서는 30% 이하로 표시한다. 각 화면 안에서는 모든 고물을 같은 배율로 줄이고 놀이 영역을 가운데 배치한다. 크레인 레일은 놀이 영역 맨 위에 고정하며 줄이 아래로 내려온다. 명목 높이와 착지 조건은 그대로다.
- 가로에서도 이동·착지 좌표는 유지한다. 공간이 부족하면 마지막 고물만 윤곽으로 표시하고, 필요하면 동일 배율로 축소한다.
- 미발견 고물 정보는 물음표로 숨긴다. 조합 이름·진척·최초 보상은 공개한다.
- 조합 완성 보상은 목업 내부에서 최초 1회 처리한다. 실제 아이템 인벤토리에 지급하지 않는다.
- 별 부족 화면의 퍼즐 이동은 안내만 표시한다. 실제 씬 전환은 하지 않는다.
- HTML을 다시 열면 예시 상태로 시작한다. 영구 저장·앱 중단 복구·실제 팝업 프레임워크 연결은 Unity 구현 범위다.
- 터치·마우스·키보드 흐름은 브라우저로 검증한다. 게임패드 및 모바일 실기기 검증은 하지 않았다.
