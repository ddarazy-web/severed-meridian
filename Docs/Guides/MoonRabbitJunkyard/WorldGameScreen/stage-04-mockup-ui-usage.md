# 4단계 게임 UI 사용 안내

상태: 4단계 구현·검증 완료 (2026-10-01). 최종 결과는 [검증 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-04-progress.md)을 확인한다.

## 시작과 다시하기

1. 레벨 에디터에서 맵을 선택한다.
2. 게임 입력을 에셋 또는 MemoryPack으로 선택하고 시드를 지정한다.
3. `게임 플레이`를 누른다. 에셋은 미저장 편집값의 사본, MemoryPack은 마지막 생성 팩을 사용한다.
4. 화면에서 이동 수와 미션 진행을 확인하며 월드 보드를 조작한다.

일시정지/결과 화면의 다시하기는 **처음 실행한 입력과 같은 시드**로 돌아간다. 원본이나 팩을 다시 읽어 다른 판으로 바꾸지 않는다. 다른 맵이나 시드로 시작하려면 Play Mode를 종료하고 에디터에서 다시 선택한다.

## 조작

| 기능 | 조작 |
| --- | --- |
| 일반 교환 | 인접한 두 칸을 누르거나 한 칸 방향으로 드래그 |
| 파워 블록 | 한 번 눌러 제자리 발동, 드래그로 교환 |
| 고물 망치 | 망치 버튼 → 제거할 칸 선택 |
| 자리 바꾸기 | 화살표 버튼 → 첫 칸 → 벽으로 막히지 않은 인접한 두 번째 칸 |
| 섞기 | 섞기 버튼을 눌러 즉시 실행 |
| 아이템 취소 | 안내 옆 `취소` 또는 선택한 아이템 버튼을 다시 누르기 |
| 미션 설명 | 미션 아이콘을 누르고 설명을 다시 눌러 닫기 |
| 일시정지 | 우측 위 버튼 → `계속하기` 또는 `처음부터 다시하기` |
| 편집으로 복귀 | Unity Play Mode 종료 |

아이템은 시험용 수량 무제한이다. 상용 재고나 보상 지급 기능은 연결하지 않았다. 일시정지 중에는 연쇄 처리도 멈춘다. 성공 결과는 라스트팡까지 끝난 뒤 표시한다. 화면 회전은 현재 판을 유지하며 선택 중인 제스처는 취소한다.

## 구성 위치

- UI: `Assets/Prefabs/UI/Puzzle/`의 PuzzleScreen, PuzzleHUD, PuzzleMission, PuzzleItemBar, PuzzlePausePopup, PuzzleResultPopup.
- 월드 보드와 세션: `Assets/Prefabs/Game/Puzzle/`.
- 게임 씬: `Assets/Scenes/PuzzleGame.unity`.
- UI 연결 생성: Unity 메뉴 `Tools > Match > 목업 UI 프리팹 연결`. Play를 종료하고 미저장 게임 씬을 확인한 뒤 사용한다. 기존 레벨 에셋/MemoryPack은 갱신하지 않는다.
- 목업 아이콘·배경은 기존 HTML에서 변환한 자료이며, 한국어 글꼴은 기존 Noto의 굵기를 고정한 MoonRabbit UI다. 기존 OFL 라이선스를 함께 유지한다.

## 검사 범위

Editor의 네 해상도와 안전 영역 모의 검사는 Android 기기 검증과 다르다. 플레이어 빌드, 실기기 터치/회전, 광고·결제·보상·다음 레벨 이동은 이번 단계의 완료 주장에 포함하지 않는다.
