# 9단계 미션 수집·진행·승패 표시 사용 안내

상태: 구현·Editor 통합 검증 및 최종 리뷰 수정 완료 (2026-10-01). [조건별 검증 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-09-progress.md)의 최신 상태를 확인한다. 빌드·실기기 검증은 수행하지 않았다.

## 실행

1. ServeredMeridian의 레벨 에디터에서 맵을 선택한다.
2. 게임 입력 소스를 `에셋` 또는 `MemoryPack`으로 선택한 뒤 `게임 플레이`를 실행한다. 에셋은 편집 데이터 사본, MemoryPack은 이미 생성된 해당 구간 데이터를 사용한다. 이 안내는 MemoryPack·Addressables 재빌드를 요청하지 않는다.
3. 게임 이미지와 데이터 준비가 끝나면 ‘정리를 시작해요!’가 0.65초 표시된다. 이때 보드 조작을 받지 않으며 시작 표시가 끝나면 기존 스와이프·파워·아이템을 사용할 수 있다.

## 화면에서 확인할 변화

- 실제 미션 진행이 증가한 제거·타격·회수에서 미션 아이콘 이미지가 해당 월드 칸에서 HUD 아이콘으로 날아간다. 한 행동의 같은 미션 증가는 묶음 한 개로 표시하며 마지막 실제 원점을 사용한다.
- 수치가 확정되는 규칙 상태와 HUD 표시 진행은 분리된다. 비행이 도착한 뒤 HUD 수치가 증가하고 아이콘이 0.15초 강조된다. 목표를 처음 넘을 때 완료 표시 `✓`가 나타난다.
- 비행은 0.32초이며 동시에 최대 8개다. 넘는 묶음은 슬롯을 기다리고 증가량을 전부 반영한다. 보드 낙하·다음 연쇄를 수집 때문에 기다리게 하지 않는다.
- 원점 또는 실제 반응 시각의 근거가 없는 변화는 비행을 만들지 않고 HUD 반응만 사용한다. 유효 피해라도 대상이 살아남아 미션 진행이 늘지 않았다면 수집하지 않는다.
- 이동 수는 실제 소비 즉시 표시·강조한다. 무효 교환에서는 줄지 않는다. ‘N 연쇄!’는 새 자동 매칭 라운드에만 표시되며 낙하 Batch를 연쇄로 세지 않는다.
- 라스트팡은 ‘남은 파워를 정리해요!’로 알린다. 최종 보드·수집·HUD 반응이 모두 끝나면 기존 승패 패널을 한 번 표시한다.

## 정지·화면 회전·다시하기

일시정지는 보드와 수집·HUD·시작·종료 표시 시간을 함께 멈춘다. 화면 회전 시 비행 위치를 현재 보드 카메라와 실제 미션 아이콘 위치로 다시 계산한다. 수집 이미지는 UI 터치를 가로채지 않는다.

다시하기는 이전 수집과 완료 강조를 초기화하고 시작 표시부터 진행한다. 재사용 이미지에는 이전 sprite 참조를 남기지 않는다. 씬 종료에서는 HUD가 소유한 이미지 객체를 파괴하고 세션이 표시 예약·아틀라스 소유권을 반환한다. 준비·표시 오류와 취소도 이전 표시가 새 세션에 이어지지 않아야 한다.

스크립트 표의 경로는 `Assets/Scripts/Features` 기준이다. 기존 일반 블록·파워·장애물·미션 이미지와 Addressables를 사용하며 새 이미지·음원·패키지는 없다. 낙하 속도·최신 드론·피해·레벨 저장 형식은 이 단계에서 바꾸지 않는다.

## 검증 진입점과 한계

`GameScreen.Editor.PuzzleProgressFeedbackVerification.Data`는 실제 미션 기록·표시 모델·중복·포화·풀 제한을 검사한다. `RunScene`은 실제 게임 씬 수집·진행·입력·수명·데이터 소스를 검사한다. 두 검사 모두 빌드를 실행하지 않는다. 검사 전 미저장 작업을 보존하고 사용자 에디터를 강제 종료하지 않는다.

실행한 로그와 검사 수는 검증 기록을 기준으로 한다. 무음 batchmode·Editor 검사 결과를 Android/iOS 실제 터치·회전·성능 검증으로 표현하지 않는다. 소리은 후속 10단계이며 현재 안내에 포함하지 않는다.
