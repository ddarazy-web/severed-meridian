# 10단계 효과음 사용 안내

상태: 효과음 연결·최종 통합 검증·리뷰 수정 완료. [최신 실행 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-10-progress.md)을 확인한다. 진동은 없다.

## 실행·활성값

ServeredMeridian 레벨 에디터에서 맵과 에셋/MemoryPack 입력을 선택하고 게임 플레이를 실행한다. 이미지·레벨 준비 후 시작 효과음이 한 번 재생된다. MemoryPack·Addressables 콘텐츠 재빌드는 이 안내의 절차에 포함하지 않는다.

`PuzzleGameSession` 컴포넌트의 `Sound Enabled`를 끄면 효과음이 중단되며 새 요청도 재생하지 않는다. 실행 중에는 `session.SoundEnabled`로 같은 설정을 바꿀 수 있다. 설정 창·영구 저장은 이번 단계에 없다. 소리 설정은 게임 규칙·난수·미션·이동 수를 바꾸지 않는다.

## 들리는 시점

- 유효 교환과 성공한 교환 아이템은 실제 교환 시작, 무효 교환은 복귀 시작에 재생한다. 차단된 입력에는 소리가 없다.
- 매칭은 실제 제거 시점, 로켓은 발사 움직임, 폭탄은 폭발, 자석은 유효 끌어당김에 맞춘다.
- 드론은 실제 돌파와 유효 타격 시각에 각각 재생한다. 상승·대기·선회에서 표적을 미리 알려주는 소리는 만들지 않는다.
- 낙하·공급은 해당 이동의 실제 종료 시각에 착지음을 묶는다.
- 미션 표시 수치가 도착으로 증가할 때 도착음을 재생한다. 같은 표시 프레임에 하나라도 목표를 완성하면 완료음만 사용한다.
- 승리·실패는 보드·수집·HUD 반응 정리 후 결과 패널 최초 표시에서 한 번 재생한다. UI 갱신마다 반복하지 않는다.

같은 종류는 0.06초 안에 한 번으로 제한한다. 최대 8개 음성을 재사용하며 밀집 시 결과·미션·파워를 착지보다 우선한다. 낮은 우선 요청은 생략할 수 있으며 소리를 기다리느라 보드 진행을 늦추지 않는다.

## 정지·반복 플레이

일시정지는 재생 중 음성의 Pause/UnPause와 표시 시간을 함께 적용한다. 앱 백그라운드는 재생·예약을 버리고, 복귀할 때 지난 소리를 다시 재생하지 않는다. 결과 패널을 아직 표시하지 않았다면 이후 최초 표시의 승패음은 정상 재생한다. 기존 게임의 앱 중단 정책 자체는 바꾸지 않는다.

다시하기·취소·오류는 이전 음성과 예약·AudioSource의 clip 참조를 정리한다. 같은 세션에서 14종 합성 클립과 8개 음성을 재사용하며 씬 종료 때 모두 파괴한다. 게임용 프리팹은 `Assets/Prefabs/Game/Puzzle/Feedback/PuzzleAudioFeedback.prefab`이고 기존 세션 프리팹이 참조한다. 리스너는 해당 프리팹에 한 개 있으므로 다른 씬에 통합할 때 중복 리스너를 만들지 않는다.

## 음원·검증 한계

현재 음원은 프로젝트 코드가 생성하는 짧고 부드러운 전자 효과음이다. 44,100Hz 모노 .08~.42초, 외부 음원·BGM·패키지는 없다. 정식 상용 음원 선정 단계와 구분한다.

무음 Editor 검사에서는 요청 시각·수·풀·PCM 형식·상태 동등성과 수명을 확인한다. 실제 음질·기기 음량·청취를 완료했다고 표현하지 않는다. 실제 청취 여부와 수행 환경은 실행 기록에 별도로 남긴다. 빌드·실기기 청취는 수행하지 않았다.
