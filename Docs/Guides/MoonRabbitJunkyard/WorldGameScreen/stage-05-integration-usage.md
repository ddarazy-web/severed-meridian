# 5단계 통합 검증 및 실행 안내

상태: 통합 검증 완료 (2026-10-01). 상세 증거는 [검증 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-05-progress.md)을 따른다.

## Editor에서 실행

1. ServeredMeridian의 레벨 에디터에서 맵과 시드를 선택한다.
2. 에셋 입력은 미저장 편집 사본을, MemoryPack 입력은 마지막 생성 팩을 사용한다. 팩은 50레벨 번호 구간으로 나뉜다.
3. `게임 플레이`로 게임 씬에 진입한다. 월드 보드와 UI 조작은 [4단계 사용법](stage-04-mockup-ui-usage.md)을 따른다.
4. 다시하기는 처음 입력과 시드를 복원한다. 다른 맵은 Play를 종료하고 선택한다. Play 종료 시 편집으로 복귀한다.

## Android 로컬 빌드

- 메뉴: `Tools > Match > Android 개발 빌드 검증`.
- Android 모듈·SDK/JDK가 준비된 Android 대상의 편집 모드에서 실행한다. 미저장 씬/레벨 또는 상용 키스토어가 선택되어 있으면 중단한다.
- 게임 씬은 `Assets/Scenes/PuzzleGame.unity` 하나로 명시한다. UI와 게임 프리팹은 각각 `Assets/Prefabs/UI/Puzzle`, `Assets/Prefabs/Game/Puzzle`에 있다.
- 출력은 `Builds/Stage05/Android/PuzzleStage05.apk`다. 기존 APK는 자동 덮어쓰지 않으므로 재검증 전 별도로 보관한다.
- 생성 아틀라스 → 50레벨 팩 → Addressables 콘텐츠를 플레이어 준비 단계에서 빌드한다. 원본 LevelDefinition의 직접/간접 포함은 차단한다.
- 보고서·해시는 `Logs/PuzzleIntegrationVerification/android-*`에 남긴다. 임시 빌드 씬/옵션은 성공·실패 모두 복원한다.
- 최종 APK는 74,181,551바이트이며 SHA256은 `3FD1435618BBA99451D24A96BB5924735A072058B9C6EA1A417A58727C005520`이다. APK와 Logs는 로컬 산출물로 Git에 포함되지 않는다.
- 메뉴는 생성 콘텐츠 등록을 유지하면서 Addressables의 원래 빌더·프로필·동시 빌드 옵션·카탈로그 경로를 성공/실패 모두 복원한다. 미저장 Addressables 설정이 있으면 저장하지 않고 거절한다.
- 빌드는 팩/아틀라스 생성 파일을 갱신할 수 있다. 기존 변경과 미저장 데이터를 먼저 확인한다. Editor 검사 중 배치 전용 종료 진입점을 직접 호출하지 않는다.
