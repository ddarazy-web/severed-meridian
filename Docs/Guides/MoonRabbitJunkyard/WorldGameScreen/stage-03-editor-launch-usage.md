# 레벨 에디터에서 게임 실행

상태: 구현·검증 완료. [3단계 검사 기록](../../../Verification/MoonRabbitJunkyard/WorldGameScreen/stage-03-progress.md)

## 실행

1. `Match → 레벨 에디터`에서 실행할 레벨을 선택한다.
2. 편집 탭의 `게임 입력`과 `게임 시드`를 정한다. 기본값은 에셋 / 12345다.
3. `게임 플레이`를 누른다. Unity Play Mode의 `PuzzleGame` 씬이 해당 데이터의 독립 사본으로 실행된다.
4. 게임 화면에서 두 블록 선택 또는 드래그로 교환한다. 파워 블록은 선택하여 발동한다.
5. Unity의 Play 버튼으로 실행을 종료하면 원래 편집 씬과 레벨 편집창으로 돌아온다.

기존 `플레이 테스트`는 편집창 안에서 규칙을 시험하는 기능이며 그대로 사용할 수 있다.

## 입력 차이

| 게임 입력 | 실행에 사용되는 값 | 갱신 |
| --- | --- | --- |
| 에셋 | 현재 선택 레벨의 메모리 편집값. 미저장 값 포함 | 실행 클릭 시 사본 생성. 원본 자동 저장 없음 |
| MemoryPack | 선택 레벨 번호가 담긴 마지막 생성 팩 파일 | 기존 플레이 테스트의 `MemoryPack 갱신`으로 명시적으로 갱신 |

클릭 시점에 번호·시드·입력 데이터가 고정된다. 실행 후 원본을 변경해도 이미 요청한 게임에는 반영되지 않는다. 시작 보드 탐색에 따라 배치가 재구성될 수 있다.

## 오류와 제한

- 레벨을 선택하지 않았거나 컴파일/Play 전환/게임 실행 중이면 실행 버튼이 비활성화된다.
- 팩이 없거나 손상됐거나 해당 번호가 없으면 편집창 안내에 실패 이유가 표시된다. 에셋이나 다른 레벨로 대체하지 않는다.
- MemoryPack에 최근 편집이 없다면 에셋 입력으로 실행하거나, 원본을 원하는 상태로 저장하고 기존 갱신 기능으로 팩을 다시 만든다.
- Play 진입 저장 확인을 취소하면 게임을 시작하지 않는다. 편집 씬과 기존 시작 씬 설정을 보존한다.
- 게임 씬을 직접 Play하면 기존 기본 MemoryPack 레벨 1 / 시드 12345 경로로 실행한다.
- 이번 단계는 에디터와 월드 게임 화면의 연결까지다. 목업 HUD·아이템·일시정지·다시하기·상세 애니메이션은 후속 단계다.
